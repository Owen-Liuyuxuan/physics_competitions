## 1. 复赛第1题 · 半球面内侧小滑块运动的最大速率 (`cpho-2013-semifinal-theory-problem-slice-q1`)

- **难度评级**：`D2`
- **核心物理模型**：三维光滑半球面内的质点受约束运动（机械能守恒 + 竖直对称轴角动量守恒）
- **教学标签**：`机械能守恒`、`对称轴角动量守恒`、`三维球面约束运动`、`接触脱离与最高点判据`、`二次方程消元技巧`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **物理建模与守恒律**：
   设滑块质量为 \(m\)，以半球面球心 \(O\) 为原点，竖直向上为 \(z\) 轴（取 \(z = 0\) 处即半球面最高点水平面为重力势能零点）。初始时刻滑块位于半球面内侧最高点（赤道面 \(z = 0\)，距 \(z\) 轴水平半径 \(\rho_0 = R\)），具有纯水平切向速度 \(v_0\)（\(v_0 \ne 0\)）。
   滑块沿光滑半球面内侧运动时，只受重力 \(m\vec{g} = -mg\hat{z}\) 与球面支持力 \(\vec{N}\)（沿径向指向球心 \(O\)）：
   - **机械能守恒**：支持力 \(\vec{N}\) 始终与速度垂直不做功，故任意时刻有
     \[
     \frac{1}{2} m v^2 + m g z = \frac{1}{2} m v_0^2 \implies v^2 = v_0^2 - 2gz
     \]
   - **竖直对称轴角动量守恒**：重力平行于 \(z\) 轴，支持力 \(\vec{N}\) 过原点 \(O\)（力臂与 \(z\) 轴相交），故外力对 \(z\) 轴的合力矩恒为零。设滑块位置球心连线与水平面向下夹角为 \(\theta\)（即 \(z = -R\sin\theta\)，离 \(z\) 轴距离 \(\rho = R\cos\theta\)），将速度分解为纬线水平切向分量 \(v_\varphi\) 与经线切向分量 \(v_\theta\)，由 \(L_z\) 守恒得
     \[
     m R v_0 = m (R\cos\theta) v_\varphi \implies v_\varphi = \frac{v_0}{\cos\theta}
     \]

2. **接触条件与边界检验（严密性自检）**：
   先检验滑块在下半球面（\(z \le 0\)，即 \(0 \le \theta \le \pi/2\)）内运动时是否会脱离球面。沿指向球心 \(O\) 方向列径向牛顿第二定律：
   \[
   N - m g \sin\theta = \frac{m v^2}{R} \implies N = m g \sin\theta + \frac{m(v_0^2 + 2gR\sin\theta)}{R} = \frac{m v_0^2}{R} + 3 m g \sin\theta
   \]
   由于 \(v_0 \ne 0\) 且在下半球内 \(\sin\theta \ge 0\)，恒有 \(N > 0\)，故滑块永不脱离下半球面。又在初始高度 \(z = 0\)（\(\theta = 0\)）处，\(v_\theta = 0\)，而初始时刻支持力水平向内、重力竖直向下，故 \(\ddot{z}(0) = -g < 0\)，滑块向下进入球内，到达最低点后反弹回到 \(z = 0\) 时再次满足 \(v_\theta = 0\) 且 \(\ddot{z} = -g < 0\)，因此滑块不会冲出球面边缘（始终满足 \(0 \le \theta \le \theta_{\max} < \pi/2\)）。

3. **求解最大速率 \(v_{\max}\)**：
   由 \(v^2 = v_0^2 + 2gR\sin\theta\) 可知，速率最大值必然出现在最低点（\(\theta = \theta_{\max}\)），即下落深度 \(h = R\sin\theta_{\max} > 0\) 处。在最低点处，竖直与经线方向速度分量均瞬间为零（\(v_\theta = 0\)），合速度纯粹为水平纬向速度 \(v_{\max} = v_\varphi(\theta_{\max})\)。
   联立最低点处的两个守恒关系（记 \(\rho_{\min} = \sqrt{R^2 - h^2}\)）：
   \[
   v_{\max}^2 = v_0^2 + 2gh, \qquad v_{\max} \sqrt{R^2 - h^2} = R v_0
   \]
   **消元捷径**：由第二式得 \(h^2 = R^2\left(1 - \frac{v_0^2}{v_{\max}^2}\right) = R^2 \frac{v_{\max}^2 - v_0^2}{v_{\max}^2}\)；由第一式得 \(h = \frac{v_{\max}^2 - v_0^2}{2g} > 0\)（因 \(v_0 \ne 0\) 且由 \(\ddot{z}(0) = -g\) 知滑块必下沉，故 \(h > 0\)）。两式消去 \(h\)：
   \[
   \frac{(v_{\max}^2 - v_0^2)^2}{4 g^2} = R^2 \frac{v_{\max}^2 - v_0^2}{v_{\max}^2}
   \]
   因 \(v_{\max}^2 - v_0^2 = 2gh > 0\)，两边约去正因子 \((v_{\max}^2 - v_0^2)\)，直接得到关于 \(v_{\max}^2\) 的一元二次方程：
   \[
   v_{\max}^4 - v_0^2 v_{\max}^2 - 4 g^2 R^2 = 0
   \]
   取正根得：
   \[
   v_{\max}^2 = \frac{v_0^2 + \sqrt{v_0^4 + 16 g^2 R^2}}{2} \implies v_{\max} = \sqrt{\frac{v_0^2 + \sqrt{v_0^4 + 16 g^2 R^2}}{2}}
   \]

4. **量纲与极限自检**：
   - 量纲：\([v_0^2] = \text{m}^2/\text{s}^2\)，\([gR] = \text{m}^2/\text{s}^2\)，开方为 \(\text{m/s}\)。
   - \(v_0 \to 0^+\) 极限：\(v_{\max} \to \sqrt{2gR}\)（趋近沿子午线滑落至球底）。
   - \(v_0 \gg \sqrt{gR}\) 极限：\(v_{\max}^2 \approx v_0^2 + \frac{4g^2 R^2}{v_0^2}\)，对应平衡倾角 \(\alpha_{\text{eq}} \approx \frac{gR}{v_0^2}\) 的两倍最大下沉角 \(\alpha_{\max} \approx \frac{2gR}{v_0^2}\)，\(h \approx \frac{2gR^2}{v_0^2}\)，物理自洽。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解结果与官方参考解答完全一致，最终表达式同为 \(v_{\max} = \sqrt{\frac{1}{2}\left(v_0^2 + \sqrt{v_0^4 + 16g^2 R^2}\right)}\)。官方解答先联立消去速度求 \(\sin\theta_{\max}\)（解二次方程 \(2gR\sin^2\theta_{\max} + v_0^2\sin\theta_{\max} - 2gR = 0\) 并在舍去 \(\sin\theta = 0\) 与负根后再回代求 \(v_\varphi^2\)）；而我们的盲解直接消去深度 \(h\) 建立关于 \(v_{\max}^2\) 的二次方程 \(v_{\max}^4 - v_0^2 v_{\max}^2 - 4g^2 R^2 = 0\)，步骤更短。此外，盲解补全了支持力 \(N = \frac{mv_0^2}{R} + 3mg\sin\theta > 0\)（永不脱离下半球）与初态 \(\ddot{z}(0) = -g < 0\)（不会冲出球口）的严格论证，而官方解答略去了这两项存在性验证。
- **核心难点**：
  - 难点1：识别三维半球面内运动的双守恒律（机械能守恒与过球心竖直轴的角动量守恒），并理解因 \(v_0 \ne 0\) 滑块无法到达球底（\(L_z \ne 0\) 形成离心势垒）。
  - 难点2：正确判断最大速率对应最低点 \(\theta_{\max}\)（经线分速度 \(v_\theta = 0\)），同时排除滑块脱离球面或越过边缘飞出的可能性。
- **高频易错点**：
  - 易错点1：误以为滑块能落到半球最低点（球底），错答 \(v_{\max} = \sqrt{v_0^2 + 2gR}\)，完全忽略了角动量守恒对最低位置的限制。
  - 易错点2：将半球面上任意位置的速度简单写为只有水平分量或漏掉 \(v_\theta\)，虽然在最低点处 \(v_\theta = 0\)，但若不说明为什么最低点速率最大且此时 \(v_\theta = 0\)，逻辑链条不完整。
  - 易错点3：在消元求解 \(\sin\theta_{\max}\) 或 \(v_{\max}^2\) 时未舍去增根（如 \(\theta = 0\) 初态对应最小速率 \(v_0\)，或负根）。
- **教练总结**：处理光滑轴对称曲面上的质点运动，标准套路是『能量守恒 + 对称轴角动量守恒 + 极值转折点 \(v_\theta = 0\)』三板斧；此外，用待求量 \(v_{\max}^2\) 直接消去几何参数 \(h\)（即设而不求 \(h\)），往往能避开复杂根式的回代化简，考场上既省时又不易算错。

## 2. 复赛第2题 · 轻杆-滑环-弹簧系统的弹性碰撞与转轴冲量 (`cpho-2013-semifinal-theory-problem-slice-q2`)

- **难度评级**：`D3`
- **核心物理模型**：刚体定轴瞬时碰撞（角动量守恒 + 机械能守恒）与质心/系统动量定理求约束冲量
- **教学标签**：`瞬时碰撞近似`、`定轴角动量守恒`、`完全弹性碰撞恢复系数`、`打击中心与铰链反冲`、`匀速圆周运动条件`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第 1 问：碰撞瞬时动力学与转轴冲量**：
   以转轴（小物块 B 所在端）为原点，碰前瞬间杆沿 \(+x\) 轴，滑块 A 的速度 \(\vec{v}_0\) 沿 \(+y\) 轴。
   - **碰撞时间极短近似**：弹簧弹力 \(k(r-l)\) 与向心力均属有限力，在 \(\Delta t \to 0\) 内冲量为零，故碰撞瞬间环 C 来不及沿杆滑移（仍处于距轴 \(r\) 处且径向速度 \(\dot{r} = 0\)），沿 \(x\) 方向系统不获得速度，转轴与杆之间的冲量纯沿 \(y\) 方向。因小环 C 与杆密接，杆获得角速度 \(\omega\) 时，环 C 同步获得切向速度 \(v_C = r\omega\)，物块 D 获得速度 \(v_D = 2l\omega\)。小物块 B 固定在固定转轴上，速度恒为零，故其动量与角动量变化均为零（质量参数 \(\alpha m\) 不参与瞬时碰撞方程）。
   - **角动量守恒（对固定转轴 B）**：整个系统 A+B+C+D+杆 在碰撞期间只受转轴的外力，外力对转轴力矩为零，故对转轴角动量守恒：
     \[
     m v_0 (2l) = m v_A (2l) + m v_D (2l) + m v_C r
     \]
     利用 \(v_D = 2l\omega, v_C = r\omega\)（或 \(v_D = \frac{2l}{r}v_C\)），上式化为：
     \[
     2l(v_0 - v_A) = (4l^2 + r^2)\omega
     \]
   - **完全弹性正碰（机械能守恒 / 恢复系数 \(e=1\)）**：弹簧形变来不及改变，所有内部约束（轻杆与光滑环）均为理想无功约束，故系统动能守恒：
     \[
     \frac{1}{2} m v_0^2 = \frac{1}{2} m v_A^2 + \frac{1}{2} m v_D^2 + \frac{1}{2} m v_C^2 \implies v_0^2 - v_A^2 = (4l^2 + r^2)\omega^2
     \]
     两式相除直接给出接触点弹性碰撞速度关系 \(v_0 + v_A = 2l\omega = v_D\)。代入角动量守恒方程：
     \[
     2l\left(v_0 - (2l\omega - v_0)\right) = (4l^2 + r^2)\omega \implies 4l v_0 = (8l^2 + r^2)\omega
     \]
     解得碰后各部分运动状态（以 \(\vec{v}_0\) 为正方向）：
     \[
     \omega = \frac{4l v_0}{8l^2 + r^2}, \quad v_D = \frac{8l^2 v_0}{8l^2 + r^2}, \quad v_C = \frac{4lr v_0}{8l^2 + r^2}, \quad v_A = -\frac{r^2 v_0}{8l^2 + r^2}
     \]
   - **整体动量定理求轴受到的冲量**：取 A+B+C+D+杆 为系统，水平面内唯一外力冲量来自固定转轴对杆的作用力冲量 \(I_{\text{轴}\to\text{系}}\)（沿 \(+y\) 方向）：
     \[
     I_{\text{轴}\to\text{系}} = m v_A + m v_D + m v_C - m v_0 = m v_0 \frac{-r^2 + 8l^2 + 4lr - (8l^2 + r^2)}{8l^2 + r^2} = \frac{2 m r (2l - r)}{8l^2 + r^2} v_0
     \]
     注意因环 C 在杆上（\(l < r \le 2l\)，一般 \(r < 2l\)），\(2l - r \ge 0\)，故轴对系统的冲量与 \(\vec{v}_0\) 同向。由牛顿第三定律，**轴受到的作用力冲量** \(\vec{I}_{\text{杆}\to\text{轴}} = -\vec{I}_{\text{轴}\to\text{系}}\)，其大小为：
     \[
     I = \frac{2 m r (2l - r)}{8l^2 + r^2} v_0
     \]
     方向**与碰前滑块 A 的初速度 \(\vec{v}_0\) 方向相反**。（物理解释：C、D 系统的打击中心距 B 为 \(l_p = \frac{4l^2 + r^2}{2l + r} < 2l\)，撞击点 D 在打击中心外侧，自由杆底端 B 将向 \(-y\) 后踢，故转轴需向前拉住 B，反过来杆给转轴向后的冲量；且当 \(r=2l\) 或 \(r=0\) 时撞击点恰好在打击中心上，轴冲量为零！）

2. **第 2 问：碰后做匀速转动的条件**：
   碰后滑块 A 向后反弹脱离半径 \(2l\) 的圆周外，不再二次碰撞。若碰后 D、C 和杆刚好做匀速转动，则环 C 沿杆保持半径 \(r\) 不变（\(\dot{r} = 0\) 且 \(\ddot{r} = 0\)），因而系统转动惯量不变、角速度 \(\omega\) 保持恒定。由于 \(r > l\)，伸长的弹簧给 C 提供指向转轴的弹力 \(k(r - l)\)，该弹力恰好充当 C 做半径为 \(r\)、线速度为 \(v_C\) 的匀速圆周运动所需的向心力：
   \[
   k(r - l) = m \frac{v_C^2}{r} = m r \omega^2 = m r \left(\frac{4 l v_0}{8l^2 + r^2}\right)^2
   \]
   解出碰前速度 \(v_0\)：
   \[
   v_0 = \frac{8l^2 + r^2}{4l} \sqrt{\frac{k(r - l)}{m r}}
   \]
   （稳定性自检：记碰撞后角动量 \(L = m(4l^2 + r^2)\omega\)，径向有效势 \(V_{\text{eff}}(r') = \frac{1}{2}k(r'-l)^2 + \frac{L^2}{2m(4l^2+r'^2)}\) 在 \(r'=r\) 处二阶导恒正，圆周运动稳定。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答所有表达式、大小及方向均完全一致。值得重点对比的是：题干故意给出了固定在转轴端 B 的小物块质量 \(\alpha m\)。官方解答第（7）–（9）式先算 B、C、D 三者的质心位置 \(x = \frac{2l+r}{\alpha+2}\) 与质心速度 \(v = \frac{v_C}{r}x\)，再乘以总质量 \((\alpha+2)m\) 才消去 \(\alpha+2\)；而在文末方括号给出了与我们盲解完全一致的捷径（直接对系统用动量定理，无需计算质心与 \(\alpha\)）。显然，\(\alpha m\) 位于固定转轴处，速度始终为零，是检验学生是否盲目代入参数的高级『干扰条件』。
- **核心难点**：
  - 难点1：识别『撞击瞬间 \(\Delta t \to 0\)』下，有限力（弹簧弹力、向心力）冲量为零、但『刚性约束反力』（杆与密接环 C 之间的切向约束力）具有无限大瞬时冲量，使 C 瞬间获得与杆同步的切向速度 \(v_C = r\omega\)。
  - 难点2：区分『轴对杆/系统的冲量』与『轴受到的作用力冲量』，准确应用牛顿第三定律确定方向（与 \(\vec{v}_0\) 相反）。
- **高频易错点**：
  - 易错点1：被参数 \(\alpha m\) 迷惑，将转轴处物块 B 算入转动惯量或错误认为 B 有速度，导致白费功夫甚至算错。
  - 易错点2：碰撞中误把小环 C 当成『光滑套在杆上故碰撞瞬间不动（\(v_C = 0\)）』，忽略了环沿杆方向自由而**垂直杆方向受杆严格约束**（切向必随杆共转）。
  - 易错点3：第 1 问方向答反（直接把轴对系统冲量当成轴受到的冲量），或误以为 \(r > l\) 对应弹簧推力而非拉力，导致第 2 问方向或条件出错。
- **教练总结**：瞬时碰撞问题要先画『约束分类表』：沿自由方向（环沿杆）无冲量，沿约束方向（环垂直杆、固定转轴、刚性杆轴向）可产生瞬时冲量。此外，用『大系统（包含入射球 A）整体动量定理』求固定支座反冲量，比拆解内力后再算多体质心要快得多且极易用『打击中心 \(r = 2l\) 时轴冲量为零』进行检验。

## 3. 复赛第3题 · 量纲与柯尼希定理求匀质杆转动动能及下摆杆内截面内力 (`cpho-2013-semifinal-theory-problem-slice-q3`)

- **难度评级**：`D3`
- **核心物理模型**：量纲分析、柯尼希定理结合自相似尺度缩放（无积分求转动惯量）、定轴摆动刚体截面剪力与拉力
- **教学标签**：`量纲分析`、`柯尼希定理`、`自相似分割法`、`刚体动力学`、`截面剪力与张力`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第 1 问：量纲分析求指数 \(\alpha, \beta, \gamma\)**：
   由 \(E_k = k \lambda^\alpha \omega^\beta L^\gamma\)，其中 \(k\) 无量纲。取质量 \([M]\)、长度 \([L]\)、时间 \([T]\) 为基本量纲：
   \[
   [E_k] = [M][L]^2[T]^{-2}, \quad [\lambda] = [M][L]^{-1}, \quad [\omega] = [T]^{-1}, \quad [L] = [L]
   \]
   由物理方程量纲齐次性（在同一单位制下数值和单位都相等）：
   \[
   [M]^1 [L]^2 [T]^{-2} = [M]^\alpha [L]^{\gamma - \alpha} [T]^{-\beta}
   \]
   比较指数得 \(\alpha = 1\)，\(-\beta = -2 \implies \beta = 2\)，\(\gamma - \alpha = 2 \implies \gamma = 3\)。故
   \[
   E_k = k \lambda \omega^2 L^3 = k m \omega^2 L^2
   \]

2. **第 2 问：用柯尼希定理与自相似拆分法求常数 \(k\)（无积分）**：
   绕一端以角速度 \(\omega\) 转动的长为 \(L\) 的匀质细杆，其总动能为 \(E_k(\lambda, \omega, L) = k \lambda \omega^2 L^3\)。
   由题意（柯尼希定理），总动能等于质心平动动能与质心系中的动能之和：
   \[
   E_k(\lambda, \omega, L) = E_{k,\text{cm}} + E_{k,\text{rel}}
   \]
   - 质心速度 \(v_{\text{cm}} = \omega \frac{L}{2}\)，总质量 \(m = \lambda L\)，故质心平动动能为：
     \[
     E_{k,\text{cm}} = \frac{1}{2} (\lambda L) \left(\frac{L}{2}\omega\right)^2 = \frac{1}{8} \lambda \omega^2 L^3
     \]
   - 在随质心平动的参考系（质心系）中，杆以角速度 \(\omega\) 绕其中点转动，相当于**两根长度各为 \(L/2\)、线密度同为 \(\lambda\) 的细杆**分别绕各自一端（公共质心）以角速度 \(\omega\) 转动，因此：
     \[
     E_{k,\text{rel}} = 2 E_k\left(\lambda, \omega, \frac{L}{2}\right) = 2 k \lambda \omega^2 \left(\frac{L}{2}\right)^3 = \frac{1}{4} k \lambda \omega^2 L^3
     \]
   代入柯尼希定理：
   \[
   k \lambda \omega^2 L^3 = \frac{1}{8}\lambda \omega^2 L^3 + \frac{1}{4} k \lambda \omega^2 L^3 \implies \frac{3}{4} k = \frac{1}{8} \implies k = \frac{1}{6}
   \]
   从而 \(E_k = \frac{1}{6}\lambda \omega^2 L^3 = \frac{1}{6} m L^2 \omega^2\)（等价于 \(I_O = \frac{1}{3}mL^2\)）。

3. **第 3 问：下摆至与水平成 \(\theta\) 角时距 \(O\) 点 \(r\) 处截面内力**：
   由机械能守恒（杆从水平 \(\theta = 0\) 静止下摆，\(\theta\) 为向下转过的角度）：
   \[
   \frac{1}{6} m L^2 \omega^2 = m g \frac{L}{2} \sin\theta \implies \omega^2 = \frac{3g}{L}\sin\theta
   \]
   利用题给复合函数求导提示对时间 \(t\) 求导（\(\omega = \frac{\mathrm{d}\theta}{\mathrm{d}t}\)，\(\dot{\omega} = \frac{\mathrm{d}\omega}{\mathrm{d}t}\)）：
   \[
   2\omega\dot{\omega} = \frac{3g}{L}\cos\theta \cdot \omega \implies \dot{\omega} = \frac{3g}{2L}\cos\theta
   \]
   （当 \(\omega = 0\) 即 \(\theta = 0\) 时，由转动定律同样满足 \(\dot{\omega} = \frac{3g}{2L}\)。）
   取距 \(O\) 点 \(r\) 到末端 \(L\) 的外侧一段（长度 \(L - r\)，质量 \(m_{\text{外}} = \frac{m}{L}(L - r)\)）为隔离体，其质心到 \(O\) 点的距离为 \(r_c = \frac{L + r}{2}\)。建立随杆旋转的单位正交基：\(\hat{e}_r\) 沿杆背离 \(O\) 点向外，\(\hat{e}_\theta\) 沿 \(\theta\) 增大（下摆切向）方向。
   该段质心的加速度分量为：
   \[
   a_r = -\omega^2 r_c = -\frac{3(L+r)}{2L}g\sin\theta, \qquad a_\theta = \dot{\omega} r_c = \frac{3(L+r)}{4L}g\cos\theta
   \]
   设内侧段（\([0, r]\)）对外侧段（\([r, L]\)）的作用力沿 \(\hat{e}_r\) 与 \(\hat{e}_\theta\) 的分量为 \(F_r\) 与 \(F_\theta\)（习惯上记沿轴向拉向 \(O\) 点的拉力为 \(N = -F_r\)，切向沿 \(\hat{e}_\theta\) 剪力为 \(T = F_\theta\)）。重力在外侧段上的分量为 \(m_{\text{外}}g\sin\theta\,\hat{e}_r + m_{\text{外}}g\cos\theta\,\hat{e}_\theta\)。由质心运动定理：
   - 法向（沿杆方向，指向 \(O\) 为正）：
     \[
     N - m_{\text{外}} g \sin\theta = m_{\text{外}} \omega^2 r_c \implies N = \frac{m}{L}(L - r) g \sin\theta \left[1 + \frac{3(L+r)}{2L}\right] = \frac{m g (L - r)(5L + 3r)}{2 L^2} \sin\theta
     \]
   - 切向（垂直杆方向，沿 \(\theta\) 增大方向为正）：
     \[
     T + m_{\text{外}} g \cos\theta = m_{\text{外}} \dot{\omega} r_c \implies T = \frac{m}{L}(L - r) g \cos\theta \left[\frac{3(L+r)}{4L} - 1\right] = \frac{m g (L - r)(3r - L)}{4 L^2} \cos\theta
     \]
   截面两侧相互作用力大小为 \(F = \sqrt{N^2 + T^2} = \frac{mg(L-r)}{4L^2}\sqrt{4(5L+3r)^2\sin^2\theta + (3r-L)^2\cos^2\theta}\)。内侧段对外侧段的拉力指向 \(O\) 点（因 \(N \ge 0\)），切向力在 \(r > L/3\) 且 \(\cos\theta > 0\) 时沿下摆方向、在 \(r < L/3\) 时沿反向；外侧段对内侧段的作用力等大反向。

4. **边界自检**：
   - \(r = L\)（自由端）：\(N = 0, T = 0\)。
   - \(r = 0, \theta = \pi/2\)（最低点轴处拉力）：\(N = \frac{5}{2} mg\)（经典值）。
   - \(r = 0, \theta = 0\)（水平刚释放瞬间轴处切向力）：\(T = -\frac{1}{4}mg\)（轴向上托住 \(\frac{1}{4}mg\)，质心加速度 \(\frac{3}{4}g\)）。
   - \(r = L/3\) 处剪力 \(T \equiv 0\)（因 \([L/3, L]\) 段平均切向加速度恰好等于 \(g\cos\theta\)）。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解三问的思路与结果同官方参考解答高度吻合，包括第 2 问不用微积分的『半杆自相似拆分 + 柯尼希定理』巧解（\(k = 1/6\)），以及第 3 问 \(T\) 和 \(N\) 的精确表达式。官方解答仅在最终呈现时分开写了 \(T\) 和 \(N\)，未再合并平方根求合内力大小 \(F\)，并特别在评分标准中注明第 2、3 问不依赖前面方法也可独立得分。
- **核心难点**：
  - 难点1：第 2 问在没有定积分工具的情况下，构造『将绕质心转动的长 \(L\) 杆拆成两根绕端点转动的长 \(L/2\) 杆』的几何自相似图像。
  - 难点2：第 3 问用复合函数链式求导从机械能表达式反推角加速度（实际上相当于推导刚体转动定律），并选取『外侧游离段 \([r, L]\)』而非『内侧含转轴段 \([0, r]\)』作隔离体以避开未知的转轴约束力。
- **高频易错点**：
  - 易错点1：第 3 问错误地选取 \([0, r]\) 段作受力分析，或忘记截面内力既有法向拉力 \(N\) 也有切向剪力 \(T\)（许多学生仅算了拉力 \(N\)）。
  - 易错点2：将外侧段质心距离 \(r_c\) 误写成 \(\frac{L-r}{2}\)（到截面距离），而忘记绕 \(O\) 点做圆周运动的半径必须从 \(O\) 点量起，即 \(r_c = r + \frac{L-r}{2} = \frac{L+r}{2}\)。
  - 易错点3：切向加速度 \(a_\theta = \dot{\omega} r_c\) 误用 \(\dot{\omega} = \frac{g\cos\theta}{L}\) 代替，或正负号定义混乱（例如 \(r < L/3\) 时 \(T < 0\) 表示切向剪力与下摆方向相反）。
- **教练总结**：刚体截面内力问题的黄金法则是『**永远隔离不含支座的那一端（自由端）**』，且切忌只列法向方程——只要杆存在角加速度 \(\dot{\omega}\)，截面必然存在剪力 \(T\)，并在 \(r = L/3\) 处发生剪力变号（弯矩极值点）。

## 4. 复赛第4题 · 滴水静电起电机（开口金属球壳）的最高电势 (`cpho-2013-semifinal-theory-problem-slice-q4`)

- **难度评级**：`D2`
- **核心物理模型**：孤立带电球壳外场电势分布、法拉第冰桶静电感应与连续极限下的能量守恒临界条件
- **教学标签**：`孤立球壳电势`、`法拉第冰桶效应`、`重力与静电势能转化`、`全程动能正定性校验`、`极端高度极限检验`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **物理图像与模型分析**：
   半径为 \(R\) 的金属球壳容器置于地面上且与环境绝缘，球心离地高度为 \(R\)，顶部开口离地高度为 \(2R\)。液滴从高 \(h\) 处的产生器 G 释放（\(h > 2R\)），因此 G 到球心的距离为 \(r_0 = h - R\)。
   由于每次在 G 与容器口之间仅有一滴液滴且忽略 G 本身电荷的影响，又题中未给出静电力常量 \(k\)，表明单个液滴电量 \(q\) 远小于容器电量 \(Q\)（忽略液滴在金属球壳上引发的自身镜像吸引力 \(\sim kq^2/R\)），可将液滴视为在球壳静电场中下落的试探点电荷。
   设某一时刻容器已带电量为 \(Q\)，对应电势为 \(V = \frac{k Q}{R}\)。则球壳外部距球心 \(r \ge R\) 处的电势为 \(\varphi(r) = \frac{k Q}{r} = \frac{R}{r} V\)；特别地，释放点 G 处的电势并非零，而是：
   \[
   \varphi_G = \varphi(h - R) = \frac{R}{h - R} V
   \]
   液滴进入球壳顶部开口（\(r = R\)，高度 \(2R\)）后，进入空腔内部（法拉第冰桶），内壁场强为零，在重力作用下落到底部并把电荷全部转移给容器。

2. **能量守恒与能否到达容器口的全程校验**：
   液滴从 G（\(r_0 = h - R\)）下落至球壳顶部外侧任意位置 \(r \in [R, h - R]\) 时，由机械能与电势能之和守恒（设到达 \(r\) 处动能为 \(E_k(r)\)）：
   \[
   E_k(r) = m g (r_0 - r) - q\left[\varphi(r) - \varphi(r_0)\right] = m g (r_0 - r) - q V R \left(\frac{1}{r} - \frac{1}{r_0}\right)
   \]
   因式分解提出 \((r_0 - r)\)：
   \[
   E_k(r) = (r_0 - r)\left[ m g - \frac{q V R}{r r_0} \right]
   \]
   观察括号内的单调性：随着液滴下落 \(r\) 减小，\(\frac{q V R}{r r_0}\) 严格增大，故最小值出现在 \(r = R\)（即容器口处）：
   \[
   E_k(R) = (h - 2R)\left[ m g - \frac{q V}{h - R} \right]
   \]
   令 \(E_k(R) = 0\) 得临界最高电势：
   \[
   m g - \frac{q V_{\max}}{h - R} = 0 \implies V_{\max} = \frac{m g (h - R)}{q}
   \]
   **严谨自检**：当 \(V < V_{\max}\) 时，对于所有 \(r \in (R, h - R)\)，均有 \(\frac{q V R}{r r_0} < \frac{q V_{\max}}{r_0} = m g\)，所以 \(E_k(r) > 0\) 在全程严格成立——即液滴在半空中先向下加速（引力大于斥力）、经过平衡点 \(r_* = \sqrt{\frac{q V R}{mg}}\) 后减速（斥力大于引力），但动能直到 \(r = R\) 处才可能降为零，绝不会中途提前折返！

3. **极端情况检验**：
   当 G 非常贴近容器口（\(h \to 2R^+\)）时，\(V_{\max} \to \frac{m g R}{q}\)，恰好等价于液滴在容器口处所受重力与球壳表面电场力平衡：\(m g = q E_{\text{surf}} = q \frac{V_{\max}}{R}\)。量纲 \([mgh/q] = \text{J/C} = \text{V}\)，完全正确。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答完全一致，结果均为 \(V_{\max} = \frac{mg(h-R)}{q}\)。官方解答由 \(mgh + \frac{kQq}{h-R} = \frac{1}{2}mv^2 + 2mgR + \frac{kQq}{R}\) 解出 \(Q_{\max} = \frac{mg(h-R)R}{kq}\) 再乘以 \(\frac{k}{R}\) 得到 \(V_{\max}\)；而我们的盲解直接用 \(V\) 表示外部电势 \(\varphi(r) = \frac{R}{r}V\)，不仅完全消除了未给出的常量 \(k\)，还顺带因子分解证明了液滴在整个下落区间 \((R, h-R)\) 内动能恒为正、不会中途提前停下。
- **核心难点**：
  - 难点1：认清滴液器 G 处于带电球壳的静电场中，其初态电势 \(\varphi_G = \frac{R}{h-R}V \ne 0\)。
  - 难点2：正确确定两个关键几何距离——高度差是 \(h - 2R\)（球底在地面、球口在高 \(2R\) 处），而球对称静电势的距离起点在球心（离地高 \(R\)），故 G 到球心为 \(h - R\)，口到球心为 \(R\)。
- **高频易错点**：
  - 易错点1：把 G 处电势误当成零（以为“远方是零电势”），列出 \(mg(h - 2R) = q V_{\max}\)，得到错误答案 \(V_{\max} = \frac{mg(h-2R)}{q}\)（其在 \(h \to 2R\) 时趋于零，明显违背静电场平衡极限）。
  - 易错点2：把球心误当成位于地面上（或把 G 到球壳顶部距离当成到球心距离），混淆 \(h\)、\(h-R\) 与 \(h-2R\)。
  - 易错点3：只根据初态受力 \(mg > qE(h-R)\) 判定下落条件（得错解 \(V = \frac{mg(h-R)^2}{qR}\)），忽略了越靠近球壳斥力越强、液滴需要克服球口前方的势垒。
- **教练总结**：本题是『能量守恒中因子分解约去 \((h-2R)\)』的绝妙范例：约去的公因式 \((h-2R)\) 直接把 \(h \to 2R\) 时的势差除以位移化为表面场强极限，考场上如能养成用 \(h \to 2R^+\) 验证结果的习惯，就能一眼秒杀漏掉 \(\varphi_G\) 的错误答案。

## 5. 复赛第5题 · 伽利略电磁变换与运动电介质极化电场 (`cpho-2013-semifinal-theory-problem-slice-q5`)

- **难度评级**：`D3`
- **核心物理模型**：低速（伽利略）电磁场变换与非磁性电介质在磁场中运动时的洛伦兹极化自洽场
- **教学标签**：`伽利略电磁变换`、`动生电场`、`运动介质极化`、`束缚面电荷退极化场`、`Wilson-Wilson 效应`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第 1 问：非相对论伽利略变换下的电磁场**：
   设带电量为 \(q\) 的试探点电荷在电容器系 \(S\) 中速度为 \(\vec{u} = (u_x, u_y, u_z)\)。参考系 \(S'\) 相对 \(S\) 以恒定速度 \(\vec{V} = (0, v, 0)\) 运动，由伽利略速度变换，该电荷在 \(S'\) 中的速度为：
   \[
   \vec{u}' = \vec{u} - \vec{V} = (u_x,\, u_y - v,\, u_z) \implies \vec{u} = \vec{u}' + \vec{V}
   \]
   在 \(S\) 系中仅有匀强磁场 \(\vec{B} = (-B, 0, 0)\)，无电场 \(\vec{E} = \vec{0}\)，电荷所受洛伦兹力为：
   \[
   \vec{F} = q \vec{u} \times \vec{B} = q (\vec{u}' + \vec{V}) \times \vec{B} = q(\vec{V} \times \vec{B} + \vec{u}' \times \vec{B})
   \]
   由已知条件，电荷量与合力在伽利略变换下不变（\(q' = q, \vec{F}' = \vec{F}\)），而在 \(S'\) 系中 \(\vec{F}' = q(\vec{E}' + \vec{u}' \times \vec{B}')\)。因上式对任意试探速度 \(\vec{u}'\) 恒成立，对比系数得：
   \[
   \vec{E}' = \vec{V} \times \vec{B}, \qquad \vec{B}' = \vec{B}
   \]
   具体计算叉乘 \(\vec{V} \times \vec{B} = (0, v, 0) \times (-B, 0, 0) = (0, 0, vB)\)（\(y \times (-x) = +z\)），故：
   \[
   (E_x', E_y', E_z') = (0, 0, vB), \qquad (B_x', B_y', B_z') = (-B, 0, 0)
   \]

2. **第 2 问：运动电介质在电容器系 \(S\) 中的电场与两极板电势差**：
   注意电路图右端极板引线为**断路（未接通外电路）**且起初未充电，因此极板上的自由面电荷始终为零（\(\sigma_f = 0\)）。
   在随液体静止的参考系 \(S'\) 中，题目给出极化后液体内总电场强度为：
   \[
   \vec{E}'_{\text{tot}} = \frac{\varepsilon_0}{\varepsilon}(E_x', E_y', E_z') = \left(0, 0, \frac{\varepsilon_0}{\varepsilon} v B\right)
   \]
   （自洽检验：极化强度 \(P_z' = (\varepsilon - \varepsilon_0) E'_{z,\text{tot}}\)，上下表面束缚面电荷 \(\pm \sigma_b = \pm P_z'\) 产生附加静电场 \(E'_{z,\text{bound}} = -\frac{P_z'}{\varepsilon_0}\)，代入 \(E'_{z,\text{tot}} = vB - \frac{\varepsilon-\varepsilon_0}{\varepsilon_0}E'_{z,\text{tot}}\) 即精确导出 \(E'_{z,\text{tot}} = \frac{\varepsilon_0}{\varepsilon}vB\)！）
   现在利用第 1 问的非相对论变换关系从 \(S'\) 系变回电容器系 \(S\)（注意 \(S\) 系相对 \(S'\) 速度为 \(-\vec{V} = (0, -v, 0)\)，且非相对论极限下极化面电荷运动产生的附加磁场比 \(B\) 小 \((v/c)^2\) 量级可忽略，故 \(\vec{B} = \vec{B}' = (-B, 0, 0)\)）：
   \[
   \vec{E}_{\text{tot}} = \vec{E}'_{\text{tot}} - \vec{V} \times \vec{B} = \left(0, 0, \frac{\varepsilon_0}{\varepsilon} v B - v B\right) = \left(0, 0, -\left(1 - \frac{\varepsilon_0}{\varepsilon}\right) v B\right)
   \]
   即 \(S\) 系中电场大小为 \(\left(1 - \frac{\varepsilon_0}{\varepsilon}\right) v B = \frac{\varepsilon - \varepsilon_0}{\varepsilon} v B\)，方向沿 \(z\) 轴负方向（向下）。
   （物理交叉验证：正束缚电荷移向 \(z = +d/2\) 上极板，负束缚电荷移向 \(z = -d/2\) 下极板，故在 \(S\) 系中仅由 \(\pm\sigma_b\) 产生的匀强电场大小为 \(\frac{\sigma_b}{\varepsilon_0} = \frac{\varepsilon - \varepsilon_0}{\varepsilon}vB\)、方向竖直向下！）
   由电势差定义，上极板（\(z = +d/2\)）与下极板（\(z = -d/2\)）间的电势差为：
   \[
   U = \varphi_{\text{上}} - \varphi_{\text{下}} = -\int_{-d/2}^{d/2} E_{z,\text{tot}}\,\mathrm{d}z = -E_{z,\text{tot}} d = \left(1 - \frac{\varepsilon_0}{\varepsilon}\right) v B d = \frac{\varepsilon - \varepsilon_0}{\varepsilon} v B d
   \]

3. **极限自检**：
   - 真空流动（\(\varepsilon = \varepsilon_0\)）：\(E_z = 0, U = 0\)。
   - 导体（\(\varepsilon \to \infty\)）：\(U \to v B d\)，退化为经典磁流体动生电动势（霍尔电动势）。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答完全一致，第 1 问 \((0, 0, vB)\) 与 \((-B, 0, 0)\)、第 2 问 \((E_x, E_y, E_z) = \left(0, 0, \left(\frac{\varepsilon_0}{\varepsilon}-1\right)vB\right)\) 与 \(V = \left(1 - \frac{\varepsilon_0}{\varepsilon}\right) v B d\) 完全吻合。官方解答两次展开洛伦兹力的 \(x, y, z\) 三个分量方程求解；而我们的盲解利用矢量式 \(\vec{E}' = \vec{E} + \vec{V}\times\vec{B}\) 与束缚面电荷自洽图像，大幅压缩了代数运算并给出了直观物理来源。
- **核心难点**：
  - 难点1：理解非相对论伽利略变换下的电磁场变换法则 \(\vec{E}' = \vec{E} + \vec{V}\times\vec{B}, \vec{B}' = \vec{B}\)（与洛伦兹变换取 \(v/c \to 0\) 且略去 \(O(v^2/c^2)\) 与 \(\vec{E}/c^2\) 项时，当 \(E \lesssim vB\) 时精确自洽）。
  - 难点2：为什么真空流过磁场时 \(S\) 系电场为零，而介质流过磁场时 \(S\) 系反倒出现了向下的静电场——本质是介质内部产生极化束缚面电荷 \(\pm\sigma_b\)，而断开的极板无自由电荷抵消该场。
- **高频易错点**：
  - 易错点1：右手定则与叉乘符号算反，把 \(\vec{B} = (-B, 0, 0)\) 误当成 \(+x\) 方向，导致 \(E_z'\) 或 \(E_z\) 差一个负号。
  - 易错点2：逆变换返回 \(S\) 系时忘了替换符号（误把 \(\vec{E}' = \vec{E} + \vec{V}\times\vec{B}\) 的加号照搬成 \(\vec{E} = \vec{E}' + \vec{V}\times\vec{B}\)），错算出 \(E_z = \left(1 + \frac{\varepsilon_0}{\varepsilon}\right) v B\)。
  - 易错点3：受『\(S'\) 系总场乘以 \(\varepsilon_0/\varepsilon\)』的误导，误以为在 \(S\) 系中直接把动生电场乘以 \(\varepsilon_0/\varepsilon\)，未做参考系逆变换或漏掉 \(\vec{V}\times\vec{B}\) 的抵消项。
- **教练总结**：处理运动介质电磁学（特别是低速 \(v \ll c\) 下的麦克斯韦-闵可夫斯基效应），最保险的路径是『① 先跳到**介质静止系 \(S'\)** 中用熟知的常规介质极化律 \(\vec{D}' = \varepsilon\vec{E}'\) 求解极化与总场；② 再用 \(\vec{E} = \vec{E}' - \vec{v}\times\vec{B}\) 变换回**实验室系 \(S\)**』，切忌直接在 \(S\) 系盲套静止介质的本构关系 \(\vec{D} = \varepsilon\vec{E}\)。

## 6. 复赛第6题 · 加热弯曲的双金属片曲率半径 (`cpho-2013-semifinal-theory-problem-slice-q6`)

- **难度评级**：`D2`
- **核心物理模型**：双金属片热膨胀几何圆弧匹配模型（中心线弧长近似）
- **教学标签**：`固体热膨胀`、`双金属片曲率半径`、`几何弧长约束`、`中性层长度近似`、`弹性修正边界探讨`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **几何建模与推导**：
   设两金属片在 \(T_1 = 20^\circ\text{C}\) 时的初始等长长度均为 \(l\)，厚度均为 \(d = 0.20\text{ mm}\)。钢片和青铜片的线膨胀系数分别为 \(\alpha_1 = 1.0 \times 10^{-5}\text{ K}^{-1}\) 与 \(\alpha_2 = 2.0 \times 10^{-5}\text{ K}^{-1}\)。
   当温度升高至 \(T_2 = 120^\circ\text{C}\)（温升 \(\Delta T = T_2 - T_1 = 100\text{ K}\)）时，因 \(\alpha_2 > \alpha_1\)，青铜伸长更多而位于凸面外侧，钢位于凹面内侧，如图所示，令图中的弯曲半径 \(r\) 为两金属片接触界面处的曲率半径，圆弧对应的圆心角为 \(\phi\)。
   由于题目未给出钢与青铜的杨氏模量 \(E_1, E_2\)，在中学竞赛常规纯几何近似下，假设弯曲时各自截面中心线（中性线）不发生轴向弹性伸缩（忽略加热时金属片厚度 \(d\) 的微小变化）。于是：
   - 钢片中心线半径为 \(r - \frac{d}{2}\)，其弧长等于自由热膨胀后的长度：
     \[
     \left(r - \frac{d}{2}\right)\phi = l \left[1 + \alpha_1 (T_2 - T_1)\right]
     \]
   - 青铜片中心线半径为 \(r + \frac{d}{2}\)，其弧长等于自由热膨胀后的长度：
     \[
     \left(r + \frac{d}{2}\right)\phi = l \left[1 + \alpha_2 (T_2 - T_1)\right]
     \]
   两式相除消去 \(l\) 和 \(\phi\)：
   \[
   \frac{r + d/2}{r - d/2} = \frac{1 + \alpha_2 \Delta T}{1 + \alpha_1 \Delta T}
   \]
   整理求解 \(r\)：
   \[
   r (\alpha_2 - \alpha_1)\Delta T = \frac{d}{2}\left[2 + (\alpha_1 + \alpha_2)\Delta T\right] \implies r = \frac{2 + (\alpha_1 + \alpha_2)\Delta T}{2(\alpha_2 - \alpha_1)\Delta T} d
   \]

2. **数值计算与物理自检**：
   代入 \(d = 0.20\text{ mm}\)，\(\Delta T = 100\text{ K}\)，\((\alpha_1 + \alpha_2)\Delta T = 3.0 \times 10^{-3}\)，\((\alpha_2 - \alpha_1)\Delta T = 1.0 \times 10^{-3}\)：
   \[
   r = \frac{2 + 3.0 \times 10^{-3}}{2 \times 1.0 \times 10^{-3}} \times 0.20\text{ mm} = 1001.5 \times 0.20\text{ mm} = 200.3\text{ mm} \approx 2.0 \times 10^2\text{ mm} = 0.20\text{ m}
   \]
   **模型自检（弹性力学疑虑记录）**：若严格按铁木辛柯（Timoshenko）双金属片弹性弯曲理论，两端焊接在一起使接触面（或端面约束）传递轴向内力 \(P\) 从而使青铜片受压、钢片受拉，则两等厚薄片的精确曲率半径应带有弹性模量比值修正因子 \(\frac{14 + E_1/E_2 + E_2/E_1}{12} \ge \frac{4}{3}\)（对钢与青铜 \(E_1 \approx 200\text{ GPa}, E_2 \approx 110\text{ GPa}\) 约为 \(1.37\)，对应 \(r \approx 0.27\text{ m}\)）。但因本题未给 \(E_1, E_2\) 且仅为 15 分短题，命题必采纳上述『中心线自由膨胀』简化几何模型。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：官方参考解答采用与盲解完全一致的『中心线自由热膨胀几何模型』（\((r - d/2)\phi = l + \Delta l_1\)，\((r + d/2)\phi = l + \Delta l_2\)），最终公式及有效数字结果同为 \(r = \frac{2 + (\alpha_1 + \alpha_2)(T_2 - T_1)}{2(\alpha_2 - \alpha_1)(T_2 - T_1)}d = 2.0 \times 10^2\text{ mm}\)。同时，我们的盲解深刻剖析了题设模型与真实弹性力学的差异（铁木辛柯弹性弯曲因子 \(\frac{14 + E_1/E_2 + E_2/E_1}{12}\)），这对面向大学物理竞赛及高水平强基/省队学生的教学极具价值。
- **核心难点**：
  - 难点1：准确把握双金属片弯曲时『中心线间隔为 \(d\)』的几何模型——在界面半径 \(r\) 两侧，钢和青铜的平均弧长半径分别为 \(r - d/2\) 和 \(r + d/2\)。
  - 难点2：识别命题的近似层级：题设没有给杨氏模量 \(E_1, E_2\)，意味着把『相互挤拉产生的轴向弹性形变』全部忽略，只保留热膨胀线度与弧长的纯几何关系。
- **高频易错点**：
  - 易错点1：把两金属片弯曲弧长半径的差错算成总厚度 \(2d\)（即误取内表面 \(r - d\) 和外表面 \(r + d\)），导致结果放大一倍变为 \(4.0 \times 10^2\text{ mm}\)。
  - 易错点2：未留意题目所给 \(d = 0.20\text{ mm}\) 是两位有效数字，最后未做有效数字修约或单位换算错误（如把 \(200\text{ mm}\) 错换算成 \(2.0\text{ m}\)）。
  - 易错点3：过度纠结『两端焊接内部无胶粘』而在考场上试图引入未知的杨氏模量，导致无法得出数值解。
- **教练总结**：在物理竞赛中，**题目给出的已知量清单本身就是物理模型近似层级的重要信号**。未给出杨氏模量却要求数值曲率半径时，必然采用『各层中心线无弹性伸缩』的几何模型；但在大学普物拓展中，不妨补充一句 Timoshenko 经典结果 \(r_{\text{elastic}} = \frac{14 + E_1/E_2 + E_2/E_1}{12} \frac{d}{(\alpha_2-\alpha_1)\Delta T}\)（等刚度时多出 \(4/3\) 因子），帮学生建立从竞赛近似到连续介质力学的完整认知桥梁。

## 7. 复赛第7题 · 微小台阶梯度折射率斜劈的多狭缝干涉 (`cpho-2013-semifinal-theory-problem-slice-q7`)

- **难度评级**：`D3`
- **核心物理模型**：纵梯度折射率台阶斜劈的光程差积分与等间距狭缝相长干涉（平方数列跳阶选缝）
- **教学标签**：`非均匀介质光程`、`梯度折射率无偏折`、`凸透镜等光程性`、`多缝干涉`、`平方阶等间距选缝技巧`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **光路特征分析（光线不偏折证明）**：
   入射平行单色光沿 \(+x\) 方向垂直射入底面 \(x = 0\)。
   - **底面**：波面与底面平行（垂直 \(x\) 轴），垂直入射不偏折。
   - **介质内部**：折射率 \(n(x) = 1 + b x\) 仅是传播方向坐标 \(x\) 的函数（梯度 \(\nabla n = b\hat{x}\) 平行于光线方向），在垂直波面的 \(yz\) 平面内折射率处处均匀，故波面始终保持与 \(x\) 轴垂直、光线沿 \(+x\) 直线传播不弯曲！
   - **出射斜面**：由于斜面由微小台阶组成，且出射上表面平行于 \(yz\) 平面（垂直于 \(x\) 轴），从这些微台阶上表面出射的光线仍垂直表面出射，方向严格保持沿 \(+x\) 轴不变（避开台阶连接垂直小面即可）。
   由图 (b)，在高度 \(y \ge 0\) 处，光线在斜劈内走过的几何厚度为 \(h_1(y) = y\tan\theta\)（劈尖总高为 \(h\)，故介质分布区间为 \(0 \le y \le h\cot\theta\)）。

2. **第 1 问：各透光狭缝的 \(y\) 坐标**：
   考察从入射波面 \(x = 0\) 到出射参考面 \(x = h\) 之间高度为 \(y\) 的光线的光程 \(\delta(y)\)：
   - 介质中（\(0 \le x \le y\tan\theta\)）：
     \[
     \delta_1(y) = \int_0^{y\tan\theta} n(x)\,\mathrm{d}x = \int_0^{y\tan\theta} (1 + b x)\,\mathrm{d}x = y\tan\theta + \frac{1}{2} b y^2 \tan^2\theta
     \]
   - 空气中（\(y\tan\theta \le x \le h\)，折射率 \(n_0 = 1\)）：
     \[
     \delta_2(y) = 1 \cdot (h - y\tan\theta)
     \]
   总光程为（线性厚度项完美相消）：
   \[
   \delta(y) = \delta_1(y) + \delta_2(y) = h + \frac{1}{2} b y^2 \tan^2\theta
   \]
   由于第一条狭缝在 \(y = 0\) 处，\(\delta(0) = h\)，故高度 \(y\) 处透射光与 \(y = 0\) 处光线的光程差为：
   \[
   \Delta\delta(y) = \delta(y) - \delta(0) = \frac{1}{2} b y^2 \tan^2\theta
   \]
   已知平行于 \(x\) 轴的各光线经薄凸透镜会聚到焦点处时，从挡板平面（波面）到像方焦点之间的光程处处相等（物像等光程性），因此焦点处的总光程差仍等于 \(\Delta\delta(y)\)。要使各狭缝透射光在焦点处彼此加强（相长干涉），光程差须为波长的整数倍：
   \[
   \frac{1}{2} b y_k^2 \tan^2\theta = k \lambda \quad (k = 1, 2, 3, \dots)
   \]
   解出其余各狭缝（\(y_k > 0\)）的坐标为：
   \[
   y_k = \cot\theta \sqrt{\frac{2 k \lambda}{b}} = A \sqrt{k}, \qquad \left(A \equiv \cot\theta\sqrt{\frac{2\lambda}{b}},\quad k = 1, 2, 3, \dots\right)
   \]
   （注：若狭缝仅刻在斜劈覆盖范围内 \(y_k \le h\cot\theta\)，则有 \(k \le \frac{b h^2}{2\lambda}\)。量纲检验：\([n]=1 \implies [b] = \text{m}^{-1}\)，\([\sqrt{\lambda/b}] = \text{m}\)，正确。）

3. **第 2 问：等距排列狭缝能否仍然满足要求？**：
   初看 \(y_k = A\sqrt{k}\) 并非线性数列（相邻间距越来越小），极易误答“不能”。但仔细审题：**只要求通过各狭缝的光彼此在焦点加强形成亮纹，并不要求相邻狭缝的干涉级次必须连续相差 1**！
   设各狭缝等距排列，从 \(y = 0\) 起位置为 \(y^{(n)} = n d\)（\(n = 0, 1, 2, \dots\)）。代入光程差公式得：
   \[
   \Delta\delta(y^{(n)}) = \frac{1}{2} b (n d)^2 \tan^2\theta = n^2 \left(\frac{1}{2} b d^2 \tan^2\theta\right)
   \]
   只要取等间距 \(d\) 满足 \(\frac{1}{2} b d^2 \tan^2\theta = m \lambda\)（其中 \(m\) 为任意正整数），即取**间距为 \(d = \sqrt{m}\,A = \cot\theta\sqrt{\frac{2m\lambda}{b}}\)**（实质上是只保留第 1 问解中的 \(k = 0, m, 4m, 9m, \dots\) 这些平方级次狭缝！例如取 \(m=1\)，间距就是 \(d = A = \cot\theta\sqrt{\frac{2\lambda}{b}}\)），则对所有 \(n = 0, 1, 2, \dots\) 都有 \(\Delta\delta(y^{(n)}) = (m n^2)\lambda\)，即任意两狭缝光程差仍是波长的整数倍，因此**仍能**在焦点处相互加强形成亮纹！（当然，若任意选取不满足 \(d = \sqrt{m}A\) 的间距，则无法满足。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答完全一致，包括第 1 问 \(y_k = \sqrt{\frac{2k\lambda}{b}}\cot\theta\) 以及第 2 问最具巧思的『选平方级次 \(k = m, 4m, 9m, \dots\) 实现等间距 \(d = \sqrt{m}A\)』结论。两处微小的表达细节差异在于：官方解答计算变折射率光程 \(\delta_1\) 时，用『线性函数平均值 \(\bar{n} = \frac{1}{2}[n(0) + n(h_1)]\) 乘以厚度 \(h_1\)』来代替积分，适合未学过微积分的高中选手；官方还补充了一句『忽略或用台阶尺度与狭缝位置避开相邻台阶连接处的光线』，非常严谨。
- **核心难点**：
  - 难点1：理解题干为何特意构造『微小台阶表面平行 \(yz\) 面』且『\(n\) 仅随 \(x\) 变化』——这双保险保证了光线穿过斜劈全程不偏折，否则普通斜劈不仅会使光线折射偏离 \(x\) 轴，还会使 \(y\) 坐标不再与出射位置一一对应。
  - 难点2：第 2 问打破思维定势——意识到波尔/菲涅尔波带式 \(\sqrt{k}\) 位置序列中蕴含着等差子列 \(k = m n^2\)（即 \(1, 4, 9, 16, \dots\) 均开方为整数）。
- **高频易错点**：
  - 易错点1：见到 \(y_k \propto \sqrt{k}\) 就草率回答“第 2 问不能等距排列”，没意识到干涉加强只需光程差为整数个波长、不必取遍所有自然数级次 \(k\)。
  - 易错点2：直接将 \(n(x) = 1 + bx\) 当成恒定折射率或错误积分（例如误算成 \(n(y) \cdot h_1(y)\)），或者漏掉在介质后面空气段 \((h - h_1)\) 里的光程，导致多出虚假的 \(y\tan\theta\) 项。
  - 易错点3：把几何厚度写反成 \(y\cot\theta\)，或忽略 \(y = 0\) 处参考缝的相干基准意义。
- **教练总结**：当光程差函数呈二次规律 \(\Delta\delta(y) \propto y^2\)（类似牛顿环、菲涅尔波带片或平方相位光栅）时，完全相长位置虽然呈 \(\sqrt{k}\) 分布，但**抽样选取 \(k = m n^2\) 即可构成严格等间距光栅**（本质正是空间周期光栅与二次相位板的塔尔博特自成像条件）。

## 8. 复赛第8题 · 逆康普顿散射的能量公式、阈值条件与高能计算 (`cpho-2013-semifinal-theory-problem-slice-q8`)

- **难度评级**：`D3`
- **核心物理模型**：相对论四动量守恒下的普遍逆康普顿散射与一维对头背向散射极值
- **教学标签**：`相对论四动量守恒`、`逆康普顿散射`、`散射阈值判据`、`极端相对论近似`、`官方勘误辨析`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第 1 问：散射后光子的能量（一般散射角与对头背向极值）**：
   取碰前电子的运动方向为 \(+x\) 轴，则碰前电子能量为 \(E_e\)、动量大小 \(p_e = \frac{1}{c}\sqrt{E_e^2 - m_e^2 c^4}\)（沿 \(+x\)）；碰前光子能量为 \(E_\gamma\)、动量大小为 \(E_\gamma / c\)（沿 \(-x\)）。
   使用相对论四动量不变量（\(P = (E/c, \vec{p})\)，度规 \((+,-,-,-)\)）：设散射后光子能量为 \(E_\gamma'\)，其出射方向与碰前电子方向（\(+x\)）夹角为 \(\alpha\)（即 \(\alpha = 0\) 表示光子被电子迎面撞回、沿电子初速度方向做 \(180^\circ\) 对头背散射；\(\alpha = \pi\) 表示光子未偏转直接穿过）。由四动量守恒 \(P_e' = P_e + K - K'\) 两边平方，并利用 \(P_e^2 = P_e'^2 = m_e^2 c^2\) 与 \(K^2 = K'^2 = 0\)：
   \[
   P_e \cdot K' + K \cdot K' = P_e \cdot K
   \]
   逐项计算四维内积：
   \[
   P_e \cdot K = \frac{E_\gamma(E_e + p_e c)}{c^2}, \quad P_e \cdot K' = \frac{E_\gamma'(E_e - p_e c \cos\alpha)}{c^2}, \quad K \cdot K' = \frac{E_\gamma E_\gamma'(1 + \cos\alpha)}{c^2}
   \]
   代入得任意出射角 \(\alpha\) 下散射后光子的能量：
   \[
   E_\gamma'(\alpha) = \frac{E_\gamma (E_e + p_e c)}{E_e - p_e c \cos\alpha + E_\gamma (1 + \cos\alpha)} = \frac{E_\gamma \left(E_e + \sqrt{E_e^2 - m_e^2 c^4}\right)}{E_e + E_\gamma + \left(E_\gamma - \sqrt{E_e^2 - m_e^2 c^4}\right)\cos\alpha}
   \]
   特别地，若考虑一维严格对头共线背散射（\(\alpha = 0\)，光子原路弹回，注意题干第 3 问未提供角度且附了 \(\sqrt{1-x} \approx 1-\frac{1}{2}x\) 提示，正对应此极限），上式化为：
   \[
   E_\gamma' = \frac{E_\gamma (E_e + p_e c)}{E_e - p_e c + 2 E_\gamma} = \frac{E_\gamma\left(E_e + \sqrt{E_e^2 - m_e^2 c^4}\right)}{\left(E_e - \sqrt{E_e^2 - m_e^2 c^4}\right) + 2E_\gamma}
   \]

2. **第 2 问：逆康普顿散射能够发生的条件**：
   逆康普顿散射要求能量由电子转移给光子，即 \(E_\gamma' > E_\gamma\)。利用普遍角分布公式作差：
   \[
   E_\gamma' - E_\gamma = \frac{E_\gamma \left(p_e c - E_\gamma\right)(1 + \cos\alpha)}{E_e - p_e c \cos\alpha + E_\gamma(1 + \cos\alpha)} > 0
   \]
   只要确实发生散射（\(\alpha \ne \pi\)，即 \(1 + \cos\alpha > 0\)，且分母恒正），该条件**与散射角 \(\alpha\) 无关**，等价于碰前电子动量大小大于光子动量大小：
   \[
   p_e c > E_\gamma \iff \sqrt{E_e^2 - m_e^2 c^4} > E_\gamma \iff E_e > \sqrt{E_\gamma^2 + m_e^2 c^4}
   \]
   （物理本质：在此条件下，质心系沿电子初速度方向运动，即 \(\beta_{\text{CM}} = \frac{p_e c - E_\gamma}{E_e + E_\gamma} > 0\)，故在非前向直穿散射下光子在实验室系必获得能量增益！）

3. **第 3 问：极端相对论数值计算**：
   已知 \(E_\gamma = 2.00\text{ eV}\)，\(E_e = 1.00 \times 10^9\text{ eV}\)，\(m_e c^2 = 0.511 \times 10^6\text{ eV}\)。
   由于 \(\frac{m_e c^2}{E_e} = 5.11 \times 10^{-4} \ll 1\)，利用题给平方根一级近似：
   \[
   p_e c = E_e \sqrt{1 - \left(\frac{m_e c^2}{E_e}\right)^2} \approx E_e \left[1 - \frac{1}{2}\left(\frac{m_e c^2}{E_e}\right)^2\right] = E_e - \frac{(m_e c^2)^2}{2 E_e}
   \]
   因此分母中不能直接令 \(p_e c \approx E_e\)，而需保留一阶差值：
   \[
   E_e - p_e c \approx \frac{(m_e c^2)^2}{2 E_e} = \frac{(0.511 \times 10^6)^2}{2 \times 1.00 \times 10^9}\text{ eV} \approx 130.56\text{ eV}
   \]
   同时分子 \(E_e + p_e c \approx 2 E_e = 2.00 \times 10^9\text{ eV}\)。注意 \(2 E_\gamma = 4.00\text{ eV}\) 约占 \(130.56\text{ eV}\) 的 \(3\%\)，在 3 位有效数字下**不可忽略**！代入对头背散射最大增益公式（\(\alpha = 0\)）：
   \[
   E_\gamma' \approx \frac{2 E_\gamma E_e}{\dfrac{(m_e c^2)^2}{2 E_e} + 2 E_\gamma} = \frac{2.00 \times 2.00 \times 10^9}{130.56 + 4.00}\text{ eV} \approx 2.97 \times 10^7\text{ eV} = 29.7\text{ MeV}
   \]

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解的全部最终结果（第 1 问含角分布通用公式及 \(\theta \to 0\) 极限、第 2 问阈值条件 \(\sqrt{E_e^2 - m_e^2 c^4} > E_\gamma\)、第 3 问 \(29.7\text{ MeV}\)）均与官方参考解答完全一致！此外，我们在对照官方解答时发现了两处**极具教学价值的官方瑕疵与排版说明**：
  1. **原题排版缺失提示**：原卷第 1 行“八、（20分）光 子 被 电 子”后半句被前题插图遮挡/断行截断（漏印“散射，若能量从”字样），但不影响语义理解。
  2. **官方解答第 2 问中间式存在系数“2”的笔误**：在参考解答第 14 页式 `(7)` 上方的 \(E_\gamma' - E_\gamma\) 通分分子中，官方多写出一个因子 \(2\)（写成 \(2E_\gamma(\sqrt{E_e^2-m_e^2 c^4} - E_\gamma)(1+\cos\theta)\)），实际上 \(E_e + p_e c - [E_e + E_\gamma + (E_\gamma - p_e c)\cos\theta] = (p_e c - E_\gamma)(1+\cos\theta)\)，并无系数 2（因 2 不改变正负号，故阈值 `(7)` 未受影响）。
  3. **官方解答第 3 问对 \(\theta \approx 0\) 的论证略显含混**：官方解答称“由 (5) 式可知 \(|p_\gamma'| \gg |p_\gamma|\)，因此有 \(\theta \approx 0\)”。严格来说，运动学公式 (5) 允许任意角度 \(\theta \in [0, \pi]\)，当 \(\theta = \pi/2\) 时 \(E_\gamma' \approx 2 E_\gamma = 4\text{ eV}\) 并不满足 \(|p_\gamma'| \gg |p_\gamma|\)；实际物理原因是极端相对论下前向辐射（汤姆孙微分散射截面）高度聚束在张角 \(\theta \lesssim 1/\gamma = m_e c^2 / E_e \approx 5\times 10^{-4}\text{ rad}\) 的极窄锥内，且最高能量恰出现在 \(\theta = 0\) 对头背向散射处。
- **核心难点**：
  - 难点1：三维四动量（或能量与三维动量余弦定理）消去反冲电子的参量，得到干净的 \(E_\gamma'(\theta)\) 表达式。
  - 难点2：极端相对论分母相消的处理：\(E_e - p_e c\) 发生大数相消，必须使用 \(\sqrt{1-x} \approx 1 - x/2\) 保留二阶小量 \(\frac{(m_e c^2)^2}{2 E_e}\)，同时不可丢掉与之同数量级的 \(2 E_\gamma\)。
- **高频易错点**：
  - 易错点1：第 3 问直接取极端相对论近似 \(p_e c = E_e\)，导致分母只剩 \(2 E_\gamma\)，从而得出荒谬结论 \(E_\gamma' \approx E_e = 10^9\text{ eV}\)（忽略了电子静止质量项 \(\frac{m_e^2 c^4}{2 E_e} \approx 130.6\text{ eV} \gg 4.00\text{ eV}\)！）。
  - 易错点2：虽然记得展开 \(\sqrt{E_e^2 - m_e^2 c^4}\)，却在分母中错把 \(2 E_\gamma\) 当小量删去，产生约 \(3\%\) 的偏差（错算得 \(30.6\text{ MeV}\)）。
  - 易错点3：把静止电子康普顿散射公式硬套到运动电子上，或误以为逆康普顿散射条件是 \(E_e > E_\gamma\) 而非 \(p_e c > E_\gamma\)。
- **教练总结**：处理高能相对论碰撞，**四动量平方不变量法**永远比先平方再套三角形余弦定理快且不易出错；凡遇 \(E_e - p_e c\) 或 \(1 - v/c\) 型相消项，务必使用 \(E_e - p_e c = \frac{m_e^2 c^4}{E_e + p_e c} \approx \frac{(m_e c^2)^2}{2 E_e}\) 这一恒等分子有理化变形！

## 9. 决赛第1题 · 连续非弹性弹跳小球的轨迹包络面积与总冲量 (`cpho-2013-final-theory-problem-slice-q1`)

- **难度评级**：`D2`
- **核心物理模型**：连续多次局部弹性碰撞的几何级数收敛（包络面积与总冲量 / 整体飞行时间动量定理）
- **教学标签**：`非弹性连续碰撞`、`无穷等比级数`、`动量定理`、`整体飞行时间法`、`抛物线弓形面积`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **各次弹跳的几何级数关系**：
   小球从高 \(h\) 处以水平初速 \(v_x = \sqrt{2gh}\) 抛出，首次落地前下落时间 \(t_0 = \sqrt{\frac{2h}{g}}\)，落地瞬间竖直向下速率为 \(v_0 = \sqrt{2gh}\)。
   设每次反弹竖直速率衰减比例为 \(\lambda\)（\(0 < \lambda < 1\)），而水平速率始终保持 \(v_x = \sqrt{2gh}\) 不变（即地面无水平摩擦力、碰撞冲量纯竖直向上）。
   那么第 \(n\) 次（\(n = 1, 2, 3, \dots\)）反弹后的向上竖直初速度为：
   \[
   v_n = \lambda^n v_0 = \lambda^n \sqrt{2gh}
   \]
   对应第 \(n\) 次反弹至第 \(n+1\) 次落地之间的斜抛弧段：
   - 最大高度：\(H_n = \frac{v_n^2}{2g} = \lambda^{2n} h\)
   - 飞行时间：\(t_n = \frac{2 v_n}{g} = 2\lambda^n \sqrt{\frac{2h}{g}}\)
   - 水平射程：\(R_n = v_x t_n = \sqrt{2gh} \cdot 2\lambda^n \sqrt{\frac{2h}{g}} = 4 \lambda^n h\)
   - 由题给提示，第 \(n\) 段轨迹与地面投影所围面积为：
     \[
     S_n = \frac{2}{3} H_n R_n = \frac{2}{3} (\lambda^{2n} h)(4 \lambda^n h) = \frac{8}{3} \lambda^{3n} h^2
     \]

2. **由总面积求衰减比率 \(\lambda\)**：
   自第一次反弹开始（\(n = 1\) 到 \(\infty\)）所围面积总和为：
   \[
   S = \sum_{n=1}^{\infty} S_n = \frac{8}{3} h^2 \sum_{n=1}^{\infty} \lambda^{3n} = \frac{8}{3} h^2 \frac{\lambda^3}{1 - \lambda^3} = \frac{8}{21} h^2
   \]
   解得：
   \[
   \frac{\lambda^3}{1 - \lambda^3} = \frac{1}{7} \implies 8 \lambda^3 = 1 \implies \lambda = \frac{1}{2}
   \]

3. **求解总冲量（双方法交叉验证）**：
   - **方法一（逐次碰撞冲量求和）**：第 \(n\) 次碰撞中，竖直速度由 \(-v_{n-1}\) 变为 \(+v_n\)（其中 \(v_0 = \sqrt{2gh}\)），地面给小球的竖直向上冲量为 \(I_n = m(v_n + v_{n-1}) = m v_0 (1 + \lambda)\lambda^{n-1}\)。求和：
     \[
     I = \sum_{n=1}^{\infty} I_n = m v_0 (1 + \lambda) \sum_{n=1}^{\infty} \lambda^{n-1} = m \sqrt{2gh} \frac{1 + \lambda}{1 - \lambda} = m \sqrt{2gh} \frac{1 + 1/2}{1 - 1/2} = 3 m \sqrt{2gh}
     \]
     方向**竖直向上**。
   - **方法二（全程竖直方向整体动量定理验证）**：从 \(t = 0\) 水平抛出（\(v_y(0) = 0\)）至无限多次弹跳停止（\(v_y(\infty) = 0\)），总飞行时间为：
     \[
     T_{\text{tot}} = t_0 + \sum_{n=1}^{\infty} t_n = \sqrt{\frac{2h}{g}} \left(1 + \frac{2\lambda}{1-\lambda}\right) = \sqrt{\frac{2h}{g}} \frac{1+\lambda}{1-\lambda} = 3\sqrt{\frac{2h}{g}}
     \]
     在整个过程中，竖直外力只有重力（向下）与地面各次撞击冲量 \(I\)（向上），因竖直总动量增量为零，必有 \(I - m g T_{\text{tot}} = 0\)，即 \(I = m g T_{\text{tot}} = 3 m\sqrt{2gh}\)，完全一致！

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答完全一致，\(\lambda = 1/2\)，总冲量 \(I = 3m\sqrt{2gh}\)，方向竖直向上。官方解答采用方法一逐次叠加冲量级数；盲解补充的『全程飞行时间 + 整体动量定理』方法不但可快速验算结果，在只求总冲量而无需写出每次单次冲量时更为简洁。
- **核心难点**：
  - 难点1：准确区分“自第一次反弹开始”对应的级数起点（从 \(n = 1\) 起的完整斜抛拱形，不含最初从高 \(h\) 平抛下落的半段轨迹）。
  - 难点2：识别每次碰撞的竖直速度增量是 \(v_n + v_{n-1}\) 而非 \(v_n - v_{n-1}\)（正负方向反转）。
- **高频易错点**：
  - 易错点1：把初段从 \(h\) 下落的半抛物线面积 \(S_0 = \frac{4}{3}h^2\) 误算入 \(S\) 中（事实上 \(S_0 > \frac{8}{21}h^2\)，若包含则无解）。
  - 易错点2：算单次冲量时只算成 \(m(v_{n-1} - v_n)\) 漏掉反向（把冲量求成了 \(m\sqrt{2gh}\)），忽略了速度方向反向使变化量变为 \(m(v_{n-1} + v_n)\)。
  - 易错点3：忘记指明冲量的矢量方向（竖直向上）。
- **教练总结**：对于无穷次弹跳问题，最顶级的物理直觉是**『全过程动量定理 \(\sum I_{\text{地面}} = mg T_{\text{total}}\)』**：因为小球最终竖直速度归零，地面在有限总时间 \(T_{\text{total}}\) 内给予的全部向上冲量必然严格抵消整个飞行过程中重力积累的向下总冲量！

## 10. 决赛第2题 · 靠光滑墙角滑落的刚性轻杆小球脱离墙面问题 (`cpho-2013-final-theory-problem-slice-q2`)

- **难度评级**：`D2`
- **核心物理模型**：双质点轻杆在光滑直角墙角内受约束滑动的脱离条件
- **教学标签**：`约束运动`、`质心运动定理`、`机械能守恒`、`临界脱离条件`、`极值速度捷径`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **运动学约束与机械能守恒**：
   以墙角为原点，地面为 \(x\) 轴，竖直墙面为 \(y\) 轴。设小球 1 未脱离竖直墙面时，杆与竖直墙面夹角为 \(\theta\)（\(0 \le \theta \le \pi/2\)）。两小球坐标为：
   \[
   x_1 = 0, \quad y_1 = l\cos\theta; \qquad x_2 = l\sin\theta, \quad y_2 = 0
   \]
   求导得速度分量（\(\omega = \dot{\theta}\)）：
   \[
   v_{1x} = 0, \quad v_{1y} = -l\omega\sin\theta; \qquad v_{2x} = l\omega\cos\theta, \quad v_{2y} = 0
   \]
   由机械能守恒（初动能为微小量趋于零）：
   \[
   \frac{1}{2} m (v_{1y}^2 + v_{2x}^2) + m g l \cos\theta = m g l \implies \frac{1}{2} m l^2 \omega^2 (\sin^2\theta + \cos^2\theta) = m g l (1 - \cos\theta)
   \]
   即 \(\omega^2 = \frac{2g}{l}(1 - \cos\theta)\)。

2. **求脱离角度（两种独立方法）**：
   - **方法一（质心运动定理 + 对时间求导）**：对 \(\omega^2 = \frac{2g}{l}(1-\cos\theta)\) 两边对时间 \(t\) 求导得角加速度 \(\dot{\omega} = \frac{g}{l}\sin\theta\)。
     系统质心水平坐标 \(x_c = \frac{1}{2}l\sin\theta\)，水平方向唯一外力是竖直墙面对球 1 的正压力 \(N_1\)，故：
     \[
     N_1 = 2m \ddot{x}_c = m l (\cos\theta\,\dot{\omega} - \sin\theta\,\omega^2) = m g \sin\theta (3\cos\theta - 2)
     \]
     球 1 开始脱离竖直墙面时（\(\theta > 0\)），正压力恰降为零 \(N_1 = 0\)，故：
     \[
     3\cos\theta - 2 = 0 \implies \theta = \arccos\frac{2}{3}
     \]
   - **方法二（小球 2 水平速度极值捷径）**：因脱离前 \(x_1 \equiv 0\)，故 \(x_c = \frac{1}{2} x_2\)，从而 \(N_1 = 2m\ddot{x}_c = m\ddot{x}_2\)！这意味着墙面正压力 \(N_1 = 0\) 的临界时刻恰对应小球 2 水平加速度为零、即水平速度 \(v_{2x}\) 达到最大值的时刻（此后因无墙面推力，整体水平动量守恒，\(v_{2x}\) 只会因杆内拉力等内力调节，而在此前全靠 \(N_1 > 0\) 加速）。由 \(v_{2x}^2 = 2gl \cos^2\theta (1 - \cos\theta)\)，令 \(u = \cos\theta\) 并对 \(f(u) = u^2 - u^3\) 求导：
     \[
     f'(u) = 2u - 3u^2 = 0 \implies u = \cos\theta = \frac{2}{3} \implies \theta = \arccos\frac{2}{3}
     \]
   - **地面接触检验**：需确认球 2 此前未脱离地面。质心竖直坐标 \(y_c = \frac{1}{2}l\cos\theta\)，求二阶导得地面支持力 \(N_2 = 2mg + 2m\ddot{y}_c = mg(3\cos^2\theta - 2\cos\theta + 1) = mg\left[3(\cos\theta - 1/3)^2 + 2/3\right] > 0\) 恒成立，球 2 永不离地。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答完全一致，均得 \(\theta = \arccos\frac{2}{3}\)。官方解答采用方法一（质心运动定理求 \(a_{cx}\)），其中在文字叙述里出现了一处微小的式号笔误：在式 `(14)` \(\sin\theta(\frac{3}{2}\cos\theta - 1) = 0\) 之后，文本连续两次误写为“方程(13)的一个解……方程(13)的另一个解……”（实际应指方程 `(14)`）。而盲解给出的**『\(v_{2x}\) 极值法』**可免去求二阶导数 \(\mathrm{d}\omega/\mathrm{d}t\)，且天然验证了 \(N_1 > 0 \to 0 \to <0\) 的变号实质；此外盲解还补验了球 2 不离地（\(N_2 > 0\)）的物理严密性。
- **核心难点**：
  - 难点1：识别『脱离墙面』的动力学判据是墙面正压力 \(N_1 = 0\)，而非某些学生想象的什么几何角度 \(45^\circ\) 或球 1 加速度等于 \(g\)（实际上此时 \(a_{1y} = -g\) 确为自由落体，但直接用 \(a_{1y} = -g\) 反求反而不如 \(N_1 = 0\) 直观）。
  - 难点2：正确写出系统质心运动定理 \(N_1 = 2m a_{cx}\)，注意质量是两球总质量 \(2m\) 而非 \(m\)。
- **高频易错点**：
  - 易错点1：把刚性轻杆换成均质重杆的模型混淆了（均质重杆中心转动惯量贡献 \(\frac{1}{12}ml^2\omega^2\)，其动能为 \(\frac{1}{6}ml^2\omega^2\) 对应脱离角 \(\arccos(2/3)\) 吗？有意思的是，均质杆 \(\frac{1}{6}ml^2\omega^2 = \frac{1}{2}mg l(1-\cos\theta) \implies \omega^2 = \frac{3g}{l}(1-\cos\theta)\)，求出来恰也是 \(\cos\theta = 2/3\)，但若是系数搞混成单质点放质心，动能少算就会出错！）。
  - 易错点2：计算 \(a_{cx} = \frac{\mathrm{d}}{\mathrm{d}t}(\frac{1}{2}l\omega\cos\theta)\) 时忘记 \(\omega\) 也是时间的函数，漏掉 \(\frac{1}{2}l\cos\theta\frac{\mathrm{d}\omega}{\mathrm{d}t}\) 这一项。
  - 易错点3：忘记乘以总质量 \(2m\) 算成 \(N_1 = m a_{cx}\)，虽巧合下 \(N_1 = 0\) 时结果一样，但在步骤分中会被扣分；或者在 \(N_1 = m\ddot{x}_2\) 中没说明为何 \(2m a_{cx} = m\ddot{x}_2\)。
- **教练总结**：当单侧约束（如靠在墙角滑落）系统仅靠墙面支持力获得水平动量时，**脱离墙面 \(\iff\) 水平外力 \(N_1\) 由正变零 \(\iff\) 系统水平总动量（即地面滑块水平速度 \(v_{2x}\)）达到极大值**！这一视角几乎把所有的光滑直角墙角脱离问题都化为了简单的一元函数求极值。

## 11. 决赛第3题 · 赤道太空飞行器与刚性竖直输送管（太空电梯模型） (`cpho-2013-final-theory-problem-slice-q3`)

- **难度评级**：`D4`
- **核心物理模型**：地球自转非惯性系中的有效势垒（引力+惯性离心力）、同步轨道势垒跨越与刚性输送管虚功平衡
- **教学标签**：`太空电梯物理模型`、`地球自转惯性离心力`、`同步轨道有效势垒`、`虚功原理`、`分段讨论临界高度`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **关键参数识别**：
   飞行器离地面高度为 \(L = \alpha R_e\)，故其到地心的径向距离为 \(r = R_e + L = (1 + \alpha) R_e\)。题给常数 \(\alpha_m = \left(\frac{G M_e}{\omega_e^2 R_e^3}\right)^{1/3} - 1\) 正好对应**地球同步轨道高度**（即 \(r_{\text{geo}} = (1 + \alpha_m) R_e = \left(\frac{G M_e}{\omega_e^2}\right)^{1/3}\)，此处引力与惯性离心力大小相等）。条件 \(\alpha > \alpha_m\) 表明飞行器位于同步轨道之外。

2. **第 1 问：地球引力和惯性离心力做的功**：
   在随地球自转的参考系中，托盘连同物资（总质量 \(m\)）沿半径方向慢速由 \(r_1 = R_e\) 升至 \(r_2 = R_e + L = (1 + \alpha) R_e\)。科里奥利力与光滑管壁支持力均垂直于径向位移，不做功。
   - 地球引力做功：
     \[
     W_G = \int_{R_e}^{(1+\alpha)R_e} \left(-\frac{G M_e m}{r^2}\right)\mathrm{d}r = -\frac{G M_e m}{R_e}\left(1 - \frac{1}{1+\alpha}\right) = -\frac{\alpha}{1 + \alpha} \frac{G M_e m}{R_e}
     \]
   - 惯性离心力做功：
     \[
     W_L = \int_{R_e}^{(1+\alpha)R_e} m \omega_e^2 r\,\mathrm{d}r = \frac{1}{2} m \omega_e^2 \left[(1+\alpha)^2 R_e^2 - R_e^2\right] = \frac{1}{2} m \omega_e^2 R_e^2 \alpha (\alpha + 2)
     \]

3. **第 2 问：外推力至少需要做多少正功**：
   审题核心在于**“正功”二字**：定义有效势能 \(U_{\text{eff}}(r) = -\frac{G M_e m}{r} - \frac{1}{2} m \omega_e^2 r^2\)。
   - 在同步轨道以内（\(R_e \le r < r_{\text{geo}}\)），引力大于离心力，\(U_{\text{eff}}(r)\) 随 \(r\) 单调递增，外推力必须向上推并做**正功**以助其翻越位于 \(r_{\text{geo}} = (G M_e / \omega_e^2)^{1/3}\) 的有效势能最高点（势垒）。
   - 一旦越过 \(r_{\text{geo}}\)（因 \(\alpha > \alpha_m\) 必经过此处），离心力大于引力，\(U_{\text{eff}}(r)\) 单调递减，物体在离心力净推力下自动加速向飞行器运动；即使为了“保持托盘运行速度不致过大”需要刹车减速，外力做的也是**负功**而非正功！
   因此，外推力所需做的最小正功恰等于把物资从地面 \(r = R_e\) 几乎静止地推到同步轨道势垒顶端 \(r_{\text{geo}}\) 处所需克服的势垒高度：
   \[
   W_{\min}^+ = U_{\text{eff}}(r_{\text{geo}}) - U_{\text{eff}}(R_e) = \left(-\frac{G M_e m}{r_{\text{geo}}} - \frac{1}{2} m \omega_e^2 r_{\text{geo}}^2\right) - \left(-\frac{G M_e m}{R_e} - \frac{1}{2} m \omega_e^2 R_e^2\right)
   \]
   利用 \(G M_e = \omega_e^2 r_{\text{geo}}^3\)，首项合并为 \(-\frac{3}{2} m (G M_e \omega_e)^{2/3}\)，故：
   \[
   W_{\min}^+ = \frac{G M_e m}{R_e} + \frac{1}{2} m \omega_e^2 R_e^2 - \frac{3}{2} m (G M_e \omega_e)^{2/3} = \frac{1}{2} m \omega_e^2 R_e^2 \alpha_m^2 (2\alpha_m + 3)
   \]

4. **第 3 问：引力与惯性离心力做功之和为零时的高度 \(L_0\)**：
   记 \(L_0 = \alpha_0 R_e\)，令 \(W_G + W_L = 0\)：
   \[
   -\frac{\alpha_0}{1+\alpha_0}\frac{G M_e m}{R_e} + \frac{1}{2}m\omega_e^2 R_e^2 \alpha_0(\alpha_0 + 2) = 0
   \]
   约去 \(\alpha_0 > 0\)，化为关于 \(\alpha_0\) 的二次方程：
   \[
   \alpha_0^2 + 3\alpha_0 + 2\left(1 - \frac{G M_e}{\omega_e^2 R_e^3}\right) = 0 \implies \alpha_0 = \frac{-3 + \sqrt{1 + \frac{8 G M_e}{\omega_e^2 R_e^3}}}{2}
   \]
   （舍去负根），故：
   \[
   L_0 = \frac{R_e}{2}\left(\sqrt{1 + \frac{8 G M_e}{\omega_e^2 R_e^3}} - 3\right)
   \]
   验证 \(L_0 > \alpha_m R_e\)：记 \(y = 1 + \alpha_m > 1\)，有 \(2y^3 > y^2 + y\)，故 \(1 + \alpha_0 > 1 + \alpha_m\) 恒成立。

5. **第 4 问：不输送物资时地面供应站对输送管的作用力**：
   输送管质量为 \(m_p\)，线密度匀质 \(\rho_l = \frac{m_p}{L}\)。当飞行器对管无作用力时，管上各微元 \(\mathrm{d}m = \rho_l \mathrm{d}r\) 受引力 \(-\frac{G M_e}{r^2}\mathrm{d}m\) 与离心力 \(+\omega_e^2 r\,\mathrm{d}m\)。利用微元积分与第 1 问功表达式的关系，整根管受到的向外（竖直向上）净体积力为：
   \[
   F_{\text{体}} = \int_{R_e}^{R_e + L} \rho_l \left(-\frac{G M_e}{r^2} + \omega_e^2 r\right)\mathrm{d}r = \frac{m_p}{m L}(W_G + W_L) = m_p \left[\frac{1}{2}\omega_e^2 R_e(\alpha + 2) - \frac{G M_e}{(1+\alpha) R_e^2}\right]
   \]
   设地面供应站对输送管的作用力以竖直向上（背离地心）为正，由静力平衡 \(F_{\text{站}\to\text{管}} + F_{\text{体}} = 0\) 得：
   \[
   F_{\text{站}\to\text{管}} = m_p \left[\frac{G M_e}{(1+\alpha) R_e^2} - \frac{1}{2}\omega_e^2 R_e (\alpha + 2)\right]
   \]
   结合第 3 问结果（\(W_G + W_L = 0 \iff L = L_0\)）分三种情形讨论：
   - **当 \(L > L_0\)（即 \(\alpha > \alpha_0\)）时**：净离心力超过净引力，管有飞向太空的趋势，故供应站对输送管的作用力大小 \(|F| = m_p\left[\frac{1}{2}\omega_e^2 R_e(\alpha+2) - \frac{G M_e}{(1+\alpha)R_e^2}\right]\)，方向**竖直向下（指向地心，拉住管道）**；
   - **当 \(L = L_0\) 时**：管所受净引力与净离心力精确平衡，作用力 \(F = 0\)；
   - **当 \(\alpha_m R_e < L < L_0\) 时**：净引力大于净离心力，管有下压地面趋势，作用力大小 \(|F| = m_p\left[\frac{G M_e}{(1+\alpha)R_e^2} - \frac{1}{2}\omega_e^2 R_e(\alpha+2)\right]\)，方向**竖直向上（背离地心，托住管道）**。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答 4 问结果完全一致！值得一提的是第 4 问求供应站作用力的方法对比：盲解通过质量积分并直接复用第 1 问的 \((W_G + W_L)\) 导出；而官方解答为了回避定积分，采用**虚功原理**——想象整根刚性管向下微移 \(\Delta l\)，等价于把顶端的微元段 \(\Delta m = m_p \Delta l / L\) 移到最底端 \(R_e\)，直接借用第 1 问公式写出 \(\Delta W_G + \Delta W_L + F_{\text{base}}\Delta l = 0\)，手法极为高妙！
- **核心难点**：
  - 难点1：第 2 问理解“至少需要做多少**正功**”与“总功 \(-(W_G+W_L)\)”的根本区别——即使 \(L > L_0\) 使全程有效势能净降低，推送物资仍必须先用正功翻越 \(r_{\text{geo}} = (1+\alpha_m)R_e\) 处的势能极大值峰顶。
  - 难点2：正确辨析题中 \(L = \alpha R_e\) 是**离地面高度**而非离地心距离（由 \(\alpha_m\) 表达式中的 \(-1\) 亦可验证），且 \(r\) 积分上下限为 \([R_e, (1+\alpha)R_e]\)。
- **高频易错点**：
  - 易错点1：第 2 问直接拿 \(-(W_G + W_L)\) 当作答案，在 \(L > L_0\) 时荒谬地算得所需正功为负数！
  - 易错点2：把“地面供应站对输送管的作用力”方向判反（\(L > L_0\) 时管要飘走，地面是向下拉管；学生常和“管对地面拉力向上”混淆）。
  - 易错点3：把 \(L\) 误当成到地心的距离，或在写管道长度与线密度时把 \(L\) 错写成 \((1+\alpha)R_e\)。
- **教练总结**：太空电梯问题集『地球自转非惯性势能极值』与『连续体虚功平衡』于一体。教给学生两条核心口诀：① 只要看到“至少需要做多少**正功**”，立刻画出势能曲线 \(U_{\text{eff}}(r)\) 找**最高势垒峰**；② 求均匀长杆/长管受非均匀力场作用时的总合外力，直接把**微元从一端移到另一端的势能差除以总长度**（即 \(F_{\text{体}} = \frac{\Delta W_{\text{单质点}}}{L}\frac{m_p}{m}\)），一秒免积分！

## 12. 决赛第4题 · 接地屏蔽球壳电阻梯形电路求导体球半径 (`cpho-2013-final-theory-problem-slice-q4`)

- **难度评级**：`D2`
- **核心物理模型**：稳恒直流分压电路与同心接地屏蔽球形电容器串并稳态电荷求解
- **教学标签**：`含容稳恒电路`、`同心球形电容器`、`静电屏蔽`、`等差数列求和`、`原理图极性勘误`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **同心球形电容器电容与静电屏蔽**：
   由于每个半径为 \(r\) 的导体球外都有内半径为 \(r_0\)（\(> r\)）的同心接地薄球壳包围（忽略小缺口影响），外球壳实现完全静电屏蔽（壳外电场为零），各导体球之间无互感电容。
   当第 \(i\) 个导体球（\(i = 1, 2, \dots, N+1\)）电势为 \(U_i\)、带电量为 \(Q_i\) 时，外球壳内表面感应电荷为 \(-Q_i\)，因外球壳接地（电势为零），由高斯定理求内外球壳电势差得：
   \[
   U_i = k Q_i \left(\frac{1}{r} - \frac{1}{r_0}\right) \implies C = \frac{1}{k\left(\frac{1}{r} - \frac{1}{r_0}\right)}
   \]

2. **电路稳态分析与电势分布（注意图上电池极性细节！）**：
   开关闭合达到稳态后，各电容支路断路（无电流流入导体球），直流电流仅沿底部电源、内阻 \(R_E\) 与串联的 \(N\) 个电阻 \(R\) 组成的闭合回路流动，电流大小为：
   \[
   I = \frac{E}{N R + R_E}
   \]
   仔细察看原题电路图：开关下方与电源 \(R_E\) 左侧的公共导线**接地**（\(\varphi = 0\)），因而开关闭合后第 \(1\) 号导体球直接接地，\(U_1 = 0\)。再细看图上电源 \(E\) 的符号：**长竖线（正极）在左，短粗线（负极）在右**！按此电源极性，电流 \(I\) 自正极向左经 \(R_E\)、向上过开关、再**向右**依次流经 \(N\) 个电阻 \(R\) 回到电源负极。因此沿电流方向电势逐级降低，第 \(i\) 号导体球的电势为：
   \[
   U_i = -(i - 1) I R = -\frac{(i - 1) E R}{N R + R_E} \qquad (i = 1, 2, \dots, N+1)
   \]
   由此所有球 \(i \ge 2\) 均带负电 \(Q_i = C U_i \le 0\)，总电量绝对值为（题中“所带的总电量为 \(Q\)”取正值大小）：
   \[
   Q = \left|\sum_{i=1}^{N+1} Q_i\right| = \frac{E R}{k\left(\frac{1}{r} - \frac{1}{r_0}\right)(N R + R_E)} \sum_{i=1}^{N+1} (i - 1) = \frac{N(N+1) E R}{2 k \left(\frac{1}{r} - \frac{1}{r_0}\right)(N R + R_E)}
   \]

3. **求解导体球半径 \(r\)**：
   由上式解出 \(\frac{1}{r} - \frac{1}{r_0}\)：
   \[
   \frac{1}{r} = \frac{1}{r_0} + \frac{N(N+1) E R}{2 k Q (N R + R_E)} \implies r = \left(\frac{1}{r_0} + \frac{N(N+1) E R}{2 k Q (N R + R_E)}\right)^{-1}
   \]

4. **极限自检**：
   - \(r_0 \to \infty\)（无屏蔽孤立球极限）：\(r \to \frac{2 k Q (N R + R_E)}{N(N+1) E R}\)。
   - 对任意 \(Q > 0\) 均自动保证 \(0 < r < r_0\)，量纲 \([k Q / E] = \text{m}\)，完全自洽。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解最终的半径表达式与官方参考解答式 `(8)` 完全一致！但对照过程揭露了一个**极其隐蔽的原卷插图与解答极性矛盾**：
  在官方解答式 `(6)` 中，直接写出了 \(U_i = +(i - 1)IR = +\frac{(i-1)ER}{NR+R_E} > 0\)，并取 \(Q = \sum Q_i > 0\)。然而放大查看原题插图，电源符号画的是**左长（正）右短（负）**，按该极性电流向左过内阻、向右过 \(N\) 个电阻 \(R\)，稳态节点电势只能是 \(U_i = -(i-1)IR \le 0\)（而非正值）！显然是命题组绘制电路图时把电池正负极画反了，却仍按左低右高写出 \(U_i = +(i-1)IR\)。只要理解 \(Q\) 代表总电荷量大小（或将电池右端视为正极），式 `(8)` 依然成立。
- **核心难点**：
  - 难点1：理解接地外球壳的『完全静电屏蔽』作用（内球与接地外壳构成独立同心球形电容器 \(U_i = k Q_i (\frac{1}{r} - \frac{1}{r_0})\)，且互不干扰）。
  - 难点2：理清梯形分压网络中稳态电容无电流（仅抵抗压降分配节点电势），并注意从 \(1\) 到 \(N+1\) 共 \(N+1\) 个球（其中 1 号球接地电势为零），有效项求和是 \(\sum_{i=1}^{N+1}(i-1) = \frac{N(N+1)}{2}\) 而非 \(\frac{(N+1)(N+2)}{2}\)。
- **高频易错点**：
  - 易错点1：算电容电势时忘记外接地壳的屏蔽项 \(-\frac{1}{r_0}\)，直接套用孤立球电势公式 \(U_i = k Q_i / r\)。
  - 易错点2：把 \(N+1\) 个球当成 \(N+1\) 个电阻，或者等差数列求和错算成 \(\frac{(N+1)(N+2)}{2}\) 或 \(\frac{N(N-1)}{2}\)。
  - 易错点3：因看清原图电池长短脚而算出负电量 \(Q_i < 0\) 后不敢直接代绝对值进公式（导致代入负 \(Q\) 时出现 \(r < 0\) 或 \(r > r_0\) 的异常结果）。
- **教练总结**：在含电容稳恒直流电路题中，标准解题顺序是『① 断电容支路求稳态回路电流；② 选接地点为零电势点顺/逆电流标出各电容极板电势；③ 用 \(Q_i = C_i (U_i - U_{\text{壳}})\) 统一求和』。遇到实物图电源长短极与直觉矛盾时，先用“电荷量大小 \(|Q|\)”做自检总能化险为夷。

## 13. 决赛第5题 · 柱对称非均匀磁场中超导细圆环的简谐运动与电流变化 (`cpho-2013-final-theory-problem-slice-q5`)

- **难度评级**：`D3`
- **核心物理模型**：磁通量守恒（超导零电阻环）驱动的磁悬浮简谐振动与安培力线性化动力学
- **教学标签**：`超导磁通量守恒`、`柱对称非均匀磁场`、`安培力受力积分`、`简谐运动`、`电磁自洽耦合`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **磁场散度自洽性与磁通量守恒**：
   首先检验所给磁场分布是否满足 \(\nabla\cdot\vec{B} = 0\)：
   \[
   \frac{1}{r}\frac{\partial (r B_r)}{\partial r} + \frac{\partial B_z}{\partial z} = \frac{1}{r}(2 B_0 \alpha r) - 2 B_0 \alpha = 0
   \]
   满足！因电流正向与 \(+z\)（竖直向上）满足右手螺旋定则，任意位置 \(z\) 处穿过超导圆环（半径 \(r_0\)、自感 \(L\)、电流 \(I\)）的向上总磁通量为外磁场通量与自感通量之和：
   \[
   \Phi(z, I) = \pi r_0^2 B_z(z) + L I = \pi r_0^2 B_0 (1 - 2\alpha z) + L I
   \]
   由超导环磁通量守恒 \(\Phi(t) = \Phi(0)\)（初态 \(z = 0, I = I_0\)）：
   \[
   \pi r_0^2 B_0 (1 - 2\alpha z) + L I = \pi r_0^2 B_0 + L I_0 \implies I(z) = I_0 + \frac{2 \pi r_0^2 B_0 \alpha}{L} z
   \]

2. **第 1 问：圆环运动性质及 \(z(t)\) 表达式**：
   对圆环上电流微元 \(I\,\mathrm{d}\vec{l}\)（沿 \(\hat{e}_\theta\) 方向）求安培力 \(\mathrm{d}\vec{F}_A = I\,\mathrm{d}\vec{l}\times\vec{B}\)：
   由于 \(\hat{e}_\theta \times \hat{e}_z = \hat{e}_r\) 沿圆周对称积分抵消，而 \(\hat{e}_\theta \times \hat{e}_r = -\hat{e}_z\)，故合力沿 \(z\) 轴方向：
   \[
   F_{A,z} = -2\pi r_0 I B_r(r_0) = -2\pi r_0^2 B_0 \alpha I
   \]
   代入 \(I(z)\) 并计入重力 \(-mg\)，得圆环所受竖直总合力为：
   \[
   F_z(z) = -2\pi r_0^2 B_0 \alpha \left(I_0 + \frac{2\pi r_0^2 B_0 \alpha}{L} z\right) - m g = -k z - (m g + F_0)
   \]
   其中等效劲度系数 \(k = \frac{4\pi^2 \alpha^2 B_0^2 r_0^4}{L}\)，初始磁力大小偏置 \(F_0 = 2\pi \alpha B_0 r_0^2 I_0\)。
   这表明圆环作**简谐运动**！平衡位置与振动角频率分别为：
   \[
   z_0 = -\frac{m g + F_0}{k} = -\frac{(m g + 2\pi\alpha B_0 r_0^2 I_0) L}{4\pi^2 \alpha^2 B_0^2 r_0^4}, \qquad \omega = \sqrt{\frac{k}{m}} = \frac{2\pi \alpha B_0 r_0^2}{\sqrt{m L}}
   \]
   （题目说“释放后向下运动”，隐含 \(z_0 < 0\)，即释放点 \(z = 0\) 在平衡位置上方。）结合初始条件 \(z(0) = 0, \dot{z}(0) = 0\)，解得：
   \[
   z(t) = z_0 (1 - \cos\omega t) = \frac{(m g + 2\pi \alpha B_0 r_0^2 I_0) L}{4\pi^2 \alpha^2 B_0^2 r_0^4}\left[\cos\left(\frac{2\pi \alpha B_0 r_0^2}{\sqrt{m L}}t\right) - 1\right]
   \]

3. **第 2 问：\(t\) 时刻圆环中电流 \(I(t)\)**：
   将 \(z(t)\) 回代 \(I(z) = I_0 + \frac{2\pi r_0^2 B_0 \alpha}{L} z\)：
   \[
   I(t) = I_0 + \left(\frac{m g}{2\pi\alpha B_0 r_0^2} + I_0\right)\left[\cos\left(\frac{2\pi\alpha B_0 r_0^2}{\sqrt{m L}}t\right) - 1\right] = \left(I_0 + \frac{m g}{2\pi\alpha B_0 r_0^2}\right)\cos\left(\frac{2\pi\alpha B_0 r_0^2}{\sqrt{m L}}t\right) - \frac{m g}{2\pi\alpha B_0 r_0^2}
   \]

4. **物理自检**：
   - \(t = 0\) 时，\(z(0) = 0, I(0) = I_0\)。
   - 在平衡位置（\(\cos\omega t = 0\)）时，\(I_{\text{eq}} = -\frac{mg}{2\pi\alpha B_0 r_0^2}\)，此时 \(F_{A,z} = +mg\) 恰好悬浮平衡重力（与初电流 \(I_0\) 无关）！
   - 量纲检验：\(\omega = \frac{2\pi\alpha B_0 r_0^2}{\sqrt{mL}}\) 单位为 \(\frac{\text{m}^{-1}\cdot\text{T}\cdot\text{m}^2}{\sqrt{\text{kg}\cdot\text{H}}} = \text{s}^{-1}\)，完全正确。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答从头至尾完全一致，包括安培力符号、\(z_0\)、\(\omega\)、\(z(t)\) 以及电流 \(I(t)\) 的两项形式。盲解中另增的『能量守恒 \(\frac{1}{2}m\dot{z}^2 + mgz + \frac{1}{2}LI^2 = \text{const}\)』与『平衡点电流 \(I_{\text{eq}}\) 与 \(I_0\) 无关』校验进一步巩固了电磁耦合的物理图像。
- **核心难点**：
  - 难点1：准确把握电流方向、右手定则与柱坐标 \(\hat{e}_\theta \times \hat{e}_r = -\hat{e}_z\) 的符号关系，判断出 \(I > 0\) 时径向向外磁场 \(B_r > 0\) 产生**向下**的吸引安培力（反之 \(I < 0\) 抗磁排斥向上）。
  - 难点2：正确计入重力 \(-mg\) 对平衡位置 \(z_0\) 和振荡振幅的影响。
- **高频易错点**：
  - 易错点1：安培力叉乘方向搞反（错写成 \(F_A = + B_r I \cdot 2\pi r_0\)），直接导致还原力变成排斥发散力（指数发散而非简谐运动）。
  - 易错点2：忘记在牛顿第二定律中计入重力 \(mg\)，错得平衡位置为 \(z_0 = -\frac{L I_0}{2\pi\alpha B_0 r_0^2}\)（并在 \(I_0 = 0\) 时误以为不运动）。
  - 易错点3：磁通量守恒漏写自感磁通 \(L I\)，或把自感系数 \(L\) 错当成位置 \(z\) 的函数，亦或把初条件写成 \(z(t) = A\sin\omega t\)（正确为初速为零余弦振荡）。
- **教练总结**：超导环悬浮问题是电磁学中少有的『既可用微分动力学（安培力 + \(F = -kz\)）解，又可直接用能量函数 \(U(z) = mgz + \frac{1}{2L}(\Phi_0 - \pi r_0^2 B_z(z))^2\) 对 \(z\) 求导秒解』的典范！只要写出 \(U(z)\)，无需判断 \(\hat{e}_\theta \times \hat{e}_r\) 也能一次得出回复力与振动频率，零出错率！

## 14. 决赛第6题 · 太阳直射薄金属盘双表面稳定温度分布 (`cpho-2013-final-theory-problem-slice-q6`)

- **难度评级**：`D2`
- **核心物理模型**：一维稳态傅里叶热传导与牛顿冷却定律串联热阻网络
- **教学标签**：`稳态热传导`、`牛顿冷却定律`、`热阻串联网络`、`守恒不变量`、`有效数字规范`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **热功率平衡方程**：
   设金属盘表面面积为 \(A\)，热导率为 \(\kappa\)，每个表面对空气（温度 \(T_0 = 300.0\text{ K}\)）的对流/牛顿散热比例系数为 \(c\)。当盘厚度为 \(t\) 时，稳态下上表面温度 \(T_t = 360.0\text{ K}\)，下表面温度 \(T_b = 340.0\text{ K}\)。
   忽略侧面热损，设太阳直射使上表面单位时间吸收的恒定辐射功率为 \(P_a\)（与盘厚度无关）。
   - **整体功率平衡**（吸收等于双面总散热）：
     \[
     P_a = c A (T_t - T_0) + c A (T_b - T_0) \implies T_t + T_b = \frac{P_a}{c A} + 2 T_0 = \text{const}
     \]
     由初始数据得恒定温度和：
     \[
     T_t + T_b = 360.0\text{ K} + 340.0\text{ K} = 700.0\text{ K}
     \]
   - **下表面散热与体内热传导平衡**（从上到下传导的热流全部由下表面散给空气）：
     \[
     \kappa A \frac{T_t - T_b}{t} = c A (T_b - T_0)
     \]
     定义无量纲导热/散热比（毕奥数倒数） \(\beta \equiv \frac{\kappa}{c t}\)，则由初态得：
     \[
     \beta = \frac{T_b - T_0}{T_t - T_b} = \frac{340.0 - 300.0}{360.0 - 340.0} = \frac{40.0}{20.0} = 2.0
     \]

2. **厚度加倍后的稳态温度**：
   当厚度增至 \(t' = 2t\) 时，无量纲参数减半为 \(\beta' = \frac{\kappa}{c(2t)} = \frac{\beta}{2} = 1.0\)。设新稳态上下表面温度为 \(T_t', T_b'\)，满足：
   \[
   T_t' + T_b' = 700.0\text{ K}, \qquad \beta'(T_t' - T_b') = T_b' - T_0 \implies 1.0 \cdot (T_t' - T_b') = T_b' - 300.0\text{ K}
   \]
   故 \(T_t' = 2 T_b' - 300.0\text{ K}\)，代入温度和方程：
   \[
   (2 T_b' - 300.0\text{ K}) + T_b' = 700.0\text{ K} \implies 3 T_b' = 1000.0\text{ K} \implies T_b' = \frac{1000.0}{3}\text{ K} \approx 333.3\text{ K}
   \]
   \[
   T_t' = 700.0\text{ K} - T_b' = \frac{1100.0}{3}\text{ K} \approx 366.7\text{ K}
   \]

3. **极限检验**：
   厚度翻倍使体内热阻翻倍，更少热量传导至下表面，因此上表面变热（\(360.0 \to 366.7\text{ K}\)）、下表面变冷（\(340.0 \to 333.3\text{ K}\)），而均值保持 \(350.0\text{ K}\) 不变，物理直观极其合理。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答完全一致，均得出 \(T_b' \approx 333.3\text{ K}\)、\(T_t' \approx 366.7\text{ K}\)。官方解答用式 `(6)` 除以式 `(7)` 直接消去 \(\kappa/c\) 得出关于 \(T_b'\) 的方程；盲解引入无量纲参数 \(\beta = \frac{\kappa}{ct}\) 后变为简明心算级代数。唯一小瑕疵是官方解答末式 `(11)` 写了 `700 - T_b'` 漏了一位小数零（而前文式 `(4)` 与 `(8)` 均严谨写作 `700.0 K`）。
- **核心难点**：
  - 难点1：识别『太阳吸收热功率 \(P_a\) 恒定』与『双表面牛顿散热规律相同』这两个条件联立导出**双面温度和 \(T_t + T_b\) 守恒**。
  - 难点2：区分内部热传导（反比于厚度 \(t\)）与表面对流散热（与厚度无关），正确构建上下表面温度耦合方程。
- **高频易错点**：
  - 易错点1：误以为上下表面温差与厚度严格成正比（即错算 \(T_t - T_b\) 从 \(20\text{ K}\) 直接翻倍成 \(40\text{ K}\)，得 \(370\text{ K}\) 和 \(330\text{ K}\)）！其实这是串联热阻分压——内热阻加倍后总热阻变大，通过下表面的热流本身减小了，故温差只从 \(20\text{ K}\) 增至 \(33.3\text{ K}\)（即 \(1/3\) 倍总数变化）。
  - 易错点2：漏掉上表面本身也向空气散热，错写 \(P_a = \kappa A (T_t - T_b)/t\)（把全部太阳能量都算成向下传导）。
  - 易错点3：未能保留四位有效数字（与题目 \(300.0, 360.0, 340.0\text{ K}\) 保持一致）。
- **教练总结**：一切一维稳态导热题都可以直接画成**直流等效电阻网络**：温度类比电压，热流功率类比电流，金属盘内热阻 \(R_{\text{cond}} = \frac{t}{\kappa A}\)，上下表面散热热阻各为 \(R_{\text{conv}} = \frac{1}{cA}\)，太阳供热则是注入上节点的恒流源 \(P_a\)！用电路分流一算就出：下支路电流比例从 \(\frac{1}{1+2} = \frac{1}{3}\) 变成 \(\frac{1}{1+2\times 1} = \frac{1}{3}\)? 不对，上表面支路电导 \(G_0 = cA\)，经金属+下表面串联支路总热阻 \(R_{\text{down}} = R_{\text{cond}} + R_0 = \frac{t}{\kappa A} + \frac{1}{cA} = \frac{1}{cA}(1 + \frac{1}{\beta})\)。初态 \(\beta=2 \implies R_{\text{down}} = \frac{3}{2} R_0\)，所以上表面散热占 \(\frac{3}{5}\)、下表面占 \(\frac{2}{5}\)（\(60:40\)）；厚加倍后 \(\beta'=1 \implies R_{\text{down}}' = 2 R_0\)，上下散热比直接变成 \(2:1\)（\(66.7:33.3\)），心算秒出！

## 15. 决赛第7题 · 激光双光束柱面反射虚像与亚毫米细丝直径干涉测量 (`cpho-2013-final-theory-problem-slice-q7`)

- **难度评级**：`D4`
- **核心物理模型**：圆柱面镜 \(45^\circ\) 斜入射子午面反射虚像定位与远场双虚光源等效杨氏双缝干涉
- **教学标签**：`柱面镜斜入射成像`、`光学虚像定位`、`一阶小角微扰`、`杨氏双缝干涉`、`费马原理相干相位校核`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第 1 问：上、下两侧反射细光束形成的两个虚像位置**：
   设细丝半径为 \(R = d/2\)，轴线在原点 \(O(0, 0)\)。考察上侧（\(y > 0, z > 0\)）沿 \(-y\) 方向垂直下落的平行细光束，以入射角 \(\theta_1\) 射到柱面 \(A_1(z_1, y_1) = (R\sin\theta_1, R\cos\theta_1)\) 处。
   由反射定律，入射光线方向角为 \(-\pi/2\)，法线外向方位角为 \(\pi/2 - \theta_1\)，故反射光线与 \(+z\) 轴夹角为 \(\beta = \frac{\pi}{2} - 2\theta_1\)。令 \(\theta_1 = \frac{\pi}{4} + \delta\)（\(|\delta| \ll 1\)），利用题给近似 \(\sin\delta \approx \delta, \cos\delta \approx 1\)，保留到 \(\delta\) 一阶项：
   \[
   z_1 = R\sin\left(\frac{\pi}{4}+\delta\right) \approx \frac{R}{\sqrt{2}}(1 + \delta), \quad y_1 = R\cos\left(\frac{\pi}{4}+\delta\right) \approx \frac{R}{\sqrt{2}}(1 - \delta), \quad \tan\beta = -\tan(2\delta) \approx -2\delta
   \]
   写出反射光线的直线方程 \(y - y_1 = \tan\beta (z - z_1)\) 并保留至 \(O(\delta)\)：
   \[
   y - \frac{R}{\sqrt{2}}(1 - \delta) \approx -2\delta \left[z - \frac{R}{\sqrt{2}}(1 + \delta)\right] \implies y \approx \frac{R}{\sqrt{2}} + \delta\left(\frac{R}{\sqrt{2}} - 2z\right)
   \]
   由于该族（所有微小 \(\delta\)）反射光线及其反向延长线共同汇交于与 \(\delta\) 无关的定点，令 \(\delta\) 的系数为零即可一步锁定上侧虚像位置（以 \(d = 2R\) 表出）：
   \[
   z_+ = \frac{R}{2\sqrt{2}} = \frac{\sqrt{2}}{8} d, \qquad y_+ = \frac{R}{\sqrt{2}} = \frac{\sqrt{2}}{4} d
   \]
   （或者用科丁顿切向反射焦距公式检验：半径 \(R\) 凸柱面镜在 \(i = 45^\circ\) 处的切向焦距 \(f_t = -\frac{R\cos 45^\circ}{2} = -\frac{R}{2\sqrt{2}}\)，自反射点 \(\left(\frac{R}{\sqrt{2}}, \frac{R}{\sqrt{2}}\right)\) 沿 \(-z\) 后退 \(|f_t|\) 即得 \(\left(\frac{R}{2\sqrt{2}}, \frac{R}{\sqrt{2}}\right)\)，完全吻合！）
   由上下对称性（\(y \to -y\)），下侧入射角 \(45^\circ\) 附近反射光束形成的虚像位置为：
   \[
   z_- = \frac{\sqrt{2}}{8} d, \qquad y_- = -\frac{\sqrt{2}}{4} d
   \]

2. **第 2 问：严密验证等效双缝干涉并求细丝直径 \(d\)**：
   不可直接不加检验地把虚像当成等相位波源——**必须验证入射线在到达柱面前走过的高度差 \((y_0 - y_1)\) 不会破坏有效缝距**！
   计算从固定上波面 \(y = y_0\) 到屏上点 \(P(D, Y)\)（其中 \(D \gg d, Y\)）的光程 \(L_1\)：
   \[
   L_1(\delta) = (y_0 - y_1) + \sqrt{(D - z_1)^2 + (Y - y_1)^2} \approx (y_0 - y_1) + (D - z_1) + \frac{(Y - y_1)^2}{2 D}
   \]
   注意到反射光线过 \((D, Y)\) 与虚像 \((z_+, y_+)\) 决定 \(Y - y_+ \approx -2\delta D\)，将 \(y_1, z_1\) 一阶展开式代入：
   \[
   L_1 \approx y_0 + D - \frac{R}{\sqrt{2}}(1-\delta) - \frac{R}{\sqrt{2}}(1+\delta) + \frac{(Y - y_+)^2}{2 D} = (y_0 + D - \sqrt{2} R) + \frac{(Y - y_+)^2}{2 D}
   \]
   **一阶项 \(+\frac{R}{\sqrt{2}}\delta\) 与 \(-\frac{R}{\sqrt{2}}\delta\) 精确对消！**（实质也是费马原理 \(\frac{\mathrm{d}L_1}{\mathrm{d}Y} = \sin\beta \approx \frac{Y-y_+}{D}\) 的体现。）同理可得下光束光程 \(L_2 = \text{const} + \frac{(Y - y_-)^2}{2D}\)。作差得：
   \[
   L_2 - L_1 = \text{const} + \frac{(Y - y_-)^2 - (Y - y_+)^2}{2 D} = \text{const} + \frac{y_+ - y_-}{D} Y = \text{const} + \frac{d}{\sqrt{2} D} Y
   \]
   可见该系统严格等效于缝距 \(\Delta y = y_+ - y_- = \frac{\sqrt{2}}{2} d\)、到屏距离 \(D - z_+ \approx D\) 的双缝干涉！由条纹间距 \(a = \frac{\lambda D}{\Delta y} = \frac{\sqrt{2}\lambda D}{d}\)，解得细丝直径：
   \[
   d = \frac{\sqrt{2} \lambda D}{a}
   \]

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答两问结果完全一致：\(y_\pm = \pm\frac{\sqrt{2}}{4}d, z_\pm = \frac{\sqrt{2}}{8}d\) 以及 \(d = \frac{\sqrt{2}\lambda D}{a}\)。而且我们的盲解在解法简洁性与物理严密性上都有显著提升：
  1. **求虚像位置的方法对比**：官方解答主体解法先延长 \(P_+ B_+\) 交 \(y\) 轴于 \(E\)，再利用 \(\triangle EOP_+\) 等腰关系与直角 \(\triangle EQF\)（以及“另解二”中的弧长 \(PP_+ = r\Delta\theta\) 与相似三角形 \(\triangle EQF \sim \triangle EQ_+P_+\)）反复做纯平面几何推算，容易算乱；而盲解直接写出反射光线解析方程并一阶展开令 \(\delta\) 系数为零，3 行直出交点坐标，极具通法优势（或直接套用凸球面斜入射子午焦距 \(f_t = -\frac{R\cos i}{2}\)）。
  2. **第 2 问相干性严谨度**：官方解答在得到两个虚像位置后直接断言“可视为双缝干涉”，未检验入射波面在 \(y_1\) 处的高度变化是否影响条纹间距 \(a\)。盲解补全了至 \(O(\delta^2)\) 的光程差展开，严格证明了光程变化中的一阶 \(\delta\) 项正负相消，从而证实了双虚光源确实仅引入恒定初始位相差、不改变等效狭缝间距 \(\frac{\sqrt{2}}{2}d\)。
- **核心难点**：
  - 难点1：圆柱面斜入射（\(45^\circ\) 附近）不像正入射那样虚像距离顶点为 \(R/2\)，而受制于切向投影，在反射面内的子午焦距缩短为 \(\frac{R\cos 45^\circ}{2} = \frac{d}{4\sqrt{2}}\)。
  - 难点2：确定等效双缝间距是两虚像在 \(y\) 轴上的垂直距离 \(y_+ - y_- = \frac{\sqrt{2}}{2}d\)（而非两反射点沿直径方向的斜距，更不是直径 \(d\) 本身！）。
- **高频易错点**：
  - 易错点1：把 \(45^\circ\) 斜入射套用近轴正入射虚像距公式 \(|f| = R/2 = d/4\)，错误得出 \(z_+ = \frac{\sqrt{2}}{4}d - \frac{d}{4}\) 等畸形坐标，或干脆把两反射点直接当双缝，得出 \(d = \sqrt{2}\lambda D / a\) 看似对却用错理由、甚至直接误取 \(d\) 为缝距漏掉 \(\sqrt{2}\)。
  - 易错点2：将入射角 \(\theta_1 = 45^\circ + \Delta\theta\) 时反射光线转角误算成 \(\Delta\theta\)（漏掉反射镜偏转引起的 **2 倍转角** \(2\Delta\theta\)），直接导致 \(z_+\) 算大一倍变为 \(\frac{\sqrt{2}}{4}d\)。
  - 易错点3：算双缝干涉距离时保留或错用了不对应的几何量，忽略了“\(D\) 远大于细丝直径”的条件。
- **教练总结**：处理曲面镜斜入射细光束的成像定位，**解析几何一阶展开法**（写出光线方程 \(y - y(\delta) = k(\delta)[z - z(\delta)]\)，展开至 \(\delta\) 一阶项并令 \(\delta\) 系数为零）是比拼凑平面几何辅助线稳健百倍的通用大杀器；且每当用到虚像替代真实波源算干涉时，都要用费马原理（一阶极值相消）检查入射光程随 \(\delta\) 的变化是否确实与出射段一阶抵消！

## 16. 决赛第8题 · 相对论同时性接力拍手（张、王、李三同学时空事件链） (`cpho-2013-final-theory-problem-slice-q8`)

- **难度评级**：`D3`
- **核心物理模型**：狭义相对论时间膨胀与不同惯性系“同时性相对性”的等比时空事件递推链
- **教学标签**：`狭义相对论`、`同时性的相对性`、`时间膨胀`、`原时与坐标时`、`几何级数时空链`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第 1 问：张同学第一次拍手时的随身时钟读数**：
   以地面（李同学）为参考系 \(S\)，三人相遇校准零时刻的事件设为时空原点 \((t=0, x=0)\)。张向右以 \(+v\) 运动（\(x_Z = v t\)），王向左以 \(-v\) 运动（\(x_W = -v t\)）。记 \(\beta = \frac{v}{c}\)，\(\gamma = \frac{1}{\sqrt{1 - \beta^2}}\)。
   地面观察两者距离为 \(L\) 时，地面时刻为 \(2 v t_1 = L \implies t_1 = \frac{L}{2v}\)。
   因张同学始终处于其自身静止系 \(S_Z\) 原点，从相遇至首次拍手（事件 \(Z_1\)）间隔在 \(S_Z\) 系中同地发生，为原时（固有时），由时间膨胀得张同学随身时钟读数：
   \[
   T \equiv \tau_{Z,1} = \frac{t_1}{\gamma} = \frac{L}{2v}\sqrt{1 - \beta^2}
   \]

2. **第 2 问：交替同时拍手链与张第 \(n\) 次拍手时的地面间距**：
   先求张、王两系之间的相对洛伦兹因子 \(\gamma_r\)。由题给相对速率 \(v_r = \frac{2\beta c}{1 + \beta^2}\)（即 \(\beta_r = \frac{2\beta}{1+\beta^2}\)）：
   \[
   \gamma_r = \frac{1}{\sqrt{1 - \beta_r^2}} = \frac{1}{\sqrt{1 - \dfrac{4\beta^2}{(1+\beta^2)^2}}} = \frac{1 + \beta^2}{1 - \beta^2}
   \]
   逐级追踪事件链（利用张、王互相观察对方时钟变慢，或用洛伦兹变换独立验算）：
   - 事件 \(Z_1\)（张第 1 次拍手）：张时钟读数 \(\tau_{Z,1} = T\)。
   - 事件 \(W_1\)（在王系 \(S_W\) 看与 \(Z_1\) 同时，王第 1 次拍手）：在 \(S_W\) 看张的时钟走慢了 \(\gamma_r\) 倍，故 \(Z_1\) 在 \(S_W\) 中发生的时刻（即王的随身时钟读数）为：
     \[
     \tau_{W,1} = \gamma_r \tau_{Z,1} = \gamma_r T
     \]
     （用地面到王系的洛伦兹变换 \(t_W = \gamma(t + vx/c^2)\) 代入 \(Z_1: (t=\frac{L}{2v}, x=\frac{L}{2})\) 验算：\(t_W = \gamma\frac{L}{2v}(1+\beta^2) = \frac{1+\beta^2}{1-\beta^2}\cdot \frac{L}{2v}\sqrt{1-\beta^2} = \gamma_r T\)，完全一致！）
   - 事件 \(Z_2\)（在张系 \(S_Z\) 看与 \(W_1\) 同时，张第 2 次拍手）：同理在 \(S_Z\) 看王的时钟走慢 \(\gamma_r\) 倍，故：
     \[
     \tau_{Z,2} = \gamma_r \tau_{W,1} = \gamma_r^2 T
     \]
   - 照此递推，张第 \(n\) 次拍手（事件 \(Z_n\)）时其随身时钟读数为：
     \[
     \tau_{Z,n} = \gamma_r^{2n - 2} T = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2n-2} \frac{L}{2v}\sqrt{1 - \beta^2}
     \]
   - 而王第 \(n\) 次拍手（事件 \(W_n\)）时其随身时钟读数为：
     \[
     \tau_{W,n} = \gamma_r^{2n - 1} T = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2n-1} \frac{L}{2v}\sqrt{1 - \beta^2}
     \]
   回到地面参考系 \(S\)（李同学系）：在事件 \(Z_n\) 时，张的时钟读数为 \(\tau_{Z,n}\)，张相对地面以速率 \(v\) 运动，故地面时钟读数为：
   \[
   t_{Z,n} = \gamma \tau_{Z,n} = \gamma_r^{2n-2} t_1 = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2n - 2} \frac{L}{2v}
   \]
   此时在地面系中，张、王同学之间的距离为：
   \[
   D_n = 2 v t_{Z,n} = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2n - 2} L
   \]

3. **第 3 问：在李同学（地面系）看来各次拍手的时刻与顺序**：
   由地面系时间膨胀关系 \(t_{Z,n} = \gamma \tau_{Z,n}\) 与 \(t_{W,n} = \gamma \tau_{W,n}\)（因张、王相对地面速率均为 \(v\)），得到李同学系中依次拍手的时刻（记全部事件按发生顺序编号为 \(k = 1, 2, 3, \dots\)，其中奇数 \(k = 2n-1\) 对应张第 \(n\) 次拍手，偶数 \(k = 2n\) 对应王第 \(n\) 次拍手）：
   \[
   t_{Z,n} = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2n - 2} \frac{L}{2v}, \qquad t_{W,n} = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2n - 1} \frac{L}{2v} \qquad (n = 1, 2, 3, \dots)
   \]
   即统一通项为 \(t_k = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{k - 1} \frac{L}{2v}\)（\(k = 1, 2, 3, \dots\)）。
   由于 \(0 < \beta < 1\)（注意张、王已分开至距离 \(L\)，必有 \(v > 0\)），公比 \(\gamma_r = \frac{1+\beta^2}{1-\beta^2} > 1\)，故在李同学参考系中这些时刻呈严格递增顺序：
   \[
   t_{Z,1} < t_{W,1} < t_{Z,2} < t_{W,2} < \dots < t_{Z,n} < t_{W,n} < \dots
   \]
   即按“张1、王1、张2、王2、\(\dots\)、张 \(n\)、王 \(n\)、\(\dots\)”的顺序依次发生。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解与官方参考解答全部结论完全一致，包括 \(T = \frac{L}{2v}\sqrt{1-\beta^2}\)、\(d_n = \left(\frac{1+\beta^2}{1-\beta^2}\right)^{2(n-1)} L\) 以及地面系时刻通项与严格递增顺序 \(t_1 < t_2 < t_3 < \dots\)。同时对照中还发现两处官方表达上的小瑕疵：
  1. **官方文本一处下标笔误**：在第 12 页官方解答说明事件 1 在王系 \(S''\) 中并非发生于王所在处时，写成了“而在 \(x_2'' \ne 0\)”（应当是事件 1 的坐标 \(x_1'' \ne 0\)，因为 \(x_2'' = 0\) 才是王所在的事件 2！）。
  2. **第 3 问通项覆盖完整性**：官方解答式 `(13)` 只写出了奇数项 \(t_{2n-1}\) 而省去了偶数项 \(t_{2n}\)，盲解给出的 \(t_{Z,n}, t_{W,n}\) 双通项与统一序列 \(t_k = \gamma_r^{k-1}\frac{L}{2v}\) 更加清晰完备。
- **核心难点**：
  - 难点1：理清**同时性传递链中的“时间膨胀方向”**——当“在王系看 \(W_1\) 与 \(Z_1\) 同时”时，是在王系看张的钟走慢，故王的钟读数 \(\tau_{W,1} = \gamma_r \tau_{Z,1}\) 反而**大于**张的钟读数（不是乘以 \(\gamma_r^{-1}\)！）。这是整个狭义相对论教学中最反直觉也最核心的一步。
  - 难点2：分清不同惯性系中的原时与坐标时：\(Z_1\) 对张是原时，对王和李只是坐标时（非同地发生），必须用各人各自的世界线结合时间膨胀（或洛伦兹变换）回到地面系。
- **高频易错点**：
  - 易错点1：把『在 \(S_W\) 系看来张的钟走慢了』误算成 \(\tau_{W,1} = \tau_{Z,1} / \gamma_r\)（搞反时间膨胀的乘除方向），导致公比变成 \(1/\gamma_r < 1\)、时间反而越拍越早甚至倒流！
  - 易错点2：忘记算相对洛伦兹因子 \(\gamma_r = \frac{1+\beta^2}{1-\beta^2}\)，误以为张、王之间的时间膨胀因子仍是 \(\gamma = \frac{1}{\sqrt{1-\beta^2}}\) 或 \(2\gamma\)。
  - 易错点3：在求地面间距 \(D_n\) 时忘了把张的原时 \(\tau_{Z,n}\) 先乘以 \(\gamma\) 变回地面坐标时 \(t_{Z,n}\)（直接写成 \(2v \tau_{Z,n}\) 而多留了一个 \(\sqrt{1-\beta^2}\)）。
- **教练总结**：处理“相对论接力同步”（类似双生子悖论中的双向信号/同时性跳变），有一条绝对防呆的校验口诀：**谁在观察，谁的坐标时就比被观察者的运动原时大 \(\gamma_{\text{rel}}\) 倍**；而且最稳妥的办法是用同一套**地面系洛伦兹变换**（或闵可夫斯基时空图上的等时线斜率 \(\pm\beta\)）一步步画阶梯，既能秒判顺序 \(t_1 < t_2 < t_3 < \dots\)，又绝不会把 \(\gamma_r\) 乘除颠倒！
