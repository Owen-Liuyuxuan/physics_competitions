# 复赛理论试题（Semifinal Theory）

## 1. 失重液滴的表面张力脉动频率与量纲分析 (`cpho-2014-semifinal-theory-problem-slice-q1`)

- **难度评级**：`D1`
- **物理模型**：流体力学 · 无重力自由液滴表面张力小振动与瑞利量纲标度律
- **教学标签**：`量纲分析法`、`表面张力与球形极小曲面`、`天宫一号太空授课`、`瑞利液滴振动标度律`、`白金汉Pi定理思想`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **平衡态形状**：
   完全失重状态下，重力场等价消失，液滴表面仅存在表面张力。设液滴体积 \(V\) 恒定、表面积为 \(S\)、表面张力系数为 \(\sigma\)，其表面能为 \(E_s = \sigma S\)。依据等周不等式，体积一定时球体的表面积最小，能量最低，因此液滴处于平衡状态时的形状为**球形**。

2. **决定振动频率 \(f\) 的主要物理量**：
   将不可压缩、低黏滞液滴的微小“脉动”视为保守系统的简谐小振动：
   - 恢复力来自表面张力（偏离球形使表面积增加 \(\Delta S \sim (\delta r)^2\)，表面能增量 \(\Delta E_s \sim \sigma (\delta r)^2\)，对应等效劲度系数 \(k_{\text{eff}} \sim \sigma\)）；
   - 惯性来自液滴的质量（动能 \(E_k \sim \frac{1}{2} m \dot{r}^2\)，其中 \(m = \frac{4}{3}\pi\rho r^3\)）。
   若取三个相互独立的主要物理量（呼应第（3）问提示中的 \(a, b, c\)），应为：**液滴的（平衡）半径 \(r\)、液体密度 \(\rho\) 和表面张力系数 \(\sigma\)**（注：亦可等效表述为液滴质量 \(m\) 与表面张力系数 \(\sigma\)）。（忽略微弱的空气阻力及液体黏滞系数 \(\eta\) 的阻尼修正，且不涉及重力加速度 \(g\)）。

3. **量纲分析推导频率关系式**：
   设
   \[
   f = k\, r^\alpha \rho^\beta \sigma^\gamma,
   \]
   其中 \(k\) 为无量纲常数。写出各物理量在基本量纲 \(L, M, T\) 下的量纲：
   \[
   [f] = T^{-1}, \quad [r] = L, \quad [\rho] = M L^{-3}, \quad [\sigma] = \frac{\text{N}}{\text{m}} = \frac{\text{kg}\cdot\text{m}\cdot\text{s}^{-2}}{\text{m}} = M T^{-2}.
   \]
   代入幂律形式要求两边量纲一致：
   \[
   T^{-1} = L^\alpha (M L^{-3})^\beta (M T^{-2})^\gamma = L^{\alpha - 3\beta} M^{\beta + \gamma} T^{-2\gamma}.
   \]
   由于力学中 \(L, M, T\) 相互独立，比较各指数得：
   \[
   \begin{cases}
   -2\gamma = -1,\\
   \beta + \gamma = 0,\\
   \alpha - 3\beta = 0,
   \end{cases}
   \implies
   \gamma = \frac{1}{2}, \quad \beta = -\frac{1}{2}, \quad \alpha = -\frac{3}{2}.
   \]
   因此得到频率关系式：
   \[
   f \propto r^{-3/2} \rho^{-1/2} \sigma^{1/2} = \sqrt{\frac{\sigma}{\rho r^3}}.
   \]
   **物理自洽性与极限检验**：
   - 将 \(m = \frac{4}{3}\pi\rho r^3\) 代入上式，立即化为 \(f \propto \sqrt{\frac{\sigma}{m}}\)，恰与“有效劲度 \(k_{\text{eff}} \sim \sigma\)、有效质量 \(m\) 的弹簧振子”频率公式一致；
   - 查阅经典流体力学（Rayleigh 1879）液滴 \(l\) 阶球谐振型精确结果 \(\omega_l^2 = l(l-1)(l+2)\frac{\sigma}{\rho r^3}\)，对于最低阶四极“脉动”模（\(l=2\)），精确解为 \(f_2 = \frac{1}{2\pi}\sqrt{\frac{8\sigma}{\rho r^3}}\)，无量纲系数 \(k = \frac{\sqrt{2}}{\pi} \approx 0.45\)，量纲标度完全吻合。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以“神舟十号”太空授课中水滴在失重环境下的周期性“脉动”为物理背景，考查表面张力的基本物理性质与量纲分析法的应用。完全失重条件下，不可压缩液滴只受内部静水压强与表面张力作用，平衡态使表面能最小而呈球形；微小形变引起的多极脉动以表面张力为恢复力、液体自身质量（密度与半径）为惯性项，由量纲分析可直接导出振动频率与 \(\sigma, \rho, r\)（或 \(\sigma, m\)）的幂律关系 \(f \propto \sqrt{\sigma/(\rho r^3)}\)。
- **递进拆解脉络**：
  1. 第一步（平衡态形状判断）：在完全失重状态下，液滴不受重力势能约束，仅受表面张力作用。自由表面能 \(E_s = \sigma S\)，在体积 \(V\) 恒定条件下，表面积 \(S\) 最小的几何体为球形，故平衡形状为球形。
  2. 第二步（确定独立主控物理量）：液滴脉动是由表面张力提供恢复力、液体质量提供惯性的无阻尼小振动。影响其振动频率 \(f\) 的三个相互独立的主要物理量为液滴平衡半径 \(r\)、液体密度 \(\rho\) 以及表面张力系数 \(\sigma\)（或者等价地取液滴质量 \(m = \frac{4}{3}\pi \rho r^3\) 与表面张力系数 \(\sigma\)）。
  3. 第三步（建立幂律并列写量纲方程）：设 \(f = k r^\alpha \rho^\beta \sigma^\gamma\)，其中 \(k\) 为无量纲比例常数。在国际单位制（基本量 \(L, M, T\)）中，\([f] = T^{-1}\)，\([r] = L\)，\([\rho] = M L^{-3}\)，\([\sigma] = \text{N/m} = M T^{-2}\)，故 \(T^{-1} = L^{\alpha - 3\beta} M^{\beta + \gamma} T^{-2\gamma}\)。
  4. 第四步（解待定指数并作物理检验）：由 \(M, L, T\) 独立性得方程组 \(\beta + \gamma = 0\)、\(\alpha - 3\beta = 0\)、\(-2\gamma = -1\)，解得 \(\gamma = \frac{1}{2}\)、\(\beta = -\frac{1}{2}\)、\(\alpha = -\frac{3}{2}\)，从而 \(f \propto \sqrt{\frac{\sigma}{\rho r^3}}\)（亦即 \(f \propto \sqrt{\frac{\sigma}{m}}\)）。
- **对照结论**：与官方参考解答完全一致。官方解答给出了“抽象物理量单位表示法（解法一）”和“国际单位制基本单位法（解法二）”两种标准写法，并在评分标准中明确指出：第（2）问写“半径 \(r\)、密度 \(\rho\) 和表面张力系数 \(\sigma\)”或写“质量 \(m\) 和表面张力系数 \(\sigma\)”均满分；第（3）问写 \(f \propto \sqrt{\frac{\sigma}{\rho r^3}}\) 或 \(f \propto \sqrt{\frac{\sigma}{m}}\) 也均给全分。这验证了我们在盲解中对两组等价主控量选择的物理洞察。
- **核心难点**：
  - 难点1：准确筛除次要与无关物理量。考生容易把环境大气压 \(p_0\)（对不可压缩液滴仅提供均匀静水压偏置，不参与形变恢复力）、重力加速度 \(g\)（题目已明确处于完全失重）或黏滞系数 \(\eta\)（影响阻尼而非固有频率）混入主控量，导致量纲方程欠定。
  - 难点2：理解表面张力系数 \(\sigma\) 的物理量纲 \([\sigma] = M T^{-2}\)（力/长度 = 能量/面积 = 劲度系数），从而建立“\(\sigma\) 充当等效弹簧劲度”的直觉图像。
- **高频易错点**：
  - 易错点1：错记表面张力系数 \(\sigma\) 的单位为 \(\text{N/m}^2\)（压强）而非 \(\text{N/m}\)，一旦写错将导致时间指数 \(\gamma\) 全盘算错。
  - 易错点2：若同时将 \(m, r, \rho\) 列入自变量，由于三者通过 \(m = \frac{4}{3}\pi\rho r^3\) 相互依赖，量纲矩阵秩亏而无法唯一解出指数；若取 \((m, r, \sigma)\)，虽然可解出 \(r\) 的指数为 \(0\)，但不符合“相互独立的主要物理量”的常规建模。
- **教练总结**：量纲分析是解决复杂流体、凝聚态乃至天体物理估算题的“瑞士军刀”。面对“无阻尼、小振幅、单恢复力”的振动系统，可先用“等效弹簧法”快速心算校验：振动角频率 \(\omega \sim \sqrt{\text{恢复力系数}/\text{质量}}\)。此处表面能增量 \(\Delta E \sim \sigma (\delta r)^2\) 给出等效劲度 \(\sim \sigma\)，立刻锁定 \(\omega \sim \sqrt{\sigma/m} \sim \sqrt{\sigma/(\rho r^3)}\)，绝不会算错指数符号。

## 2. Clément-Desormes 方法测定理想气体绝热指数 (`cpho-2014-semifinal-theory-problem-slice-q2`)

- **难度评级**：`D1`
- **物理模型**：热力学 · 变质量放气过程转换为定质量绝热膨胀与等容升温模型
- **教学标签**：`克莱门特-德索尔姆法`、`变质量气体控制体选取`、`绝热膨胀方程`、`小量一阶线性展开`、`实验误差与建模思想`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **选取固定质量气体（破除变质量陷阱）**：
   开阀 \(H\) 放气时，有少量气体逸出瓶外，瓶内气体总摩尔数改变。为应用定质量理想气体的热力学方程，取**阀门 \(H\) 关闭后仍然留在瓶内的那部分气体**为研究对象。设瓶的容积为 \(V_0\)，外部环境大气压为 \(p_0\)，室温为 \(T_0\)，U 形管液体密度为 \(\rho\)。
   - **初态 1**（打开 \(H\) 前）：该部分气体占据瓶内体积 \(V_1\)（\(V_1 < V_0\)），压强 \(p_i = p_0 + \rho g h_i\)，温度 \(T_1 = T_0\)。
   - **中间态 2**（放气后瓶内外压强相等并立即关闭 \(H\) 瞬间）：该部分气体恰好充满全瓶体积 \(V_2 = V_0\)，压强 \(p_2 = p_0\)，温度降为 \(T_2\)（\(T_2 < T_0\)）。
   - **末态 3**（等待内外温度重新相等）：因 U 形管极细，体积变化可忽略，故体积仍为 \(V_3 = V_0\)，温度恢复为 \(T_3 = T_0\)，压强回升至 \(p_f = p_0 + \rho g h_f\)。

2. **列写各过程状态方程**：
   - 过程 \(1 \to 2\) 时间极短且无热量交换，对留在瓶内的这部分气体而言，压差较小且膨胀推动前方逸出气体做功，近似视为准静态绝热膨胀：
     \[
     p_i V_1^\gamma = p_0 V_0^\gamma \implies \frac{V_0}{V_1} = \left(\frac{p_i}{p_0}\right)^{1/\gamma}.
     \]
   - 对比初态 1 与末态 3：两者温度均为 \(T_0\)，且研究的是同一固定质量气体，由等温过程玻意耳定律 \(p_1 V_1 = p_3 V_3\) 得：
     \[
     p_i V_1 = p_f V_0 \implies \frac{V_0}{V_1} = \frac{p_i}{p_f}.
     \]
   - （交叉验证：若不引入 \(V_1\)，直接联立绝热温压关系 \(\left(\frac{T_2}{T_0}\right)^\gamma = \left(\frac{p_0}{p_i}\right)^{\gamma - 1}\) 与等容升温 \(\frac{p_0}{T_2} = \frac{p_f}{T_0}\)，同样消去 \(T_2/T_0 = p_0/p_f\)，得 \(\left(\frac{p_0}{p_i}\right)^{1/\gamma} = \frac{p_f}{p_i}\)。）

3. **求解 \(\gamma\) 与微小压差近似**：
   联立上述两式：
   \[
   \left(\frac{p_i}{p_0}\right)^{1/\gamma} = \frac{p_i}{p_f} \implies \gamma = \frac{\ln(p_i/p_0)}{\ln(p_i/p_f)}.
   \]
   记大气压对应的液柱高度差尺度为 \(h_0 \equiv \frac{p_0}{\rho g}\)，则 \(p_i = p_0\left(1 + \frac{h_i}{h_0}\right)\)，\(p_f = p_0\left(1 + \frac{h_f}{h_0}\right)\)。
   题目指出初始时瓶内压强比大气压强“稍高”，即 \(h_i \ll h_0\)、\(h_f \ll h_0\)（注意题中未给出 \(p_0\) 和 \(\rho\)，正说明二者必须在近似中消去）。利用一阶泰勒展开 \(\ln(1+x) \approx x\)（\(|x| \ll 1\)）：
   \[
   \ln\frac{p_i}{p_0} = \ln\left(1 + \frac{h_i}{h_0}\right) \approx \frac{h_i}{h_0},
   \]
   \[
   \ln\frac{p_i}{p_f} = \ln\left(1 + \frac{h_i}{h_0}\right) - \ln\left(1 + \frac{h_f}{h_0}\right) \approx \frac{h_i - h_f}{h_0}.
   \]
   代入即得摩尔热容比：
   \[
   \gamma = \frac{h_i}{h_i - h_f}.
   \]
   **合理性检验**：因绝热膨胀降温后等容升温使压强回弹，必有 \(p_0 < p_f < p_i\)，即 \(0 < h_f < h_i\)，故 \(\gamma = \frac{h_i}{h_i - h_f} > 1\)，符合理想气体 \(C_p > C_V\) 的热力学普遍要求。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是热学实验中的经典问题——Clément-Desormes 方法测气体摩尔热容比 \(\gamma = C_p / C_V\)。大瓶放气时瓶内气体总摩尔数减少，属于开放（变质量）系统，不能直接对瓶内全空间套用封闭气体的 \(p V^\gamma = \text{const}\)。解题关键在于选取“最终留在瓶内的那部分气体”作为固定研究对象（控制质量法）：该部分气体先经历快速（绝热）膨胀至大气压 \(p_0\)，再在恒定体积 \(V_0\) 下等容回温至室温 \(T_0\)。在压强微高于大气压（\(\rho g h \ll p_0\)）的条件下，利用 \(\ln(1+x)\approx x\) 消去未知的大气压 \(p_0\) 与液柱密度 \(\rho\)，最终得到极为简洁的实验公式 \(\gamma = \frac{h_i}{h_i - h_f}\)。
- **递进拆解脉络**：
  1. 第一步（选定固定质量研究对象并写出初末态参量）：选取放气关闭开关 \(H\) 后**留在瓶内的那部分理想气体**为研究对象。设大瓶容积为 \(V_0\)、室温为 \(T_0\)、外界大气压为 \(p_0\)、U 形管液体密度为 \(\rho\)。该部分气体初态参量为 \((p_i, V_i, T_0)\)，其中 \(p_i = p_0 + \rho g h_i\)，体积 \(V_i < V_0\)；放气结束瞬间（关闭 \(H\) 时）参量为 \((p_0, V_0, T)\)，温度降至 \(T < T_0\)；静置至内外温度再次相等的末态参量为 \((p_f, V_0, T_0)\)，其中 \(p_f = p_0 + \rho g h_f\)。
  2. 第二步（列写绝热膨胀与等容升温方程）：快速放气过程可视为可逆绝热膨胀，满足 \(p_i^{1-\gamma} T_0^\gamma = p_0^{1-\gamma} T^\gamma\)（或用初态假想体积 \(V_i\) 写为 \(p_i V_i^\gamma = p_0 V_0^\gamma\)）；随后的等容回温过程（忽略 U 形管引起的体积微小变化）满足 \(\frac{p_0}{T} = \frac{p_f}{T_0}\)。
  3. 第三步（联立消去中间温度 \(T\) 与体积 \(V_i\)）：由前两式消去 \(T/T_0 = p_0/p_f\)（或由初末态同温利用玻意耳定律 \(p_i V_i = p_f V_0\)），得 \(\left(\frac{p_0}{p_i}\right)^{1/\gamma} = \frac{p_f}{p_i}\)，两边取自然对数得精确表达式 \(\gamma = \frac{\ln(p_i/p_0)}{\ln(p_i/p_f)}\)。
  4. 第四步（利用微小压差条件做线性近似）：由题设“压强比大气压强稍高”，令 \(p_0 = \rho g h_0\)，则 \(h_i/h_0 \ll 1\)、\(h_f/h_0 \ll 1\)。利用 \(\ln(1+x)\approx x\)，分子化为 \(\ln(1 + h_i/h_0) \approx h_i/h_0\)，分母化为 \(\ln(1 + h_i/h_0) - \ln(1 + h_f/h_0) \approx (h_i - h_f)/h_0\)，消去 \(h_0\) 即得 \(\gamma = \frac{h_i}{h_i - h_f}\)。
- **对照结论**：与官方参考解答完全吻合。官方解答同时列出了两种标准解法：解法一追踪初态全部气体在压强降至 \(p_0\) 时的假想膨胀体积 \(V'\) 再利用 \(N_f / N_i = V_0 / V'\)；解法二正是我们在盲解中采用的“仅考虑留在容器内的气体”结合 \(p_i^{\gamma-1}T_0^{-\gamma} = p_0^{\gamma-1}T^{-\gamma}\)。两者数学完全等价，而控制质量法在列式时逻辑链条更短。
- **核心难点**：
  - 难点1：变质量热力学系统的建模转化。若误把瓶内空间本身当成定质量气体，会直接写出 \(p_i V_0^\gamma = p_0 V_0^\gamma\) 从而得出 \(p_i = p_0\) 的荒谬结论。必须通过“划定留在瓶内的气体”或“引入膨胀后总体积 \(V'\)”来恢复定质量条件。
  - 难点2：准确识别并实施小量近似。虽然题目未显式写出 \(p_0 \gg \rho g h_i\) 的符号不等式，但“稍高”以及结果仅用 \(h_i, h_f\) 表示都在提示必须做一阶线性化近似。
- **高频易错点**：
  - 易错点1：把等容回温后的最终压强 \(p_f\) 记成低于大气压（或直接拿 \(h_i/h_f\) 乱凑比例）。实际上放气关闭时瓶内已经达到 \(p_0\) 且温度 \(T < T_0\)，后续吸热回温至 \(T_0\) 时压强必然回升到 \(p_f > p_0\)，且必有 \(h_f < h_i\)。
  - 易错点2：一阶展开时直接对 \(\Delta p\) 套用绝热方程却漏掉常数基准 \(p_0\)，或忘记讨论 \(h_i \ll h_0\) 的近似前提而被扣掉步骤分。
- **教练总结**：遇到含放气/充气阀门的气体热力学问题，永远先问一句“系统质量是否守恒”。若质量改变，两条路二选一：（1）**控制质量法**：反向追踪最终留在容器里的那部分气体的虚拟初始体积 \(V_1\)；（2）**全量假想体积法**：把初态全部气体假想装入可伸缩气囊一同膨胀到 \(V'\)。另外，若把本实验反过来——先快速压气使压强升高再等容冷却，利用同样公式可得 \(\gamma = \frac{h_i}{h_i - h_f}\)（此时放气变打气，\(h_i, h_f\) 符号意义对应），体现物理对称性。

## 3. 铰链等腰三角形平板的三维力矩平衡与支反力不变轨迹 (`cpho-2014-semifinal-theory-problem-slice-q3`)

- **难度评级**：`D2`
- **物理模型**：刚体静力学 · 三维力与力矩平衡方程及支反力静不定性
- **教学标签**：`刚体三维静力平衡`、`三角形质心位置`、`轴向支反力静不定性`、`右手坐标系叉乘`、`力作用点等反力轨迹`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **坐标系与几何参量检查**：
   细读题图可知：原点 \(O\) 为 \(AB\) 中点，\(x\) 轴沿水平铰链轴由 \(B\) 指向 \(A\)（\(A\) 点坐标 \(\left(\frac{b}{2}, 0, 0\right)\)，\(B\) 点坐标 \(\left(-\frac{b}{2}, 0, 0\right)\)），\(z\) 轴在板面内由 \(O\) 指向顶点 \(C\)，\(y\) 轴垂直板面斜向上，与竖直方向夹角为 \(\frac{\pi}{2} - \varphi\)。用矢量叉乘验证：\(\hat{x} \times \hat{y} = \hat{z}\)，该坐标系为标准右手系。
   等腰三角形底边 \(AB = b\)、腰长 \(a\)，总高 \(H = \sqrt{a^2 - \frac{b^2}{4}}\)，质量均匀分布的三角形质心 \(G\) 位于中线 \(OC\) 的三分之一处：
   \[
   \mathbf{r}_G = (0, 0, h), \quad h = \frac{1}{3}\sqrt{a^2 - \frac{b^2}{4}}.
   \]
   竖直向上单位矢量 \(\hat{e}_{\text{up}} = \sin\varphi\,\hat{y} + \cos\varphi\,\hat{z}\)，故重力矢量为：
   \[
   \mathbf{P}_G = -mg\,\hat{e}_{\text{up}} = (0,\ -mg\sin\varphi,\ -mg\cos\varphi).
   \]
   垂直板面拉力（依图沿 \(+y\) 方向，平衡重力向左侧倾倒的趋势）为 \(\mathbf{Q} = (0, Q, 0)\)，作用点 \(\mathbf{r}_{M_0} = (x_0, 0, z_0)\)。两光滑铰链对板的约束力记为 \(\mathbf{N}_A = (N_{Ax}, N_{Ay}, N_{Az})\) 和 \(\mathbf{N}_B = (N_{Bx}, N_{By}, N_{Bz})\)。

2. **列写第（1）问静力平衡方程**：
   - 力平衡 \(\sum \mathbf{F} = \mathbf{0}\)：
     \[
     N_{Ax} + N_{Bx} = 0,
     \]
     \[
     N_{Ay} + N_{By} + Q - mg\sin\varphi = 0,
     \]
     \[
     N_{Az} + N_{Bz} - mg\cos\varphi = 0.
     \]
   - 对原点 \(O\) 的力矩平衡 \(\sum \mathbf{r} \times \mathbf{F} = \mathbf{0}\)：
     各力矩分别为：
     - \(\mathbf{r}_G \times \mathbf{P}_G = (h\hat{z}) \times (-mg\sin\varphi\,\hat{y} - mg\cos\varphi\,\hat{z}) = +mgh\sin\varphi\,\hat{x}\)；
     - \(\mathbf{r}_{M_0} \times \mathbf{Q} = (x_0\hat{x} + z_0\hat{z}) \times (Q\hat{y}) = -Q z_0\,\hat{x} + Q x_0\,\hat{z}\)；
     - \(\mathbf{r}_A \times \mathbf{N}_A = \left(\frac{b}{2}\hat{x}\right) \times \mathbf{N}_A = -\frac{b}{2} N_{Az}\,\hat{y} + \frac{b}{2} N_{Ay}\,\hat{z}\)；
     - \(\mathbf{r}_B \times \mathbf{N}_B = \left(-\frac{b}{2}\hat{x}\right) \times \mathbf{N}_B = +\frac{b}{2} N_{Bz}\,\hat{y} - \frac{b}{2} N_{By}\,\hat{z}\)。
     分轴令总力矩为零：
     \[
     \sum M_x = mgh\sin\varphi - Q z_0 = 0,
     \]
     \[
     \sum M_y = \frac{b}{2}(N_{Bz} - N_{Az}) = 0,
     \]
     \[
     \sum M_z = Q x_0 + \frac{b}{2}(N_{Ay} - N_{By}) = 0.
     \]
   - **求解**：
     由 \(\sum M_x = 0\) 解得拉力大小：
     \[
     Q = \frac{mgh\sin\varphi}{z_0} = \frac{mg\sqrt{4a^2 - b^2}\sin\varphi}{6 z_0}.
     \]
     由 \(\sum F_z = 0\) 与 \(\sum M_y = 0\) 解得 \(N_{Az} = N_{Bz} = \frac{1}{2}mg\cos\varphi\)。
     由 \(\sum F_y = 0\) 与 \(\sum M_z = 0\) 联立：
     \[
     N_{Ay} + N_{By} = mg\sin\varphi - Q, \quad N_{Ay} - N_{By} = -\frac{2x_0}{b} Q,
     \]
     解得：
     \[
     N_{Ay} = \frac{1}{2}mg\sin\varphi\left[1 - \frac{h}{z_0}\left(1 + \frac{2x_0}{b}\right)\right], \quad N_{By} = \frac{1}{2}mg\sin\varphi\left[1 - \frac{h}{z_0}\left(1 - \frac{2x_0}{b}\right)\right].
     \]
     沿铰链轴 \(x\) 方向只有 \(N_{Ax} + N_{Bx} = 0\) 一个独立约束，两支点间存在轴向静不定内力（\(N_{Bx} = -N_{Ax}\)）。
     **特例极限检验**：若把作用点选在质心 \(M_0 = (0, 0, h)\)，则 \(Q = mg\sin\varphi\) 且 \(N_{Ay} = N_{By} = 0\)，拉力恰完全抵消重力垂直板面的分量，物理图像自洽！

3. **求解第（2）问作用点轨迹**：
   当 \(M(x, 0, z)\) 从 \(M_0(x_0, 0, z_0)\) 缓慢移动并始终维持角度 \(\varphi\) 不变（设 \(\sin\varphi \neq 0\)；若 \(\varphi = 0\) 则 \(Q = 0\) 且支反力恒为零）：
   - **情形 A（使 \(N_{Ay}\) 保持不变）**：
     要求 \(\frac{1 + \frac{2x}{b}}{z} = \text{const} = \frac{1 + \frac{2x_0}{b}}{z_0}\)，即
     \[
     z = \frac{z_0}{x_0 + \frac{b}{2}}\left(x + \frac{b}{2}\right) \quad (z > 0,\ M \text{ 在三角形板内}).
     \]
     这是一条**在平板内通过铰链支点 \(B\left(-\frac{b}{2}, 0, 0\right)\) 的射线（不包含 \(B\) 点自身）**。
     **物理解释**：以过 \(B\) 点平行于 \(z\) 轴的轴线为矩心轴时，\(Q\) 对该轴的力臂为 \((x + b/2)\)，而绕 \(x\) 轴平衡要求 \(Q \propto 1/z\)，故只要 \((x + b/2)/z\) 恒定，\(Q\) 对过 \(B\) 轴的力矩就不变，从而另一端 \(A\) 的法向反力 \(N_{Ay}\) 保持恒定！
   - **情形 B（使 \(N_{By}\) 保持不变）**：
     同理要求 \(\frac{1 - \frac{2x}{b}}{z} = \frac{1 - \frac{2x_0}{b}}{z_0}\)，即
     \[
     z = \frac{z_0}{\frac{b}{2} - x_0}\left(\frac{b}{2} - x\right) \quad (z > 0,\ M \text{ 在三角形板内}),
     \]
     这是一条**在平板内通过铰链支点 \(A\left(\frac{b}{2}, 0, 0\right)\) 的射线（不包含 \(A\) 点自身）**。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题考查刚体在三维空间中的一般静力学平衡条件。均匀等腰三角形平板可绕水平轴 \(AB\)（\(x\) 轴）自由转动，受重力、点 \(M_0\) 处的垂直板面拉力 \(\mathbf{Q}\) 以及两光滑铰链支点 \(A, B\) 的约束力 \(\mathbf{N}_A, \mathbf{N}_B\)。由于共轴双铰链沿轴线 \(x\) 方向的约束存在静不定性，只能定出 \(N_{Ax} + N_{Bx} = 0\)，而垂直于轴的 \(y, z\) 分量由总力和对原点 \(O\) 的三维力矩方程完全唯一确定。第（2）问通过令 \(N_{Ay}\) 或 \(N_{By}\) 在 \(M(x, 0, z)\) 缓慢移动且保持倾角 \(\varphi\) 不变时维持恒定，揭示出一个极优美的几何结论：作用点 \(M\) 的轨迹必为平板内分别过另一支点 \(B\) 或 \(A\) 的射线。
- **递进拆解脉络**：
  1. 第一步（确定坐标系、各力矢量及质心坐标）：由题意及附图确认 \((x, y, z)\) 为右手直角坐标系，\(A\left(\frac{b}{2}, 0, 0\right)\)，\(B\left(-\frac{b}{2}, 0, 0\right)\)。三角形高 \(H = \sqrt{a^2 - \frac{b^2}{4}}\)，均匀平板质心位于 \(\left(0, 0, h\right)\)，其中 \(h = \frac{1}{3}\sqrt{a^2 - \frac{b^2}{4}}\)。平板与竖直方向夹角为 \(\varphi\)，重力在板系中的分量为 \(\mathbf{G} = (0, -mg\sin\varphi, -mg\cos\varphi)\)，拉力 \(\mathbf{Q} = (0, Q, 0)\) 作用于 \((x_0, 0, z_0)\)。
  2. 第二步（列写三维力平衡与力矩平衡方程）：力平衡给出 \(N_{Ax} + N_{Bx} = 0\)、\(N_{Ay} + N_{By} + Q - mg\sin\varphi = 0\)、\(N_{Az} + N_{Bz} - mg\cos\varphi = 0\)。对原点 \(O\) 列力矩平衡 \(\sum \mathbf{r} \times \mathbf{F} = \mathbf{0}\)：绕 \(x\) 轴有 \(mgh\sin\varphi - Q z_0 = 0\)；绕 \(y\) 轴有 \(\frac{b}{2}(N_{Bz} - N_{Az}) = 0\)；绕 \(z\) 轴有 \(Q x_0 + \frac{b}{2}(N_{Ay} - N_{By}) = 0\)。
  3. 第三步（解出 \(Q\) 与支座反力 \(\mathbf{N}_A, \mathbf{N}_B\)）：由绕 \(x\) 轴力矩平衡直接解得 \(Q = \frac{mgh\sin\varphi}{z_0}\)。再由 \(y, z\) 方向力与力矩方程解得 \(N_{Az} = N_{Bz} = \frac{1}{2}mg\cos\varphi\)，\(N_{Ay} = \frac{1}{2}mg\sin\varphi\left[1 - \frac{h}{z_0}\left(1 + \frac{2x_0}{b}\right)\right]\)，\(N_{By} = \frac{1}{2}mg\sin\varphi\left[1 - \frac{h}{z_0}\left(1 - \frac{2x_0}{b}\right)\right]\)；轴向分量满足 \(N_{Ax} = -N_{Bx}\)（静不定）。
  4. 第四步（推导支反力法向分量不变的轨迹方程）：保持 \(\varphi\) 不变而移动作用点 \(M(x, 0, z)\)，若要 \(N_{Ay}\) 保持不变，需 \(\frac{b + 2x}{z} = \text{const} = \frac{b + 2x_0}{z_0}\)，即 \(z = \frac{z_0}{x_0 + b/2}\left(x + \frac{b}{2}\right)\)，这是平板内通过支点 \(B\left(-\frac{b}{2}, 0, 0\right)\) 的一条射线（不含 \(B\) 点）；同理，若要 \(N_{By}\) 保持不变，需 \(\frac{b - 2x}{z} = \frac{b - 2x_0}{z_0}\)，轨迹为平板内通过支点 \(A\left(\frac{b}{2}, 0, 0\right)\) 的一条射线（不含 \(A\) 点）。
- **对照结论**：与官方参考解答高度一致！仅有一个符号习惯的差异：官方解答直接把质心高度记为 \(h = \frac{1}{3}\sqrt{a^2 - b^2/4}\)，而我们在盲解推导中也特意先算出总高 \(H\) 再记质心坐标为 \(h\)，两者结果完全相同（例如官方写 \(N_{Ay} = \frac{mg\sin\varphi}{2}[1 - \frac{h}{b}(\frac{b}{z_0} + \frac{2x_0}{z_0})]\)）。官方解答同样保留了轴向静不定分量 \(N_{Ax}\) 与 \(-N_{Ax}\)，并在第（2）问强调了轨迹为“通过 \(A\) 点（或 \(B\) 点）的任一条射线（不包含 \(A\) 或 \(B\) 点）”。
- **核心难点**：
  - 难点1：三维刚体平衡中轴向静不定性的处理。很多中学生遇到 6 个平衡方程却要解 6 个支座反力分量（外加未知力 \(Q\) 共 7 个未知量）时会产生恐慌，不知为何 \(N_{Ax}, N_{Bx}\) 无法单独解出——其实双同轴铰链沿轴线方向本来就是静不定的。
  - 难点2：第（2）问中从代数比例关系 \(\frac{b - 2x}{z} = \text{const}\) 识别出几何意义“过支点 \(A\)（或 \(B\)）的射线”，并理解“保 \(N_{Ay}\) 不变需过 \(B\)、保 \(N_{By}\) 不变需过 \(A\)”的交叉对应关系。
- **高频易错点**：
  - 易错点1：把等腰三角形的质心位置误当成 \(H/2\) 而非 \(H/3\)，或者把质心到 \(AB\) 边距离写成 \(\frac{1}{3}\sqrt{a^2 - b^2}\)（漏掉底边一半的平方 \((b/2)^2\)）。
  - 易错点2：右手坐标系下力矩正负号判断失误，特别是 \(\mathbf{r}_{M_0} \times \mathbf{Q} = -Q z_0 \hat{x} + Q x_0 \hat{z}\) 与 \(\mathbf{r}_A \times \mathbf{N}_A\) 的符号；另外，容易漏掉“射线不包含铰链点 \(A\) 或 \(B\) 本身（因为 \(z=0\) 处无法提供绕 \(x\) 轴平衡所需的有限拉力 \(Q\)）”。
- **教练总结**：三维静力学问题务必先写清楚坐标轴方向、检验右手系，再用标准矢量叉乘 \(\mathbf{r} \times \mathbf{F}\) 统一计算所有力矩，可彻底杜绝力臂正负号出错。此外，看到第（2）问这种“保持某支座反力不变”的反问题，先在脑中对该另一支点取力矩，往往比盲目化简方程更快直击几何本质。

## 4. 竖直细轴上可滑动旋转圆环与双下滑小球的耦合动力学 (`cpho-2014-semifinal-theory-problem-slice-q4`)

- **难度评级**：`D3`
- **物理模型**：刚体与质点系动力学 · 角动量守恒、机械能守恒与三维约束反力临界离地条件
- **教学标签**：`角动量守恒`、`球面运动径向加速度合成`、`圆环绕直径转动惯量`、`起跳（上滑）临界条件`、`非惯性旋转系离心势能`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **基本守恒律（圆环尚未上滑阶段）**：
   设均匀圆环质量 \(m_0\)、半径 \(R\)，由垂直轴定理，圆环绕垂直环面中心轴的转动惯量为 \(m_0 R^2\)，故绕其直径轴 \(OO'\) 的转动惯量为：
   \[
   I_0 = \frac{1}{2} m_0 R^2.
   \]
   两小球自环顶（\(\theta = 0\)）静止释放并对称下滑，在夹角 \(\theta\) 处距轴 \(OO'\) 距离 \(r = R\sin\theta\)。
   - **角动量守恒**：轴 \(OO'\) 光滑且无绕竖直轴的外力矩，环与两球系统总角动量守恒：
     \[
     I_0 \omega_0 = \left(I_0 + 2 m R^2 \sin^2\theta\right) \omega \implies \omega(\theta) = \frac{m_0}{m_0 + 4 m \sin^2\theta} \omega_0.
     \]
   - **机械能守恒**：环尚未沿 \(OO'\) 上滑前，环心 \(C\) 静止。小球在实验室系中的合速度由沿环切向相对速率 \(v = R\dot{\theta}\) 与水平圆周牵连速率 \(\omega R\sin\theta\) 正交合成：\(v_{\text{lab}}^2 = v^2 + \omega^2 R^2 \sin^2\theta\)。内力做功之和为零，机械能守恒：
     \[
     \frac{1}{2} I_0 \omega_0^2 = \frac{1}{2} I_0 \omega^2 + m \left(v^2 + \omega^2 R^2 \sin^2\theta\right) - 2 m g R (1 - \cos\theta).
     \]
     利用旋转动能合并技巧 \(\frac{1}{2} I_0 \omega^2 + m \omega^2 R^2\sin^2\theta = \frac{1}{2} I(\theta) \omega^2 = \frac{(I_0 \omega_0)^2}{2 I(\theta)}\)，立得：
     \[
     m v^2 = 2 m g R (1 - \cos\theta) + \frac{1}{4} m_0 R^2 \omega_0^2 \left(1 - \frac{m_0}{m_0 + 4m\sin^2\theta}\right) = 2 m g R (1 - \cos\theta) + \frac{m_0 m R^2 \omega_0^2 \sin^2\theta}{m_0 + 4m\sin^2\theta}.
     \]
     进而有：
     \[
     v^2 + \omega^2 R^2\sin^2\theta = 2 g R (1 - \cos\theta) + \frac{m_0 R^2 \omega_0^2 \sin^2\theta(2m_0 + 4m\sin^2\theta)}{(m_0 + 4m\sin^2\theta)^2} = 2 g R (1 - \cos\theta) + \frac{m_0^2 R^2 \omega_0^2}{4m}\left[\frac{4m\sin^2\theta(2m_0 + 4m\sin^2\theta)}{m_0(m_0 + 4m\sin^2\theta)^2}\right]
     \]
     利用恒等式 \(\frac{\alpha s (2 + \alpha s)}{(1+\alpha s)^2} = 1 - \frac{1}{(1+\alpha s)^2}\)（其中 \(\alpha = 4m/m_0\)，\(s = \sin^2\theta\)），可紧凑写为：
     \[
     v^2 + \omega^2 R^2\sin^2\theta = 2 g R (1 - \cos\theta) + \frac{m_0 R^2 \omega_0^2}{4m} \left[1 - \frac{m_0^2}{(m_0 + 4m\sin^2\theta)^2}\right].
     \]

2. **第（1）问：圆环沿 \(OO'\) 轴上滑的条件**：
   环对小球的正压力可分解为环平面内指向环心 \(C\) 的分量 \(N\)（正值表示指向 \(C\)）与垂直环面的水平分量 \(T_\phi\)。由于 \(T_\phi\) 纯水平，只有 \(-N\) 具有竖直分量。在球面坐标 \((R, \theta, \phi)\) 中，小球指向球心 \(C\) 的向心加速度为 \(a_R = \frac{v^2}{R} + \omega^2 R\sin^2\theta\)，故：
   \[
   N + m g \cos\theta = m \left(\frac{v^2}{R} + \omega^2 R\sin^2\theta\right).
   \]
   代入前式得：
   \[
   N(\theta) = m g (2 - 3\cos\theta) + \frac{m_0 R \omega_0^2}{4}\left[1 - \frac{m_0^2}{(m_0 + 4m\sin^2\theta)^2}\right].
   \]
   两小球对圆环向上的总作用力为 \(F_{\text{up}}(\theta) = 2 N(\theta) \cos\theta\)。注意到当 \(\theta \in (\pi/2, \pi]\) 时，\(N > 2mg > 0\) 且 \(\cos\theta < 0\)，故 \(F_{\text{up}} < 0\)（只可能下压圆环）。圆环要有可能沿 \(OO'\) 轴上滑，必须在下滑过程某角度 \(\theta \in (0, \pi/2)\) 处满足 \(2 N(\theta)\cos\theta > m_0 g\)（临界条件取等号），即存在 \(\theta \in (0, \pi/2)\) 使：
   \[
   6 m \cos^2\theta - 4 m \cos\theta + m_0 - \frac{m_0 R \omega_0^2 \cos\theta}{2 g} \left[1 - \frac{m_0^2}{(m_0 + 4m\sin^2\theta)^2}\right] \le 0.
   \]
   （特别地：若 \(\omega_0 = 0\)，\(\cos\theta(2-3\cos\theta)\) 最大值为 \(1/3\)，此时要求 \(2m > 3m_0\)；若 \(2m \le 3m_0\)，则必须有足够大的初角速度 \(\omega_0\) 使上式最大值满足起跳条件。）

3. **第（2）问：\(\theta = 30^\circ\) 处开始上滑时的 \(\omega_0, \omega, v\)**：
   在 \(\theta = 30^\circ\) 处，\(\sin^2 30^\circ = \frac{1}{4}\)，\(\cos 30^\circ = \frac{\sqrt{3}}{2}\)，取上滑临界等号：
   \[
   \left(\frac{9}{2} - 2\sqrt{3}\right) m + m_0 = \frac{\sqrt{3} m_0 R \omega_0^2}{4 g} \left[1 - \frac{m_0^2}{(m_0 + m)^2}\right] = \frac{\sqrt{3} m_0 m (2m_0 + m) R \omega_0^2}{4 g (m_0 + m)^2}.
   \]
   解出 \(\omega_0\)：
   \[
   \omega_0 = (m_0 + m) \sqrt{\frac{2\left[2\sqrt{3} m_0 + (9\sqrt{3} - 12)m\right] g}{3 m m_0 (2m_0 + m) R}}.
   \]
   （数值检验表明对任意正质量 \(m, m_0\)，\(F_{\text{up}}(\theta)\) 在 \((0, 30^\circ)\) 上均严格小于 \(m_0 g\)，直到 \(30^\circ\) 首次达到 \(m_0 g\)，故 \(30^\circ\) 确为首次上滑位置。）
   由角动量守恒得 \(\theta = 30^\circ\) 时圆环角速度：
   \[
   \omega = \frac{m_0}{m_0 + m}\omega_0 = \sqrt{\frac{2 m_0 \left[2\sqrt{3} m_0 + (9\sqrt{3} - 12)m\right] g}{3 m (2m_0 + m) R}}.
   \]
   再由 \(\theta = 30^\circ\) 处的能量式（或直接反代径向力方程 \(v^2/R = \frac{m_0 g}{\sqrt{3}m} + \frac{\sqrt{3}}{2}g - \frac{1}{4}\omega^2 R\)）得小球相对圆环滑动速率：
   \[
   v = \sqrt{g R} \sqrt{\frac{2\sqrt{3} m_0^2 + (12 - \sqrt{3}) m m_0 + 3\sqrt{3} m^2}{6 m (2m_0 + m)}}.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是经典的“圆环套竖直轴上滑”模型的转动推广版。当两小球自圆环顶端对称下滑时，由于圆环本身绕竖直细轴 \(OO'\) 旋转，小球除了沿环滑动的速率 \(v\) 外，还具有随圆环转动的牵连角速度 \(\omega\)。在圆环尚未沿 \(OO'\) 上滑之前，整个系统对 \(OO'\) 轴角动量守恒、机械能守恒，圆环绕竖直直径的转动惯量为 \(I_0 = \frac{1}{2} m_0 R^2\)。解答的关键在于正确写出小球指向环心的径向加速度 \(a_R = \frac{v^2}{R} + \omega^2 R\sin^2\theta\)（不可漏掉牵连圆周运动向心加速度的径向投影！），再由牛顿第三定律令两小球对圆环的竖直向上总拉力大于等于环重 \(m_0 g\)。
- **递进拆解脉络**：
  1. 第一步（转动惯量与角动量守恒）：均匀圆环绕过其直径的竖直轴 \(OO'\) 的转动惯量为 \(I_0 = \frac{1}{2} m_0 R^2\)。小球滑至夹角 \(\theta\) 时到转轴的距离为 \(r = R\sin\theta\)，因竖直轴光滑无外力矩，系统角动量守恒：\(I_0 \omega_0 = (I_0 + 2 m R^2\sin^2\theta)\omega\)，得 \(\omega = \frac{m_0}{m_0 + 4 m\sin^2\theta}\omega_0\)。
  2. 第二步（机械能守恒求下滑速率 \(v\)）：圆环尚未上滑时，能量守恒给出 \(\frac{1}{2} I_0 \omega_0^2 + 2 m g R (1 - \cos\theta) = \frac{1}{2} I_0 \omega^2 + m\left[v^2 + (\omega R\sin\theta)^2\right]\)。将环与小球的旋转动能合并为 \(\frac{1}{2}I(\theta)\omega^2 = \frac{I_0^2\omega_0^2}{2 I(\theta)}\)，直接解出 \(v^2 + (\omega R\sin\theta)^2 = 2 g R(1 - \cos\theta) + \frac{m_0 R^2 \omega_0^2}{4m}\left[1 - \frac{m_0^2}{(m_0 + 4m\sin^2\theta)^2}\right]\)。
  3. 第三步（小球向心加速度合成与上滑条件）：在球面坐标系中，小球指向圆环中心 \(C\) 的加速度分量为自身沿环滑动的向心加速度 \(\frac{v^2}{R}\) 与绕轴转动向心加速度 \(\omega^2 R\sin\theta\) 沿半径的投影 \(\omega^2 R\sin^2\theta\) 之和。由径向牛顿第二定律 \(N + m g\cos\theta = m\frac{v^2 + \omega^2 R^2\sin^2\theta}{R}\)，环受两球竖直向上的总作用力为 \(2 N \cos\theta\)（注意垂直环面的侧向弹力水平，不影响竖直运动），上滑条件为在 \((0, \pi/2)\) 存在某角度 \(\theta\) 满足 \(2 N\cos\theta \ge m_0 g\)。
  4. 第四步（代入 \(\theta = 30^\circ\) 精确求解）：当 \(\theta = 30^\circ\) 时，\(\sin^2 30^\circ = \frac{1}{4}\)、\(\cos 30^\circ = \frac{\sqrt{3}}{2}\)，恰好化简 \(m_0 + 4m\sin^2 30^\circ = m_0 + m\)，从而立即依次解出临界初角速度 \(\omega_0\)、此刻角速度 \(\omega = \frac{m_0}{m_0+m}\omega_0\) 及相对滑动速率 \(v\)。
- **对照结论**：与官方参考解答高度一致！第（1）问条件方程（15）和第（2）问的 \(\omega_0, \omega, v\) 三式（16）（17）（18）在符号和整数系数上与官方答案一字不差！值得一提的是，官方解答在推导圆环绕直径的转动惯量 \(I_0 = \frac{1}{2}m_0 R^2\) 时，除垂直轴定理外，还展示了一个用半圆环投影面积微元 \(\Delta S = R\Delta z\) 求和的初等几何证法，非常适合尚未学过垂直轴定理的高一竞赛生学习。
- **核心难点**：
  - 难点1：三维复合运动中向心加速度的分解与合成。很多同学误以为小球在环面上只受沿环向心加速度 \(v^2/R\)，漏掉了牵连水平圆周运动向心加速度 \(\omega^2 R\sin\theta\) 沿球半径方向的投影 \(\omega^2 R\sin^2\theta\)。
  - 难点2：正确判断环与球之间作用力的三个正交分量及其对竖直运动的影响。垂直于环面的正压力分量 \(T_\phi\) 仅改变角动量、不做总功，且完全在水平面内，绝不提供竖直升力；竖直升力只来自径向反力 \(N\) 的竖直分量。
- **高频易错点**：
  - 易错点1：把细圆环绕竖直直径的转动惯量误记为 \(m_0 R^2\)（这是绕过圆心且垂直环面的轴！）或 \(\frac{1}{4}m_0 R^2\)（这是实心圆盘绕直径的值）。
  - 易错点2：在列机械能守恒时误认为“圆环不转”或者误把旋转动能写成 \(\frac{1}{2} I_0 (\omega - \omega_0)^2\)，漏掉小球随圆环转动的水平速度 \(\omega R\sin\theta\)。
- **教练总结**：对于“可绕对称轴转动的约束面 + 滑动质点”的耦合动力学问题，有一套铁律三步法：（1）**轴向角动量守恒**给出 \(\omega(\theta)\)；（2）**合并总转动惯量的机械能守恒**把所有随转角平动与转动动能打包成 \(\frac{L_0^2}{2 I(\theta)}\)；（3）在**随动球坐标**下写出径向加速度 \(a_R = -\frac{v^2 + \omega^2 R^2\sin^2\theta}{R}\)，从而绕开科里奥利力直接秒杀法向约束反力。

## 5. 发光圆盘成像中的可变光阑渐晕与视场光阑边界 (`cpho-2014-semifinal-theory-problem-slice-q5`)

- **难度评级**：`D3`
- **物理模型**：几何光学 · 有限口径薄透镜成像光锥截断、孔径光阑与视场光阑区分
- **教学标签**：`孔径光阑与视场光阑`、`渐晕与暗角效应`、`极限边缘光线追踪`、`薄透镜成像光锥分析`、`几何相似三角形`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：无光阑时的圆盘像**：
   由薄透镜公式 \(\frac{1}{u} + \frac{1}{v} = \frac{1}{f}\)，代入 \(u = 20\text{ cm}\)、\(f = 10\text{ cm}\)，得像距 \(v = 20\text{ cm}\)（凸透镜后方 \(20\text{ cm}\) 处）。
   横向放大率 \(\beta = -\frac{v}{u} = -1\)，因此光屏上成一个**倒立、半径为 \(5\text{ cm}\) 的圆形实像**（与物圆盘等大）。

2. **统一光锥截断模型（求解第 2–5 问的核心工具）**：
   设凸透镜平面为 \(z = 0\)，光屏位于 \(z = v = 20\text{ cm}\)。来自物盘的各像点 \((0, y', 20)\)（\(0 \le y' \le 5\text{ cm}\)）的会聚光束由凸透镜（半径 \(R_L = 15\text{ cm}\)）边缘约束为一个圆锥。在透镜后方 \(z = d\)（\(0 < d < 20\text{ cm}\)）的垂直光轴平面内，该圆锥的截面是一个圆盘：
   - 圆心纵坐标：\(Y_c(d) = \frac{d}{v} y' = \frac{d}{20} y'\)；
   - 截面半径：\(\rho(d) = \left(1 - \frac{d}{v}\right) R_L = 15\left(1 - \frac{d}{20}\right)\text{ cm}\)。
   像点 \((0, y', 20)\) 能在屏上接收到光，当且仅当该光锥截面圆盘与中心在 \((0,0)\)、半径为 \(r\) 的光阑圆孔存在交集，即：
   \[
   |Y_c(d)| - \rho(d) < r \quad (\text{精确边界：} r_{\text{crit}}(y') = Y_c(d) - \rho(d)).
   \]

3. **第（2）问：光阑置于凸透镜后方 \(d_1 = 6\text{ cm}\) 处**：
   代入 \(d_1 = 6\text{ cm}\)：
   \[
   \rho(6) = 15 \times \left(1 - \frac{6}{20}\right) = 10.5\text{ cm}, \quad Y_c(6) = 0.3 y' \in [0, 1.5\text{ cm}].
   \]
   因为对全盘任意像点均有 \(Y_c(6) \le 1.5\text{ cm} < \rho(6) = 10.5\text{ cm}\)，光轴点 \((0,0)\) 恒落在每一个像点光锥的内部！
   因此当 \(r\) 逐渐减小时（只要 \(r > 0\)）：
   - 当 \(r \ge 12.0\text{ cm}\) 时像全亮不变；
   - 当 \(9.0\text{ cm} < r < 12.0\text{ cm}\) 时边缘开始出现渐晕变暗；当 \(r < 9.0\text{ cm}\)（尤其 \(r < 10.5\text{ cm}\)）时整个像盘亮度减弱且中心较亮、边缘更暗；
   - **但圆盘像的圆形形状和半径大小（\(5\text{ cm}\)）保持不变**（直至 \(r=0\) 完全遮挡）。故**不存在**使像半径减半的 \(r_a\)。

4. **第（3）问：光阑移至凸透镜后方 \(d_2 = 18\text{ cm}\) 处**：
   代入 \(d_2 = 18\text{ cm}\)：
   \[
   \rho(18) = 15 \times \left(1 - \frac{18}{20}\right) = 1.5\text{ cm}, \quad Y_c(18) = 0.9 y'.
   \]
   - 当 \(r \ge 0.9 \times 5 + 1.5 = 6.0\text{ cm}\) 时，全像无损失；
   - 当 \(3.0\text{ cm} \le r < 6.0\text{ cm}\) 时，边缘出现渐晕但像边界半径仍为 \(5\text{ cm}\)；
   - 当 \(r < 3.0\text{ cm}\) 时，边缘光线被完全挡住，像半径 \(R_i'\) 随 \(r\) 减小而缩小，满足 \(0.9 R_i' - 1.5 = r \implies R_i' = \frac{r + 1.5}{0.9}\text{ cm}\)（直至 \(r \to 0^+\) 时像半径趋于 \(\frac{5}{3}\text{ cm}\)）。
   令 \(R_i' = \frac{1}{2} \times 5\text{ cm} = 2.5\text{ cm}\)，由于 \(2.5\text{ cm} \in \left(\frac{5}{3}\text{ cm}, 5\text{ cm}\right)\)，故**存在**该光阑半径：
   \[
   r_a = 0.9 \times 2.5 - 1.5 = 0.75\text{ cm}.
   \]
   （极限边缘光线校验：从透镜下缘 \((0, -15, 0)\) 射向像点 \((0, 2.5, 20)\) 的光线在 \(z = 18\text{ cm}\) 处的高度为 \(-15 \times \frac{2}{20} + 2.5 \times \frac{18}{20} = -1.5 + 2.25 = 0.75\text{ cm}\)，完全一致。）

5. **第（4）问：光阑放置在哪些位置时像大小与 \(r\) 有关**：
   只要存在正的 \(r\) 能切断最外缘像点 \(y' = 5\text{ cm}\)，即需 \(Y_c - \rho > 0\)：
   - **透镜后方**：\(\frac{d}{20} \times 5 > 15\left(1 - \frac{d}{20}\right) \implies \frac{d}{4} > 15 - \frac{3}{4}d \implies d > 15\text{ cm}\)，且光阑不能位于光屏之后，故位置范围为**凸透镜后方 \(15\text{ cm}\)（不含临界点 \(C\)）到 \(20\text{ cm}\)（光屏处）之间**。
   - **物像对称补充（透镜前方）**：由于 \(u = v = 20\text{ cm}\) 且 \(R_0 = R_i = 5\text{ cm}\)，若允许将光阑移至透镜前方（如第 5 问），由光路可逆性，当光阑位于**凸透镜前方 \(15\text{ cm}\) 到 \(20\text{ cm}\)（物盘处）之间**时，像大小同样与 \(r\) 有关。

6. **第（5）问：光阑移至凸透镜前方 \(6\text{ cm}\) 处**：
   因 \(6\text{ cm} < 15\text{ cm}\)，从物盘边缘 \((0, -5, -20)\) 经透镜前 \(6\text{ cm}\) 处光轴中心 \((0, 0, -6)\) 射出的光线打在透镜上的高度为 \(Y_L = 5 \times \frac{6}{14} = \frac{15}{7}\text{ cm} \approx 2.14\text{ cm} < R_L = 15\text{ cm}\)，必然穿过透镜并会聚到像盘边缘 \((0, +5, +20)\)。因此结论与第（2）问相同：**像的形状和半径（\(5\text{ cm}\)）不变，仅亮度减弱（先边缘渐晕后全盘变暗）；不存在使像半径减半的 \(r_a\)**。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是几何光学中极具区分度的“光阑位置效应”好题，深刻揭示了**孔径光阑**（决定像的亮度）与**视场光阑**（决定像的可见范围/大小）的本质区别。当物体圆盘半径 \(R_0 = 5\text{ cm}\) 经半径 \(R_L = 15\text{ cm}\)、焦距 \(f = 10\text{ cm}\) 的凸透镜在 \(v = 20\text{ cm}\) 处成等大倒立实像时，透镜下边缘到像上边缘的极限边缘光线与光轴交于距透镜 \(15\text{ cm}\) 处的交点 \(C\)。光阑置于 \(C\) 与透镜之间（如 \(d=6\text{ cm}\)）时，无论孔径缩得多小（只要 \(r>0\)），光轴附近总有光线能通过光阑到达像盘边缘，因此只变暗（渐晕）不缩小；只有置于 \(C\) 与光屏之间（\(15\text{ cm} < d \le 20\text{ cm}\)，如 \(d=18\text{ cm}\)）时，光阑才会扮演视场光阑从而裁剪像的半径。
- **递进拆解脉络**：
  1. 第一步（无光阑成像分析）：由物距 \(u = 20\text{ cm}\)、焦距 \(f = 10\text{ cm}\) 及薄透镜成像公式 \(\frac{1}{u} + \frac{1}{v} = \frac{1}{f}\) 得像距 \(v = 20\text{ cm}\)，横向放大率 \(\beta = -\frac{v}{u} = -1\)，故光屏上得到半径为 \(5\text{ cm}\) 的倒立圆形亮斑（圆盘状实像）。
  2. 第二步（光锥截面法判定光阑的临界轴向位置）：过透镜下边缘 \((0, -R_L)\) 与像盘上边缘 \((v, +R_i)\) 的极限边缘光线与光轴交于 \(C\) 点，由相似三角形 \(\frac{z_C}{v - z_C} = \frac{R_L}{R_i} = \frac{15}{5} = 3\) 得 \(z_C = 15\text{ cm}\)。等价地，任意像点 \(y' \in [0, 5\text{ cm}]\) 的会聚光锥在透镜后方距离 \(d\) 处截得一个中心在 \(Y_c = \frac{d}{v}y'\)、半径为 \(\rho = \left(1 - \frac{d}{v}\right)R_L\) 的圆盘；当且仅当 \(Y_c > \rho\) 即 \(d > 15\text{ cm}\) 时，足够小的中心光阑才能彻底阻断像边缘的光线。
  3. 第三步（\(d_1 = 6\text{ cm}\) 与透镜前 \(6\text{ cm}\) 分析）：\(d_1 = 6\text{ cm} < 15\text{ cm}\) 时，光锥中心偏移最大仅 \(1.5\text{ cm} < \rho(6) = 10.5\text{ cm}\)，原点恒在每一像点光锥内部。故 \(r\) 减小时（\(r>0\)）像的形状和大小始终不变，仅亮度减弱（先边缘渐晕，后整体变暗），不存在使像半径减半的 \(r_a\)。同理置于透镜前 \(6\text{ cm}\) 时，由物像对称性（\(u=20\text{ cm}, R_0=5\text{ cm}\)），结果完全相同。
  4. 第四步（\(d_2 = 18\text{ cm}\) 计算 \(r_a\)）：当 \(d_2 = 18\text{ cm} > 15\text{ cm}\) 时，\(Y_c(18) = 0.9 y'\)，\(\rho(18) = 1.5\text{ cm}\)。当 \(r < 4.5 - 1.5 = 3.0\text{ cm}\) 后，外圈像点光锥彻底错开光阑，可见像半径按 \(R_i' = \frac{r + 1.5}{0.9}\) 缩小（最小趋于 \(\frac{5}{3}\text{ cm}\)）。令 \(R_i' = 2.5\text{ cm}\)，解得 \(r_a = 0.9 \times 2.5 - 1.5 = 0.75\text{ cm}\)。
- **对照结论**：与官方参考解答核心结论（\(v=20\text{ cm}, R_i=5\text{ cm}\)，\(6\text{ cm}\) 处不变且无 \(r_a\)，\(18\text{ cm}\) 处缩小且 \(r_a = 0.75\text{ cm}\)）完全一致！官方解答采用的是几何交点法：先连接透镜上端 \(A\) 与像下端 \(B\) 求与光轴交点 \(C\)（\(15\text{ cm}\)），再在（3）中连接 \(A\) 与半高点 \(E\) 求交点 \(D\)（距像 \(\frac{20}{7}\text{ cm}\)）并作相似三角形。有趣的是，官方解答在第（4）问只写了透镜后方“\(C\) 点（\(15\text{ cm}\)）与光屏之间”（因为题干起初说光阑在透镜后），而我们在盲解中顺带把物像对称的“透镜前方 \(15\text{ cm}\sim 20\text{ cm}\)”也一并覆盖了，教学上能帮助学生真正打通光路可逆性。
- **核心难点**：
  - 难点1：打破“只画主光线（过光心光线）”的思维定势。在 \(d=6\text{ cm}\) 处，主光线在光阑面上的高度为 \(0.3 \times 5 = 1.5\text{ cm}\)，若只跟踪主光线，会误以为 \(r < 1.5\text{ cm}\) 就会裁切掉像的外圈！必须明白：只要透镜上仍有偏离光心的边缘区域能把光线折过光阑小孔，像边缘就依然被照亮。
  - 难点2：正确区分“亮度下降/渐晕”（只要遮住部分光锥即可发生）与“像大小缩小”（必须把某像点的**全部**光锥完全堵死，即连最靠近光轴的那一条极限边缘光线也被挡住）。
- **高频易错点**：
  - 易错点1：在第（3）问算 \(r_a\) 时误用主光线相似比 \(r_a = \frac{18}{20} \times 2.5 = 2.25\text{ cm}\)，或者误把光阑当成“小孔成像”直接投影。
  - 易错点2：在第（4）问漏掉凸透镜有限口径 \(R_L = 15\text{ cm}\) 的作用，误以为任何在透镜后的光阑只要半径足够小都能改变像的大小；实际上临界位置 \(15\text{ cm}\) 正是由透镜口径和像大小共同决定的。
- **教练总结**：涉及“有限大小透镜 + 附加光阑”的遮挡问题，最稳妥通用的口诀是：**“最远边缘像点连透镜最远对侧边缘，交光轴处即视场分界点 \(C\)”**。在 \(C\) 与透镜之间，光阑主要起**孔径光阑**（及渐晕）作用，减孔径只变暗不缩像；越过 \(C\) 靠近像面（或对称地靠近物面）后，光阑开始充当**视场光阑**，直接线性裁剪像场外径。

## 6. 双扇形多极板旋转电容器的电容、静电力矩与交流能耗均值 (`cpho-2014-semifinal-theory-problem-slice-q6`)

- **难度评级**：`D3`
- **物理模型**：静电场与交流电路 · 分段重叠扇形极板电容、虚功力矩及参量调制能量时间平均
- **教学标签**：`多极板并联电容器`、`大扇形角重叠平台区`、`断电恒电荷虚功力矩`、`参数调制交流平均能量`、`官方解答隐含假设辨析`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：分段重合角与电容 \(C(\theta)\)**：
   \(N+1\) 片定片与 \(N\) 片动片交错叠加，每片动片正反两面各形成一个间隙，共组成 \(2N\) 个完全相同的并联电容单元。利用 \(k = \frac{1}{4\pi\varepsilon_0} \implies \varepsilon_0 = \frac{1}{4\pi k}\)，总电容为：
   \[
   C(\theta) = 2 N \frac{\varepsilon_0 A(\theta)}{s} = \frac{N A(\theta)}{2\pi k s},
   \]
   其中 \(A(\theta)\) 为一对相邻动、定双扇形极板的有效重合面积。
   设定片占据角区间 \([-\theta_0/2, \theta_0/2]\) 与 \([\pi - \theta_0/2, \pi + \theta_0/2]\)；转动 \(\theta\)（\(-\theta_0 \le \theta \le \theta_0\)）后动片占据 \([-\theta_0/2 + \theta, \theta_0/2 + \theta]\) 及其对顶扇区。因为 \(\frac{\pi}{2} \le \theta_0 < \pi\)，其互补空隙角 \(\pi - \theta_0 \le \theta_0\)，故须分两段讨论：
   - **当 \(|\theta| \le \pi - \theta_0\) 时**：动片每一扇区只与原对应的定片扇区重合，重合法向角为 \(\theta_0 - |\theta|\)。两对顶扇区总面积：
     \[
     A(\theta) = 2 \cdot \frac{1}{2} R^2 (\theta_0 - |\theta|) = R^2 (\theta_0 - |\theta|),
     \]
     故
     \[
     C(\theta) = \frac{N R^2 (\theta_0 - |\theta|)}{2\pi k s} \quad \left(|\theta| \le \pi - \theta_0\right).
     \]
   - **当 \(\pi - \theta_0 < |\theta| \le \theta_0\) 时**：动片在滑出原定片扇区的同时，另一侧边缘进入了对侧定片扇区（重合角为 \(|\theta| + \theta_0 - \pi\)），两对顶扇区重合角总和为 \(2[(\theta_0 - |\theta|) + (|\theta| + \theta_0 - \pi)] = 2(2\theta_0 - \pi)\)，不再随 \(\theta\) 变化！故：
     \[
     A(\theta) = R^2 (2\theta_0 - \pi) \implies C(\theta) = \frac{N R^2 (2\theta_0 - \pi)}{2\pi k s} \quad \left(\pi - \theta_0 < |\theta| \le \theta_0\right).
     \]
   （检验特例 \(\theta_0 = \frac{\pi}{2}\)：此时 \(\pi - \theta_0 = \frac{\pi}{2} = \theta_0\)，第二段退化为端点，全区间仅余 \(C(\theta) = \frac{N R^2(\pi/2 - |\theta|)}{2\pi k s}\)。）

2. **第（2）问：最大电容处充断电后的电荷量与驱动力矩大小**：
   电容在 \(\theta = 0\) 处取最大值：
   \[
   C_{\max} = \frac{N R^2 \theta_0}{2\pi k s}.
   \]
   接通电动势 \(E\) 稳定后极板所带总电荷量为：
   \[
   Q = C_{\max} E = \frac{N R^2 \theta_0 E}{2\pi k s}.
   \]
   断开电源后电荷 \(Q\) 保持不变。在电容“接近最大”处（即 \(|\theta|\) 为非零小量，如 \(\theta \to 0^+\)），极板储能 \(U(\theta) = \frac{Q^2}{2 C(\theta)}\)。由虚功原理，静电驱动力矩的大小为：
   \[
   |\tau| = \left|-\frac{\mathrm{d}U}{\mathrm{d}\theta}\right|_{\theta \to 0} = \frac{Q^2}{2 C_{\max}^2} \left|\frac{\mathrm{d}C}{\mathrm{d}\theta}\right|_{\theta \to 0} = \frac{1}{2} E^2 \cdot \frac{N R^2}{2\pi k s} = \frac{N R^2 E^2}{4\pi k s}.
   \]
   （其方向始终指向 \(\theta = 0\)，即试图拉回最大电容、最低能量态。）

3. **第（3）问：边缘效应修正模型下的交流周期平均能量与极大值条件**：
   当 \(\theta_0 = \frac{\pi}{2}\) 时，由第（1）问估算 \(C_{\max} = \frac{N R^2}{4 k s}\)，且 \(C_{\min} = \lambda C_{\max}\)（\(0 < \lambda < 1\)）。代入 \(\theta = \omega_m t\) 与 \(V = V_0 \cos\omega t\)，电容器瞬时能量为：
   \[
   W(t) = \frac{1}{2} C(\theta) V^2 = \frac{1}{4}\left[(C_{\max} + C_{\min}) + (C_{\max} - C_{\min})\cos(2\omega_m t)\right] \cdot \frac{V_0^2}{2}\left[1 + \cos(2\omega t)\right].
   \]
   利用积化和差展开：
   \[
   W(t) = \frac{C_{\max} V_0^2}{8}\left[(1+\lambda) + (1+\lambda)\cos(2\omega t) + (1-\lambda)\cos(2\omega_m t) + \frac{1-\lambda}{2}\cos 2(\omega_m + \omega)t + \frac{1-\lambda}{2}\cos 2(\omega_m - \omega)t\right].
   \]
   对时间取周期平均（或在足够多周期上的平均值，\(\omega, \omega_m \ge 0\)）：
   - **一般情形（\(\omega_m \neq 0\) 且 \(\omega_m \neq \pm\omega\)）**：四个余弦项均值全为零，故
     \[
     \overline{W}_1 = \frac{1+\lambda}{8} C_{\max} V_0^2 = \frac{(1+\lambda) N R^2 V_0^2}{32 k s}.
     \]
   - **非零同步共振情形（\(\omega_m = \pm\omega \neq 0\)）**：差频项 \(\cos 2(\omega_m - \omega)t \equiv 1\)，其余三项均值为零，故
     \[
     \overline{W}_2 = \frac{1}{8}\left[(1+\lambda) + \frac{1-\lambda}{2}\right] C_{\max} V_0^2 = \frac{3+\lambda}{16} C_{\max} V_0^2 = \frac{(3+\lambda) N R^2 V_0^2}{64 k s}.
     \]
     因 \(0 < \lambda < 1\)，明显有 \(\overline{W}_2 - \overline{W}_1 = \frac{1-\lambda}{16} C_{\max} V_0^2 > 0\)。
   - **静止临界特例（\(\omega_m = 0\)）**：若允许转轴完全不转（\(\omega_m = 0\)，即 \(\theta(t) \equiv 0\) 始终停在最大电容处），此时 \(\cos(2\omega_m t) = 1\) 且两差和频项退化为 \(\cos(2\omega t)\)，得出：
     \[
     \overline{W}_0 = \frac{1}{4} C_{\max} V_0^2 = \frac{N R^2 V_0^2}{16 k s}.
     \]
     注意到 \(\overline{W}_0 - \overline{W}_2 = \frac{1-\lambda}{16} C_{\max} V_0^2 > 0\)！因此，在**严格转动条件（\(\omega_m \neq 0\)）下**，平均能量取最大值对应的角速度为 **\(\omega_m = \omega\)（或 \(\pm\omega\)）**；若数学上允许 \(\omega_m = 0\)，则全局最大值在 \(\omega_m = 0\) 处取到。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是经典的旋片式可变空气电容器综合题，看似常规却暗藏三处精巧物理细节：其一，题干特意限定每片对顶双扇形的圆心角 \(\frac{\pi}{2} \le \theta_0 < \pi\)，这意味着当转角超过 \(|\theta| > \pi - \theta_0\) 时，转片离开当前定片扇区的同时已开始转入**对侧**定片扇区，导致重合面积出现恒定的“平台区”而非一路线性递减到零；其二，第（2）问断电源后于 \(\theta = 0\) 尖点附近求力矩，官方特以红字强调求“力矩的大小”，因左右偏移对称反号；其三，第（3）问对随时间同步或异步旋转的电容器求交流周期平均能量，需要分辨共振拍频项 \(\cos 2(\omega_m - \omega)t\) 与静止特例 \(\omega_m = 0\)。
- **递进拆解脉络**：
  1. 第一步（计数并联单元与单间隙重叠面积）：\(N+1\) 片固定双扇形板与 \(N\) 片可旋转双扇形板相间排列，共有 \(2N\) 个完全相同的平行板电容器并联，单个单元电容 \(C_1(\theta) = \frac{\varepsilon_0 A(\theta)}{s} = \frac{A(\theta)}{4\pi k s}\)。因 \(\frac{\pi}{2} \le \theta_0 < \pi\)，当 \(|\theta| \le \pi - \theta_0\) 时两板仅在对应扇区重合，总重合角为 \(2(\theta_0 - |\theta|)\)；当 \(\pi - \theta_0 < |\theta| \le \theta_0\) 时转片同时进入对侧扇区，总重合角保持恒定 \(2(2\theta_0 - \pi)\)，由此写出分段电容 \(C(\theta)\)。
  2. 第二步（断电恒电荷状态下的能量与虚功力矩）：在 \(\theta \to 0\) 处电容最大 \(C_{\max} = \frac{N R^2 \theta_0}{2\pi k s}\)，充电稳定后电荷量 \(Q_{\max} = C_{\max} E\)。断开电源后 \(Q_{\max}\) 恒定，在 \(\theta > 0\) 附近微扰转角，系统储能 \(U(\theta) = \frac{Q_{\max}^2}{2 C(\theta)}\)。由虚功原理 \(|\tau| = \left|\frac{\mathrm{d}U}{\mathrm{d}\theta}\right|_{\theta \to 0} = \frac{Q_{\max}^2}{2 C_{\max}^2}\left|\frac{\mathrm{d}C}{\mathrm{d}\theta}\right|_{\theta\to 0} = \frac{N R^2 E^2}{4\pi k s}\)。
  3. 第三步（展开交流调制瞬时能量）：当 \(\theta_0 = \frac{\pi}{2}\)、\(\theta = \omega_m t\) 且 \(V = V_0 \cos\omega t\) 时，\(C_{\max} = \frac{N R^2}{4 k s}\)、\(C_{\min} = \lambda C_{\max}\)。瞬时静电能 \(W(t) = \frac{1}{2} C(t) V(t)^2 = \frac{V_0^2}{8}\left[(C_{\max}+C_{\min}) + (C_{\max}+C_{\min})\cos 2\omega t + (C_{\max}-C_{\min})\cos 2\omega_m t + \frac{1}{2}(C_{\max}-C_{\min})(\cos 2(\omega_m+\omega)t + \cos 2(\omega_m-\omega)t)\right]\)。
  4. 第四步（周期平均与极值分析）：当 \(\omega_m \neq 0, \pm\omega\) 时，全部余弦项时间平均为零，得 \(\overline{W}_1 = \frac{1+\lambda}{8} C_{\max} V_0^2 = \frac{(1+\lambda)N R^2 V_0^2}{32 k s}\)；当非零同步转动 \(\omega_m = \pm\omega\) 时，差频项 \(\cos 2(\omega_m-\omega)t \equiv 1\)，得 \(\overline{W}_2 = \frac{3+\lambda}{16} C_{\max} V_0^2 = \frac{(3+\lambda)N R^2 V_0^2}{64 k s} > \overline{W}_1\)。同时严谨指出：若允许静止特例 \(\omega_m = 0\)（极板一直停在 \(\theta=0\) 最大电容处），则 \(\overline{W}(0) = \frac{1}{4}C_{\max}V_0^2\) 实际上比 \(\overline{W}_2\) 更大。
- **对照结论**：对照官方参考解答，我们发现了三处极有教学价值的“官方细节与疏漏”：（1）第（1）（2）问结果与官方 100% 一致，包括官方用红字专门修正第（2）问求“力矩的大小”并补充说明“在 \(\theta=0\) 附近取 \(\theta>0\) 并趋近于 0”；（2）第（3）问存在一处原题印刷语病“而 \(C_{\min}\) 是 \(C_{\max}\) 的比值 \(\lambda\) 是已知的”（意为 \(C_{\min}/C_{\max} = \lambda\)），同时官方参考解答在第 14 页给出了两个互相矛盾的数值版本（一版按 \(C_{\max} = \frac{NR^2}{4ks}\)、\(C_{\min} = \lambda C_{\max}\) 得出我们的 \((1+\lambda)\) 与 \((3+\lambda)\) 结果，评分标准即按此版赋分；另一版括号补充却额外假设 \(C_{\max}-C_{\min} = C_{\max}^{\text{ideal}}\) 导致出现 \(1+2\lambda\) 与 \(3+4\lambda\)）；（3）官方解答在判定最大值时只比较了 \(\overline{U}_2(\omega_m=\omega)\) 与 \(\overline{U}_1(\omega_m\neq\omega)\)，直接忽略了 \(\omega_m = 0\) 给出 \(\frac{1}{4}C_{\max}V_0^2 > \overline{U}_2\) 的数学事实（隐含默认 \(\omega_m \neq 0\)）。
- **核心难点**：
  - 难点1：第（1）问中大张角扇形（\(\theta_0 \ge \pi/2\)）转角较大时“一侧滑出、另一侧滑入对侧扇区”造成的电容平台效应，这解释了为何题干特意限定 \(\frac{\pi}{2} \le \theta_0 < \pi\)。
  - 难点2：第（2）问断电条件（\(Q\) 恒定）与带电接源条件（\(V\) 恒定）下虚功力矩公式符号的区别，以及在 \(\theta=0\) 不可导尖点处取单侧极限求力矩大小的处理。
- **高频易错点**：
  - 易错点1：把 \(N+1\) 片定片和 \(N\) 片动片误算成 \(N\) 个或 \(2N+1\) 个电容器并联（正确为 \(2N\) 个间隙并联）。
  - 易错点2：在第（2）问用 \(U = \frac{Q^2}{2C}\) 对 \(\theta\) 求导时忘记带入 \(C(\theta)\) 在分母引起的链式求导，或者把 \(U = \frac{1}{2}CV^2\)（恒压条件）当成 \(Q\) 恒定状态直接求导导致力矩反号。
  - 易错点3：在第（3）问漏掉 \(\cos(2\omega_m t)\cos(2\omega t)\) 展开后的差频共振项 \(\cos 2(\omega_m - \omega)t\)，错以为所有转速下的均值都相同。
- **教练总结**：求解可变电容器问题须谨记“三步防错口诀”：（1）先数**有效间隙数**（交错片数较少的组每片贡献 2 个面，故 \(2N\) 单元并联）；（2）算力矩统一用结论 \(\tau = +\frac{1}{2}V^2 \frac{\mathrm{d}C}{\mathrm{d}\theta}\)（无论电源接通还是断开，求瞬时力矩均可直接代瞬时电压 \(V\) 与 \(\frac{\mathrm{d}C}{\mathrm{d}\theta}\)，避免符号混淆！）；（3）处理双频率周期乘积平均时，务必全部展开为单频和差角形式再判断共振条件（且勿忘检验 \(\omega_m = 0\) 边界）。

## 7. Z-箍缩双层钨丝阵列的安培力、磁压强与柱壳磁场几何证明 (`cpho-2014-semifinal-theory-problem-slice-q7`)

- **难度评级**：`D3`
- **物理模型**：静磁场与磁流体力学 · 离散导线阵列自箍缩安培力、磁压强与无安培环路定理之纯几何磁场证明
- **教学标签**：`Z-箍缩惯性约束聚变`、`离散N根导线精确求和`、`双层柱面磁压强比较`、`圆弦几何对称性消元`、`毕奥-萨伐尔定律几何替代证明`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：单根内圈钨丝微元的安培力**：
   注意 \(N\) 未必无穷大，且导线自身不对自己产生安培力，必须对其余 \(N-1\) 根导线精确叠加！
   每根内圈钨丝通电流 \(i = \frac{I_{\text{内}}}{N}\)。考虑第 0 根钨丝，与圆心连线夹角为 \(\varphi\) 的另一根钨丝到它的距离为 \(d = 2r\sin\frac{\varphi}{2}\)。两平行同向载流直导线相互吸引，在长度 \(\Delta L\) 上的安培力大小为 \(F_0 = k_m \frac{i^2}{d}\Delta L\)。
   由圆周对称性，切向分量相互抵消，沿径向指向轴心的分量为：
   \[
   F_{r}(\varphi) = F_0 \sin\frac{\varphi}{2} = \frac{k_m i^2 \Delta L}{2r\sin(\varphi/2)}\cdot \sin\frac{\varphi}{2} = \frac{k_m i^2 \Delta L}{2r} \quad (\text{与 }\varphi\text{ 无关!}).
   \]
   因此其余 \(N-1\) 根导线对它施加的总安培力为：
   \[
   F = (N - 1)\frac{k_m i^2 \Delta L}{2r} = \frac{(N - 1) k_m I_{\text{内}}^2 \Delta L}{2 N^2 r},
   \]
   方向**沿半径垂直指向圆柱轴线**。

2. **第（2）问：连续圆柱面单位面积安培力（磁压强）**：
   内圈熔化为连续柱面对应 \(N \gg 1\)，将 \(N\) 根长 \(\Delta L\) 钨丝所受向内合力 \(N F \approx \frac{k_m I_{\text{内}}^2 \Delta L}{2r}\) 除以柱带侧面积 \(\Delta S = 2\pi r \Delta L\)：
   \[
   P_{\text{内}} = \frac{k_m I_{\text{内}}^2}{4\pi r^2}.
   \]
   代入数据 \(k_m = 2\times 10^{-7}\text{ N/A}^2\)、\(I_{\text{内}} = 2\times 10^7\text{ A}\)、\(r = 0.25\text{ cm} = 2.5\times 10^{-3}\text{ m}\)：
   \[
   P_{\text{内}} = \frac{2\times 10^{-7}\times (2\times 10^7)^2}{4\pi \times (2.5\times 10^{-3})^2} = \frac{3.2\times 10^{12}}{\pi}\text{ N/m}^2 \approx 1.02\times 10^{12}\text{ Pa}.
   \]
   折合大气压数（\(1\text{ atm} \approx 1.013\times 10^5\text{ Pa}\)）：
   \[
   \frac{P_{\text{内}}}{1\text{ atm}} \approx 1.0\times 10^7\text{ atm}\quad (\text{约 } 10^7\text{ 个大气压}).
   \]

3. **第（3）问：证明均匀轴向电流长圆柱面内部磁场为零**：
   - **证法一（过内点作微角张角几何配对法，不依赖安培环路定理）**：
     取柱面内任意一点 \(A\)，由轴对称与镜面对称可知若存在磁场必在横截面内。在横截面内过 \(A\) 作两条夹角为微小角 \(\Delta\theta\) 的直线，在圆周上截出两段微小圆弧 \(L_1, L_2\)，它们到 \(A\) 点的距离分别为 \(l_1, l_2\)。由圆弦性质，弦与两处圆切线夹角相等（记为 \(\psi\)），故弧长 \(L_1 = \frac{l_1 \Delta\theta}{\sin\psi}\)、\(L_2 = \frac{l_2 \Delta\theta}{\sin\psi}\)。因电流均匀分布，两段弧微元的电流之比 \(\frac{I_1}{I_2} = \frac{L_1}{L_2} = \frac{l_1}{l_2}\)。它们在 \(A\) 点产生的磁感应强度大小分别为 \(B_1 = k_m\frac{I_1}{l_1}\) 与 \(B_2 = k_m\frac{I_2}{l_2}\)，故 \(B_1 = B_2\)，且由右手螺旋定则方向恰**完全相反**！将整个圆周分成无数对这样的微弧，总磁场处处为零。
   - **证法二（安培环路定理+对称性）**：利用绕轴旋转与沿轴平移对称性及轴矢量反射对称性知 \(\mathbf{B} = B_\theta(\rho)\hat{\theta}\)，对内部同轴圆环用 \(\oint \mathbf{B}\cdot\mathrm{d}\mathbf{l} = \mu_0 I_{\text{enc}} = 0\) 得 \(B = 0\)。
   因此，均匀通电外圈钨丝柱面在内圈处不产生磁场，不改变前两小题结果。

4. **第（4）问：外圈半径 \(R\) 满足的条件**：
   外圈共有 \(M\) 根钨丝，每根电流同内圈为 \(i = \frac{I_{\text{内}}}{N}\)，故外圈总电流 \(I_{\text{外}} = \frac{M}{N} I_{\text{内}}\)。
   外圈每根钨丝同时受到：（a）其余 \(M-1\) 根外圈导线产生的自箍缩力 \(\frac{M-1}{2 R} k_m \Delta L i^2\)；（b）内圈总电流产生的外磁场 \(B_{\text{内}}(R) = k_m \frac{I_{\text{内}}}{R}\) 施加的安培力 \(i B_{\text{内}}(R) \Delta L\)。
   全外柱面总向内安培力为 \(F_{\text{外}} = \left(\frac{M(M-1)}{2} i^2 + M i I_{\text{内}}\right)\frac{k_m \Delta L}{R}\)。取连续柱面极限（\(M \gg 1\)，即 \(M-1 \approx M\)），除以侧面积 \(2\pi R \Delta L\) 得外柱面单位面积安培力：
   \[
   P_{\text{外}} = \frac{k_m (I_{\text{外}}^2 + 2 I_{\text{内}} I_{\text{外}})}{4\pi R^2} = \frac{k_m I_{\text{内}}^2}{4\pi R^2}\left(\frac{M^2}{N^2} + \frac{2M}{N}\right).
   \]
   要求 \(P_{\text{外}} > P_{\text{内}} = \frac{k_m I_{\text{内}}^2}{4\pi r^2}\)，并兼顾几何上外圈在外部（\(R > r\)），得：
   \[
   r < R < r\sqrt{\frac{M^2 + 2 N M}{N^2}} = \frac{r}{N}\sqrt{M(M + 2N)}
   \]
   （仅当 \(\frac{M}{N} > \sqrt{2} - 1\) 时该区间非空；若不省略 \(M-1\)，上界为 \(\frac{r}{N}\sqrt{M(M-1+2N)}\)）。

5. **第（5）问：用非安培环路定理的方法证明柱面外磁场等效于全部电流集中于轴线**：
   - **方法 A（直接毕奥-萨伐尔积分法）**：
     取柱外一点 \(C(\rho, 0)\)（\(\rho > r\)），圆周角 \(\theta\) 处微元电流 \(\mathrm{d}I = \frac{I_{\text{内}}}{2\pi}\mathrm{d}\theta\)。由对称性 \(B_x = 0\)，
     \[
     B_y = k_m \frac{I_{\text{内}}}{2\pi} \int_0^{2\pi} \frac{\rho - r\cos\theta}{\rho^2 + r^2 - 2\rho r\cos\theta}\,\mathrm{d}\theta.
     \]
     利用恒等式 \(\frac{\rho - r\cos\theta}{\rho^2 + r^2 - 2\rho r\cos\theta} = \frac{1}{2\rho} + \frac{\rho^2 - r^2}{2\rho(\rho^2 + r^2 - 2\rho r\cos\theta)}\)，作半角代换 \(t = \tan(\theta/2)\) 算得后一项积分为 \(\frac{2\pi}{\rho^2 - r^2}\)，从而 \(B_y = k_m \frac{I_{\text{内}}}{2\pi}\left(\frac{\pi}{\rho} + \frac{\pi}{\rho}\right) = k_m \frac{I_{\text{内}}}{\rho}\)。
   - **方法 B（二维静电场高斯定理类比）**：将长直导线磁场 \(\mathrm{d}\mathbf{B} = k_m \frac{\mathrm{d}I}{d^2}(\hat{z} \times \mathbf{d})\) 类比为二维线电荷电场 \(\mathrm{d}\mathbf{E} = \frac{\mathrm{d}\lambda}{2\pi\varepsilon_0 d^2}\mathbf{d}\) 绕轴旋转 \(90^\circ\) 的结果，借助高斯球壳定律的二维柱壳版本立得柱外等效于轴心集中线源。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以惯性约束核聚变的 Z-箍缩装置为现代科技背景，层层递进地融合了离散对称求和与连续柱壳极限。第（1）问中，圆周上任意两根同向载流直导线间的吸引安培力投影到径向时，几何弦长因子 \(\sin(\varphi/2)\) 恰好消去，使其余 \(N-1\) 根导线对选定导线的径向贡献完全相等！第（2）问取连续极限给出高达 \(10^7\text{ atm}\) 的惊人磁压强。第（3）与第（5）问则要求**不用安培环路定理**而另辟蹊径，利用过观察点作微元张角与圆相交产生的一对弧元满足圆幂弦角相等定理，巧妙证明均匀载流长圆柱壳内部磁场为零、外部等效于全部电流集中于轴线。
- **递进拆解脉络**：
  1. 第一步（离散 \(N\) 根导线的精确自箍缩安培力）：圆周上任意另一根导线与选定导线夹角为 \(\varphi\)，间距 \(d = 2r\sin\frac{\varphi}{2}\)，两平行同向电流吸引力的径向内收分量为 \(F_r = \frac{k_m \Delta L i^2}{2r\sin(\varphi/2)} \cdot \sin\frac{\varphi}{2} = \frac{k_m \Delta L i^2}{2r}\)，竟与角度 \(\varphi\) 无关！故对剩余 \(N-1\) 根导线求和并代入 \(i = I_{\text{内}}/N\) 得 \(F = \frac{(N-1)k_m \Delta L I_{\text{内}}^2}{2 r N^2}\)，方向沿径向指向轴线。
  2. 第二步（连续圆柱面磁压强估算）：当内圈熔化为连续柱面（\(N \gg 1\)）时，所有 \(N\) 根导线总内收力除以柱面侧面积 \(2\pi r \Delta L\) 得单位面积安培力 \(P = \frac{k_m I_{\text{内}}^2}{4\pi r^2}\)。代入 \(I_{\text{内}} = 2\times 10^7\text{ A}\)、\(r = 2.5\times 10^{-3}\text{ m}\)，算出 \(P \approx 1.02\times 10^{12}\text{ Pa} \approx 1.0\times 10^7\text{ atm}\)。
  3. 第三步（几何张角微元法证明壳内磁场为零、壳外等效轴线电流）：对第（3）问壳内任意点 \(A\)，过 \(A\) 作微张角 \(\Delta\theta\) 截圆周于两弧段 \(L_1, L_2\)（距离 \(l_1, l_2\)），由弦切角相等得 \(I_1/I_2 = L_1/L_2 = l_1/l_2\)，两段电流在 \(A\) 点磁场大小 \(k_m I_1/l_1 = k_m I_2/l_2\) 且方向相反，配对抵消。对第（5）问壳外距轴 \(l\) 的任意点 \(C\)，过 \(C\) 作张角 \(\Delta\theta\) 截两弧元 \(L_3, L_4\)，由正弦定理得 \(l_3 + l_4 = 2l\cos\theta\)，从而投影到总磁场方向的合场为 \(k_m \left(\frac{I_3}{l_3} + \frac{I_4}{l_4}\right)\cos\theta = 2 k_m \frac{I_3+I_4}{l_3+l_4}\cos\theta = k_m \frac{I_3+I_4}{l}\)，逐对叠加即等效于总电流集中于轴心。
  4. 第四步（双层柱面磁压强比较求外半径条件）：外圈共有 \(M\) 根导线、总电流 \(I_{\text{外}} = \frac{M}{N} I_{\text{内}}\)。每根外圈导线同时受到“其余 \(M-1\) 根外圈导线的自箍缩力”与“内圈总电流产生磁场 \(k_m I_{\text{内}}/R\) 的安培力”，在连续极限（\(M\gg 1\)）下外柱面单位面积所受安培力 \(P_{\text{外}} = \frac{k_m(I_{\text{外}}^2 + 2 I_{\text{内}} I_{\text{外}})}{4\pi R^2}\)。令 \(P_{\text{外}} > P_{\text{内}}\)，结合几何约束 \(R > r\)，解得 \(r < R < r\sqrt{\frac{M^2 + 2NM}{N^2}}\)（其中需 \(M/N > \sqrt{2}-1\)）。
- **对照结论**：前四问答案与官方参考解答完全一致（包括官方在（4）式中先保留 \(M-1\) 随后在（16）式顺滑过渡到连续近似 \(M^2 + 2NM\)）。第（5）问中官方解答给出了一个比微积分代换**更加初等精巧的纯几何证明**：在截面内从外部点 \(C\) 作张角 \(\Delta\theta\) 截圆于两弧元 \(L_3, L_4\)，利用正弦定理证明 \(l_3 + l_4 = 2l\cos\theta\)（\(l = CO\)），于是 \(\Delta B_C = k_m\left(\frac{I_3}{l_3} + \frac{I_4}{l_4}\right)\cos\theta = 2 k_m \frac{I_3+I_4}{l_3+l_4}\cos\theta = k_m \frac{I_3+I_4}{l}\)，与我们在（3）中使用的几何张角法一脉相承，无需任何积分技巧！
- **核心难点**：
  - 难点1：连续柱面自作用力中的 \(1/2\) 因子来源。通过第（1）问先算离散 \(N\) 根导线的自箍缩，再用第（4）问叠加内圈外场，能深刻体会到“自场取内外均值 \(B/2\)，外场取全值 \(B_{\text{内}}\)”的物理图像。
  - 难点2：第（5）问禁用安培环路定理后如何求解任意柱外点磁场——无论是半角三角代换积分，还是圆心正弦定理配对法，都对数学转化能力要求极高。
- **高频易错点**：
  - 易错点1：第（1）问错把连续柱壳外磁场公式 \(B = k_m I_{\text{内}}/r\) 直接代入计算某根内圈钨丝受力，导致丢失 \((N-1)/(2N)\) 因子（差了整整 2 倍！）。
  - 易错点2：第（4）问计算外圈柱面受力时，只计算了内圈磁场对它的作用力而漏掉外圈自身电流间的箍缩力（或者反过来把外圈自身也错按全磁场计算而漏了 \(1/2\) 因子）；另外容易忽略几何前提 \(R > r\)。
- **教练总结**：涉及圆柱面电流（或球面电荷）的等效性问题，记住三种“去环路/去高斯定理”的常规武器：（1）**微角对弧几何法**（用 \(\Delta S \propto l^2\Delta\Omega\) 或 \(L \propto l\Delta\theta/\sin\psi\) 结合正弦定理）；（2）**直接毕奥-萨伐尔积分分解**（把 \(\rho - r\cos\theta\) 拆成常数和圆心反演项）；（3）**势函数（磁矢势 \(A_z\) / 电势）展开**。此外，多层同轴载流壳的磁压力永远可以直接用公式 \(P = \frac{B_{\text{外}}^2 - B_{\text{内}}^2}{2\mu_0}\) 一键秒查校验！

## 8. 巴耳末系光谱红移与哈勃定律测定星系距离 (`cpho-2014-semifinal-theory-problem-slice-q8`)

- **难度评级**：`D1`
- **物理模型**：近代物理与天体物理 · 氢原子能级跃迁、非相对论多普勒红移与哈勃膨胀定律
- **教学标签**：`氢原子巴耳末线系`、`宇宙学红移与多普勒效应`、`哈勃定律测距`、`频率比值法识谱`、`有效数字相减损失`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：确定巴耳末系跃迁及实验室波长**：
   氢原子从能级 \(n > 2\) 跃迁至 \(k = 2\) 发出的光子频率满足：
   \[
   h\nu_n = |E_0|\left(\frac{1}{2^2} - \frac{1}{n^2}\right) = 13.60\,\text{eV}\left(\frac{1}{4} - \frac{1}{n^2}\right).
   \]
   由于统一红移因子 \((1+z)\) 满足 \(\nu_n' = \frac{\nu_n}{1+z}\)，两观测频率之比直接等于静止频率之比：
   \[
   \frac{\nu_2'}{\nu_1'} = \frac{6.141\times 10^{14}}{4.549\times 10^{14}} \approx 1.3500 = \frac{27}{20}.
   \]
   逐一检验巴耳末系相邻能级比值，当 \(n_1 = 3, n_2 = 4\) 时：
   \[
   \frac{\frac{1}{4} - \frac{1}{16}}{\frac{1}{4} - \frac{1}{9}} = \frac{3/16}{5/36} = \frac{27}{20} = 1.3500,
   \]
   且由题给常数 \(E_0 = -13.60\text{ eV}\)、\(h = 6.626\times 10^{-34}\text{ J}\cdot\text{s}\)、\(e = 1.602\times 10^{-19}\text{ C}\)、\(c = 2.998\times 10^8\text{ m/s}\) 计算静止频率：
   \[
   \nu_{3\to 2} = \frac{13.60 \times \frac{5}{36} \times 1.602\times 10^{-19}}{6.626\times 10^{-34}} \approx 4.567\times 10^{14}\text{ Hz},
   \]
   \[
   \nu_{4\to 2} = \frac{13.60 \times \frac{3}{16} \times 1.602\times 10^{-19}}{6.626\times 10^{-34}} \approx 6.165\times 10^{14}\text{ Hz},
   \]
   两者均仅略高于观测值（符合红移变长、频率变低）。对应的实验室波长分别为：
   \[
   \lambda_1 = \frac{c}{\nu_{3\to 2}} = 656.5\text{ nm}\quad (n=3\to 2,\ H_\alpha \text{ 线}),
   \]
   \[
   \lambda_2 = \frac{c}{\nu_{4\to 2}} = 486.3\text{ nm}\quad (n=4\to 2,\ H_\beta \text{ 线}).
   \]

2. **第（2）问：红移量 \(z\) 与星系退行速度 \(V\)**：
   由定义 \(z = \frac{\lambda' - \lambda}{\lambda} = \frac{\nu - \nu'}{\nu'}\)，两条谱线分别给出：
   \[
   z_1 = \frac{4.5669 - 4.549}{4.549} \approx 3.93\times 10^{-3}, \quad z_2 = \frac{6.1653 - 6.141}{6.141} \approx 3.95\times 10^{-3},
   \]
   取均值 \(z \approx 3.94\times 10^{-3}\)。（注：由于分子相减后有效数字仅剩 2~3 位，四舍五入取两位有效数字约为 \(3.9\times 10^{-3}\)。）
   由于 \(z \ll 1\)（低速退行 \(V \ll c\)），由相对论纵多普勒公式 \(\lambda' = \lambda\sqrt{\frac{1+V/c}{1-V/c}} \approx \lambda\left(1 + \frac{V}{c}\right)\) 得 \(z \approx \frac{V}{c}\)，从而退行速度大小：
   \[
   V = c z \approx 2.998\times 10^8 \times 3.94\times 10^{-3} \approx 1.18\times 10^6\text{ m/s} = 1.18\times 10^3\text{ km/s}.
   \]

3. **第（3）问：星系距离 \(D\)**：
   由哈勃定律 \(V = H D\)（其中 \(H = 67.80\text{ km/(s}\cdot\text{Mpc)}\)）：
   \[
   D = \frac{V}{H} = \frac{1.181\times 10^3\text{ km/s}}{67.80\text{ km/(s}\cdot\text{Mpc)}} \approx 17.4\text{ Mpc}.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题把原子物理的氢原子巴耳末系跃迁与现代天体物理的星系红移测距结合在一起。由于观测到的所有谱线受到统一的红移因子 \((1+z)\) 缩放，两条观测频率的比值严格等于其在实验室静止系中的比值，利用 \(\nu_2'/\nu_1' \approx 1.35 = \frac{27}{20}\)（或利用 \(z \ll 1\) 直接反解量子数 \(n\)）即可唯一锁定两条谱线为 \(H_\alpha\)（\(n=3\to 2\)）和 \(H_\beta\)（\(n=4\to 2\)）。随后通过波长/频率红移定义求出 \(z\)，由低速多普勒近似 \(z \approx V/c\) 算出退行速度 \(V\)，最后由哈勃定律 \(D = V/H\) 算出星系距离。特别值得训练的是“相近大数相减导致的有效数字退化”。
- **递进拆解脉络**：
  1. 第一步（识别量子数 \(n_1, n_2\) 及实验室波长）：氢原子巴耳末系（跃迁至 \(k=2\)）光子能量满足 \(h\nu = |E_0|\left(\frac{1}{4} - \frac{1}{n^2}\right)\)。由于红移量 \(z = \frac{\lambda' - \lambda}{\lambda} = \frac{\nu - \nu'}{\nu'} \ll 1\)，将 \(\nu_1' = 4.549\times 10^{14}\text{ Hz}\)、\(\nu_2' = 6.141\times 10^{14}\text{ Hz}\) 代入 \(n \approx \left(\frac{1}{4} - \frac{h\nu'}{|E_0|}\right)^{-1/2}\)，或直接对比频率比 \(\frac{\nu_2'}{\nu_1'} = 1.3500 = \frac{1/4 - 1/16}{1/4 - 1/9}\)，唯一确定两条谱线分别对应 \(n_1 = 3 \to 2\)（\(H_\alpha\) 线）和 \(n_2 = 4 \to 2\)（\(H_\beta\) 线）。由 \(\lambda = \frac{hc}{\Delta E}\) 算得实验室波长分别为 \(\lambda_1 \approx 656.5\text{ nm}\) 与 \(\lambda_2 \approx 486.3\text{ nm}\)。
  2. 第二步（计算红移量 \(z\) 与退行速度 \(V\)）：由 \(z = \frac{\nu - \nu'}{\nu'}\) 对两条谱线分别求出 \(z_1 \approx 3.93\times 10^{-3}\) 与 \(z_2 \approx 3.95\times 10^{-3}\)，取均值 \(z \approx 3.94\times 10^{-3}\)（若先将 \(\nu_1, \nu_2\) 保留四位有效数字取差再除，则受相减损失限制保留两位有效数字为 \(z \approx 0.0040\)）。因 \(z \ll 1\)，相对论多普勒公式 \(\nu' = \nu\sqrt{\frac{1-V/c}{1+V/c}}\) 简化为 \(z \approx \frac{V}{c}\)，解得 \(V = c z \approx 1.18\times 10^6\text{ m/s}\)（或两位有效数字 \(1.2\times 10^6\text{ m/s}\)）。
  3. 第三步（由哈勃定律求距离 \(D\)）：将 \(V\) 与 \(H = 67.80\text{ km/(s}\cdot\text{Mpc)}\) 代入哈勃定律 \(D = \frac{V}{H}\)，求得星系距离 \(D \approx 17.4\text{ Mpc}\)（取两位有效数字为 \(17\text{ Mpc}\) 或按 \(z=0.0040\) 得 \(18\text{ Mpc}\)）。
- **对照结论**：物理模型与推导完全一致，但出现了一个极具教学意义的**有效数字舍入差异**：盲解中保持全部中间精度算出 \(\nu_2 = 6.1653\times 10^{14}\text{ Hz}\)，得出 \(z = 3.94\times 10^{-3}, D = 17.4\text{ Mpc}\)（两位有效数字为 \(17\text{ Mpc}\)）；而官方参考解答先将 \(\nu_1, \nu_2\) 分别舍入至四位有效数字 \(4.567\times 10^{14}\text{ Hz}\) 与 \(6.166\times 10^{14}\text{ Hz}\)（注意 `6.16526` 进位为 `6.166` 属小幅舍入误差），再相减时意识到有效数字退化为 2 位，从而给出 \(z = 0.0040\)、\(V = 1.2\times 10^6\text{ m/s}\) 及 \(D = 18\text{ Mpc}\)。对此官方评分标准也专门加注：“有效数字位数正确但数值有微小差别的，仍给分”。
- **核心难点**：
  - 难点1：在不知道具体 \(z\) 的前提下识别两条观测谱线对应的巴耳末能级 \(n_1, n_2\)（比值法可完全消去未知红移因子 \((1+z)\)，也可以用 \(z \ll 1\) 先近似代入反求整数 \(n\)）。
  - 难点2：数值计算中的“相近大数相减”引发的有效数字降阶意识（4 位减 4 位在小数点后第三位对齐，仅剩 2 位有效数字）。
- **高频易错点**：
  - 易错点1：把单位 \(\text{Mpc}\) 硬换算成米或光年（题干并未给出 \(1\text{ pc}\) 的数值），或忘记把 \(V\) 的单位从 \(\text{m/s}\) 换算为 \(\text{km/s}\)（\(H\) 中为 \(\text{km/(s}\cdot\text{Mpc)}\)）导致距离差出 \(10^3\) 倍。
  - 易错点2：把红移公式用反（写成 \(z = \frac{\nu' - \nu}{\nu}\) 或误把 \(z\) 当作负值），或者把 \(E_0 = -13.60\text{ eV}\) 直接按焦耳代入而忘记乘以元电荷 \(e\)。
- **教练总结**：天体光谱红移识别题有两大标准技巧：（1）**双线比值消红移**：未知 \(z\) 时，多条观测线频率比值与红移无关，能精准匹配原子跃迁比例；（2）**中间过程多留一位有效数字**：凡涉及 \((\nu - \nu')/\nu'\) 的微小差值计算，中间结果若提前四舍五入很容易使最终两位结果跳变 5% 以上，计算时应多保留 1–2 位，仅在最后一步依据相减后的有效位数按规则修约。

# 决赛理论试题（Final Theory）

## 9. 含点电荷与弹簧的旋转细管转速控制及径向微振动 (`cpho-2014-final-theory-problem-slice-q1`)

- **难度评级**：`D3`
- **物理模型**：刚体与质点动力学 · 电磁力-弹簧-离心力耦合平衡、角动量守恒与径向微振动稳定性
- **教学标签**：`角动量守恒`、`库仑力变号瞬变`、`轻质细管等效单球转动惯量`、`有效势能法判定稳定性`、`径向微振动周期`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：弹簧系数 \(k_0\) 与 \(B\) 处转速 \(\omega_B\)**：
   （记静电常数 \(k = \frac{1}{4\pi\varepsilon_0}\)，弹簧自由长度 \(L_0 = L/4\)。）
   - **小球到达 \(A\) 处（\(r_A = L\)，开关触发前瞬间）**：
     细管转速 \(\omega_A\) 缓慢增大使球刚好在 \(A\) 处相对细管径向平衡（\(\dot{r}_A \approx 0\)）。此时 \(O\) 点电荷为 \(+Q\)，弹簧伸长量 \(\frac{3}{4}L\) 产生向内拉力，库仑斥力向外，径向动力学方程为：
     \[
     \frac{3}{4} k_0 L - k \frac{q Q}{L^2} = m L \omega_A^2. \tag{1}
     \]
   - **触发后到 \(B\) 处（\(r_B = L/2\)）**：
     触发控制开关后外力矩瞬时变为零；又因绝缘细管为轻质（转动惯量忽略不计），系统对转轴的总角动量仅由小球承担且从触发时刻起严格守恒：
     \[
     J = m L^2 \omega_A = m \left(\frac{L}{2}\right)^2 \omega_B \implies \omega_B = 4 \omega_A. \tag{2}
     \]
     此时 \(O\) 点电荷已变为 \(-Q\)，球在 \(B\) 处（弹簧伸长量 \(\frac{L}{2} - \frac{L}{4} = \frac{L}{4}\)）处于新的径向平衡，向内的弹力与向内的库仑引力共同提供向心力：
     \[
     \frac{1}{4} k_0 L + k \frac{q Q}{(L/2)^2} = m \frac{L}{2} \omega_B^2. \tag{3}
     \]
     将 \(\omega_B^2 = 16\omega_A^2\) 代入 (3) 式，得 \(\frac{1}{4} k_0 L + \frac{4 k q Q}{L^2} = 8 m L \omega_A^2\)。联立 (1) 式消去 \(m L \omega_A^2\)：
     \[
     \frac{1}{4} k_0 L + \frac{4 k q Q}{L^2} = 8\left(\frac{3}{4} k_0 L - \frac{k q Q}{L^2}\right) = 6 k_0 L - \frac{8 k q Q}{L^2} \implies \frac{23}{4} k_0 L = \frac{12 k q Q}{L^2}.
     \]
     解得弹簧劲度系数：
     \[
     k_0 = \frac{48 k q Q}{23 L^3} = \frac{12 q Q}{23 \pi \varepsilon_0 L^3}.
     \]
     代回 (1) 式检验正定性：\(m L \omega_A^2 = \left(\frac{36}{23} - 1\right)\frac{k q Q}{L^2} = \frac{13 k q Q}{23 L^2} > 0\)，物理上完全可行！从而 \(B\) 处细管转速（角速度）为：
     \[
     \omega_B = 4\omega_A = 4\sqrt{\frac{13 k q Q}{23 m L^3}} = \sqrt{\frac{52 q Q}{23 \pi \varepsilon_0 m L^3}}.
     \]
     （附带自检：\(A\) 点触发前外力驱动恒角速度下的平衡稳定性 \(U_{\text{eff}}''(L) = \frac{1}{4}k_0 + \frac{3kqQ}{L^3} > 0\) 成立，说明静态随转速增大可平稳抵达 \(A\) 处。）

2. **第（2）问：\(B\) 附近径向微振动存在性及周期**：
   触发后外力矩为零，小球在径向微振动中**角动量 \(J = m r^2 \omega(r)\) 保持守恒**（切忌把 \(\omega\) 当成常数！）。
   令径向坐标 \(r = \frac{L}{2} + x\)（\(|x| \ll L\)），由有效势能法：
   \[
   U_{\text{eff}}(r) = \frac{J^2}{2 m r^2} + \frac{1}{2} k_0 \left(r - \frac{L}{4}\right)^2 - \frac{k q Q}{r}.
   \]
   一阶导数在 \(r_B = L/2\) 处为零（即平衡方程 (3)）；求二阶导数得等效回复劲度系数 \(k_{\text{eff}} = U_{\text{eff}}''(L/2)\)：
   \[
   k_{\text{eff}} = \frac{3 J^2}{m r_B^4} + k_0 - \frac{2 k q Q}{r_B^3} = 3 m \omega_B^2 + k_0 - \frac{16 k q Q}{L^3}.
   \]
   代入 \(m\omega_B^2 = \frac{208 k q Q}{23 L^3}\) 与 \(k_0 = \frac{48 k q Q}{23 L^3}\)：
   \[
   k_{\text{eff}} = \left(\frac{624 + 48}{23} - 16\right) \frac{k q Q}{L^3} = \frac{672 - 368}{23} \frac{k q Q}{L^3} = \frac{304 k q Q}{23 L^3} > 0.
   \]
   因为 \(k_{\text{eff}} > 0\)，\(B\) 点为稳定平衡点，**存在**相对细管的径向微振动，振动周期为：
   \[
   T = 2\pi\sqrt{\frac{m}{k_{\text{eff}}}} = 2\pi\sqrt{\frac{23 m L^3}{304 k q Q}} = \frac{\pi}{2}\sqrt{\frac{23 m L^3}{19 k q Q}} = \pi\sqrt{\frac{23 \pi \varepsilon_0 m L^3}{19 q Q}}.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题巧妙设计了一个结合静电力、胡克弹力与转动惯性力的机电稳速测量装置。触发开关 \(A\) 前细管由外力矩准静态加速，球抵达 \(A\) 处刚好平衡；触发后外力矩撤除、原点电荷由 \(+Q\) 反转为 \(-Q\)，小球移至新平衡点 \(B\)（\(r_B = L/2\)）。由于“细管轻质”且无外力矩，触发前后系统角动量完全由小球承担且严格守恒（\(\omega_B = 4\omega_A\)），联立 \(A, B\) 两处的径向平衡方程即可唯一消去未知 \(\omega_A\) 确定弹簧系数 \(k_0\)。第（2）问则是高能物理与天体物理常见的“角动量守恒稳定陷阱”：若误把 \(\omega\) 当常数，\(1/r^2\) 吸引库仑力下 \(B\) 点将失稳；必须计入角动量守恒带来的 \(+J^2/(mr^3)\) 离心势垒回复项，方能正确判稳并算出周期。
- **递进拆解脉络**：
  1. 第一步（\(A\) 点平衡与触发后角动量守恒）：球在 \(A\) 处（\(r_A = L\)，原点电荷 \(+Q\)）径向平衡，弹力向内、库仑斥力向外，满足 \(k_0\frac{3}{4}L - \frac{k q Q}{L^2} = m L \omega_A^2\)。触发开关后外力矩归零且细管轻质，系统角动量全部由小球贡献并严格守恒：\(m L^2 \omega_A = m\left(\frac{L}{2}\right)^2 \omega_B \implies \omega_B = 4\omega_A\)。
  2. 第二步（\(B\) 点平衡联立解出 \(k_0\) 与 \(\omega_B\)）：触发后原点电荷变为 \(-Q\)，球在 \(B\) 处（\(r_B = L/2\)）受向内的弹力和库仑引力共同提供向心力，满足 \(k_0\frac{L}{4} + \frac{k q Q}{(L/2)^2} = m\frac{L}{2}\omega_B^2 = 8 m L \omega_A^2\)。消去 \(m L \omega_A^2\) 解得 \(k_0 = \frac{48 k q Q}{23 L^3}\)（即 \(\frac{12 q Q}{23 \pi \varepsilon_0 L^3}\)），代回即得 \(\omega_B = 4\sqrt{\frac{13 k q Q}{23 m L^3}}\)。
  3. 第三步（引入角动量守恒有效势分析径向微振动）：令球在 \(B\) 附近发生微小径向偏移 \(r = \frac{L}{2} + x\)（\(|x| \ll L\)），角动量守恒要求瞬时角速度随 \(r\) 变化：\(\omega(r) = \omega_B \frac{(L/2)^2}{r^2} \approx \omega_B\left(1 - \frac{4x}{L}\right)\)。由有效势 \(U_{\text{eff}}(r) = \frac{J^2}{2mr^2} + \frac{1}{2}k_0\left(r - \frac{L}{4}\right)^2 - \frac{k q Q}{r}\) 求二阶导，或直接将合力 \(F(x) = -k_0(\frac{L}{4}+x) - \frac{k q Q}{(L/2+x)^2} + m(\frac{L}{2}+x)\omega(r)^2\) 线性展开。
  4. 第四步（判定稳定存在并求解周期）：一阶线性展开得恢复力 \(F(x) = -\left(k_0 + 3 m \omega_B^2 - \frac{16 k q Q}{L^3}\right)x = -\frac{304 k q Q}{23 L^3} x\)。因等效劲度系数 \(k_{\text{eff}} = \frac{304 k q Q}{23 L^3} > 0\)，稳定径向微振动**存在**，其周期为 \(T = 2\pi\sqrt{\frac{m}{k_{\text{eff}}}} = \frac{\pi}{2}\sqrt{\frac{23 m L^3}{19 k q Q}}\)。
- **对照结论**：与官方参考解答 100% 一致，包括 \(k_0 = \frac{48 k q Q}{23 L^3}\)、\(\omega_B = 4\sqrt{\frac{13 k q Q}{23 m L^3}}\) 及微振动周期 \(T = \frac{\pi}{2}\sqrt{\frac{23 m L^3}{19 k q Q}}\)（系数和指数分毫不差）。相比之下，官方解答在第（2）问采用力函数 \(F(x)\) 直接在非惯性参考系展开到 \(x\) 的一阶项，而我们的盲解采用的有效势二阶导方法一步得到 \(3 m \omega_B^2\)，在教学中两者可相互印证。
- **核心难点**：
  - 难点1：理解“外力矩变为零后角速度并非恒定”，微振动过程中小球径向进退会通过角动量守恒引起细管转速 \(\omega(r)\) 同步脉动，正是这个调制使等效离心力随 \(r^{-3}\) 剧增从而稳定住 \(r^{-2}\) 库仑引力。
  - 难点2：正确计入“细管轻质”这一隐含条件——这意味着细管本身不携带角动量，否则还需知道细管转动惯量 \(I_{\text{管}}\)。
- **高频易错点**：
  - 易错点1：第（2）问错把角速度 \(\omega_B\) 当作常数代入离心力 \(m(L/2+x)\omega_B^2\)，从而得到等效劲度 \(k_0 - m\omega_B^2 - \frac{16kqQ}{L^3} < 0\)，误判为“不存在微振动”（正好踩中命题人设计的陷阱！）。
  - 易错点2：在列 \(A, B\) 两处的径向平衡方程时，把弹簧自由长度 \(L/4\) 忘掉而直接用 \(L\) 和 \(L/2\) 乘以 \(k_0\)，或把原点电荷由 \(+Q\) 反转为 \(-Q\) 后的吸引力方向画反。
- **教练总结**：凡遇“无外力矩旋转管道/杆上的径向滑块微振动”，第一条铁律就是把离心项写成守恒量形式 \(\frac{J^2}{m r^3}\)（有效势 \(\frac{J^2}{2 m r^2}\)），而不是 \(m \omega^2 r\)（有效势 \(-\frac{1}{2} m \omega^2 r^2\)）！二者二阶导数分别是 \(+3m\omega^2\) 与 \(-m\omega^2\)，一念之差直接颠倒稳定与失稳的物理结论。

## 10. 潜艇发射多弹头母弹高空水平分裂的弹道求解与实现条件 (`cpho-2014-final-theory-problem-slice-q2`)

- **难度评级**：`D3`
- **物理模型**：抛体运动与动量守恒 · 质心运动分解、高空水平对称分裂与双目标命中几何条件
- **教学标签**：`质心运动与相对运动分解`、`三弹头水平等速分裂对称性`、`二维圆与直线交点分析`、`双弹着点分支讨论`、`官方参考解答勘误`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **坐标系建立与分裂瞬间动量守恒**：
   取海岸线为 \(x\) 轴，两目标中点为原点，\(W\left(-\frac{L}{2}, 0, 0\right)\)、\(N\left(+\frac{L}{2}, 0, 0\right)\)；海域侧为 \(y < 0\)，潜艇巡弋线为 \(y = -d\)（发射点 \((x_0, -d, 0)\)），竖直向上为 \(z\) 轴。设母弹以速率 \(v_0\)、仰角 \(\theta\)（相对水平面）、水平射向与 \(+x\) 轴夹角（或法线方位角）发射，其水平分速度为 \(\mathbf{V}_h = (v_{0x}, v_{0y})\)，竖直分速度为 \(v_{0z} = v_0\sin\theta\)。
   到达最高点耗时 \(t_1 = \frac{v_{0z}}{g}\)。在最高点分裂成三个等质量分弹头，相对母弹速度 \(\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\) 均在水平面内且大小均为 \(v\)。由爆炸动量守恒：
   \[
   \mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 = \mathbf{0}, \quad |\mathbf{v}_1| = |\mathbf{v}_2| = |\mathbf{v}_3| = v.
   \]
   三等长共面矢量之和为零，故它们**互成 \(120^\circ\) 对称分布**。

2. **落点匹配与仰角、时间锁定**：
   因分裂在水平面内，所有分弹头在最高点处竖直初速均为零，故下落耗时仍为 \(t_2 = t_1 = \frac{v_{0z}}{g}\)，总飞行时间为 \(2t_1\)。两实弹落点水平坐标为：
   \[
   \mathbf{r}_1 = \mathbf{r}_0 + 2 t_1 \mathbf{V}_h + \mathbf{v}_1 t_1 = \left(-\frac{L}{2}, 0\right), \quad \mathbf{r}_2 = \mathbf{r}_0 + 2 t_1 \mathbf{V}_h + \mathbf{v}_2 t_1 = \left(+\frac{L}{2}, 0\right).
   \]
   - **两式相减**：
     \[
     (\mathbf{v}_2 - \mathbf{v}_1) t_1 = (L, 0).
     \]
     因 \(|\mathbf{v}_1| = |\mathbf{v}_2| = v\) 且夹角 \(120^\circ\)，有 \(|\mathbf{v}_2 - \mathbf{v}_1| = \sqrt{3}\, v\)，由此唯一解出半程时间 \(t_1\)、竖直速度与发射仰角 \(\theta\)：
     \[
     t_1 = \frac{L}{\sqrt{3}\, v}, \quad v_{0z} = g t_1 = \frac{g L}{\sqrt{3}\, v} \implies \sin\theta = \frac{g L}{\sqrt{3}\, v_0 v}, \quad \cos\theta = \sqrt{1 - \frac{g^2 L^2}{3 v_0^2 v^2}}.
     \]
   - **两式相加取均值（质心轨迹方程）**：
     注意到 \((\mathbf{v}_1 + \mathbf{v}_2) \cdot (\mathbf{v}_2 - \mathbf{v}_1) = v^2 - v^2 = 0\)，故 \(\mathbf{v}_1 + \mathbf{v}_2 = -\mathbf{v}_3\) 必垂直于海岸线（沿 \(\pm y\) 方向），且大小为 \(v\)！因此存在两个物理可行的分裂朝向：
     - **情形 I（质心落于海面，即假弹头向海飞 \(\mathbf{v}_3 = -v\hat{y}\)、实弹前扑海岸 \(\mathbf{v}_1+\mathbf{v}_2 = +v\hat{y}\)）**；
     - **情形 II（质心落于陆地，即假弹头飞越海岸线 \(\mathbf{v}_3 = +v\hat{y}\)、实弹向后分裂 \(\mathbf{v}_1+\mathbf{v}_2 = -v\hat{y}\)）**。
     质心落点水平坐标为 \(\mathbf{r}_{\text{cm}} = \mathbf{r}_0 + 2 t_1 \mathbf{V}_h = \left(0, \mp \frac{v t_1}{2}\right) = \left(0, \mp \frac{L}{2\sqrt{3}}\right)\)（负号对应情形 I，正号对应情形 II）。

3. **潜艇位置、水平发射方向及实现条件**：
   质心总水平射程为：
   \[
   s = 2 t_1 v_0 \cos\theta = \frac{2L}{\sqrt{3}\, v} \sqrt{v_0^2 - \frac{g^2 L^2}{3 v^2}} = \frac{2L}{3 v^2}\sqrt{3 v_0^2 v^2 - g^2 L^2}.
   \]
   由 \((x_0 - 0)^2 + \left(-d - \left(\mp \frac{L}{2\sqrt{3}}\right)\right)^2 = s^2\) 解出潜艇可行的对称发射坐标 \((x_0, -d)\)：
   \[
   x_0 = \pm \sqrt{\frac{4 L^2}{9 v^4}\left(3 v_0^2 v^2 - g^2 L^2\right) - \left(d \mp \frac{L}{2\sqrt{3}}\right)^2}.
   \]
   记水平发射方向与巡弋线（\(+x\) 方向，指向或背向海岸）的夹角为 \(\alpha\)（\(v_{0y} = v_0\cos\theta \sin\alpha\)，\(v_{0x} = \pm v_0\cos\theta\cos\alpha\)），则：
   \[
   \sin\alpha = \frac{d \mp \frac{L}{2\sqrt{3}}}{s} = \frac{(2\sqrt{3}\, d \mp L) v}{4 L v_0 \sqrt{1 - \frac{g^2 L^2}{3 v_0^2 v^2}}}, \quad \cos\alpha = \frac{|x_0|}{s} = \sqrt{1 - \frac{9 v^4 \left(d \mp \frac{L}{2\sqrt{3}}\right)^2}{4 L^2 \left(3 v_0^2 v^2 - g^2 L^2\right)}}.
   \]
   （注：在情形 I 中，当 \(d < \frac{L}{2\sqrt{3}}\) 时，\(v_{0y} < 0\)，表示潜艇先略向离岸方向发射再靠实弹前扑命中目标。）
   **实现条件**：
   1. \(0 < \frac{g L}{\sqrt{3}\, v_0 v} \le 1\)（即 \(v_0 v \ge \frac{gL}{\sqrt{3}}\) 且 \(v_0 v > \frac{gL}{\sqrt{3}}\) 以保证水平射程非零）；
   2. \(x_0^2 \ge 0 \iff |\sin\alpha| \le 1\)，即 \(\frac{|2\sqrt{3}\,d \mp L| v}{4 L v_0 \sqrt{1 - \frac{g^2 L^2}{3 v_0^2 v^2}}} \le 1\)；
   3. 潜艇在海上即 \(d > 0\)。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是经典的“多弹头分导式导弹”力学建模题。母弹在最高点分裂为三个等质量、相对母弹速率同为 \(v\) 且共处同一水平面的分弹头，由爆炸瞬间动量守恒立即可知三者的相对速度必然构成互成 \(120^\circ\) 的正三角形。又因分裂速度全在水平面内，两实弹下降时间仍与母弹上升时间 \(t\) 严格相等。利用两实弹落点之差与落点中点，即可把发射时间 \(t = \frac{L}{\sqrt{3}v}\)（即竖直分速度与仰角）完全锁定，并将潜艇可能位置归结为两条分支（分弹头向前冲向海岸 vs 假弹头向前引诱雷达）对应的圆与直线交点。对照分析还发现了官方两种参考解法在 \(\cos\alpha\) 中漏写分母因子 4 的印刷错误。
- **递进拆解脉络**：
  1. 第一步（高空分裂速度几何对称性分析）：设海岸线为 \(x\) 轴，两目标为 \(W(-L/2, 0)\)、\(N(+L/2, 0)\)，潜艇航线在 \(y = -d\) 上。母弹达最高点分裂为三个等质量、相对速率为 \(v\) 的水平分弹头，由水平动量守恒 \(\mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 = \mathbf{0}\) 与等模长条件，三者速度矢量必构成正三角形，任意两者夹角为 \(120^\circ\)。
  2. 第二步（运动分解定出飞行半程时间与发射仰角）：因分裂相对速度无竖直分量，两实弹从最高点下落的时间等于母弹上升时间 \(t = \frac{v_{0z}}{g}\)。在水平面内，两实弹落点位置矢量差为 \(\mathbf{r}_2 - \mathbf{r}_1 = (\mathbf{v}_2 - \mathbf{v}_1) t\)。因 \(|\mathbf{v}_2 - \mathbf{v}_1| = \sqrt{3}\, v\) 且须跨距 \(L\)，立即确定 \(t = \frac{L}{\sqrt{3}\,v}\)，进而竖直分速度 \(v_{0z} = \frac{g L}{\sqrt{3}\,v}\)、发射仰角满足 \(\sin\theta = \frac{g L}{\sqrt{3}\,v_0 v}\)。
  3. 第三步（质心落点双分支与潜艇发射位置）：母弹质心总水平射程为 \(s = 2 t \sqrt{v_0^2 - v_{0z}^2} = \frac{2L}{3v^2}\sqrt{3 v_0^2 v^2 - g^2 L^2}\)。因 \((\mathbf{v}_1+\mathbf{v}_2) \perp (\mathbf{v}_2-\mathbf{v}_1)\) 且大小为 \(v\)，实弹 1、2 相对质心的纵向偏移大小为 \(\frac{v t}{2} = \frac{L}{2\sqrt{3}}\)，对应质心落点位于垂直平分线上 \((0, -\frac{L}{2\sqrt{3}})\)（海面上空分裂，实弹前扑海岸）或 \((0, +\frac{L}{2\sqrt{3}})\)（陆地上空分裂，假弹头前飞）。由此潜艇位置 \(x = \pm \sqrt{s^2 - \left(d \mp \frac{L}{2\sqrt{3}}\right)^2}\)。
  4. 第四步（发射方位角与实现条件）：射程方位角 \(\alpha\)（水平投影与海岸线夹角，正负区分斜向陆地或背向海岸）满足 \(\sin\alpha = \frac{d \mp L/(2\sqrt{3})}{s}\) 及 \(\cos\alpha = \frac{|x|}{s} = \sqrt{1 - \frac{9 v^4 (d \mp L/(2\sqrt{3}))^2}{4 L^2(3 v_0^2 v^2 - g^2 L^2)}}\)。操作可行条件即仰角 \(\sin\theta \le 1\)、方位角 \(|\sin\alpha| \le 1\) 以及 \(d > 0\)。
- **对照结论**：核心物理模型、双分支分类与位置/仰角公式与官方两套参考解答（直接分弹头轨迹法与质心分解法）完全一致！更重要的是，通过逐项核对，我们在官方解答中发现了**一处明确的计算排版错误**：在官方“参考解答（一）”的⑦⑧式以及“参考解答（二）”的⑧式中，由 \(\cos\alpha = |x|/s\) 推导的表达式均漏掉了根号内第二项分母上的因子 **\(4\)**（官方印成 \(\sqrt{1 - \frac{9 v^4 (d \mp \frac{L}{2\sqrt{3}})^2}{L^2(3 v_0^2 v^2 - g^2 L^2)}}\)，而由其自身的 \(\sin\alpha\) 平方可得 \(\sin^2\alpha = \frac{9v^4(d \mp \frac{L}{2\sqrt{3}})^2}{4L^2(3v_0^2 v^2 - g^2 L^2)}\)，正确分母必须带系数 \(4\)，否则 \(\sin^2\alpha + \cos^2\alpha \neq 1\)！）；此外官方参考解答（一）第二分支还把公式编号⑦⑧写反了。盲解中的矢量投影法从根源上避免了这一代数抄漏。
- **核心难点**：
  - 难点1：发现“爆炸瞬间动量守恒”结合“相对速度共面等大”将三个速度夹角死死锁在 \(120^\circ\)，且因为实弹相对速度无竖直分量，下落时间仍与上升时间相同。
  - 难点2：避免漏解！假弹头可以向后飞向海面（质心落在海中），也可以向前飞向内陆（质心落在陆地），且 \(d < \frac{L}{2\sqrt{3}}\) 时水平分速度还可背向海岸。
- **高频易错点**：
  - 易错点1：误以为潜艇一定在目标中垂线 \(x=0\) 处发射，忽略了固定发射速率 \(v_0\) 下仰角 \(\theta\) 已被 \(L, v\) 唯一锁定，从而总射程 \(s\) 是定值，导致潜艇位置只能取以质心落点为圆心、\(s\) 为半径的圆与航线 \(y=-d\) 的交点（一般为两个对称点）。
  - 易错点2：对 \(\sin\alpha\) 与 \(\cos\alpha\) 化简时出错（甚至官方解答自身在将 \(s = \frac{2L}{3v^2}\sqrt{3v_0^2 v^2 - g^2 L^2}\) 平方代回时也漏掉了 \(2^2 = 4\)）。
- **教练总结**：多体爆炸抛体问题最强的降维工具永远是**“质心运动与相对质心运动分离 + \(\mathbf{r}_2 - \mathbf{r}_1\) 与 \(\mathbf{r}_1 + \mathbf{r}_2\) 矢量和差法”**。凡遇未知发射位置、发射方向的多变量搜索，写成矢量方程后“两式相减消发射参数、两式相加定质心轨迹”，可把复杂的立体三角方程瞬间简化为平面圆与直线的求交问题。

## 11. 三室绝热容器中自由膨胀、压缩与双组分气体绝热膨胀 (`cpho-2014-final-theory-problem-slice-q3`)

- **难度评级**：`D3`
- **物理模型**：热力学 · 自由膨胀不可逆过程、能量守恒混合与双组分理想气体等效绝热指数
- **教学标签**：`自由膨胀内能守恒`、`连通气室体积计入`、`热力学混合平衡`、`双组分气体等效绝热指数`、`熵恒定推导过程方程`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **初始参量整理**：
   - 气体 1（单原子理想气体，\(A\) 室）：\(\nu_1 = 1\text{ mol}\)，\(C_{V1} = \frac{3}{2}R\)，\(C_{p1} = \frac{5}{2}R\)，\(\gamma_1 = \frac{5}{3}\)，初态 \((p_0, V_0, T_0)\)，满足 \(p_0 V_0 = R T_0\)。
   - 气体 2（双原子理想气体，\(C\) 室）：\(\nu_2 = 2\text{ mol}\)，\(C_{V2} = \frac{5}{2}R\)，\(C_{p2} = \frac{7}{2}R\)，初态体积 \(V_0\)、温度 \(T_C = 0.50 T_0\)（可见 \(p_C = \frac{2 R (0.5 T_0)}{V_0} = p_0\)）。

2. **第（1）问：压缩过程前后的温度与压强**：
   - **压缩前（自由膨胀后平衡态）**：
     打开 \(K_1\) 后气体 1 向真空 \(B\) 室自由膨胀，总体积变为 \(V_1 = V_A + V_B = 2 V_0\)。该过程绝热（\(Q=0\)）且不对真空做功（\(W=0\)），由热力学第一定律 \(\Delta U = 0\)，理想气体温度不变：
     \[
     T_1 = T_0, \quad p_1 = \frac{\nu_1 R T_1}{2 V_0} = \frac{1}{2} p_0 = 0.50\,p_0.
     \]
   - **压缩后（\(V_A' = 0.70 V_0\)）**：
     注意阀门 \(K_1\) 仍开启，故气体 1 实际被压缩后的总体积为：
     \[
     V' = V_A' + V_B = 0.70 V_0 + V_0 = 1.70 V_0.
     \]
     缓慢推动绝热活塞 \(H\) 为准静态绝热过程，套用提示式 (I)（或 \(T V^{\gamma_1 - 1} = \text{const}\)）：
     \[
     \frac{3}{2}\ln\frac{T'}{T_0} + \ln\frac{1.70 V_0}{2.00 V_0} = 0 \implies T' = \left(\frac{20}{17}\right)^{2/3} T_0 = 0.85^{-2/3} T_0 \approx 1.114\, T_0.
     \]
     压强由状态方程（或 \(p V^{5/3} = \text{const}\)）得：
     \[
     p' = p_1 \left(\frac{2.00}{1.70}\right)^{5/3} = \frac{1}{2} \left(\frac{20}{17}\right)^{5/3} p_0 = \frac{1}{2} \times 0.85^{-5/3} p_0 \approx 0.656\, p_0.
     \]

3. **第（2）问：打开 \(K_2\) 自由混合后的温度与压强**：
   保持 \(K_1\) 开启再打开 \(K_2\)，容器总容积固定为 \(V'' = 0.70 V_0 + V_0 + V_0 = 2.70 V_0\)，绝热刚性边界下 \(Q = 0, W = 0\)，故两气体混合前后总内能守恒：
   \[
   \nu_1 C_{V1} T' + \nu_2 C_{V2} T_C = (\nu_1 C_{V1} + \nu_2 C_{V2}) T''.
   \]
   代入 \(\nu_1 C_{V1} = \frac{3}{2} R\)、\(\nu_2 C_{V2} = 2\times \frac{5}{2} R = 5 R\)、\(T_C = \frac{1}{2} T_0\)：
   \[
   \frac{3}{2} R T' + 5 R \left(\frac{1}{2} T_0\right) = \frac{13}{2} R T'' \implies T'' = \frac{3 T' + 5 T_0}{13} = \frac{3(20/17)^{2/3} + 5}{13} T_0 \approx 0.642\, T_0.
   \]
   由道尔顿分压定律（理想气体混合态方程），总摩尔数 \(\nu_{\text{tot}} = 1 + 2 = 3\text{ mol}\)，混合压强为：
   \[
   p'' = \frac{3 R T''}{2.70 V_0} = \frac{10}{9}\frac{T''}{T_0} p_0 = \frac{10\left[3(20/17)^{2/3} + 5\right]}{117} p_0 \approx 0.713\, p_0.
   \]

4. **第（3）问：拉回活塞至 \(V_A'' = V_0\) 后的温度与压强**：
   总容积准静态绝热膨胀至 \(V''' = V_0 + V_0 + V_0 = 3.0 V_0\)。两气体已均匀混合且温度同步变化，直接应用提示式 (II) \((\Delta S_1)_{2\to 3} + (\Delta S_2)_{2\to 3} = 0\)：
   \[
   (\nu_1 C_{V1} + \nu_2 C_{V2})\ln\frac{T'''}{T''} + (\nu_1 + \nu_2) R \ln\frac{V'''}{V''} = 0.
   \]
   代入 \(\nu_1 C_{V1} + \nu_2 C_{V2} = \frac{13}{2}R\) 与 \((\nu_1 + \nu_2)R = 3 R\)：
   \[
   \frac{13}{2}\ln\frac{T'''}{T''} + 3\ln\frac{3.0}{2.7} = 0 \implies T''' = \left(\frac{9}{10}\right)^{6/13} T'' = 0.90^{6/13} \frac{3(20/17)^{2/3} + 5}{13} T_0 \approx 0.611\, T_0.
   \]
   （可见混合气体等效绝热指数为 \(\gamma_m = 1 + \frac{3}{13/2} = \frac{19}{13}\)。）
   由状态方程得末态压强：
   \[
   p''' = \frac{3 R T'''}{3 V_0} = \frac{T'''}{T_0} p_0 = 0.90^{6/13} \frac{3(20/17)^{2/3} + 5}{13} p_0 = 0.90^{19/13} p'' \approx 0.611\, p_0.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题把绝热容器中的真空自由膨胀、准静态绝热压缩、两种不同自由度气体的不可逆混合以及随后的混合气体准静态绝热膨胀串联成一个四阶段热力学实验链。解题的核心陷阱有两处：其一，第（1）问中阀门 \(K_1\) 开启后并未关闭，推动活塞压缩 \(A\) 室体积减小 \(30\%\) 时，气体总体积由 \(2V_0\) 变为 \(1.70 V_0\)（而非 \(0.70 V_0\)）；其二，第（3）问混合气体准静态绝热膨胀时不能乱套单原子或双原子的 \(\gamma\)，而须由题给熵守恒式（II）\((\Delta S_1)_{if} + (\Delta S_2)_{if} = 0\)（或由热力学第一定律 \(\mathrm{d}Q = 0\) 直接积分）导出混合气体的等效绝热指数 \(\gamma_m = \frac{\nu_1 C_{p1} + \nu_2 C_{p2}}{\nu_1 C_{V1} + \nu_2 C_{V2}} = \frac{19}{13}\)。
- **递进拆解脉络**：
  1. 第一步（阶段 1a：真空自由膨胀）：打开 \(K_1\)，\(A\) 室中 \(\nu_1 = 1\text{ mol}\) 单原子气体（\(C_{V1} = \frac{3}{2}R, \gamma_1 = \frac{5}{3}\)）向真空 \(B\) 室自由膨胀，体积变为 \(V_1 = 2V_0\)。因 \(Q=0, W=0\)，内能守恒故温度不变 \(T_1 = T_0\)，压强降至 \(p_1 = \frac{1}{2} p_0\)。
  2. 第二步（阶段 1b：准静态绝热压缩）：保持 \(K_1\) 开启，缓慢推动活塞 \(H\) 使 \(A\) 室体积为 \(0.70 V_0\)，气体总体积成为 \(V' = 0.70V_0 + V_0 = 1.70 V_0\)。由可逆绝热方程 \(p_1 V_1^{5/3} = p' V'^{5/3}\) 得压缩后压强 \(p' = \frac{1}{2}\left(\frac{2.0}{1.7}\right)^{5/3} p_0 = 0.85^{-5/3}\frac{p_0}{2}\)，温度 \(T' = \left(\frac{2.0}{1.7}\right)^{2/3} T_0 = 0.85^{-2/3} T_0\)。
  3. 第三步（阶段 2：开阀 \(K_2\) 混合达平衡）：保持 \(K_1\) 开、打开 \(K_2\)，两气体在刚性绝热总容积 \(V'' = 0.70V_0 + V_0 + V_0 = 2.70 V_0\) 内自由混合。因 \(Q=0, W=0\)，系统总内能守恒：\(\nu_1\frac{3}{2}R T' + \nu_2\frac{5}{2}R T_C = \left(\nu_1\frac{3}{2}R + \nu_2\frac{5}{2}R\right)T''\)。代入 \(\nu_1=1, \nu_2=2, T_C=0.50 T_0\)，得 \(T'' = \frac{3 T' + 5 T_0}{13}\)，由总摩尔数 \(\nu_1 + \nu_2 = 3\) 得混合压强 \(p'' = \frac{3 R T''}{2.70 V_0} = \frac{10}{9}\frac{T''}{T_0} p_0\)。
  4. 第四步（阶段 3：混合气体准静态绝热膨胀）：缓慢拉动活塞使 \(A\) 室恢复 \(V_0\)（总体积 \(V''' = 3.0 V_0\)）。利用提示中混合气体可逆绝热熵变为零式（II），得 \((\nu_1 C_{V1} + \nu_2 C_{V2})\ln\frac{T'''}{T''} + (\nu_1 + \nu_2)R\ln\frac{V'''}{V''} = 0\)，等效绝热指数 \(\gamma_m = 1 + \frac{3R}{\frac{13}{2}R} = \frac{19}{13}\)。故 \(T''' = \left(\frac{2.7}{3.0}\right)^{6/13} T'' = 0.90^{6/13} T''\)，压强 \(p''' = \frac{3 R T'''}{3 V_0} = \frac{T'''}{T_0} p_0 = 0.90^{19/13} p''\)。
- **对照结论**：与官方参考解答 100% 一致！无论是 \(0.85^{-5/3}\frac{p_0}{2}\)、\(0.85^{-2/3}T_0\)、\(\frac{3\times 0.85^{-2/3}+5}{13}T_0\) 还是 \(0.90^{19/13}p''\)、\(0.90^{6/13}T''\)，全部符号与小数结果完全一致。官方解答还在最后附带展示了（a）利用题给熵公式（II）和（b）不利用提示直接对 \(\mathrm{d}Q_1 + \mathrm{d}Q_2 = 0\) 积分两种方式证明 \(\gamma_m = \frac{\nu_1 C_{p1} + \nu_2 C_{p2}}{\nu_1 C_{V1} + \nu_2 C_{V2}}\)。
- **核心难点**：
  - 难点1：准确区分可逆过程与不可逆过程所适用的物理定律。阶段 1a（自由膨胀）和阶段 2（不同温气体自由混合）都是不可逆绝热过程，**熵必增加**，绝不能用公式（I）（II），必须用总内能守恒；阶段 1b 和阶段 3（缓慢推拉活塞）才是准静态绝热等熵过程。
  - 难点2：正确导出混合理想气体的等效绝热指数 \(\gamma_m = \frac{\nu_1 C_{p1} + \nu_2 C_{p2}}{\nu_1 C_{V1} + \nu_2 C_{V2}}\)——切忌按摩尔分数加权平均各自的 \(\gamma_i\)（即 \(\frac{\nu_1\gamma_1 + \nu_2\gamma_2}{\nu_1+\nu_2}\) 是错的，应分别对 \(C_p\) 和 \(C_V\) 加权求和再相除！）。
- **高频易错点**：
  - 易错点1：第（1）问中误把压缩后气体总体积写成 \(0.70 V_0\) 而忘记 \(B\) 室的 \(V_0\) 依然连通。
  - 易错点2：第（3）问错把混合气体绝热指数算成 \(\frac{1\times \frac{5}{3} + 2\times \frac{7}{5}}{3} = \frac{67}{45}\)（误算 \(\gamma\) 的算术平均值而非 \(C_p/C_V\) 总比值 \(\frac{19}{13}\)）。
  - 易错点3：算压强时漏用 \(\nu_1 = 1\text{ mol}\) 给出的基准关系 \(p_0 V_0 = R T_0\)，导致答案里多余残留 \(R\) 或 \(V_0\)。
- **教练总结**：多室绝热题遵循严格的“流程状态机”习惯：每一步先标出（过程可逆性、体积变化、摩尔数变化）三要素。切记混合理想气体的任何热力学常数都是先对广延量（\(\sum \nu_i C_{Vi}\) 与 \(\sum \nu_i C_{pi}\)）求加和，再求比值 \(\gamma_m\)，绝不可直接平均强度量 \(\gamma_i\)。

## 12. 光纤布拉格光栅多层介质的相干反射与最小层数设计 (`cpho-2014-final-theory-problem-slice-q4`)

- **难度评级**：`D2`
- **物理模型**：波动光学 · 四分之一波长介质膜系相干加强与单次反射振幅叠加模型
- **教学标签**：`光纤布拉格光栅`、`半波损失与光程差`、`四分之一波长膜层`、`透射衰减与单次反射叠加`、`界面计数细节`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **各层最小厚度 \(d_1, d_2\)**：
   由题给反射公式，光从 \(n_1 = 1.51\) 垂直射入 \(n_2 = 1.55\) 时，振幅反射比 \(r_{12} = \frac{n_1 - n_2}{n_1 + n_2} < 0\)（产生 \(\pi\) 相位突变，即半波损失）；从 \(n_2\) 射入 \(n_1\) 时，\(r_{21} = \frac{n_2 - n_1}{n_1 + n_2} = -r_{12} > 0\)（无半波损失）。
   - 比较第 1 界面（\(n_1 \to n_2\)）与第 2 界面（\(n_2 \to n_1\)）的反射波：第 2 界面波多走了光程 \(2 n_2 d_2\)，但少了一次 \(\pi\) 跃变，总相位差 \(\Delta\phi_{21} = \frac{2\pi}{\lambda}(2 n_2 d_2) - \pi\)。欲相干加强且厚度最小正值，取 \(\Delta\phi_{21} = 0\)：
     \[
     2 n_2 d_2 = \frac{\lambda}{2} \implies d_2 = \frac{\lambda}{4 n_2} = \frac{1.06\,\mu\text{m}}{4 \times 1.55} \approx 0.171\,\mu\text{m} = 171\text{ nm}.
     \]
   - 比较第 2 界面（\(n_2 \to n_1\)）与第 3 界面（\(n_1 \to n_2\)）的反射波：第 3 界面波多走了光程 \(2 n_1 d_1\) 且多了一次 \(\pi\) 跃变，总相位差 \(\Delta\phi_{32} = \frac{2\pi}{\lambda}(2 n_1 d_1) + \pi\)。欲相干加强取最小正值 \(\Delta\phi_{32} = 2\pi\)：
     \[
     2 n_1 d_1 = \frac{\lambda}{2} \implies d_1 = \frac{\lambda}{4 n_1} = \frac{1.06\,\mu\text{m}}{4 \times 1.51} \approx 0.1755\,\mu\text{m} \approx 175.5\text{ nm}.
     \]
   在此四分之一波长厚度下，全部反射界面回波均严格同相相干叠加加强。

2. **器件反射率达到 \(8\%\) 所需的最小总层数 \(N\)**：
   细看图（a）：基体材料为 \(n_1\)，调制区第 1 层至第 \(N\) 层依次为 \(n_2, n_1, n_2, n_1, \dots, n_2\)，而后出射回基体 \(n_1\)，共有 **\(N + 1\) 个反射界面**。
   设入射电场振幅为 \(E_0\)，单界面反射振幅绝对值：
   \[
   r = \frac{n_2 - n_1}{n_1 + n_2} = \frac{1.55 - 1.51}{1.55 + 1.51} = \frac{2}{153} \approx 0.013072.
   \]
   穿过单个界面来回一次的振幅透射乘积为：
   \[
   t_{12} t_{21} = \left(\frac{2 n_1}{n_1 + n_2}\right)\left(\frac{2 n_2}{n_1 + n_2}\right) = \frac{4 n_1 n_2}{(n_1 + n_2)^2} = 1 - r^2 \approx 0.999829.
   \]
   题干限定仅考虑每层界面的单次反射，故第 \(j\) 个界面（\(j = 1, 2, \dots, N+1\)）返回入射端的同相振幅为 \(E_j = E_0 r (1 - r^2)^{j-1}\)。求和得总反射振幅：
   \[
   E_{\text{refl}} = E_0 r \sum_{j=0}^{N} (1 - r^2)^j = E_0 r \frac{1 - (1 - r^2)^{N+1}}{1 - (1 - r^2)} = E_0 \frac{1 - (1 - r^2)^{N+1}}{r}.
   \]
   要求反射率 \(R = \left(\frac{E_{\text{refl}}}{E_0}\right)^2 \ge 0.08\)，即 \(\frac{E_{\text{refl}}}{E_0} \ge \sqrt{0.08} \approx 0.28284\)：
   \[
   (1 - r^2)^{N+1} \le 1 - r\sqrt{0.08} \implies N + 1 \ge \frac{\ln(1 - 0.013072\times 0.28284)}{\ln(1 - 0.013072^2)} \approx 21.68 \implies N \ge 20.68.
   \]
   （若近似取 \(t_{12}t_{21} \approx 1\)，线性相干累加 \((N+1)r \ge \sqrt{0.08} \implies N \ge \frac{\sqrt{0.08}}{r} - 1 \approx 20.64\)，同样得到 \(N \ge 21\)；注意奇数 \(N = 21\) 恰保证末层为 \(n_2\) 层！）
   因此，总层数 \(N\) 至少为 **\(21\)** 层。（注：此时共 22 个界面，理论单次反射率约 \(8.24\%\)。）

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以光通信核心器件——光纤布拉格光栅（FBG）为背景，考查薄膜干涉中半波损失、相位相干条件以及弱反射界面多层累加的振幅计算。由于从 \(n_1 = 1.51\) 入射至 \(n_2 = 1.55\) 时产生 \(\pi\) 相位突变（半波损失），而由 \(n_2\) 入射至 \(n_1\) 时无半波损失，为使各界面反射波全部同相相干加强，每层光学厚度均须取四分之一波长（\(n_1 d_1 = n_2 d_2 = \lambda/4\)）。计算达到 \(8\%\) 反射率所需总层数 \(N\) 时，题目明确“只考虑单次反射”，既可用提示中的透射系数计入往返衰减因子 \((t_{12}t_{21})^j = (1 - r^2)^j\) 求等比级数和，也可利用 \(n_1 \approx n_2\) 直接线性累加（两者均得出至少需要 22 个界面，即总层数 \(N = 21\)）。
- **递进拆解脉络**：
  1. 第一步（半波损失分析与最小层厚）：单层界面反射率振幅 \(r_1 = \frac{n_1 - n_2}{n_1 + n_2} < 0\)（\(n_1 \to n_2\) 存在 \(\pi\) 相位跃变），而 \(r_2 = \frac{n_2 - n_1}{n_1 + n_2} = -r_1 > 0\)（\(n_2 \to n_1\) 无相位跃变）。为使第 2 个界面（\(n_2 \to n_1\)）的反射波与第 1 个界面同相叠加，往返光程差 \(2 n_2 d_2\) 须补偿 \(\pi\) 相差，故最小厚度 \(d_2 = \frac{\lambda}{4 n_2} \approx 171\text{ nm}\)。同理第 3 个界面（\(n_1 \to n_2\)）相对第 2 个界面多一次 \(\pi\) 跃变，须 \(2 n_1 d_1 = \frac{\lambda}{2}\)，最小厚度 \(d_1 = \frac{\lambda}{4 n_1} \approx 175\text{ nm}\)（精确 \(175.5\text{ nm}\)）。
  2. 第二步（核对总层数 \(N\) 与界面数关系）：观察图（a）标号，第 1 层至第 \(N\) 层交替为 \(n_2, n_1, \dots, n_2\)，末层（第 \(N\) 层，\(n_2\)）右侧依然接回 \(n_1\) 基体纤芯，因此 \(N\) 个调制层共形成 \(N + 1\) 个反射界面！
  3. 第三步（单次反射相干振幅叠加）：每跨越往返一次界面，透射振幅乘以 \(t_1 t_2 = \frac{4 n_1 n_2}{(n_1 + n_2)^2} = 1 - r_1^2\)。因所有 \(N+1\) 个反射界面单次反射波严格同相，总反射电场振幅大小为 \(E_{\text{refl}} = E_0 \sum_{j=0}^{N} |r_1| (t_1 t_2)^j = E_0 |r_1| \frac{1 - (t_1 t_2)^{N+1}}{1 - t_1 t_2}\)。
  4. 第四步（解出最小总层数 \(N\)）：令反射率 \(R = (E_{\text{refl}}/E_0)^2 \ge 0.08\)，代入 \(|r_1| = \frac{0.04}{3.06} \approx 0.013072\)、\(t_1 t_2 = 1 - r_1^2 \approx 0.999829\)，解出 \(N + 1 \ge 21.68 \implies N \ge 20.68\)，故总层数至少为 \(N = 21\)（若忽略透射衰减近似 \(E_{\text{refl}} \approx (N+1)|r_1|E_0\)，得 \(N \ge 20.64\)，同样为 \(N = 21\)）。
- **对照结论**：与官方参考答案完全一致！官方主解法正是采用了保留 \((t_1 t_2)^j\) 的单次反射几何级数得到 \(N = 20.68 \implies 21\)；官方末尾的 `[另一方法]` 则是近似 \(t_1 t_2 \approx 1\) 得 \(N = 20.64 \implies 21\)，两者与我们的盲解推导连小数后两位（20.68 与 20.64）都分毫不差！唯一微小的舍入差异是官方写 \(d_1 \approx 175\text{ nm}\)（由 \(1060 / 6.04 = 175.497\text{ nm}\) 略微下舍，严格四舍五入应为 \(175\text{ nm}\) 或 \(175.5\text{ nm}\)）。
- **核心难点**：
  - 难点1：准确数出“\(N\) 层周期层对应 \(N+1\) 个界面”。很多同学看惯了单面空气-薄膜-基底，容易下意识以为 \(N\) 层就是 \(N\) 个界面，算得 \(N = 22\) 而差出 1 层。
  - 难点2：注意透射能量流/振幅公式在两侧折射率不同时的对称性——从 \(n_1 \to n_2\) 是 \(\frac{2n_1}{n_1+n_2}\)，返回时从 \(n_2 \to n_1\) 必须换成 \(\frac{2n_2}{n_1+n_2}\)，两者乘积恰好满足能量守恒恒等式 \(t_{12}t_{21} = 1 - r^2\)。
- **高频易错点**：
  - 易错点1：把**光强反射率**直接相加（\(R_{\text{tot}} \approx (N+1)r^2\)）而非**电场振幅相干相加后再平方**！若误按非相干光强叠加，会算出需要几百层甚至上千层（\(0.08 / 1.71\times 10^{-4} \approx 468\) 层）。
  - 易错点2：在用题干提示的透射公式时误以为往返两次都乘以 \(\frac{2n_1}{n_1+n_2}\)（没把 \(n_1, n_2\) 对调，算成 \((2\times 1.51/3.06)^2 \approx 0.974\)，导致每层指数衰减严重偏大甚至永远达不到 \(8\%\) 反射率！）。
- **教练总结**：介质多层膜/布拉格光栅题目要牢记三大原则：（1）**光波先叠加复振幅，最后再取模平方算光强**；（2）往返穿透同一异质界面一次，振幅透射因子必为 \(t_{12} t_{21} = 1 - r^2\)（自动接近 1 且保证小于 1，绝不会出现 \((2n_1/(n_1+n_2))^2\) 这种违背互易性的错式）；（3）弱折射率调制（\(\Delta n \ll n\)）且 \(R \ll 1\) 时，单次反射叠加给出简洁规律 \(R \approx (M r)^2\)，其中 \(M\) 为界面数（非层数）。

## 13. 核聚变中性粒子分析器的平行板二阶角聚焦与磁谱设计 (`cpho-2014-final-theory-problem-slice-q5`)

- **难度评级**：`D4`
- **物理模型**：带电粒子在电磁场中的运动 · 平行板静电能量分析器角聚焦（Green-Proca 30° 模型）及后续磁偏转质谱
- **教学标签**：`中性粒子分析器(NPA)`、`平行板二阶角聚焦(30度)`、`极板外无场漂移几何`、`小发散角一阶变分消元`、`官方题目及答案双处勘误`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **审图纠偏（关键几何观察）**：
   仔细观察题中示意图可见：入射孔 \(A\) 与出射孔 \(B\) 并不在两极板之间，而是均位于**下极板外侧（下方）**的无场区，垂直下极板的距离分别为 \(h_1\) 和 \(h_2\)（下极板在进、出位置处有狭缝开口，以虚线示意）。这与第（1）问“给出离子**在极板内**垂直于极板方向的最大飞行距离”的说法高度吻合。
   此外，第（2）问文本印作 `(\Delta\alpha = \theta)`，结合示意图中细小发散角 \(\Delta\alpha\) 与高分辨一阶聚焦物理要求（有限大区间 \([0, \theta]\) 内全部轨迹不可能聚于单点 \(B\)），断定此为文档公式转码将 `≪` 误印为 `=` 的排版错误，实为 **\(\Delta\alpha \ll \theta\)**。

2. **第（1）问：\(E\) 与 \(l\) 的关系及极板内最大垂直飞行距离**：
   设离子质量 \(m\)、电荷 \(q\)、动能 \(E = \frac{1}{2}m v_0^2\)。
   - **极板外入射漂移段**：离子沿与下极板成 \(\theta\) 角的直线进入极板缝隙，平行极板位移 \(x_1 = h_1 \cot\theta\)。
   - **极板间匀强电场段**：垂直极板加速度大小 \(a_y = \frac{q V}{m d}\)，初速度分量 \(v_{0x} = v_0\cos\theta\)、\(v_{0y} = v_0\sin\theta\)。板内平行极板射程：
     \[
     x_{\text{field}} = \frac{2 v_{0x} v_{0y}}{a_y} = \frac{2 v_0^2\sin\theta\cos\theta}{qV/(md)} = \frac{2 E d \sin 2\theta}{q V}.
     \]
     离子**在极板内**垂直于极板方向的最大飞行距离（以板内最高点距下极板计）为：
     \[
     H = \frac{v_{0y}^2}{2 a_y} = \frac{v_0^2 \sin^2\theta}{2 q V / (m d)} = \frac{E d \sin^2\theta}{q V}.
     \]
   - **极板外出射漂移段**：离子以对称角 \(-\theta\) 穿出下极板并保持速率 \(v_0\) 直线到达 \(B\) 孔，平行极板位移 \(x_2 = h_2 \cot\theta\)。
   总平行距离 \(l = x_1 + x_{\text{field}} + x_2 = (h_1 + h_2)\cot\theta + \frac{2 E d \sin 2\theta}{q V}\)，由此解出能量与 \(l\) 的关系：
   \[
   E = \frac{q V \left[l - (h_1 + h_2)\cot\theta\right]}{2 d \sin 2\theta}.
   \]

3. **第（2）问：小发散角聚焦条件下的 \(h_2\) 与 \(E(l)\) 关系**：
   要求能量为 \(E\)、入射角在 \(\theta\) 附近微小变化（\(\Delta\alpha \ll \theta\)）的离子均聚焦在同一点 \(B\)，即一阶方向聚焦条件 \(\frac{\partial l}{\partial\theta} = 0\)：
   \[
   \frac{\partial l}{\partial\theta} = -(h_1 + h_2)\csc^2\theta + \frac{4 E d \cos 2\theta}{q V} = 0 \implies h_1 + h_2 = \frac{4 E d \sin^2\theta\cos 2\theta}{q V}.
   \]
   故：
   \[
   h_2 = \frac{4 E d \sin^2\theta\cos 2\theta}{q V} - h_1.
   \]
   将 \(h_1 + h_2\) 代入第（1）问 \(l\) 的表达式消去 \(h_1 + h_2\)：
   \[
   l = \frac{4 E d \sin\theta\cos\theta\cos 2\theta}{q V} + \frac{4 E d \sin\theta\cos\theta}{q V} = \frac{4 E d \sin\theta\cos\theta (1 + \cos 2\theta)}{q V} = \frac{8 E d \sin\theta\cos^3\theta}{q V},
   \]
   反解出聚焦时能量 \(E\) 与 \(l\) 的简洁正比关系（也顺带得到几何形式 \(h_2 = \frac{\sin\theta\cos 2\theta}{2\cos^3\theta} l - h_1\)）：
   \[
   E = \frac{q V l}{8 d \sin\theta\cos^3\theta} = \frac{q V l}{2 d \sin 2\theta (1 + \cos 2\theta)}.
   \]
   （注：再求二阶导 \(\frac{\partial^2 l}{\partial\theta^2} \propto (1 - 4\sin^2\theta)\)，恰好在 \(\theta = 30^\circ\) 时一、二阶导同时为零！）

4. **第（3）问：极板最小间距 \(d\) 及 \(\theta = 30^\circ\) 的结果**：
   保证量程上限能量 \(E_{\max}\)（恰好落于 \(l_{\max}\) 处）的离子不碰到上极板，需满足 \(H_{\max} \le d\)：
   \[
   \frac{E_{\max} d \sin^2\theta}{q V} \le d \implies E_{\max} \le \frac{q V}{\sin^2\theta}.
   \]
   结合第（2）问 \(E_{\max} = \frac{q V l_{\max}}{8 d \sin\theta\cos^3\theta}\) 消去 \(E_{\max}\) 与 \(qV\)：
   \[
   \frac{l_{\max}}{8 d \sin\theta\cos^3\theta} \le \frac{1}{\sin^2\theta} \implies d \ge d_{\min} = \frac{\sin\theta}{8\cos^3\theta} l_{\max} = \frac{l_{\max}\sin^2\theta}{2\sin 2\theta (1 + \cos 2\theta)}.
   \]
   代入 \(\theta = 30^\circ\)（\(\sin 30^\circ = \frac{1}{2}, \cos 30^\circ = \frac{\sqrt{3}}{2}\)）：
   \[
   d_{\min} = \frac{1/2}{8 \cdot (3\sqrt{3}/8)} l_{\max} = \frac{1}{6\sqrt{3}} l_{\max} = \frac{\sqrt{3}}{18} l_{\max}.
   \]

5. **第（4）问：区分离子质量的后续装置设计**：
   经过狭缝 \(B\) 出射的离子能量 \(E\) 相同，但不同同位素离子质量 \(m\) 不同（故动量 \(p = \sqrt{2mE}\) 不同）。在 \(B\) 孔下方紧接一个**垂直于离子运动平面的均匀磁场区（\(180^\circ\) 半圆形磁质谱仪）**，磁感应强度为 \(B_0\)。离子在洛伦兹力下做匀速圆周运动：
   \[
   q v B_0 = \frac{m v^2}{R} \implies m v = q B_0 R.
   \]
   在出射面处沿检测平面测出离子半圆回旋半径 \(R\)（打在位置探测器上的直径 \(2R\)），结合已知能量 \(E\) 即得离子质量表达式：
   \[
   m = \frac{(m v)^2}{2 E} = \frac{q^2 B_0^2 R^2}{2 E} = \frac{4 q B_0^2 R^2 d \sin\theta\cos^3\theta}{V l} = \frac{q B_0^2 R^2 d \sin 2\theta (1 + \cos 2\theta)}{V l}.
   \]
   若已按第（3）问取最小间距 \(d = d_{\min}\)，则进一步化为：
   \[
   m = \frac{q B_0^2 R^2 l_{\max}\sin^2\theta}{2 V l} \quad \left(\text{当 } l = l_{\max},\ \theta = 30^\circ \text{ 时为 } \frac{q B_0^2 R^2}{8 V}\right).
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题源自核聚变等离子体诊断中的经典仪器——平行板静电能量分析器（Green & Proca 1970 著名的 \(30^\circ\) 二阶聚焦结构）。粒子从下极板外侧距离 \(h_1\) 处的 \(A\) 孔射入，经过一段无场直线漂移进入板间匀强电场作斜抛偏转，再穿出下极板经另一段无场漂移抵达出射孔 \(B\)。第（2）问通过令微发散角 \(\Delta\alpha \ll \theta\) 下的一阶偏移 \(\partial l / \partial\theta = 0\) 确定聚焦条件 \(h_1 + h_2 = \frac{\sin\theta\cos 2\theta}{2\cos^3\theta} l\)；第（3）问保证最高能量粒子不碰上极板推出最小极板间距 \(d = \frac{\sin\theta}{8\cos^3\theta}l_{\max}\)，在 \(\theta = 30^\circ\) 时恰得极简比值 \(\frac{\sqrt{3}}{18} l_{\max}\)（同时实现二阶聚焦 \(\partial^2 l/\partial\theta^2 = 0\)）；第（4）问串联垂直半圆形均匀磁场区即可分离同能量、不同质量的聚变离子。对照中发现原题印刷把 \(\Delta\alpha \ll \theta\) 误印为 \(\Delta\alpha = \theta\)，且官方答案（14）式漏写了分母因子 2。
- **递进拆解脉络**：
  1. 第一步（分段轨迹推导能量公式与最大飞行高度）：看清示意图中 \(A, B\) 均位于下极板外侧。离子先无场直线飞行平行极板距离 \(h_1\cot\theta\) 进入极板区，以速率 \(v_0 = \sqrt{2E/m}\)、加速度 \(a_y = -\frac{qV}{md}\) 作斜抛运动，板内平行射程为 \(\frac{2 E d\sin 2\theta}{qV}\)、最大垂直极板飞行距离 \(H = \frac{E d \sin^2\theta}{qV}\)，穿出下极板后继续漂移 \(h_2\cot\theta\) 到 \(B\)。总距离 \(l = (h_1+h_2)\cot\theta + \frac{2 E d\sin 2\theta}{qV}\)，反解得 \(E = \frac{qV[l - (h_1+h_2)\cot\theta]}{2d\sin 2\theta}\)。
  2. 第二步（小发散角一阶聚焦条件）：勘误原题印刷误差“\(\Delta\alpha = \theta\)”实为 \(\Delta\alpha \ll \theta\)。对 \(l(\theta)\) 关于入射角 \(\theta\) 求一阶变分并令 \(\frac{\partial l}{\partial\theta} = 0\)，得 \(-(h_1+h_2)\csc^2\theta + \frac{4Ed\cos 2\theta}{qV} = 0\)，即 \(h_2 = \frac{4Ed\sin^2\theta\cos 2\theta}{qV} - h_1 = \frac{\sin\theta\cos 2\theta}{2\cos^3\theta}l - h_1\)。代回消去 \(h_1+h_2\) 得聚焦状态下能量表达式 \(E = \frac{q V l}{8 d \sin\theta\cos^3\theta} = \frac{q V l}{2 d\sin 2\theta(1+\cos 2\theta)}\)。
  3. 第三步（不碰上极板的最小间距 \(d\) 及 \(30^\circ\) 特例）：对量程上限 \(E_{\max}\)（对应 \(l_{\max}\)），不碰上极板要求 \(H_{\max} = \frac{E_{\max} d \sin^2\theta}{qV} \le d\)，即 \(E_{\max} \le \frac{qV}{\sin^2\theta}\)。结合第二步的 \(E_{\max}(l_{\max})\) 解得最小允许间距 \(d_{\min} = \frac{\sin\theta}{8\cos^3\theta} l_{\max} = \frac{l_{\max}\sin^2\theta}{2\sin 2\theta(1+\cos 2\theta)}\)。代入 \(\theta = 30^\circ\) 即得 \(d_{\min} = \frac{\sqrt{3}}{18} l_{\max}\)（且此时 \(\partial^2 l/\partial\theta^2 = 0\)，实现二阶聚焦）。

- **核心难点**：
  - 难点1：精确读图判断 \(A, B\) 处于极板之外的无场区，从而在轨迹公式中计入前后两段等斜率直线漂移位移 \((h_1 + h_2)\cot\theta\)。
  - 难点2：小角一阶变分聚焦思想（\(\partial l/\partial\theta = 0\)），理解为何在 \(\theta = 30^\circ\) 时非但消除了 \((\Delta\alpha)^1\) 像散，连 \((\Delta\alpha)^2\) 像散也同步归零（\(1 - 4\sin^2 30^\circ = 0\)），使分析器兼具高流强与高能量分辨率。
- **高频易错点**：
  - 易错点1：未仔细看图而直接假设 \(A, B\) 在极板内部（\(y_A = h_1, y_B = h_2\)），算出错误的 \(l\) 表达式 \(l\tan\theta + h_1 - h_2 = \frac{qVl^2}{4Ed\cos^2\theta}\)，后续第（2）（3）问全部脱节。

## 14. 第二类超导体的磁通格子、上临界场与磁通流阻 (`cpho-2014-final-theory-problem-slice-q6`)

- **难度评级**：`D3`
- **物理模型**：凝聚态物理初步 · Abrikosov 磁通涡旋格子几何、上临界场估算与 Bardeen-Stephen 磁通流阻
- **教学标签**：`第二类超导体混合态`、`Abrikosov三角磁通格子`、`上临界磁场Bc2`、`磁通流阻与洛伦兹力`、`磁通钉扎效应`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：磁通涡旋线间距 \(a\)**：
   在边长为 \(a\) 的正三角形格子（图 1）中，每个正三角形面积为 \(\frac{\sqrt{3}}{4}a^2\)，其 3 个顶点各被 6 个正三角形共用，故每个正三角形含 \(3 \times \frac{1}{6} = \frac{1}{2}\) 个涡旋（等效地，一个菱形原胞含两个正三角形、面积 \(A = \frac{\sqrt{3}}{2}a^2\)，恰好包含 1 个磁通量子 \(\Phi_0\)）。
   平均磁通密度等于外磁场 \(B_a\)，故：
   \[
   B_a \cdot \frac{\sqrt{3}}{2} a^2 = \Phi_0 \implies a = \sqrt{\frac{2 \Phi_0}{\sqrt{3} B_a}}.
   \]
   代入 \(B_a = 5\times 10^{-2}\text{ T}\)、\(\Phi_0 = 2.07\times 10^{-15}\text{ Wb}\)：
   \[
   a = \sqrt{\frac{2 \times 2.07\times 10^{-15}}{1.73205 \times 5\times 10^{-2}}} \approx 2.19\times 10^{-7}\text{ m} = 0.219\,\mu\text{m}.
   \]

2. **第（2）问：上临界磁场 \(B_{c2}\)**：
   涡旋中心为半径 \(\xi\) 的正常态圆柱芯。当 \(B_a\) 增大至相邻两涡旋正常芯刚接触重叠时（即最近邻间距 \(a = 2\xi\)），整个材料失去全局超导电性而转为正常态。利用第（1）问公式代入 \(a = 2\xi\)（\(\xi = 5\times 10^{-9}\text{ m}\)）：
   \[
   B_{c2} = \frac{\Phi_0}{\frac{\sqrt{3}}{2}(2\xi)^2} = \frac{\Phi_0}{2\sqrt{3}\xi^2} = \frac{2.07\times 10^{-15}}{2\sqrt{3}\times (5\times 10^{-9})^2} \approx 23.9\text{ T}.
   \]
   （注：与严格金兹堡-朗道理论 \(B_{c2}^{\text{GL}} = \frac{\Phi_0}{2\pi\xi^2} \approx 13.2\text{ T}\) 处于同一数量级，本半定量几何模型直接承接第 1 问。）

3. **第（3）问：涡旋流动方向与磁通流阻率 \(\rho\)**：
   - **流动方向**：
     如题图 3 所示，\(B_a\) 竖直向上（\(+\hat{z}\)），电流 \(I\) 沿长度 \(d\) 方向（\(+\hat{y}\)）。由安培/洛伦兹驱动力关系 \(\mathbf{f}_A = \mathbf{J} \times \mathbf{B}_a\)，方向沿宽度 \(c\) 向右（\(+\hat{x}\)），故**磁通涡旋线垂直于电流和外磁场方向、沿带材宽度 \(c\) 向右流动**。
     （法拉第电磁感应验算：磁力线以速度 \(v\hat{x}\) 向右横切静止带材，等效于导体相对磁力线以 \(-v\hat{x}\) 向左运动，感生电动势方向为 \((-\mathbf{v}) \times \mathbf{B}_a \parallel -\hat{y}\)，恰好阻碍电流 \(I\)，外电源需做正功克服焦耳损耗，能量守恒自洽！）
   - **电阻率推导**：
     超导带材体积为 \(bcd\)，横截面积为 \(bc\)，总安培驱动力 \(F_A = I B_a d\)，故单位体积受力 \(f_A = \frac{F_A}{bcd} = \frac{I B_a}{b c} = J B_a\)。
     代入稳态粘滞关系 \(f_A = \eta \frac{B_a}{\Phi_0} v\)，解出涡旋流速度：
     \[
     v = \frac{f_A \Phi_0}{\eta B_a} = \frac{I \Phi_0}{\eta b c}.
     \]
     磁通线横穿带材在长度 \(d\) 上感生电压（压降）为 \(U = B_a v d\)，由欧姆定律得磁通流阻为：
     \[
     R = \frac{U}{I} = \frac{B_a v d}{I} = \frac{\Phi_0 B_a d}{\eta b c}.
     \]
     再由电阻定律 \(R = \rho \frac{d}{b c}\)，约去带材尺寸 \(b, c, d\) 得**磁通流阻率**：
     \[
     \rho = \frac{\Phi_0 B_a}{\eta}.
     \]
     （量纲自检：\([\eta] = \frac{[f_A]}{[B_a/\Phi_0][v]} = \text{N}\cdot\text{s/m}^2\)，故 \([\Phi_0 B_a / \eta] = \frac{\text{V}\cdot\text{s}\cdot\text{N}/(\text{A}\cdot\text{m})}{\text{N}\cdot\text{s/m}^2} = \frac{\text{V}\cdot\text{m}}{\text{A}} = \Omega\cdot\text{m}\)，精确为电阻率量纲！）

4. **第（4）问：消除磁通流阻的方案**：
   通过掺杂、辐照或热处理等材料工艺，在第二类超导体内部引入微观缺陷（如晶界、位错、空位、间隙原子或纳米级非超导沉淀相颗粒），使其成为**磁通钉扎中心**。由于涡旋芯本身为正常态，进入缺陷可降低系统凝聚能，形成钉扎力阻碍涡旋在安培力下的粘滞流动，从而在实用大电流和强磁场下维持零电阻超导态。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是极具现代凝聚态物理科普与前沿色彩的理论题，围绕强磁场超导磁体中第二类超导体的混合态展开。第（1）问根据正三角形晶格几何（一个菱形原胞由两个正三角形组成、恰好包含 1 个磁通量子 \(\Phi_0\)）求涡旋线间距 \(a\)；第（2）问通过“正常态涡旋芯相切重叠（\(a \le 2\xi\)）”判据由（1）的结果自然导出上临界磁场 \(B_{c2}\)；第（3）问结合洛伦兹/安培驱动力密度 \(f_A = J B_a\) 与磁通线横移引起的等效切割感生电动势 \(E = B_a v\)，导出磁通流阻率 \(\rho = \frac{\Phi_0 B_a}{\eta}\)（样本尺寸 \(b, c, d\) 最终全部约去！）；第（4）问引出实用超导材料的核心技术——引入微观缺陷实现**磁通钉扎**。
- **递进拆解脉络**：
  1. 第一步（正三角形磁通格子的元胞面积与涡旋间距 \(a\)）：在正三角形晶格中，每个正三角形的 3 个顶点各由 6 个三角形共享，故每个三角形平均含 \(\frac{1}{2}\) 个磁通量子；即每两个正三角形（面积 \(A_{\text{cell}} = \frac{\sqrt{3}}{2} a^2\)）对应一个磁通量子 \(\Phi_0\)。由 \(B_a A_{\text{cell}} = \Phi_0\) 解得 \(a = \sqrt{\frac{2 \Phi_0}{\sqrt{3} B_a}} \approx 2.19\times 10^{-7}\text{ m}\)。
  2. 第二步（相邻涡旋正常芯重叠估算上临界磁场 \(B_{c2}\)）：随着外磁场 \(B_a\) 增大，间距 \(a\) 缩小；当相邻半径为 \(\xi\) 的正常态涡旋线芯相互接触重叠（\(a \le 2\xi\)）时，整块超导体转变为正常态。代入 \(a = 2\xi\) 到第一步公式得 \(B_{c2} = \frac{2\Phi_0}{\sqrt{3}(2\xi)^2} = \frac{\Phi_0}{2\sqrt{3}\xi^2} \approx 23.9\text{ T}\)。
  3. 第三步（磁通涡旋线运动方向与粘滞流速）：由图 3 电流 \(I\) 沿长度 \(d\) 方向、外磁场 \(B_a\) 竖直向上，电流元受安培力沿 \(\mathbf{J}\times\mathbf{B}_a\) 指向右侧（其实涡旋与电流间相互作用满足牛顿第三定律，为保证耗散功率 \(\mathbf{J}\cdot\mathbf{E} > 0\)，等效于超导体相对静止磁力线向左切割运动，从而激发沿电流方向、阻滞超导流的感生电场 \(E = B_a v\)，故磁通涡旋线**沿宽度 \(c\) 向右**垂直于电流和磁场方向流动）。单位体积涡旋线受安培驱动力 \(f_A = J B_a = \frac{I B_a}{bc}\)，代入 \(f_A = \eta \frac{B_a}{\Phi_0} v\) 解得 \(v = \frac{I \Phi_0}{\eta b c}\)。
  4. 第四步（导出磁通流阻及电阻率）：带材两端产生的电动势 \(U = B_a v d\)，由欧姆定律得电阻 \(R = \frac{U}{I} = \frac{\Phi_0 B_a d}{\eta b c}\)，再利用 \(R = \rho \frac{d}{bc}\) 约去尺寸 \(b, c, d\)，得磁通流阻率为 \(\rho = \frac{\Phi_0 B_a}{\eta}\)。
  5. 第五步（消除磁通流阻的工程方案）：在超导体内部人工引入晶界、位错、空位、填隙原子或纳米级非超导析出相等微观缺陷作为钉扎中心，产生**磁通钉扎（flux pinning）效应**束缚涡旋线使其无法在安培力下滑动，从而实现实用化的高临界电流零电阻传输（即非理想第二类超导体）。
- **对照结论**：与官方参考解答 100% 吻合！官方在第（2）问明确采用相邻正常芯开始重叠 \(a \le 2\xi\)，得出 \(B_{c2} = 23.85\text{ T}\)（差异仅为官方取 \(2\sqrt{3} \approx 3.47\) 造成的 0.05 T 舍入）；第（3）问公式完全一致，并且官方参考解答（8）–（11）式揭示了为何题干写“用 \(B_a, \Phi_0, \eta, b, c, d\) 表示”：官方在中间步骤先保留了 \(b, c, d\) 算出 \(v = \frac{I d \Phi_0}{\eta (bcd)}\) 与电阻 \(R = \frac{\Phi_0 B_a d^2}{\eta(bcd)}\)，最终在电阻率 \(\rho = R\frac{bc}{d}\) 时将 \(b, c, d\) 悉数消去！
- **核心难点**：
  - 难点1：正确建立正三角形晶格的“单位磁通面积”概念——很多同学直接用单个正三角形面积 \(\frac{\sqrt{3}}{4}a^2\) 除以 \(\Phi_0\)，导致少算了 2 倍的因子（漏掉每个顶点被 6 个三角形共享）。

  - 易错点2：第（3）问混淆“电阻 \(R\)”与“电阻率 \(\rho\)”，算出 \(R = \frac{\Phi_0 B_a d}{\eta b c}\) 就停笔；或者在计算驱动力时错把 \(f_A\) 当成总力而非单位体积力。
- **教练总结**：前沿科技背景的竞赛题往往考察“如何用普通物理基本定律（法拉第感应定律、洛伦兹力、几何晶胞计数、欧姆定律）快速搭建半定量凝聚态模型”。遇到像 \(\rho = \Phi_0 B_a / \eta\) 这种“题干列出几何尺寸却在最后全部消掉”的情况，不要慌张——电阻率本身就是材料和外场的局部本征性质，尺寸必然消去，这恰恰是最可靠的自检信号！

## 15. 恒定风场与线性空气阻力下抛体哑铃高空碰撞及阻力做功 (`cpho-2014-final-theory-problem-slice-q7`)

- **难度评级**：`D4`
- **物理模型**：质点系与刚体动力学 · 线性阻尼下质心与转动解耦、牛顿第二定律时间/角度积分与功能原理
- **教学标签**：`线性阻力质心转动解耦`、`无求时间显式积分技巧`、`刚性轻杆偏心完全弹性碰撞`、`角速度随转角线性衰减`、`功能原理求阻力做功`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问之一：最高点弹性碰撞后初始角速度 \(\omega_0\)**：
   上抛阶段 \(A, B\) 水平速度相同、受风力与阻力完全对称，连线始终保持水平（\(A\) 在 \(C\) 左侧 \(-l\)、\(B\) 在右侧 \(+l\)），最高点时 \(v_{Ay} = v_{By} = 0\)。
   小石块（\(m_1\)，速度 \(+u_1\hat{y}\)）与球 \(A\) 发生时间极短的竖直完全弹性碰撞（记碰后石块竖直速度为 \(u_2\)，质心 \(C\) 竖直速度为 \(v_{Cy}'\)，顺时针角速度为 \(\omega_0\)）。
   - 竖直动量守恒：\(m_1 u_1 = m_1 u_2 + 2 m v_{Cy}'\)；
   - 对碰前质心瞬间重合惯性点的角动量守恒：\(m_1 u_1 l = m_1 u_2 l + (2 m l^2)\omega_0\)；
   两式相减消去 \(m_1(u_1 - u_2)\) 立刻得到 \(v_{Cy}' = \omega_0 l\)！由此碰后 \(A, B\) 两球竖直速度分别为：
   \[
   v_{Ay}' = v_{Cy}' + \omega_0 l = 2\omega_0 l, \quad v_{By}' = v_{Cy}' - \omega_0 l = 0!
   \]
   即碰后瞬间 \(B\) 球尚静止，撞击等效于石块与质量为 \(m\) 的单球 \(A\) 作一维弹性正碰！代入机械能守恒（水平分量不变）：
   \[
   \frac{1}{2} m_1 u_1^2 = \frac{1}{2} m_1 u_2^2 + \frac{1}{2}(2m)(v_{Cy}')^2 + \frac{1}{2}(2 m l^2)\omega_0^2 = \frac{1}{2} m_1 u_2^2 + \frac{1}{2} m (v_{Ay}')^2.
   \]
   解出一维弹性碰速 \(v_{Ay}' = \frac{2 m_1 u_1}{m_1 + m}\)，从而初始转动角速度为：
   \[
   \omega_0 = \frac{v_{Ay}'}{2 l} = \frac{m_1 u_1}{(m_1 + m) l}.
   \]

2. **第（1）问之二：空气阻力下转动演化及 \(\omega_s\) 与 \(n\) 的关系**：
   记风速 \(\mathbf{u} = u\hat{x}\)，对质点系（\(A, B\) 位置 \(\mathbf{r}_C \mp \mathbf{l}\)、速度 \(\mathbf{v}_C \mp \dot{\mathbf{l}}\)）计算外力与外力矩：
   - 总空气阻力：\(\mathbf{F}_f = -k(\mathbf{v}_A - \mathbf{u}) - k(\mathbf{v}_B - \mathbf{u}) = -2 k (\mathbf{v}_C - \mathbf{u})\)（**质心运动与转动完全解耦**）。
   - 对质心 \(C\) 的总空气阻力矩：
     \[
     \boldsymbol{\tau}_f = (-\mathbf{l}) \times (-k(\mathbf{v}_A - \mathbf{u})) + \mathbf{l} \times (-k(\mathbf{v}_B - \mathbf{u})) = \mathbf{l} \times \left[-k(\mathbf{v}_B - \mathbf{v}_A)\right] = \mathbf{l} \times (-2 k \dot{\mathbf{l}}) = -2 k l^2 \boldsymbol{\omega}.
     \]
     （风速 \(\mathbf{u}\) 与质心平动速度 \(\mathbf{v}_C\) 因等力臂反向而在力矩中严格消去！）
   由刚体绕质心转动定理 \(I_C \dot{\omega} = \tau_f\)（\(I_C = 2 m l^2\)）：
   \[
   2 m l^2 \frac{\mathrm{d}\omega}{\mathrm{d}t} = -2 k l^2 \omega \implies \frac{\mathrm{d}\omega}{\mathrm{d}t} = -\frac{k}{m}\omega \implies \frac{\mathrm{d}\omega}{\mathrm{d}\theta} = -\frac{k}{m}.
   \]
   对碰撞后到落回 \(s\) 点的全部转角 \(\Delta\theta = 2\pi n\) 积分：
   \[
   \omega_s - \omega_0 = -\frac{k}{m}(2\pi n) \implies \omega_s = \omega_0 - \frac{2\pi n k}{m} = \frac{m_1 u_1}{(m_1 + m) l} - \frac{2\pi n k}{m}.
   \]

3. **第（2）问：空气阻力总功 \(W_f\) 与 \(n, s, T\) 的关系**：
   因线性阻力方程可直接对时间全积分消去不可显式解出的中间高度与分段时刻：
   - **\(x\) 方向末速 \(v_{xs}\)**：由 \(2 m \frac{\mathrm{d} v_{Cx}}{\mathrm{d}t} = -2 k (v_{Cx} - u)\) 从 \(t=0\) 到 \(t=T\) 积分（初速 \(v_{Cx}(0)=0\)，碰撞不改 \(v_{Cx}\)，全位移 \(\int_0^T v_{Cx}\,\mathrm{d}t = s\)）：
     \[
     v_{xs} - 0 = -\frac{k}{m}(s - u T) \implies v_{xs} = \frac{k}{m}(u T - s).
     \]
   - **\(y\) 方向末速 \(v_{Cy}(T)\)**：由 \(m \frac{\mathrm{d} v_{Cy}}{\mathrm{d}t} = -mg - k v_{Cy}\) 在碰撞前 \([0, t_1^-]\) 与碰撞后 \([t_1^+, T]\) 两段分别积分再相加：
     \[
     (0 - v_0) + \left(v_{Cy}(T) - v_{Cy}'\right) = -g T - \frac{k}{m}\left[(y_1 - 0) + (0 - y_1)\right] = -g T.
     \]
     中间高度 \(y_1\) 精确抵消！代入 \(v_{Cy}' = \omega_0 l = \frac{m_1 u_1}{m_1 + m}\) 得：
     \[
     v_{Cy}(T) = v_0 + \frac{m_1 u_1}{m_1 + m} - g T \quad (\text{即向下速率 } v_{ys} = g T - v_0 - \frac{m_1 u_1}{m_1 + m}).
     \]
   - **功能原理结算 \(W_f\)**：
     始末态 \(y_C(0) = y_C(T) = 0\) 且两球重力势能相对质心恒抵消，故全过程重力势能增量为零。
     初动能 \(E_{k0} = m v_0^2\)；碰撞给哑铃提供的机械能增量 \(\Delta E_{\text{coll}} = \frac{1}{2}(2m)(v_{Cy}')^2 + \frac{1}{2}(2ml^2)\omega_0^2 = 2 m \left(\frac{m_1 u_1}{m_1 + m}\right)^2\)；末态落至 \(s\) 点总动能 \(E_{ks} = m v_{xs}^2 + m v_{Cy}(T)^2 + m l^2 \omega_s^2\)。
     因此空气阻力做的总功（包含风在水平方向可能做的正功）为：
     \[
     W_f = E_{ks} - E_{k0} - \Delta E_{\text{coll}} = \frac{k^2}{m}(u T - s)^2 + m\left(g T - v_0 - \frac{m_1 u_1}{m_1 + m}\right)^2 + m\left(\frac{m_1 u_1}{m_1 + m} - \frac{2\pi n k l}{m}\right)^2 - m v_0^2 - 2 m\left(\frac{m_1 u_1}{m_1 + m}\right)^2.
     \]

  4. 第四步（由功能原理求阻力总功 \(W_f\)）：因 \(C\) 点起落同高且刚杆两球高度差反号，重力总功为零；石块碰撞传递给系统的动能增量 \(\Delta E_{\text{coll}} = \frac{1}{2}m v_{Ay}'^2 = 2 m\left(\frac{m_1 u_1}{m_1+m}\right)^2\)。由全过程功能原理 \(W_f = E_{k,\text{末}} - E_{k,0} - \Delta E_{\text{coll}}\)，代入末态平动与转动动能即得 \(W_f\) 完整表达式。

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：粒子平均动能及太阳核心压强**：

   \[
   \bar{E}_k = \frac{3}{2} k T = \frac{1.5 \times 1.381\times 10^{-23}\times 1.5\times 10^7}{1.602\times 10^{-19}}\text{ eV} \approx 1.94\times 10^3\text{ eV} = 1.94\text{ keV}.
   \]
   核心氢原子完全电离成等量质子与电子，**每个氢原子产生 2 个自由粒子**！单氢原子质量 \(m_{\text{H}} = m_p + m_e = 938.78\text{ MeV}/c^2 \approx 1.671\times 10^{-27}\text{ kg}\)，总粒子数密度 \(n = \frac{2\rho}{m_{\text{H}}} \approx 1.915\times 10^{32}\text{ m}^{-3}\)。核心压强为：

2. **第（2）问：反应（II）未知粒子 \(x\) 的性质、动能、动量及参考系**：
   反应 \(\text{D} + {}^1\text{H} \to {}^3\text{He} + \text{x}\) 中质量数与电荷数守恒要求 \(A_x = 0, Z_x = 0\)，在选项（\(\alpha, \beta, \gamma, \text{p}, \text{n}\)）中，\(x\) 只能是**\(\gamma\) 光子**（中性且无静质量）。
   粒子反应前热动能约 \(0.002\text{ MeV}\)，小于题给质量 \(0.01\text{ MeV}/c^2\) 误差，故可按初态静止计算。设反应前总静止质量 \(M_i = m_D + m_p = 2813.88\text{ MeV}/c^2\)，质量亏损 \(Q_2 = M_i c^2 - m_{^3\text{He}} c^2 = 5.50\text{ MeV}\)。考虑精确相对论二体反冲，由动量守恒 \(p_{^3\text{He}} = p_\gamma = E_\gamma / c\) 及能量守恒 \(M_i c^2 = \sqrt{m_{^3\text{He}}^2 c^4 + E_\gamma^2} + E_\gamma\)：
   \[
   E_\gamma = \frac{(M_i^2 - m_{^3\text{He}}^2) c^2}{2 M_i} = Q_2\left(1 - \frac{Q_2}{2 M_i c^2}\right) \approx 5.50 \times (1 - 0.00098) \approx 5.495\text{ MeV}\ (\text{在给定精度下为 } 5.50\text{ MeV}),
   \]
   动量大小：
   \[
   p_\gamma = \frac{E_\gamma}{c} \approx 5.495\text{ MeV}/c \approx 2.93\times 10^{-21}\text{ kg}\cdot\text{m/s}.
   \]
   **能否找到使 \(x\) 动能为零的参考系？**

3. **第（3）问：反应（I）中各产物动能范围**：
   反应 \(^1\text{H} + {}^1\text{H} \to \text{D} + \text{e}^+ + \nu_e\) 释放总动能（\(m_\nu < 3\text{ eV}/c^2 \approx 0\)）：
   \[
   Q_1 = (2 m_p - m_D - m_e) c^2 = (2\times 938.27 - 1875.61 - 0.51)\text{ MeV} = 0.42\text{ MeV}.
   \]
   由三体静止衰变极值定理（任一粒子均可通过另两粒子等大反向动量使其自身静止从而达到 \(K_{\min} = 0\)；另两粒子共动反向飞行时达到其 \(K_{\max}\)），设 \(M = 2 m_p = 1876.54\text{ MeV}/c^2\)：
   - **正电子 \(\text{e}^+\)**（需严格用相对论公式！）：当 \(\nu_e\) 动量趋零、\(\text{D}\) 与 \(\text{e}^+\) 反冲时取极大值：
     \[
     K_{e,\max} = \frac{(M - m_e)^2 - m_D^2}{2 M} c^2 \approx 0.4198\text{ MeV} \implies 0 \le K_e \le 0.42\text{ MeV}.
     \]
   - **中微子 \(\nu_e\)**：当 \(\text{D}\) 与 \(\text{e}^+\) 相对静止共动时取极大值：
     \[
     K_{\nu,\max} \approx \frac{M^2 - (m_D + m_e)^2}{2 M} c^2 \approx 0.4200\text{ MeV} \implies 0 \le K_\nu \le 0.42\text{ MeV}.
     \]
   - **氘核 \(\text{D}\)**：当 \(p_\nu \to 0\)、\(\text{e}^+\) 与 \(\text{D}\) 背靠背分享动量 \(p_D = p_e\) 时取极大值（不可对 \(\text{e}^+\) 错用非相对论公式！）：
     \[
     K_{D,\max} = \frac{(M - m_D)^2 - m_e^2}{2 M} c^2 = \frac{Q_1 (Q_1 + 2 m_e c^2)}{2 M c^2} = \frac{0.42 \times 1.44}{3753.08}\text{ MeV} \approx 1.61\times 10^{-4}\text{ MeV} = 161\text{ eV}.
     \]
     故 \(0 \le K_D \le 1.61\times 10^{-4}\text{ MeV}\)（在题给 \(0.01\text{ MeV}\) 误差精度下可近似视为 \(K_D \approx 0\)）。

4. **第（4）问：康普顿散射能量公式及单次散射角 \(\phi\)**：
   \(e^+ + e^- \to \gamma + \gamma\) 产生一对等能反向光子，初能量 \(E_0 = m_e c^2 = 0.51\text{ MeV}\)，初波长 \(\lambda_0 = \frac{h c}{E_0} = \frac{h}{m_e c} \approx 2.43\times 10^{-12}\text{ m}\)。
   光子和静止自由电子作康普顿散射后能量为 \(E\)、散射角 \(\phi\)，反冲电子动量 \(p_e\)、动能 \(T_e = E_0 - E\)。由动量守恒消去电子散射角得 \(p_e^2 c^2 = E_0^2 + E^2 - 2 E_0 E\cos\phi\)；又由电子相对论色散 \((m_e c^2 + T_e)^2 - m_e^2 c^4 = p_e^2 c^2\)，即 \((E_0 - E)^2 + 2 m_e c^2(E_0 - E) = E_0^2 + E^2 - 2 E_0 E\cos\phi\)。化简消去 \(E_0^2 + E^2\) 得：
   \[
   m_e c^2 (E_0 - E) = E_0 E (1 - \cos\phi) \implies \frac{1}{E} - \frac{1}{E_0} = \frac{1 - \cos\phi}{m_e c^2} \implies E = \frac{E_0}{1 + \frac{E_0}{m_e c^2}(1 - \cos\phi)}.
   \]
   两侧同乘 \(hc\) 即得单次波长偏移 \(\Delta\lambda = \frac{h}{m_e c}(1 - \cos\phi)\)。因每次散射均使波长增加同一定量，\(N = 10^{26}\) 次同角度散射后总波长变为：
   \[
   \lambda_f - \lambda_0 = N \frac{h}{m_e c}(1 - \cos\phi).
   \]
   由于 \(\lambda_f = 5.4\times 10^{-7}\text{ m} \gg \lambda_0 = 2.43\times 10^{-12}\text{ m}\)，故 \(1 - \cos\phi \approx \frac{\phi^2}{2} \approx \frac{\lambda_f m_e c}{10^{26} h}\)：
   \[
   \phi \approx \sqrt{\frac{2 \lambda_f m_e c}{10^{26} h}} = \sqrt{\frac{2 \times 5.4\times 10^{-7} \times 0.51\times 10^6 \times 1.602\times 10^{-19}}{10^{26} \times 6.626\times 10^{-34} \times 3.0\times 10^8}} \approx 6.66\times 10^{-11}\text{ rad} \approx 6.7\times 10^{-11}\text{ rad}.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题综合考查热力学与统计、相对论核反应动力学以及量子光学康普顿散射，将太阳内部的氢-氦核聚变能源演化物理完整串联起来。第（1）问易错点在于氢原子完全电离成“质子 + 电子”双组分等离子体，粒子数密度翻倍从而使太阳核心压强达到约 \(4\times 10^{11}\text{ atm}\)；第（2）问识别未知粒子为 \(\gamma\) 光子，并说明光速不变下不存在光子动能为零的惯性系；第（3）问分析质子-质子弱反应三体产物的动能区间，体现重粒子（氘核）因反冲极小只能分得极微弱动能（精确上限仅 \(161\text{ eV}\)，在 \(0.01\text{ MeV}\) 精度内近似为零）而正电子与中微子平分 \(0 \sim 0.42\text{ MeV}\) 区间；第（4）问从能量守恒与动量守恒严格导出康普顿散射能量公式，利用波长移位的可加性从 \(10^{26}\) 次散射估算出极微小的单次散射角。
- **递进拆解脉络**：
  1. 第一步（太阳核心平均动能与等离子体压强）：粒子处于热平衡，单粒子（质子和电子均可视为单原子分子模型、无转动自由度）平均热动能 \(\bar{E}_k = \frac{3}{2} k T \approx 1.94\text{ keV} \approx 2\text{ keV}\)。因中性氢电离为质子和电子，每摩尔氢原子贡献 \(2\text{ mol}\) 自由粒子，利用 \(\rho = 1.6\times 10^5\text{ kg/m}^3\)（氢原子摩尔质量约 \(1\text{ g/mol}\)，或由质子加电子质量算总粒子数密度 \(n = \frac{2\rho}{m_p+m_e}\)），得压强 \(p = n k T \approx 3.9\times 10^{11}\text{ atm} \approx 4\times 10^{11}\text{ atm}\)。
  2. 第二步（反应 II 粒子识别、能量动量与参考系讨论）：由核子数与电荷守恒（\(A_x=0, Z_x=0\)）及质量亏损 \(\Delta m c^2 = (1875.61 + 938.27 - 2808.38)\text{ MeV} = 5.50\text{ MeV}\)，判定 \(x\) 为**\(\gamma\) 光子**。热初动能（\(\sim 2\text{ keV}\)）远小于误差与能损可忽略；考虑二体相对论反冲，\(E_\gamma = \frac{(m_D + m_p)^2 - m_{^3\text{He}}^2}{2(m_D + m_p)}c^2 \approx 5.495\text{ MeV}\)（在 \(0.01\text{ MeV}\) 误差内约为 \(5.5\text{ MeV}\)），动量 \(p_\gamma = E_\gamma / c \approx 5.5\text{ MeV}/c \approx 2.93\times 10^{-21}\text{ kg}\cdot\text{m/s}\)。因光子静止质量为零、在一切惯性系中速度恒为 \(c\)，**找不到**使其动能为零的惯性参考系。
  3. 第三步（反应 I 三体产物的动能区间）：反应释放总动能 \(Q_1 = (2 m_p - m_D - m_e)c^2 = 0.42\text{ MeV}\)。利用相对论三体衰变极值定理（某粒子动能最大时其余两粒子相对静止并反向共动），算得：\(0 \le K_e \le 0.42\text{ MeV}\)（严格 \(0.4198\text{ MeV}\)）、\(0 \le K_\nu \le 0.42\text{ MeV}\)（严格 \(0.4200\text{ MeV}\)），而氘核 \(D\) 因质量极大只能分走极小反冲动能 \(0 \le K_D \le \frac{Q_1(Q_1 + 2m_e c^2)}{4 m_p c^2} \approx 1.61\times 10^{-4}\text{ MeV} \ll 0.01\text{ MeV}\)（即数据精度下 \(K_D \approx 0\)）。
  4. 第四步（康普顿散射公式推导及 \(10^{26}\) 次散射角估算）：\(e^+ e^-\) 湮灭光子初能量 \(E_0 = m_e c^2 = 0.51\text{ MeV}\)（\(\lambda_0 = \frac{hc}{m_e c^2} \approx 2.43\times 10^{-12}\text{ m}\)）。对静止电子列写能量和动量守恒消去反冲电子参数，推出单次散射后光子能量 \(E = \frac{E_0}{1 + \frac{E_0}{m_e c^2}(1 - \cos\phi)}\)，化为波长偏移 \(\lambda' - \lambda = \frac{h}{m_e c}(1 - \cos\phi)\)。因每次波长增量叠加且仅依赖 \(\phi\)，\(N = 10^{26}\) 次散射后 \(\lambda_f - \lambda_0 = N \frac{h}{m_e c}(1 - \cos\phi)\)。利用 \(\lambda_f \gg \lambda_0\) 与小角展开 \(1 - \cos\phi \approx \frac{\phi^2}{2}\)，解得 \(\phi \approx \sqrt{\frac{2\lambda_f m_e c}{10^{26} h}} \approx 6.7\times 10^{-11}\text{ rad}\)。
- **对照结论**：与官方参考解答高度一致！官方在第（1）问取 \(1\text{ g/mol}\) 氢原子并显式强调因子 2（“因为考虑了等离子体中电子贡献的缘故”），得 \(2\text{ keV}\) 与 \(4\times 10^{11}\text{ atm}\)；在第（2）（3）问因题目给定质量精度为 \(0.01\text{ MeV}/c^2\)，官方忽略了氦-3 与氘核的微弱反冲（给出 \(E_{k x} = 5.5\text{ MeV}\)、\(E_{k D} < 0.01\text{ MeV} \approx 0\) 与 \(0 < E_{k e}, E_{k\nu} < 0.42\text{ MeV}\)），而我们的盲解同时算出了精确微反冲值（\(5.495\text{ MeV}\) 与 \(161\text{ eV}\)），从数值上严谨证明了为何可以忽略；第（4）问官方特别补充说明“\(m_p \gg m_e\)，光子与离子散射几乎无波长变化，故只需考虑与电子的康普顿散射”，并导出完全相同的 \(\phi = 6.7\times 10^{-11}\text{ rad}\)。
- **核心难点**：
  - 难点1：第（1）问等离子体粒子数密度的双组分计数——完全电离氢等离子体包含自由质子和自由电子，分子数密度是中性氢原子数密度的 2 倍。
  - 难点2：第（3）问三体衰变能谱的极值分配以及为什么重核（氘核）只带走不到两百电子伏的反冲动能，而两个轻粒子（\(e^+, \nu_e\)）几乎瓜分全部 \(0.42\text{ MeV}\) 能量。
  - 难点3：第（4）问从能量与动量守恒完整推导康普顿散射公式，以及识别“光子对电子的 \(1/E\)（即波长 \(\lambda\)）满足线性逐次叠加”从而瞬间解决 \(10^{26}\) 次级联问题。
- **高频易错点**：
  - 易错点1：第（1）问算太阳核心压强时漏乘电子贡献的因子 2，算出 \(2\times 10^{11}\text{ atm}\)。
  - 易错点2：第（3）问误以为在反冲计算中 \(0.42\text{ MeV}\) 远小于电子静能 \(0.51\text{ MeV}\) 而对正电子强行套用非相对论 \(K_e = \frac{p^2}{2m_e}\)，实际上两者同量级，必须用相对论色散关系。
  - 易错点3：第（4）问把 \(\lambda_C = \frac{h}{m_e c}\) 中的质量错代成质子质量，或未注意电子静能 \(m_e c^2 = 0.51\text{ MeV}\) 恰好直接给出光子初波长 \(\lambda_0 = \lambda_C\) 而反复换算出错。
- **教练总结**：跨模块现代物理综合题的制胜关键是“先判标度、再定近似”：反应前热动能 \(2\text{ keV}\) 比核反应释放能 \(0.42\text{–}5.5\text{ MeV}\) 小 2–3 个数量级，故可作零温静止初态；重核反冲动能比 \(\sim Q / (M c^2) \sim 10^{-4}\)，故在 \(1\%\) 质量误差下轻粒子带走几乎全部动能。对于级联多次康普顿散射，牢记**“波长移位（而非能量损失率）具有严格线性可加性”**是最强大的化简武器。
