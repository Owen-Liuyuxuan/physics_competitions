# 复赛理论试题（Semifinal Theory）

## 1. 圆筒内均质小圆柱无滑滚动的耦合微振动频率 (`cpho-2017-semifinal-theory-problem-slice-q1`)

- **难度评级**：`D2`
- **物理模型**：刚体平面动力学 · 无滑滚动运动学约束与双刚体耦合简谐微振动
- **教学标签**：`刚体无滑滚动`、`小角简谐微振动`、`耦合双刚体动力学`、`非典型守恒量识别`、`等效转动惯量与折合质量`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **几何坐标与无滑滚动运动学约束**：
   设外薄圆筒中心轴 \(O\) 水平固定，小圆柱中心为 \(C\)，两轴间距为 \(OC = R - r\)。取小圆柱质心连线 \(OC\) 相对竖直向下方向的偏角为 \(\theta\)（逆时针向右偏为正），取小圆柱绕自身中心轴的绝对转角为 \(\phi\)（逆时针为正），取外薄圆筒绕轴 \(O\) 的转角为 \(\psi\)（逆时针为正）。
   在极坐标基矢 \((\hat{r}, \hat{\theta})\) 中（\(\hat{r}\) 由 \(O\) 指向 \(C\) 及切点 \(P\)，\(\hat{\theta}\) 指向逆时针方向，\(\hat{z} = \hat{r} \times \hat{\theta}\) 垂直纸面向外）：
   - 小圆柱质心速度为 \(\mathbf{v}_C = (R - r)\dot{\theta}\,\hat{\theta}\)；
   - 小圆柱上切点 \(P\) 相对质心的矢径为 \(\mathbf{r}_{CP} = r\,\hat{r}\)，故小圆柱上 \(P\) 点的速度为：
     \[
     \mathbf{v}_P = \mathbf{v}_C + \dot{\phi}\hat{z} \times (r\hat{r}) = \left[(R - r)\dot{\theta} + r\dot{\phi}\right]\hat{\theta};
     \]
   - 外圆筒上切点 \(P\) 的速度为 \(\mathbf{v}_{\text{track}} = R\dot{\psi}\,\hat{\theta}\)。
   由切点处无相对滑动 \(\mathbf{v}_P = \mathbf{v}_{\text{track}}\)，得一般运动学约束：
   \[
   (R - r)\dot{\theta} + r\dot{\phi} = R\dot{\psi} \implies \dot{\phi} = \frac{R\dot{\psi} - (R - r)\dot{\theta}}{r}.
   \]
   两刚体绕各自中心轴的转动惯量分别为：
   \[
   I_m = \frac{1}{2}mr^2, \qquad I_M = MR^2.
   \]

2. **情形（1）：圆筒固定（\(\psi = \dot{\psi} = 0\)）**：
   此时 \(\dot{\phi} = -\frac{R - r}{r}\dot{\theta}\)。以最低点为势能零点，小圆柱总机械能为：
   \[
   E = \frac{1}{2}m(R - r)^2\dot{\theta}^2 + \frac{1}{2}\left(\frac{1}{2}mr^2\right)\left(\frac{R - r}{r}\dot{\theta}\right)^2 + mg(R - r)(1 - \cos\theta) = \frac{3}{4}m(R - r)^2\dot{\theta}^2 + mg(R - r)(1 - \cos\theta).
   \]
   对时间求导并取小角近似 \(\sin\theta \approx \theta\)：
   \[
   \frac{3}{2}m(R - r)^2\ddot{\theta} + mg(R - r)\theta = 0 \implies \ddot{\theta} + \frac{2g}{3(R - r)}\theta = 0.
   \]
   因此角频率 \(\omega_1 = \sqrt{\frac{2g}{3(R - r)}}\)，振动频率为：
   \[
   f_1 = \frac{1}{2\pi}\sqrt{\frac{2g}{3(R - r)}} = \frac{1}{\pi}\sqrt{\frac{g}{6(R - r)}}.
   \]
   **极限检验**：\(r \to 0\) 时化为质点在半径 \(R\) 圆弧内滚振频率 \(\frac{1}{2\pi}\sqrt{\frac{2g}{3R}}\)，量纲为 \(\text{s}^{-1}\)，自洽。

3. **情形（2）：圆筒可绕固定光滑中心细轴自由转动**：
   - **方法一（牛顿-欧拉动力学方程）**：
     设切点 \(P\) 处圆筒对小圆柱的静摩擦力为 \(F_s\)（沿 \(+\hat{\theta}\) 方向），则小圆柱对圆筒的反作用力为 \(-F_s\hat{\theta}\)。圆筒所受重力与细轴支持力均通过 \(O\)，切点法向支持力 \(N\) 也过 \(O\)，故仅静摩擦力对各自转轴产生力矩：
     \[
     M R^2 \ddot{\psi} = -F_s R, \qquad \frac{1}{2}mr^2\ddot{\phi} = +F_s r.
     \]
     消去 \(F_s\) 得 \(M R \ddot{\psi} + \frac{1}{2}mr\ddot{\phi} = 0 \implies \ddot{\psi} = -\frac{mr}{2MR}\ddot{\phi}\)。
     将运动学约束求导 \((R - r)\ddot{\theta} + r\ddot{\phi} = R\ddot{\psi}\) 代入上式：
     \[
     (R - r)\ddot{\theta} + r\ddot{\phi} = -\frac{m}{2M}r\ddot{\phi} \implies r\ddot{\phi} = -\frac{2M}{2M + m}(R - r)\ddot{\theta},
     \]
     从而静摩擦力为 \(F_s = \frac{1}{2}mr\ddot{\phi} = -\frac{Mm}{2M + m}(R - r)\ddot{\theta}\)。
     再写小圆柱质心沿切向 \(\hat{\theta}\) 的运动方程：
     \[
     m(R - r)\ddot{\theta} = -mg\sin\theta + F_s = -mg\sin\theta - \frac{Mm}{2M + m}(R - r)\ddot{\theta}.
     \]
     整理并作小角近似 \(\sin\theta \approx \theta\)：
     \[
     \left(1 + \frac{M}{2M + m}\right)(R - r)\ddot{\theta} + g\theta = 0 \implies \frac{3M + m}{2M + m}(R - r)\ddot{\theta} + g\theta = 0,
     \]
     即：
     \[
     \ddot{\theta} + \frac{2M + m}{3M + m}\frac{g}{R - r}\theta = 0.
     \]
     故振动频率为：
     \[
     f_2 = \frac{1}{2\pi}\sqrt{\frac{2M + m}{3M + m}\frac{g}{R - r}}.
     \]
   - **方法二（拉格朗日循环坐标交叉验证）**：
     系统总动能 \(T = \frac{1}{2}MR^2\dot{\psi}^2 + \frac{1}{2}m(R-r)^2\dot{\theta}^2 + \frac{1}{4}m\left[R\dot{\psi} - (R-r)\dot{\theta}\right]^2\)。因势能 \(V(\theta)\) 不显含 \(\psi\)，广义动量 \(p_\psi = \frac{\partial T}{\partial \dot{\psi}} = \left(M + \frac{1}{2}m\right)R^2\dot{\psi} - \frac{1}{2}mR(R-r)\dot{\theta}\) 守恒（注意这并非总角动量，而是外筒与小圆柱自转角动量的线性组合）。消去 \(\dot{\psi}\) 后有效动能化为 \(T_{\text{eff}} = \frac{1}{2}m(R-r)^2\frac{3M+m}{2M+m}\dot{\theta}^2\)，立即复现 \(f_2\)。
   - **双极限检验**：
     - \(M \to \infty\)（圆筒趋于固定）：\(\frac{2M+m}{3M+m} \to \frac{2}{3}\)，\(f_2 \to f_1\)；
     - \(M \to 0\)（圆筒无质量）：\(\frac{2M+m}{3M+m} \to 1\)，\(f_2 \to \frac{1}{2\pi}\sqrt{\frac{g}{R-r}}\)，因无质量圆筒无法承受任何摩擦反力矩（\(F_s = 0\)），小圆柱失去切向摩擦约束而蜕化为摆长 \(R - r\) 的单摆！

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以圆筒内小圆柱的无滑滚动为模型，第（1）问考察单刚体滚振的等效惯量计算，第（2）问引入可绕光滑中心轴自由转动的薄圆筒，使两刚体通过静摩擦力耦合。解决第（2）问既可直接联立平动定理、两刚体的定轴转动定理与纯滚动加速度约束，也可从分析力学角度识别出转角 \(\psi\) 为循环坐标并利用守恒的共轭广义动量直接降维，最终得到结构极美的频率公式 \(f_2 = \frac{1}{2\pi}\sqrt{\frac{2M+m}{3M+m}\frac{g}{R-r}}\)。
- **递进拆解脉络**：
  1. 第一步（建立无滑滚动运动学关系）：区分小圆柱质心公转角 \(\theta\)、小圆柱绕自身轴绝对转角 \(\phi\) 与外圆筒转角 \(\psi\)。利用切点速度相等 \((R-r)\dot{\theta} + r\dot{\phi} = R\dot{\psi}\)（或相对弧长关系 \(R\theta = r(\phi + \theta) - R\psi\) 统一正方向）建立角速度/角加速度约束。
  2. 第二步（求解固定圆筒情形）：当 \(\psi = 0\) 时，通过能量守恒或力矩消元得小圆柱切向等效惯量为 \(\frac{3}{2}m\)，从而 \(\ddot{\theta} + \frac{2g}{3(R-r)}\theta = 0\)，解得 \(f_1 = \frac{1}{\pi}\sqrt{\frac{g}{6(R-r)}}\)。
  3. 第三步（列写可动圆筒耦合方程）：对外圆筒与小圆柱分别绕各自中心轴列写转动定理（静摩擦力对两者的力矩分别为 \(-F_s R\) 与 \(+F_s r\)），消去 \(F_s\) 得 \(MR\ddot{\psi} + \frac{1}{2}mr\ddot{\phi} = 0\)；联立无滑滚动加速度关系解出 \(F_s = -\frac{Mm}{2M+m}(R-r)\ddot{\theta}\)。
  4. 第四步（消元求解微振动频率并做极限校验）：将 \(F_s\) 代入小圆柱质心切向方程，在小角近似 \(\sin\theta \approx \theta\) 下得 \(\ddot{\theta} + \frac{2M+m}{3M+m}\frac{g}{R-r}\theta = 0\)，求出 \(f_2\) 并用 \(M\to\infty\) 与 \(M\to 0\) 两个极限验证结果。
- **盲解手记**：盲解时先用极坐标矢量严谨推出了无滑滚动速度约束 \((R-r)\dot{\theta} + r\dot{\phi} = R\dot{\psi}\)，确认第（1）问为 \(\frac{1}{\pi}\sqrt{\frac{g}{6(R-r)}}\)。第（2）问先用拉格朗日量意外发现外筒转角 \(\psi\) 是循环坐标，随后用牛顿-欧拉两体法反推验证了为什么 \(MR^2\dot{\psi} + \frac{1}{2}mrR\dot{\phi}\) 守恒（虽然系统对 \(O\) 轴有重力矩，但静摩擦力是唯一的切向转动耦合源），两种方法得到完全一致的 \(f_2\)。
- **对照结论**：与官方参考解答结果完全一致（官方第（1）问写成 \(\frac{1}{\pi}\sqrt{\frac{g}{6(R-r)}}\)，第（2）问写成 \(\frac{1}{2\pi}\sqrt{\frac{2M+m}{3M+m}\frac{g}{R-r}}\)）。官方解答在角度符号设定上取小圆柱绕自身轴转角 \(\theta_1\) 与质心偏角同向相反（\(R\theta = r(\theta_1 + \theta) - R\theta_2\)），统一用牛顿-欧拉转动定理与质心运动定理求解；盲解则同时给出了牛顿-欧拉法与拉格朗日循环坐标法，互相印证了符号细节。
- **核心难点**：
  - 难点1：正确建立双动体无滑滚动的几何与速度约束关系。当圆筒自身以 \(\dot{\psi}\) 转动且质心在摆动时，极易弄混“相对圆筒的滚过弧长”与“实验室系绝对转角”。
  - 难点2：理解为什么系统总角动量不守恒（重力有外力矩），但仍存在一个由外筒转动与小圆柱自转组成的守恒量 \(MR\dot{\psi} + \frac{1}{2}mr\dot{\phi}\)（本质上是内摩擦力矩冲量之比恒定为 \(-R/r\)）。
- **高频易错点**：
  - 易错点1：套用定轴纯滚动时误把小圆柱自转角速度直接写成 \(\frac{R}{r}\dot{\theta}\)（漏掉连心线自身公转扣除的 \(1\) 倍 \(\dot{\theta}\)，即正确系数为 \(\frac{R-r}{r}\)），导致分母变成 \(R\) 而非 \(R-r\)。
  - 易错点2：在第（2）问中误以为系统绕 \(O\) 轴角动量守恒，错误写出 \(MR^2\dot{\psi} + m(R-r)^2\dot{\theta} + \frac{1}{2}mr^2\dot{\phi} = 0\)，从而把本该由重力驱动的质心摆动错误锁定。
- **教练总结**：遇到“物体在可动曲面内无滑滚动”的耦合问题，最稳妥的办法是用统一惯性参考系方向（例如全部逆时针为正）写质心速度与切点速度矢量 \(\mathbf{v}_P = \mathbf{v}_C + \boldsymbol{\omega}\times\mathbf{r}_{CP}\)，再令两接触体切点速度相等，绝不会出错。若再检验拉格朗日量中大圆筒转角是否循环，还能瞬间看出隐藏守恒量！

## 2. 抛物线轨道彗星穿越地球轨道的时间间隔与速率 (`cpho-2017-semifinal-theory-problem-slice-q2`)

- **难度评级**：`D2`
- **物理模型**：天体力学 · 抛物线零能轨道运动学、径向能量积分与开普勒面积定律
- **教学标签**：`抛物线轨道`、`角动量与机械能守恒`、`径向时间积分`、`开普勒第二定律交叉检验`、`天体数值估算`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **轨道参数与近日点条件**：
   彗星轨道为抛物线，偏心率 \(\varepsilon = 1\)，故总机械能 \(E = 0\)。轨道方程为：
   \[
   r = \frac{k}{1 + \cos\theta}, \qquad k = \frac{L^2}{GMm^2}.
   \]
   近日点 \(A\) 对应 \(\theta = 0\)，已知 \(r_A = \frac{1}{3}R_E\)，于是：
   \[
   r_A = \frac{k}{2} = \frac{1}{3}R_E \implies k = \frac{2}{3}R_E, \qquad \frac{L}{m} = \sqrt{GMk} = \sqrt{\frac{2}{3}GM R_E}.
   \]
   交点 \(C, D\) 满足 \(r = R_E\)，即 \(\frac{\frac{2}{3}R_E}{1 + \cos\theta} = R_E \implies \cos\theta = -\frac{1}{3}\)（因此 \(C, D\) 对称位于极轴两侧）。

2. **第（1）问：先后两次穿过地球轨道所用的时间 \(T\)**：
   - **解法一（径向能量方程直接积分，呼应题给积分公式）**：
     由机械能守恒（\(E = 0\)）：
     \[
     \frac{1}{2}m\dot{r}^2 + \frac{L^2}{2mr^2} - \frac{GMm}{r} = 0.
     \]
     代入 \(\frac{L^2}{m^2} = GMk = 2GM r_A\)：
     \[
     \dot{r}^2 = \frac{2GM}{r} - \frac{2GM r_A}{r^2} = \frac{2GM(r - r_A)}{r^2}.
     \]
     从近日点 \(A\)（\(r = r_A\)）运动到交点 \(C\)（\(r = R_E\)）的过程中 \(\dot{r} > 0\)，故：
     \[
     dt = \frac{1}{\sqrt{2GM}}\frac{r\,dr}{\sqrt{r - r_A}}.
     \]
     利用对称性，从 \(C\) 经 \(A\) 到 \(D\) 的总时间 \(T = 2\Delta t_{A\to C}\)：
     \[
     T = \frac{2}{\sqrt{2GM}} \int_{r_A}^{R_E} \frac{r\,dr}{\sqrt{r - r_A}} = \sqrt{\frac{2}{GM}}\left[\frac{2}{3}(r - r_A)^{3/2} + 2 r_A (r - r_A)^{1/2}\right]_{r_A}^{R_E}.
     \]
     （这里对照题给公式 \(\int \frac{x\,dx}{\sqrt{x+a}} = \frac{2}{3}(x+a)^{3/2} - 2a(x+a)^{1/2} + C\) 取 \(x = r\)、\(a = -r_A\)）。
     代入 \(r_A = \frac{1}{3}R_E\)（故 \(R_E - r_A = \frac{2}{3}R_E\)）：
     \[
     T = \sqrt{\frac{2}{GM}}\left[\frac{2}{3}\left(\frac{2}{3}R_E\right)^{3/2} + \frac{2}{3}R_E\left(\frac{2}{3}R_E\right)^{1/2}\right] = \sqrt{\frac{2}{GM}} \cdot \frac{10}{9}\sqrt{\frac{2}{3}} R_E^{3/2} = \frac{20}{9\sqrt{3}}\sqrt{\frac{R_E^3}{GM}} = \frac{20\sqrt{3}}{27}\sqrt{\frac{R_E^3}{GM}}.
     \]
   - **解法二（开普勒第二定律面积元交叉检验）**：
     由 \(\frac{1}{2}r^2\dot{\theta} = \frac{L}{2m} = \frac{1}{2}\sqrt{GMk}\)，得 \(T = \frac{2}{\sqrt{GMk}}\int_0^{\theta_0} r^2\,d\theta\)，其中 \(\cos\theta_0 = -\frac{1}{3} \implies \tan\frac{\theta_0}{2} = \sqrt{2}\)。借助巴克方程积分得 \(T = \frac{k^{3/2}}{\sqrt{GM}}\left(\tan\frac{\theta_0}{2} + \frac{1}{3}\tan^3\frac{\theta_0}{2}\right) = \left(\frac{2}{3}\right)^{3/2}\frac{5\sqrt{2}}{3}\sqrt{\frac{R_E^3}{GM}} = \frac{20\sqrt{3}}{27}\sqrt{\frac{R_E^3}{GM}}\)，完全一致！
   - **代入数值**：
     取 \(G = 6.67\times 10^{-11}\,\text{m}^3\cdot\text{kg}^{-1}\cdot\text{s}^{-2}\)，\(M = 1.99\times 10^{30}\,\text{kg}\)，\(R_E = 1.49\times 10^{11}\,\text{m}\)：
     \[
     \sqrt{\frac{R_E^3}{GM}} = \sqrt{\frac{(1.49\times 10^{11})^3}{6.67\times 10^{-11}\times 1.99\times 10^{30}}} \approx 4.992\times 10^6\,\text{s},
     \]
     \[
     T = \frac{20\sqrt{3}}{27}\times 4.992\times 10^6\,\text{s} \approx 6.405\times 10^6\,\text{s} \approx 6.40\times 10^6\,\text{s}\ (\approx 74.1\,\text{天}).
     \]

3. **第（2）问：经过 \(C, D\) 两点时速度的大小**：
   抛物线轨道总机械能 \(E = 0\)，在任意位置均有 \(\frac{1}{2}mv^2 - \frac{GMm}{r} = 0\)，故在 \(r_C = r_D = R_E\) 处速率相等：
   \[
   v_C = v_D = \sqrt{\frac{2GM}{R_E}} = \sqrt{\frac{2\times 6.67\times 10^{-11}\times 1.99\times 10^{30}}{1.49\times 10^{11}}} \approx 4.22\times 10^4\,\text{m/s}.
   \]
   **物理合理性检验**：地球公转速率约 \(29.8\,\text{km/s}\)，在 \(1\,\text{AU}\) 处的太阳逃逸速度为 \(\sqrt{2}\times 29.8 \approx 42.2\,\text{km/s}\)；且地球一年 \(365\,\text{天}\) 对应 \(2\pi\sqrt{R_E^3/(GM)}\)，故 \(\frac{T}{1\,\text{年}} = \frac{10\sqrt{3}}{27\pi} \approx 0.204\)，对应 \(74\,\text{天}\)，完全合理。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以抛物线彗星穿越地球轨道为背景，考查开普勒轨道方程、机械能与角动量守恒以及径向微元积分。因为抛物线轨道机械能恰好为零，第（2）问可直接给出逃逸速率 \(\sqrt{2GM/R_E}\)；第（1）问则通过分离径向动能与角向离心势能，将 \(dt\) 化为关于 \(r\) 的积分，借助题给不定积分公式与轨道对称性即可迅速求得往返时间。
- **递进拆解脉络**：
  1. 第一步（确定抛物线轨道参数与零能性质）：由抛物线离心率 \(\varepsilon = 1\) 得机械能 \(E = 0\) 与轨道方程 \(r = \frac{k}{1+\cos\theta}\)；在近日点 \(\theta = 0\) 处由 \(r_{\min} = \frac{k}{2} = \frac{R_E}{3}\)（或由近日点径向速度为零的能量方程）定出 \(\frac{L^2}{2GMm^2} = \frac{R_E}{3}\)。
  2. 第二步（建立径向速度与时间微分关系）：在极坐标机械能守恒式 \(\frac{1}{2}m\dot{r}^2 + \frac{L^2}{2mr^2} - \frac{GMm}{r} = 0\) 中消去 \(L\)，得 \(\frac{dr}{dt} = \pm\sqrt{\frac{2GM}{r} - \frac{2GM r_{\min}}{r^2}} = \pm\frac{\sqrt{2GM}\sqrt{r - R_E/3}}{r}\)。
  3. 第三步（对称区间积分求解穿越时间）：由对称性，从 \(C\) 经 \(A\) 到 \(D\) 的时间是 \(A\to C\) 时间的两倍。代入题给积分公式在 \([R_E/3, R_E]\) 上积分，得解析式 \(T = \frac{20\sqrt{3}}{27}\sqrt{\frac{R_E^3}{GM}}\) 及数值 \(6.40\times 10^6\,\text{s}\)。
  4. 第四步（直接由零能量守恒求交点速率）：在 \(C, D\) 两点处矢径均等于 \(R_E\)，由 \(\frac{1}{2}mv^2 - \frac{GMm}{R_E} = 0\) 立即得 \(v_C = v_D = \sqrt{\frac{2GM}{R_E}} \approx 4.22\times 10^4\,\text{m/s}\)。
- **盲解手记**：盲解时同时采用了“径向能量公式直接积分（配合题给积分公式）”与“开普勒第二定律对真近点角 \(\theta\) 积分（巴克方程）”两种途径互验，均得出解析式 \(\frac{20\sqrt{3}}{27}\sqrt{\frac{R_E^3}{GM}}\) 与 \(v_C = v_D = \sqrt{\frac{2GM}{R_E}}\)。数值计算分别对应 \(6.40\times 10^6\,\text{s}\)（约 \(74.1\) 天）与 \(42.2\,\text{km/s}\)。
- **对照结论**：与官方参考解答完全一致！官方第（1）问通过近日点径向速度为零（\(\frac{L^2}{2mr_{\min}^2} = \frac{GMm}{r_{\min}}\)）直接关联 \(L\) 与 \(r_{\min}\)，甚至不需用到 \(k = L^2/(GMm^2)\) 即可进入积分；最后得 \(T = \frac{20\sqrt{3}}{27}\frac{R_E^{3/2}}{\sqrt{GM}} \approx 6.40\times 10^6\,\text{s}\)，第（2）问得 \(v_C = v_D = 4.22\times 10^4\,\text{m/s}\)，完全吻合。
- **核心难点**：
  - 难点1：在极坐标守恒方程中识别出总动能必须拆分为“径向平动动能 \(\frac{1}{2}m\dot{r}^2\)”与“横向角动量离心项 \(\frac{L^2}{2mr^2}\)”，不可把 \(\dot{r}\) 误当成总速率 \(v\)。
  - 难点2：正确使用题给不定积分公式 \(\int \frac{x\,dx}{\sqrt{x+a}}\) 时的变量代换符号匹配（令 \(a = -r_{\min} = -\frac{R_E}{3}\)，从而 \(-2a = +\frac{2}{3}R_E\)）。
- **高频易错点**：
  - 易错点1：积分忘记乘以 2（只算了从近日点到 \(C\) 的半程时间），或者代换 \(a = -R_E/3\) 时弄反加减号导致结果算成 \(\frac{4}{9}\) 而非 \(\frac{10}{9}\)。
  - 易错点2：求 \(C, D\) 速度时去求速度的径向与切向分量再合成，绕远路且易算错夹角；其实由抛物线 \(E=0\) 一步即可得到总速率 \(\sqrt{2GM/R_E}\)。
- **教练总结**：有心力场求运行时间通常有三条路：（1）按 \(r\) 积分（利用有效势能与机械能守恒，适合题给径向积分公式的情形）；（2）按 \(\theta\) 积分（利用开普勒第二定律面积元与极坐标轨道方程，如抛物线可用巴克公式、椭圆可用面积直接求扫过扇形）；（3）反演开普勒时间方程（偏近点角 \(E\)）。养成算完后与“地球 \(1\) 年、\(30\,\text{km/s}\)”心算比对的习惯，能瞬间排除数量级与系数错误。

## 3. 制动卡车与载重物滑动及碰撞的分段多过程动力学 (`cpho-2017-semifinal-theory-problem-slice-q3`)

- **难度评级**：`D3`
- **物理模型**：多体摩擦与非弹性碰撞 · 临界停驻判据、分段碰撞与质心运动定理
- **教学标签**：`多体分段动力学`、`滑动摩擦与静摩擦自锁检验`、`完全非弹性碰撞`、`临界工况分类讨论`、`质心运动定理降维`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **受力分析与加速度**：
   卡车制动后且重物尚未撞击前壁时，重物 \(B\) 相对于车厢向前滑动，受车厢向后的滑动摩擦力 \(f_2 = \mu_2 m g\)，故 \(B\) 相对地面的减速度大小为：
   \[
   a_2 = \mu_2 g.
   \]
   卡车 \(A\) 受地面对车轮向后的滑动摩擦力 \(f_1 = \mu_1(M + m)g\) 与重物对车厢向前的滑动摩擦力 \(f_2 = \mu_2 mg\)，由牛顿第二定律，卡车减速度大小为：
   \[
   a_1 = \frac{\mu_1(M + m)g - \mu_2 m g}{M} = \frac{\mu_1 M + (\mu_1 - \mu_2)m}{M}g.
   \]
   因 \(\mu_2 < \mu_1\)，显然有 \(a_1 > \mu_1 g > \mu_2 g = a_2\)，即卡车减速比重物快，卡车先停下。
   **自锁检验**：卡车停下后，若重物仍在车板上滑动，重物对卡车向前的摩擦力为 \(\mu_2 mg\)；而地面能提供的最大静摩擦力为 \(\mu_1(M + m)g > \mu_2 mg\)，因此卡车停下后不会在撞击前被重物重新拖动。

2. **第（1）问：不发生碰撞时的时间、路程与判据**：
   - 卡车停下所需时间与路程：
     \[
     t_1 = \frac{v_0}{a_1} = \frac{M v_0}{[\mu_1 M + (\mu_1 - \mu_2)m]g}, \qquad s_1 = \frac{v_0^2}{2a_1} = \frac{M v_0^2}{2[\mu_1 M + (\mu_1 - \mu_2)m]g}.
     \]
   - 重物停下所需时间与路程：
     \[
     t_2 = \frac{v_0}{\mu_2 g}, \qquad s_2 = \frac{v_0^2}{2\mu_2 g}.
     \]
   - 在整个运动过程中，总有 \(v_B(t) \ge v_A(t)\)，重物相对车厢向前位移单调递增至最大值 \(s_2 - s_1\)。因此不发生碰撞（含恰以零相对速度到达前壁）的条件为：
     \[
     L \ge s_2 - s_1 = \frac{v_0^2}{2g}\left[\frac{1}{\mu_2} - \frac{M}{\mu_1 M + (\mu_1 - \mu_2)m}\right] = \frac{(\mu_1 - \mu_2)(M + m)v_0^2}{2\mu_2[\mu_1 M + (\mu_1 - \mu_2)m]g}.
     \]

3. **第（2）问：发生碰撞（\(L < s_2 - s_1\)）的两种子情形**：
   在 \(t_1\) 时刻（卡车恰好首次停稳时），重物相对车厢前滑的临界距离为：
   \[
   \Delta s_c = s_2'(t_1) - s_1 = \left(v_0 t_1 - \frac{1}{2}a_2 t_1^2\right) - \frac{1}{2}v_0 t_1 = \frac{1}{2}(a_1 - a_2)t_1^2 = \frac{(\mu_1 - \mu_2)(M + m)M v_0^2}{2[\mu_1 M + (\mu_1 - \mu_2)m]^2 g}.
   \]
   因为 \(\mu_1 M + (\mu_1 - \mu_2)m > \mu_2 M\)，必有 \(\Delta s_c < s_2 - s_1\)，故碰撞区间自然分为两个子情形：

   - **子情形（i）：卡车已停稳后才发生碰撞（\(\Delta s_c < L < s_2 - s_1\)）**：
     卡车先在 \(t_1\) 时停下，已行进距离 \(s_1\)；重物继续匀减速，撞击前壁前总路程为 \(s_1 + L\)。由动能定理（或运动学），撞击前瞬间重物速度 \(v_2\) 满足：
     \[
     v_2 = \sqrt{v_0^2 - 2\mu_2 g(s_1 + L)} = \sqrt{\frac{(\mu_1 - \mu_2)(M + m)v_0^2}{\mu_1 M + (\mu_1 - \mu_2)m} - 2\mu_2 g L}.
     \]
     撞击极短时间内地面有限摩擦力的冲量可略，由动量守恒得碰后共同速度：
     \[
     m v_2 = (M + m)V \implies V = \frac{m}{M + m}v_2.
     \]
     重物对车厢前壁的冲量大小等于卡车动量增量：
     \[
     I = M V = \frac{Mm}{M + m}\sqrt{\frac{(\mu_1 - \mu_2)(M + m)v_0^2}{\mu_1 M + (\mu_1 - \mu_2)m} - 2\mu_2 g L}.
     \]
     撞击发生时刻 \(t_2' = \frac{v_0 - v_2}{\mu_2 g}\)，此后整体以减速度 \(\mu_1 g\) 共同滑行直至最终停止：
     \[
     t' = \frac{V}{\mu_1 g} = \frac{m v_2}{(M + m)\mu_1 g}, \qquad s_1' = \frac{V^2}{2\mu_1 g} = \frac{m^2 v_2^2}{2(M + m)^2 \mu_1 g}.
     \]
     故总时间与卡车总路程分别为：
     \[
     t^{(\text{i})} = t_2' + t' = \frac{v_0}{\mu_2 g} - \frac{\mu_1 M + (\mu_1 - \mu_2)m}{\mu_1 \mu_2 (M + m)g}v_2,
     \]
     \[
     s^{(\text{i})} = s_1 + s_1' = \frac{[\mu_1 M(M + m) + (\mu_1 - \mu_2)m^2]v_0^2}{2\mu_1(M + m)[\mu_1 M + (\mu_1 - \mu_2)m]g} - \frac{\mu_2 m^2 L}{\mu_1(M + m)^2}.
     \]

   - **子情形（ii）：卡车尚未停稳时发生碰撞（\(0 < L \le \Delta s_c\)）**：
     撞击时刻 \(t\) 满足 \(\frac{1}{2}(a_1 - a_2)t^2 = L\)，而 \(a_1 - a_2 = \frac{(\mu_1 - \mu_2)(M + m)}{M}g\)，故：
     \[
     t = \sqrt{\frac{2ML}{(\mu_1 - \mu_2)(M + m)g}}.
     \]
     撞击前瞬间相对速度 \(v_{\text{rel}} = (a_1 - a_2)t\)，由动量守恒与折合质量可知重物对前壁冲量为：
     \[
     I' = \frac{Mm}{M + m} v_{\text{rel}} = \frac{Mm}{M + m}\sqrt{2(a_1 - a_2)L} = m\sqrt{\frac{2M(\mu_1 - \mu_2)g L}{M + m}}.
     \]
     注意到在 \([0, t_{\text{tot}}]\) 整个制动过程中（因卡车在碰前未停，碰后又一起往前滑行直至同停），地面始终对卡车施加恒定的水平外力 \(-\mu_1(M + m)g\)，系统质心始终做减速度为 \(\mu_1 g\) 的匀减速运动！直接由质心动力学定理：
     - 总时间 \(t^{(\text{ii})} = \frac{v_0}{\mu_1 g}\)（与 \(L\) 无关！）；
     - 质心总位移 \(\Delta x_c = \frac{v_0^2}{2\mu_1 g} = \frac{M s^{(\text{ii})} + m(s^{(\text{ii})} + L)}{M + m}\)，立即解得卡车总路程：
       \[
       s^{(\text{ii})} = \frac{v_0^2}{2\mu_1 g} - \frac{m}{M + m}L.
       \]
     （用分段运动学相加 \(s_{\text{pre}} + s_{\text{post}}\) 及边界 \(L = \Delta s_c\) 连续性检验，与子情形（i）完美衔接。）

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是一道典型的板块摩擦叠加瞬时非弹性碰撞的分段动力学问题。由于车轮与地面的摩擦因数 \(\mu_1\) 大于重物与车厢底板的摩擦因数 \(\mu_2\)，制动后卡车减速比重物更快。第（2）问的灵魂在于不能想当然地认为“碰撞一定发生在卡车停下之前”，而是必须比较车厢长度 \(L\) 与卡车停稳时刻的相对位移 \(\Delta s_c\)，分“先停后撞”和“未停先撞”两类情形讨论；在“未停先撞”情形中，运用质心运动定理可直接秒杀总时间与总路程。
- **递进拆解脉络**：
  1. 第一步（求各自减速度与不碰撞条件）：分别隔离卡车和重物求得 \(a_1 = \frac{\mu_1 M + (\mu_1-\mu_2)m}{M}g\) 与 \(a_2 = \mu_2 g\)。因 \(\mu_2 < \mu_1\)，卡车先停且停后地面最大静摩擦力足以锁住卡车不被重物拖行，由此算出各自的停驻时间与路程，以及不碰撞判据 \(L \ge s_2 - s_1\)。
  2. 第二步（划分碰撞的两个临界区间）：计算卡车停下时刻 \(t_1\) 重物相对车厢滑过的距离 \(s_2' - s_1 = \frac{1}{2}(a_1 - a_2)t_1^2\)，将碰撞域 \(0 < L < s_2 - s_1\) 严格拆分为（i）车停后再撞和（ii）车未停先撞两类。
  3. 第三步（求解车停后再撞情形）：用动能定理求重物撞击前速度 \(v_2\)，由动量守恒求碰后共速 \(V = \frac{m}{M+m}v_2\) 与冲量 \(I = MV\)，再计入碰后共同减速阶段的时间 \(t'\) 与路程 \(s_1'\) 得到总时间与总路程。
  4. 第四步（利用质心运动定理与分段运动学求车未停先撞情形）：由相对运动求碰撞时刻 \(t\) 与相对速度 \(v_{\text{rel}}\)，利用折合质量得出冲量 \(I'\)；借助整个过程地面滑动摩擦力始终全额做功（质心恒以 \(\mu_1 g\) 匀减速），直接导出 \(t^{(\text{ii})} = \frac{v_0}{\mu_1 g}\) 与 \(s^{(\text{ii})} = \frac{v_0^2}{2\mu_1 g} - \frac{m}{M+m}L\)。
- **盲解手记**：盲解时第一时间警惕到 \(\mu_2 < \mu_1\) 导致卡车可能先停下，随后验证了卡车停下后重物摩擦力 \(\mu_2 mg < \mu_1(M+m)g\) 确实无法拖走卡车，进而主动切分出“撞前车已停”与“撞前车未停”两大子情形，并在两段分别推导了时间、路程与冲量（对车未停情形同时用了分段积分和质心运动定理验证），还检验了两种情形在临界长度 \(L = \Delta s_c\) 处的连续性。
- **对照结论**：与官方参考解答完全一致，甚至思路几乎逐行重合！官方解答同样将第（2）问分为 \(t_2 > t > t_1\) 与 \(t \le t_1\) 两种情况，且在 \(t \le t_1\) 末尾补充了“质心运动定理”的简便解法，与盲解完全吻合。**官方勘误记录**：官方解答第 7 页式（20）第一行等号后将撞前卡车路程误印为 \(v_0 t + \frac{1}{2}a_1 t^2\)（加号应为减号，即 \(v_0 t - \frac{1}{2}a_1 t^2\)），但紧接着的最终表达式 \(s_1^{(\text{ii})} = \frac{v_0^2}{2\mu_1 g} - \frac{mL}{M+m}\) 是完全正确的。
- **核心难点**：
  - 难点1：识别碰撞时刻与卡车停止时刻的先后顺序。绝大多数同学只做了“车未停就撞上”的情形，漏掉“卡车先停下后被重物二次撞飞再滑行一段”的区间，丢失一半以上分数。
  - 难点2：准确判断卡车首次停下后在重物继续滑动期间是否会受重物摩擦力重新启动（须比较 \(\mu_2 mg\) 与地面最大静摩擦 \(\mu_1(M+m)g\)），以及碰撞瞬间为何可视为地面外力冲量可忽略。
- **高频易错点**：
  - 易错点1：计算卡车与地面之间的摩擦力时忘记加上重物的质量，误写成 \(\mu_1 M g\) 而非 \(\mu_1(M + m)g\)。
  - 易错点2：碰撞后忽略卡车被撞动还会继续滑行一段路程 \(s_1'\)，或误以为一旦撞上，无论碰撞前车是否停下，总时间永远等于 \(v_0/(\mu_1 g)\)（事实上在先停后撞情形中，卡车静止等待期间地面静摩擦力小于 \(\mu_1(M+m)g\)，故总时间必大于 \(v_0/(\mu_1 g)\)）。
- **教练总结**：板块类多体运动问题必须遵守“三步安检”：（1）谁先减速到零？（2）先停者能否被未停者用静摩擦重新拖动？（3）临界长度或临界速度处是否发生分段切换？而在“未停先撞”且撞后不分离的整个过程中，因地面始终提供满额滑动摩擦力，**质心运动定理**可以直接跳过碰撞细节求得总时间和总位移，既省算力又防出错。

## 4. 双内切半圆导轨中旋转金属棒的感生电动势与安培力 (`cpho-2017-semifinal-theory-problem-slice-q4`)

- **难度评级**：`D2`
- **物理模型**：电磁感应 · 分段几何回路磁通量变化率与变电阻等效闭合电路
- **教学标签**：`法拉第电磁感应定律`、`分段几何拓扑识别`、`动生电动势等效`、`变长均匀电阻杆`、`能量守恒力矩检验`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **几何结构与分段临界时刻识别**：
   大半圆以 \(O\) 为圆心、半径为 \(2a\)，直径为 \(MN\)；小半圆以 \(O_1\) 为圆心、半径为 \(a\)，内切于 \(M\)，故 \(O_1\) 为 \(MO\) 中点，小半圆的直径恰为 \(MO = 2a\)（过 \(M\) 和 \(O\)）。磁场仅存在于两半圆弧与半径 \(ON\) 围成的区域内，即小半圆 \(MQO\) 内部**无磁场**。
   金属棒 \(OP\) 绕 \(O\) 顺时针旋转，\(t\) 时刻转角为 \(\theta = \omega t \in [0, \pi]\)：
   - **第一阶段（\(0 \le t \le \frac{\pi}{2\omega}\)，即 \(0 \le \omega t \le \frac{\pi}{2}\)）**：
     射线 \(OP\) 与小半圆弧交于点 \(Q\)（不同于 \(O\)）。由直径 \(MO = 2a\) 所对圆周角为直角（或等腰三角形 \(\triangle O_1 O Q\)），有 \(OQ = 2a\cos(\omega t)\)，棒处于磁场内的有效长度：
     \[
     L_{QP} = OP - OQ = 2a(1 - \cos\omega t).
     \]
   - **第二阶段（\(\frac{\pi}{2\omega} < t \le \frac{\pi}{\omega}\)，即 \(\frac{\pi}{2} < \omega t \le \pi\)）**：
     金属棒已转入右象限，小半圆弧完全位于 \(O\) 点左侧，此时棒 \(OP\) 仅在端点 \(O\) 处与小半圆弧接触（即 \(Q\) 退化并停留于 \(O\) 点，\(OQ = 0\)），整根金属棒 \(OP\)（长度 \(L_{QP} = 2a\)）全部处在磁场中！

2. **第（1）问：沿回路 \(QPMQ\) 的感应电动势 \(\mathcal{E}\)**：
   - **第一阶段（\(0 \le \omega t \le \frac{\pi}{2}\)）**：
     - 法拉第定律法：小半圆内 \(\angle M O_1 Q = 2\omega t\)，故扫过的磁场面积为扇形 \(MOP\) 面积减去小半圆内区域 \(MQO\) 的面积：
       \[
       S(t) = \frac{1}{2}(2a)^2(\omega t) - \left[\frac{1}{2}a^2(2\omega t) + \frac{1}{2}a^2\sin(\pi - 2\omega t)\right] = a^2\left(\omega t - \frac{1}{2}\sin 2\omega t\right).
       \]
       磁通量 \(\Phi = BS(t)\)（垂直纸面向下增加），故感应电动势：
       \[
       \mathcal{E} = -\frac{d\Phi}{dt} = - B\omega a^2 (1 - \cos 2\omega t) = - 2 B \omega a^2 \sin^2(\omega t)
       \]
       （负号表示感生电流/电动势方向沿回路 \(Q \to P \to M \to Q\) 逆时针方向）。
     - 动生电动势交叉验证：\(OQ\) 段在无磁场区不产生电动势，\(QP\) 段切割磁感线，\(\mathcal{E} = \int_{2a\cos\omega t}^{2a} B\omega r\,dr = \frac{1}{2}B\omega\left[(2a)^2 - (2a\cos\omega t)^2\right] = 2 B\omega a^2 \sin^2(\omega t)\)，方向由 \(\mathbf{v}\times\mathbf{B}\) 指向 \(Q \to P\)，完全一致！
   - **第二阶段（\(\frac{\pi}{2} < \omega t \le \pi\)）**：
     整根长度为 \(2a\) 的棒 \(OP\) 切割磁感线（且扫过面积速率恒为 \(\frac{dS}{dt} = \frac{1}{2}(2a)^2\omega = 2\omega a^2\)）：
     \[
     \mathcal{E} = - 2 B \omega a^2 \quad (\text{大小 } 2 B \omega a^2,\ \text{方向仍沿 } Q\to P\to M\to Q).
     \]

3. **第（2）问：金属棒 \(OP\) 所受原磁场 \(B\) 的作用力大小 \(F\)**：
   由于两半圆弧电阻忽略不计，即使 \(O\) 点与小半圆弧相接，小半圆弧 \(QO\) 段电阻为零且 \(OQ\) 段无电动势，故 \(OQ\) 段棒被弧 \(QO\) 短路（电流为零），回路 \(QPMQ\) 中的总电阻仅为均质金属棒 \(QP\) 段的电阻：
   \[
   R_{QP} = \frac{L_{QP}}{2a} R.
   \]
   - **第一阶段（\(0 < \omega t \le \frac{\pi}{2}\)）**：
     \(L_{QP} = 2a(1 - \cos\omega t)\)，故 \(R_{QP} = R(1 - \cos\omega t)\)。回路电流大小为：
     \[
     I = \frac{|\mathcal{E}|}{R_{QP}} = \frac{2 B \omega a^2 \sin^2(\omega t)}{R(1 - \cos\omega t)} = \frac{2 B \omega a^2}{R}(1 + \cos\omega t) = \frac{4 B \omega a^2}{R}\cos^2\left(\frac{\omega t}{2}\right).
     \]
     注意到因子 \((1 - \cos\omega t)\) 恰好约去，\(t \to 0^+\) 时电流趋于有限值 \(\frac{4 B\omega a^2}{R}\)（而 \(t = 0\) 时刻 \(P, Q, M\) 重合不构成闭合有面积回路）。棒在磁场中受安培力大小为：
     \[
     F = B I L_{QP} = B \left[\frac{2 B\omega a^2}{R}(1 + \cos\omega t)\right] \cdot 2a(1 - \cos\omega t) = \frac{4 B^2 \omega a^3}{R}\sin^2(\omega t) = \frac{2 B^2 \omega a^3}{R}(1 - \cos 2\omega t).
     \]
   - **第二阶段（\(\frac{\pi}{2} < \omega t \le \pi\)）**：
     此时 \(L_{QP} = 2a\)，\(R_{QP} = R\)，\(I = \frac{2 B \omega a^2}{R}\)，安培力大小为：
     \[
     F = B I (2a) = \frac{4 B^2 \omega a^3}{R}.
     \]
   **连续性与能量守恒校验**：在 \(\omega t = \frac{\pi}{2}\) 处左右极限均为 \(\frac{4B^2\omega a^3}{R}\)，连续平滑衔接；计算安培阻力矩 \(\tau = \int_{OQ}^{2a} B I r\,dr\)，在两阶段均满足 \(\tau\omega = |\mathcal{E}|I = I^2 R_{QP}\)，能量守恒完全成立！

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题巧妙结合几何圆弧导轨与分段电磁感应。解题核心有二：其一是敏锐捕捉时间范围 \(0 \le t \le \pi/\omega\) 在 \(t = \pi/(2\omega)\) 处的几何拓扑分界——前半段棒与小半圆相交于移动点 \(Q\)，后半段棒进入右象限后 \(Q\) 停留于原点 \(O\)；其二是准确判定均质金属棒仅处于磁场中的 \(QP\) 段参与回路导电（\(OQ\) 段无电动势且被零电阻小半圆弧短路），从而棒的有效电阻随长度动态变化，并在电流表达式中优雅地与分子中的 \(1 - \cos\omega t\) 约去。
- **递进拆解脉络**：
  1. 第一步（划分时间分段与确定几何交点 \(Q\)）：分析半圆 \(O_1\) 的空间范围可知，仅当 \(0 \le \omega t \le \pi/2\) 时 \(OP\) 与小半圆弧有异于 \(O\) 的交点 \(Q\)，且 \(OQ = 2a\cos\omega t\)；当 \(\pi/2 < \omega t \le \pi\) 时，\(Q\) 恒与 \(O\) 重合，整根棒 \(OP\) 均在磁场中。
  2. 第二步（分阶段求感应电动势 \(\mathcal{E}\)）：既可用扇形与三角形面积差求磁通变化率 \(-\frac{d\Phi}{dt}\)，也可直接对磁场段 \([OQ, 2a]\) 用动生电动势积分 \(\int B\omega r\,dr\)，两阶段分别得 \(-2B\omega a^2\sin^2\omega t\) 与 \(-2B\omega a^2\)（沿 \(QPMQ\) 逆时针方向）。
  3. 第三步（确定有效电阻与感应电流）：由两半圆弧电阻为零且 \(OQ\) 段无电动势，得出回路电阻就是均匀杆 \(QP\) 段的电阻 \(R_{QP} = \frac{L_{QP}}{2a}R\)。代入 \(I = |\mathcal{E}|/R_{QP}\) 约去 \(1 - \cos\omega t\)，求得两阶段电流。
  4. 第四步（求安培力并做连续性与能量检验）：由 \(F = B I L_{QP}\) 求得两阶段安培力 \(\frac{2B^2\omega a^3}{R}(1-\cos 2\omega t)\) 与 \(\frac{4B^2\omega a^3}{R}\)，并验证 \(\omega t = \pi/2\) 处连续及安培力矩功率等于焦耳热功率。
- **盲解手记**：盲解时特别注意到题设区间是 \(0 \le t \le \pi/\omega\) 而非 \(\pi/(2\omega)\)，第一时间画图检查右半象限交点，立即意识到在 \(\pi/2 < \omega t \le \pi\) 时 \(Q\) 退化为 \(O\) 点，必须分段求解；同时仔细核对了 \(OQ\) 段是否被零电阻小半圆弧短路且因无磁场不产生电动势。最终用动生电动势积分与法拉第面积求导交叉核对，并验证了 \(\tau\omega = I^2 R_{QP}\)。
- **对照结论**：与官方参考解答完全一致！官方解答同样在 \(\omega t = \pi/2\) 处分两段求解（式⑧、⑨及式⑮、⑯），采用“扇形加减面积求磁通变化率”的思路，并把结果写成 \(-(1 - \cos 2\omega t)\omega a^2 B\) 和 \((1 - \cos 2\omega t)\frac{2\omega a^3 B^2}{R}\)，与盲解的 \(2\sin^2\omega t\) 写法恒等。官方题干写“在 \(t\ (0\le t\le \pi/\omega)\) 时刻，半径 \(OP\) 与半圆 \(O_1\) 交于 \(Q\) 点”，对后半程实际上是利用“端点 \(O\) 仍属半圆 \(O_1\)”，教学时应向学生明确指出这一几何极限。
- **核心难点**：
  - 难点1：识别 \(\omega t = \pi/2\) 处的分段突变。若不画图分析，直接将公式 \(OQ = 2a\cos\omega t\) 套用到 \(\pi/2 < \omega t \le \pi\)，会出现负长度甚至荒谬的周期振荡结果。
  - 难点2：正确分析均匀电阻杆的局部接入电路问题。许多学生会把整根金属棒的电阻 \(R\) 当作回路电阻，而忽略了真正接入回路 \(QPMQ\) 的只是 \(QP\) 段，导致电流和安培力算错。
- **高频易错点**：
  - 易错点1：求小半圆内非磁场区面积时，误把圆心角 \(\angle M O_1 Q\) 当成 \(\omega t\)（实际由圆周角定理是 \(2\omega t\)），从而漏掉或算错三角项。
  - 易错点2：忘记在 \(\omega t \in (\pi/2, \pi]\) 时，\(OQ = 0\) 意味着整根棒都切割磁感线且整根棒 \(R\) 都接入回路，错把 \(t > \pi/(2\omega)\) 的电动势设为零。
- **教练总结**：旋转导体杆与非共心圆弧导轨组合问题，先画临界角位置草图（如本题的 \(\omega t = \pi/2\)），确定有效切割区间 \([r_{\min}(t), r_{\max}(t)]\)；再用**动生电动势积分**（快准狠）与**法拉第磁通求导**双轨验证；最后检查“总电阻是否随接触点移动而变化”。

## 5. 单向电场回旋加速器中的折返漂移与出射能谱上限 (`cpho-2017-semifinal-theory-problem-slice-q5`)

- **难度评级**：`D4`
- **物理模型**：带电粒子在组合电磁场中的轨道动力学 · 折返反射机制与数论整除不等式
- **教学标签**：`回旋加速器变体`、`洛伦兹力圆周运动`、`带电粒子在电场中折返`、`几何避碰不等式约束`、`官方答案瑕疵辨析`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **关键物理机制辨析（为何必须仔细推导下穿极板时的电场作用）**：
   离子从离子源 \(S\) 静止出发，经两极板间电场加速，由 \(O\) 点竖直向上射入上半空间匀强磁场，其初动能 \(E_1 = qU\)，速率 \(v = \sqrt{\frac{2qU}{m}}\)，回旋半径：
   \[
   r = \frac{mv}{qB} = \frac{1}{B}\sqrt{\frac{2mU}{q}}.
   \]
   由于“其它部分存在匀强磁场”（上下半空间磁场同向，垂直纸面使向上射出的离子向右偏转），在上半空间出射与下半空间返回时有以下严格运动学定理：
   - 离子在横坐标 \(x\) 处向上进入上半圆磁场，以半径 \(r_{\text{上}}\) 偏转到 \(x + 2r_{\text{上}}\) 处向下射出；
   - 离子在横坐标 \(x'\) 处向下进入下半圆磁场，以半径 \(r_{\text{下}}\) 向左偏转到 \(x' - 2r_{\text{下}}\) 处向上射出。
   由此可见：
   - 若 \(x_1 = 2r > D\) 但 \(2r < bD\)，离子从无场虚线缝隙进入下半空间（\(r_{\text{下}} = r\)），必折回 \(x_2 = 2r - 2r = 0\) 处打在离子源外壁 \(S\) 上被吸收；
   - 若两极板间是“无论上下穿过都加速的交流高频电场”，则在 \(x_1 < D\) 向下穿过极板后 \(r_{\text{下}} = \sqrt{2}r > r\)，必左偏到 \(x_2 = 2(1 - \sqrt{2})r < 0\)，最终超出左侧器壁被吸收（因题图 \(O\) 紧邻左侧器壁且未给出左侧尺寸）；
   - **唯一可行的物理机制**：两极板间电场方向始终向上（仅当粒子在极板间经过时存在，消除 \(x > D\) 处的边缘场干扰）。当离子以动能 \(qU\) 在 \(x < D\) 处向下进入极板间时，被向上电场减速至下极板处速率恰为零，随即被同一电场重新向上加速，以速率 \(v\)（动能仍为 \(qU\)）从同一位置 \(x\) 再次向上射入上半磁场！

2. **第（1）问：磁感应强度 \(B\) 的最小值**：
   当离子不返回极板区、仅走半个圆周直接从 \(O\) 到达出射孔 \(P\) 时，直径 \(2r = bD \implies r = \frac{bD}{2}\)（若 \(r > \frac{bD}{2}\) 则撞击上方圆形器壁被吸收；若 \(\frac{D}{2} < r < \frac{bD}{2}\) 则回打 \(S\) 被吸收；若 \(r = \frac{D}{2}\) 则撞击极板右端）。由此得 \(B\) 的最小值：
   \[
   B_{\min} = \frac{2}{bD}\sqrt{\frac{2mU}{q}}.
   \]

3. **第（2）问：磁感应强度 \(B\) 的其它所有可能值**：
   当 \(r < \frac{D}{2}\) 时，离子在极板上方做直径为 \(2r\) 的连续跳跃，在下极板处反复减速折返，依次落于 \(x = 2r, 4r, \dots, 2kr\)（\(k \ge 1\) 为正整数）。设进行了 \(k\) 次这样的向上/折返跳跃后，在第 \(k+1\) 次跳跃时落到极板右端之外：
   \[
   2kr < D < 2(k+1)r \quad (\text{若允许擦过极板右端，边界为 } 2kr \le D < 2(k+1)r,\ \text{注意 } 2(k+1)r < D + 2r < 2D < bD\text{ 因 } b > 2).
   \]
   在 \(2(k+1)r > D\) 处，离子穿过无场虚线区间进入下半磁场（半径仍为 \(r\)），向左转半周后恰好回到 \(x = 2kr \le D\) 处竖直向上穿过下极板进入极板间！
   此后每经历一次“下\(\to\)上穿过极板”，离子动能增加 \(qU\)。设如此穿过极板被额外加速 \(n\) 次（总加速次数为 \(n+1\)，动能为 \((n+1)qU\)），其在上半磁场中的半径变为 \(r_n = \sqrt{n+1}\, r\)（因 \(2kr + 2\sqrt{2}r > D - 2r + 2\sqrt{2}r > D\)，故一旦 \(n \ge 1\)，以后每次向下落地必在 \(x > D\) 的无场区，均原路从下半圆安全返回 \(x = 2kr\) 处再次向上加速！）。
   最终从 \(P\) 射出的条件为：
   \[
   2kr + 2r_n = bD \implies (\sqrt{n+1} + k) r = \frac{bD}{2}, \qquad \text{即 } B_{k,n} = \frac{2(\sqrt{n+1} + k)}{bD}\sqrt{\frac{2mU}{q}}.
   \]
   将 \(r = \frac{bD}{2(\sqrt{n+1}+k)}\) 代入几何约束 \(\frac{D}{2(k+1)} < r \le \frac{D}{2k}\)（若不允许擦极板端则严格小于 \(\frac{D}{2k}\)）：
   \[
   k b \le \sqrt{n+1} + k < (k+1)b \implies (b-1)k \le \sqrt{n+1} < (b-1)k + b,
   \]
   等价于整数 \(n \ge 1\) 满足：
   \[
   (b-1)^2 k^2 - 1 \le n \le [(b-1)k + b]^2 - 2.
   \]
   同时还必须满足磁场可调上限 \(B_{k,n} \le B_{\max}\)，即 \(r \ge r_{\min} = \frac{1}{B_{\max}}\sqrt{\frac{2mU}{q}}\)：
   \[
   \sqrt{n+1} + k \le \frac{b D B_{\max}}{2}\sqrt{\frac{q}{2mU}} \equiv \frac{b a}{2} \quad \left(\text{其中记 } a \equiv D B_{\max}\sqrt{\frac{q}{2mU}} = \frac{D}{r_{\min}}\right).
   \]
   由 \(2k r \le D \implies k \le \frac{D}{2r_{\min}} = \frac{a}{2}\)，故 \(k = 1, 2, \dots, \left\lfloor \frac{a}{2} \right\rfloor\)（且需有对应的 \(n\) 满足 \(\sqrt{n+1}+k \le \frac{ba}{2}\)）。

4. **第（3）问：出射离子能量的最大值**：
   离子经总计 \(n+1\) 次加速后，出射能量 \(E_{k,n} = (n+1)qU\)。要使 \(E_{k,n}\) 最大，即求在所有允许整数组 \((k, n)\) 中 \(n\) 的最大值 \(n_{\max}\)：
   - 对于给定的 \(k \in \{1, 2, \dots, \lfloor a/2 \rfloor\}\)，受几何与 \(B_{\max}\) 双重约束，\(n\) 的上限为：
     \[
     n \le \min\left\{ [(b-1)k + b]^2 - 2,\;\; \left\lfloor \left(\frac{ba}{2} - k\right)^2 \right\rfloor - 1 \right\}
     \]
     （注意当 \(k = \lfloor a/2 \rfloor\) 且 \(a/2\) 非接近 \(k+1\) 的小数时，\(B_{\max}\) 约束 \(\frac{ba}{2} - k\) 往往比几何上界 \((b-1)k + b\) 更紧，此时甚至更小的 \(k' < \lfloor a/2 \rfloor\) 反而可能给出更大的 \(n\)！）。因此普遍严谨表达式为：
     \[
     E_{\max} = \max_{\substack{1 \le k \le \lfloor a/2 \rfloor \\ (b-1)k \le \sqrt{n+1} < \min\left((b-1)k+b,\; \frac{ba}{2}-k + 0^+\right)}} (n+1)qU,
     \]
     （其中 \(\le \frac{ba}{2}-k\) 为闭区间），而当 \(\frac{a}{2} \gg 1\) 或恰好 \(\frac{a}{2}\) 足够靠近整数上界时，\(E_{\max} \approx \left(\frac{b-1}{b}\right)^2 \frac{q^2 B_{\max}^2 b^2 D^2}{8m} = \frac{q^2 B_{\max}^2 (b-1)^2 D^2}{8m}\)。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是整套复赛试题中最具思维深度的题目，构思了一个表面形似回旋加速器、实则依赖“单向减速折返 + 单向加速回旋”的新型加速器。其核心物理悖论在于：在上下同向的匀强磁场中，若正离子向下穿过极板也获得加速，回旋半径变大必使轨迹向左跨越原点 \(O\) 撞毁于器壁；唯有极板内始终维持向上的匀强电场，使初动能仅为 \(qU\) 的离子在极板区内向下穿过时“减速至零再原路反向加速”，实现沿 \(OP\) 轴向极板右端之外步进，再经下半圆回旋绕回极板下方进入单向加速循环。
- **递进拆解脉络**：
  1. 第一步（识别单向电场的折返机制与求 \(B_{\min}\)）：算出初始半径 \(r = \frac{1}{B}\sqrt{\frac{2mU}{q}}\)。若 \(r > \frac{bD}{2}\) 撞器壁，若 \(\frac{D}{2} < r < \frac{bD}{2}\) 则回打离子源 \(S\)；唯有直接半圆 \(2r = bD\) 才出射，给出 \(B_{\min} = \frac{2}{bD}\sqrt{\frac{2mU}{q}}\)。
  2. 第二步（追踪极板内 \(k\) 次折返与越过右端回环）：当 \(r < \frac{D}{2}\) 时，离子在极板区向下进入时被减速到零再加速弹回，沿 \(x = 2r, 4r, \dots, 2kr\) 向右跳跃 \(k\) 次直至满足 \(2kr \le D < 2(k+1)r\)。第 \(k+1\) 次跳出极板右端进入无场隙，经下半磁场向左绕半圆回到 \(x = 2kr\) 处由下方射入极板。
  3. 第三步（建立单向加速 \(n\) 次后的出射方程与约束）：回到 \(x = 2kr\) 的离子每次自下而上穿过极板均获加速 \(+qU\)，第 \(n\) 次额外加速后半径为 \(\sqrt{n+1}\,r\)。因 \(b > 2\) 保证了中途不碰右侧壁且此后下落点均在 \(D\) 右侧，最终出射条件为 \(2(\sqrt{n+1}+k)r = bD\)，导出所有离散允许值 \(B_{k,n}\) 及对 \(k, n\) 的整除不等式。
  4. 第四步（结合 \(B \le B_{\max}\) 讨论能量最大值）：总加速次数为 \(n+1\)，能量 \(E = (n+1)qU\)。必须同时检查几何约束 \((b-1)^2 k^2 - 1 \le n < [(b-1)k+b]^2 - 1\) 与磁场上限约束 \(\sqrt{n+1}+k \le \frac{ba}{2}\)（其中 \(\frac{a}{2} = \frac{DB_{\max}}{2}\sqrt{\frac{q}{2mU}}\)）。
- **盲解手记**：盲解时一度被题面“回旋加速器”与“仅在带电粒子经过的过程中存在匀强电场”迷惑，通过严密证明“上下同向匀强磁场下，若向下加速则必左移到负半轴撞毁”排除了交流双向加速与反向磁场两种误读，成功自行重建了“向上直流电场使能量为 \(qU\) 的离子在极板内减速至零再弹回”的核心机制！并在随后推导出了完全匹配离散能谱 \(B_{k,n}\) 的全部条件，同时敏锐地对 \(B_{k,n} \le B_{\max}\) 作了约束检查。
- **对照结论**：主体物理机制与离散 \(B_{k,n}\) 公式（官方式①–⑰）与官方解答完全吻合！但对照发现官方解答存在**两处明显瑕疵/勘误**：（1）第 12 页式⑭把对应 \(B_{\max}\) 的最小回旋半径误写成了 \(r_{\max}\)（应为 \(r_{\min}\)）；（2）**实质性物理错误**：官方在式⑮、⑲、⑳中仅由几何区间定出 \(k \le [a/2]\)，随后直接令 \(k = [a/2]\) 并取该 \(k\) 下仅受几何边界限制的最大 \(n_{\max} = [(b-1)k+b]^2 - 2\)，**完全忘记校验 \(B_{k, n_{\max}} \le B_{\max}\)**！反例：取 \(b=3, a/2=1.1\)，则 \(k=1\)，官方公式给出 \(n_{\max} = 23\)（\(E_{\max}=24qU\)），但此时所需磁场 \(B_{1,23} \approx 1.79 B_{\max} > B_{\max}\) 完全不可实现（实际仅 \(n \le 4\)）；更甚者当 \(a/2 = 2.01\) 时，\(k=2\) 受 \(B_{\max}\) 限制只能到 \(n=15\)，而更小的 \(k=1\) 反而可达到 \(n=23\)！教学时务必把这一精细检验讲透。
- **核心难点**：
  - 难点1：打破“回旋加速器必为双向高频交流加速”的思维定势。在上下同向磁场与偏置左端源的构型中，只有固定方向电场实现的“低能折返向右爬行 + 越端后单向回旋加速”才能避免撞向左侧器壁与离子源。
  - 难点2：正确转化多指标离散约束。不仅要满足 \(2kr \le D < 2(k+1)r\)（几何窗口），更要同时满足 \(r \ge r_{\min}(B_{\max})\)（磁场强度上限），两个上界需取交集而非只取其一。
- **高频易错点**：
  - 易错点1：未看清题目要求“其它部分存在匀强磁场”，擅自假设上下半区磁场反向，直接写成 \(2kr = bD\) 的匀速向右跳步。
  - 易错点2：忽略 \(k \ge 1\) 这一步的必要性——若 \(r > D/2\)（\(k = 0\)），离子第一次落下即越过 \(D\)，经下半圆必精准回到 \(x = 0\) 撞毁于离子源外壁。
- **教练总结**：当题中给出的装置几何与教科书常规模型不同（如本题源 \(O\) 偏置在左壁且极板仅长 \(D\)）时，千万不要套背结论，而要手推第一步、第二步轨迹的坐标变化 \(x_1, x_2\)。此外，对于带可调参数上限 \(B_{\max}\) 的离散量子化条件，所有候选离散解的最后一个参数上界都必须回代检验 \(B \le B_{\max}\)，绝不能只拿几何不等式的端点当答案。

## 6. 弗兰克-赫兹氢原子单条可见光激发与质心碰撞反冲阈值 (`cpho-2017-semifinal-theory-problem-slice-q6`)

- **难度评级**：`D2`
- **物理模型**：原子能级跃迁与一维非弹性正碰 · 光谱筛选与质心系最小激发能量
- **教学标签**：`氢原子能级与巴耳末系`、`非弹性碰撞阈值`、`质心系最大能量转化`、`电子与质子碰撞反冲差异`、`有效数字规范`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：识别激发能级与唯一可见光波长**：
   氢原子能级公式为 \(E_n = -\frac{13.60\,\text{eV}}{n^2}\)。可见光波长范围 \(400\,\text{nm} \sim 760\,\text{nm}\) 对应的光子能量范围为：
   \[
   E_{\min} = \frac{1240\,\text{nm}\cdot\text{eV}}{760\,\text{nm}} \approx 1.63\,\text{eV}, \qquad E_{\max} = \frac{1240\,\text{nm}\cdot\text{eV}}{400\,\text{nm}} = 3.10\,\text{eV}.
   \]
   逐系检验氢原子跃迁能量差：
   - 赖曼系（末态 \(n_f = 1\)）：最小跃迁 \(2\to 1\) 能量为 \(10.20\,\text{eV} > 3.10\,\text{eV}\)（紫外）；
   - 帕邢系（末态 \(n_f = 3\)）：最大跃迁 \(\infty\to 3\) 能量为 \(1.51\,\text{eV} < 1.63\,\text{eV}\)（红外）；
   - 因此可见光仅可能来自巴耳末系（末态 \(n_f = 2\)）：
     - \(n = 3 \to 2\)：\(\Delta E_{32} = (-1.511) - (-3.40) = 1.889\,\text{eV}\)（取三位有效数字 \(1.89\,\text{eV}\)），落入 \([1.63, 3.10]\,\text{eV}\)；
     - \(n = 4 \to 2\)：\(\Delta E_{42} = (-0.850) - (-3.40) = 2.55\,\text{eV}\)，也在可见光范围内。
   要使被激发的氢原子**仅能**发出一条可见光光谱线，原子必须被激发到 \(n = 3\)（第二激发态），而不能被激发到 \(n \ge 4\)。
   所发出的唯一可见光波长为：
   \[
   \lambda = \frac{hc}{\Delta E_{32}} = \frac{1240\,\text{nm}\cdot\text{eV}}{1.89\,\text{eV}} \approx 656\,\text{nm} \quad (\text{若不中间修约取 } \frac{68}{36}\,\text{eV 则得 } 656.5\,\text{nm}).
   \]

2. **第（2）问：加速电子动能 \(E_k\) 的范围**：
   设入射粒子质量为 \(m_1\)、初动能为 \(E_k\)，静止氢原子质量为 \(M_H = m_p + m_e \approx 1837\,m_e\)。在一维正碰中，仅在质心系中的动能可供转化为原子内能 \(\Delta E\)。最大可转换能量（即完全非弹性碰撞极限）为：
   \[
   Q_{\max} = \frac{M_H}{m_1 + M_H} E_k.
   \]
   因此能激发内能 \(\Delta E\) 的动力学阈值条件为：
   \[
   E_k \ge \left(1 + \frac{m_1}{M_H}\right)\Delta E.
   \]
   由 \(n = 3\) 可激发而 \(n = 4\) 不可激发，有 \(\Delta E_{31} = 13.60\left(1 - \frac{1}{9}\right) \approx 12.09\,\text{eV}\)，\(\Delta E_{41} = 13.60\left(1 - \frac{1}{16}\right) = 12.75\,\text{eV}\)。
   对电子 \(m_1 = m_e\)，\(\frac{m_e}{M_H} = \frac{1}{1837}\)：
   \[
   E_{k,\min} = \left(1 + \frac{1}{1837}\right)\times 12.09\,\text{eV} \approx 12.10\,\text{eV},
   \]
   \[
   E_{k,\max} = \left(1 + \frac{1}{1837}\right)\times 12.75\,\text{eV} \approx 12.76\,\text{eV},
   \]
   故电子动能范围为：
   \[
   12.10\,\text{eV} \le E_k < 12.76\,\text{eV}.
   \]

3. **第（3）问：换用质子时的加速电压 \(U\) 范围**：
   当入射粒子为质子（\(m_1 = m_p = 1836\,m_e\)，电荷 \(q = e\)）时，\(1 + \frac{m_p}{M_H} = 1 + \frac{1836}{1837} = \frac{3673}{1837} \approx 1.99946\)：
   \[
   e U_{\min} = \frac{3673}{1837}\times 12.09\,\text{eV} \approx 24.17\,\text{eV}, \qquad e U_{\max} = \frac{3673}{1837}\times 12.75\,\text{eV} \approx 25.49\,\text{eV},
   \]
   因此加速电压范围为：
   \[
   24.17\,\text{V} \le U < 25.49\,\text{V}.
   \]
   （注：若按 \(12.089\,\text{eV}\) 不修约计算，下限仍为 \(24.171 \approx 24.17\,\text{V}\)，与四位有效数字完全一致；若忽略电子质量取 \(M_H \approx m_p\) 则系数为 \(2\)，得 \(24.18\,\text{V} \le U < 25.50\,\text{V}\)。）

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题将弗兰克-赫兹原子激发实验与非弹性碰撞力学耦合起来，重点考查两个层面：一是通过可见光波段反向锁定氢原子必须恰被激发至第二激发态 \(n = 3\)；二是纠正“入射动能只要大于能级差就能激发”的常见误区——在自由靶一维非弹性碰撞中，因动量守恒限制，激发阈值必须乘以反冲修正因子 \(1 + m_1/M\)。这一修正在电子撞击时仅约千分之一，而在质子撞击时直接翻倍（约等于 2），深刻揭示了实验室系与质心系的区别。
- **递进拆解脉络**：
  1. 第一步（将可见光波长转化为光子能量窗）：利用 \(E = hc/\lambda\) 将 \(400\sim 760\,\text{nm}\) 换算成 \(1.63\sim 3.10\,\text{eV}\)，逐系排查赖曼、巴耳末、帕邢线系，判定仅能发一条可见光对应的激发态必为 \(n = 3\)，发出 \(3\to 2\) 谱线 \(\lambda = 656\,\text{nm}\)。
  2. 第二步（推导一维正碰的激发能量阈值）：联立动量守恒 \(m_1 v_1 = m_1 v_2 + M u_2\) 与能量守恒（由二次方程判别式或质心系最大损耗公式），得到 \(E_k \ge \left(1 + \frac{m_1}{M}\right)\Delta E\)。
  3. 第三步（代入激发能隙求电子动能范围）：要求能到 \(n = 3\)（\(E_{31} = 12.09\,\text{eV}\)）但不能到 \(n = 4\)（\(E_{41} = 12.75\,\text{eV}\)），计入 \(M = m_p + m_e = 1837m_e\) 得出 \(12.10\,\text{eV} \le E_k < 12.76\,\text{eV}\)。
  4. 第四步（换为质子后求加速电压范围）：将入射质量改为 \(m_p = 1836 m_e\)，反冲因子 \(1 + \frac{1836}{1837} \approx 1.9995\)，结合 \(eV = E_k\) 解得 \(24.17\,\text{V} \le V < 25.49\,\text{V}\)。
- **盲解手记**：盲解时由可见光能量区间迅速锁定 \(n = 3\) 激发态与 \(\lambda \approx 656\,\text{nm}\)，并在第（2）（3）问中直接调用质心系最大内能转换公式 \(Q_{\max} = \frac{M}{m_1 + M} E_k\) 一步得出阈值因子 \((1 + m_1/M)\)，特别留意到 \(M_H = m_p + m_e = 1837 m_e\) 与粗略取 \(1836 m_e\) 之间在 4 位有效数字下的微小差别（\(24.17\) vs \(24.18\)）。
- **对照结论**：与官方参考解答数值和结论百分之百吻合！官方第（1）问给出 \(\lambda = 656\,\text{nm}\)；第（2）问通过联立一维碰撞方程消去靶速度再令关于电子末速的一元二次方程判别式 \(\Delta \ge 0\) 导出 \(E_k \ge (1 + m_e/M)\Delta E\)，最终取 \(M = m_p + m_e = 1837m_e\) 得出 \(12.10\,\text{eV} \le E_k < 12.76\,\text{eV}\)；第（3）问同样得到 \(24.17\,\text{V} \le V < 25.49\,\text{V}\)。盲解的质心系法比官方的判别式法计算简洁得多。
- **核心难点**：
  - 难点1：理解“仅能发出一条可见光”等价于“最高只能激发到 \(n = 3\) 能级”，即允许的能隙区间为左闭右开区间 \([E_{31}, E_{41})\)。
  - 难点2：建立质心系中碰撞能阈值意识——靶粒子自由静止时，为保证动量守恒，至少有一部分平动动能必须保留给质心平动，不能全部用于原子内能激发。
- **高频易错点**：
  - 易错点1：第（2）问直接忽略电子质量反冲写 \(12.09\,\text{eV} \le E_k < 12.75\,\text{eV}\)（丢了 \(0.01\,\text{eV}\) 修正），第（3）问甚至忘了质子与氢原子质量相近、直接错写成和电子一样的 \(12.09 \sim 12.75\,\text{V}\)！
  - 易错点2：将上限处写成闭区间 \(\le\)，而实际上一旦达到 \((1+m_1/M)E_{41}\) 就有可能激发到 \(n=4\) 从而发出 \(4\to 2\)（\(486\,\text{nm}\)）第二条可见光谱线；此外第（3）问把 \(M\) 写成 \(m_p\) 时会得出 \(24.18\) 与 \(25.50\)，而严格 \(M = m_p + m_e\) 才给出官方的 \(24.17\) 与 \(25.49\)。
- **教练总结**：遇到“自由微观粒子碰撞激发能级或产生新粒子”的问题，先写质心系可用动能 \(E_{\text{cm}} = \frac{M}{m_1+M}E_k\)，即可绕开繁琐的二次方程判别式！同时注意题干给出的“质子质量为电子质量的 1836 倍”通常既暗示电子反冲不能丢，也暗示氢原子质量为 \((1836+1)m_e\)。

## 7. 理想气体直线-等温循环的最高温度与变号摩尔热容 (`cpho-2017-semifinal-theory-problem-slice-q7`)

- **难度评级**：`D2`
- **物理模型**：热力学过程分析 · 直线过程温度极值、非多方过程摩尔热容与吸放热反转
- **教学标签**：`热力学第一定律`、`直线过程最高温度`、`过程摩尔热容量`、`吸放热转换临界点`、`负热容物理意义`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **直线 \(AB\) 过程方程与第（1）问最高温度**：
   直线过 \(A\left(\frac{V_0}{2}, P_0\right)\) 与 \(B\left(V_0, \frac{P_0}{2}\right)\)，故：
   \[
   P(V) = P_0\left(\frac{3}{2} - \frac{V}{V_0}\right), \qquad \frac{V_0}{2} \le V \le V_0.
   \]
   由理想气体状态方程 \(PV = \nu RT\)：
   \[
   T(V) = \frac{P_0}{\nu R}\left(\frac{3}{2}V - \frac{V^2}{V_0}\right) = \frac{P_0}{\nu R V_0}\left[\frac{9}{16}V_0^2 - \left(V - \frac{3}{4}V_0\right)^2\right].
   \]
   可见在 \(V_m = \frac{3}{4}V_0 \in \left[\frac{V_0}{2}, V_0\right]\) 处温度达到最大值：
   \[
   T_{\max} = \frac{9 P_0 V_0}{16 \nu R}.
   \]
   （端点温度 \(T_A = T_B = \frac{P_0 V_0}{2\nu R} = \frac{8}{9}T_{\max}\)，确为等温线衔接两端。）

2. **第（2）问：摩尔热容量 \(C_m(V)\)、吸放热分段及转变温度 \(T_c\)**：
   由热力学第一定律 \(dQ = \nu C_m dT = \nu C_V dT + P dV\)（双原子气体 \(C_V = \frac{5}{2}R\)），得：
   \[
   C_m = C_V + \frac{P}{\nu}\frac{dV}{dT}.
   \]
   对 \(T(V)\) 求导得 \(\frac{dT}{dV} = \frac{P_0}{2\nu R V_0}(3V_0 - 4V)\)，代入得：
   \[
   C_m(V) = \frac{5}{2}R + R\frac{3V_0 - 2V}{3V_0 - 4V} = \frac{3R(7V_0 - 8V)}{2(3V_0 - 4V)} = \frac{21V_0 - 24V}{3V_0 - 4V}\frac{R}{2}.
   \]
   为避开 \(V = \frac{3}{4}V_0\) 处 \(C_m \to \pm\infty\) 的奇异表象，直接改写微元热量对体积的导数：
   \[
   \frac{dQ}{dV} = \nu C_m\frac{dT}{dV} = \frac{3 P_0}{4}\left(7 - 8\frac{V}{V_0}\right) = \left(\frac{21}{4} - \frac{6V}{V_0}\right)P_0.
   \]
   随体积 \(V\) 从 \(\frac{V_0}{2}\) 增至 \(V_0\)（\(dV > 0\)）：
   - 当 \(\frac{V_0}{2} \le V < \frac{3}{4}V_0\) 时：\(C_m > 0,\ \frac{dT}{dV} > 0 \implies \frac{dQ}{dV} > 0\)，**吸热**；
   - 当 \(\frac{3}{4}V_0 < V < \frac{7}{8}V_0\) 时：\(C_m < 0,\ \frac{dT}{dV} < 0 \implies \frac{dQ}{dV} > 0\)，**依然吸热**（对外膨胀做功大于内能减少）；
   - 当 \(\frac{7}{8}V_0 < V \le V_0\) 时：\(C_m > 0,\ \frac{dT}{dV} < 0 \implies \frac{dQ}{dV} < 0\)，**放热**。
   吸热与放热的转变发生在 \(V_c = \frac{7}{8}V_0\)（此时 \(P_c = \frac{5}{8}P_0\)），对应的转变温度为：
   \[
   T_c = \frac{P_c V_c}{\nu R} = \frac{35 P_0 V_0}{64 \nu R}.
   \]

3. **第（3）问：直线 \(AB\) 净吸热与一个正循环净功**：
   - 因 \(T_A = T_B\)，直线过程 \(AB\) 初末内能相等（\(\Delta U_{AB} = 0\)），故净吸热量等于气体对外做功：
     \[
     Q_{AB} = W_{AB} = \frac{1}{2}\left(P_0 + \frac{P_0}{2}\right)\left(V_0 - \frac{V_0}{2}\right) = \frac{3}{8}P_0 V_0
     \]
     （亦可积分 \(\int_{V_0/2}^{V_0}\left(\frac{21}{4} - \frac{6V}{V_0}\right)P_0\,dV = \frac{3}{8}P_0 V_0\) 相互印证）。
   - 等温压缩过程 \(B \to A\) 中温度恒为 \(T_A = \frac{P_0 V_0}{2\nu R}\)，对外做功：
     \[
     W_{BA} = \int_{V_0}^{V_0/2} \frac{\nu R T_A}{V}\,dV = -\frac{1}{2}P_0 V_0 \ln 2.
     \]
   - 故一个正循环中气体对外净功为：
     \[
     W_{\text{净}} = W_{AB} + W_{BA} = \left(\frac{3}{8} - \frac{\ln 2}{2}\right)P_0 V_0 > 0 \quad (\approx 0.0284\, P_0 V_0).
     \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以直线膨胀与等温压缩构成的闭合热力学循环为载体，系统考查热力学第一定律在非多方变热容过程中的应用。直线过程在 \(P\text{-}V\) 图上呈现出两个错开的关键特征点：最高温度 \(T_{\max}\) 出现在等温线相切的 \(V = \frac{3}{4}V_0\) 处（此时摩尔热容量发散变号），而吸热向放热转变的临界点则出现在与绝热线相切的 \(V_c = \frac{7}{8}V_0\) 处。在区间 \((\frac{3}{4}V_0, \frac{7}{8}V_0)\) 内，气体一边降温一边吸热，体现出负摩尔热容的经典物理图像。
- **递进拆解脉络**：
  1. 第一步（列写直线方程与抛物线求最高温度）：写出 \(P(V) = P_0(\frac{3}{2} - \frac{V}{V_0})\)，结合 \(PV = \nu RT\) 配平方得出二次函数 \(T(V)\)，确定最高温度 \(T_{\max} = \frac{9 P_0 V_0}{16\nu R}\) 在 \(V = \frac{3}{4}V_0\) 处取得。
  2. 第二步（导出摩尔热容量并讨论吸放热区间）：由 \(C_m = C_V + \frac{P}{\nu}\frac{dV}{dT}\) 导出 \(C_m(V) = \frac{21V_0 - 24V}{3V_0 - 4V}\frac{R}{2}\)，进而计算 \(\frac{dQ}{dV} = \nu C_m\frac{dT}{dV} = (\frac{21}{4} - \frac{6V}{V_0})P_0\)，划分出 \([\frac{V_0}{2}, \frac{3}{4}V_0)\)、\((\frac{3}{4}V_0, \frac{7}{8}V_0)\) 吸热与 \((\frac{7}{8}V_0, V_0]\) 放热三段，算得转变温度 \(T_c = \frac{35 P_0 V_0}{64\nu R}\)。
  3. 第三步（求解 \(AB\) 净吸热与循环净功）：注意到 \(T_A = T_B\) 使 \(\Delta U_{AB} = 0\)，直接由梯形面积求得 \(Q_{AB} = W_{AB} = \frac{3}{8}P_0 V_0\)（与 \(dQ\) 积分结果互验），再减去等温线 \(B\to A\) 压缩放热做功 \(\frac{1}{2}P_0 V_0\ln 2\) 得到循环净功。
- **盲解手记**：盲解全程一步到位，不仅推出了 \(C_m(V)\) 的精确分式表达式，还主动构造了 \(\frac{dQ}{dV}\) 避开 \(V = \frac{3}{4}V_0\) 处 \(dT = 0\) 导致的 \(C_m\) 奇异性，并用“\(\Delta U_{AB} = 0\) 推知 \(Q_{AB} = W_{AB}\)”和“直接对 \(dQ\) 积分”两种途径双验了第（3）问结果。
- **对照结论**：与官方参考解答百分之百一致！官方在式⑫–⑭同样细致地把 \([V_0/2, V_0]\) 分成三段分别指出 \(C_m\) 与 \(dT/dV\) 的符号同正（吸热）、同负（吸热）和异号（放热），只是把 \(\frac{7}{8}V_0\) 写成了未约分的 \(\frac{21}{24}V_0\)，其余每一步公式和结果完全一致。
- **核心难点**：
  - 难点1：破除“最高温度点就是吸放热转折点”的直觉错觉。在 \(V_m = \frac{3}{4}V_0\) 处 \(dT = 0\)，但气体仍在膨胀做功（\(P\,dV > 0\)），故必须继续吸热；直到绝热线相切处 \(V_c = \frac{7}{8}V_0\)，温度下降释放的内能才刚好够支付膨胀做功，之后才开始放热。
  - 难点2：正确处理 \(V = \frac{3}{4}V_0\) 处 \(C_m(V)\) 的无穷大奇点，必须通过 \(dQ = \nu C_m\frac{dT}{dV}dV\) 恢复连续有限的吸放热判断。
- **高频易错点**：
  - 易错点1：见到 \(C_m < 0\) 就误以为该区间在放热，忘记 \(dQ = \nu C_m dT\) 中 \(dT < 0\)，负负得正仍是吸热！
  - 易错点2：将“直线 \(AB\) 过程吸收的净热量”误解为“仅吸热阶段（\(A \to V_c\)）所吸收的热量”（如果计算热机效率才需要只算吸热正值 \(Q_+\)，而题问“整个直线 \(AB\) 过程中所吸收的净热量”是指代数和 \(Q_{AB} = \frac{3}{8}P_0 V_0\)）。
- **教练总结**：处理 \(P\text{-}V\) 图上的直线膨胀过程，记住两条核心几何直观：**等温线切点是最高温度 \(T_{\max}\)，绝热线切点是吸放热转换点 \(T_c\)**！用 \(\frac{dQ}{dV} = \frac{1}{\gamma - 1}\left(\gamma P + V\frac{dP}{dV}\right)\) 一行就能判断任何曲线各处的吸放热符号。

## 8. 非近轴菲涅尔阶梯透镜的球面几何设计与全反射孔径极限 (`cpho-2017-semifinal-theory-problem-slice-q8`)

- **难度评级**：`D3`
- **物理模型**：非近轴几何光学 · 球面折射正弦定理、共焦环带设计与全反射临界孔径
- **教学标签**：`菲涅尔透镜`、`非近轴球面折射`、`正弦定理与笛卡尔卵形面思想`、`全反射孔径极限`、`近轴极限退化校验`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **单环带球面折射的精确几何关系（非近轴）**：
   平行于光轴 \(z\) 的光线在镜内沿 \(+\hat{z}\) 方向传播，在距离光轴高度为 \(h\) 处入射到某一球面环带的点 \(A\)。因环带间距 \(d\) 很小（忽略环带轴向台阶深度及带内像差），\(A\) 点可近似位于过透镜中心 \(O\) 的垂直平面内，即 \(OA = h\)，\(OF = f\)，故：
   \[
   AF = \sqrt{f^2 + h^2}.
   \]
   设该环带所属球面的球心位于光轴上的点 \(C\)，球半径为 \(R = CA\)。光线自折射率为 \(n\) 的玻璃射入空气，设入射角为 \(\alpha\)（即 \(\angle CAF\) 的余角？不，法线沿 \(CA\) 方向，入射光线平行于 \(CF\)，故入射角 \(\alpha = \angle ACF\)），折射角为 \(\beta\)（出射光线 \(AF\) 与法线外延线的夹角，故 \(\triangle ACF\) 中 \(\angle CAF = \pi - \beta\)）。
   - 由折射定律：
     \[
     \sin\beta = n\sin\alpha.
     \]
   - 在 \(\triangle ACF\) 中应用正弦定理：
     \[
     \frac{CF}{\sin(\pi - \beta)} = \frac{AF}{\sin\alpha} \implies \frac{CF}{AF} = \frac{\sin\beta}{\sin\alpha} = n!
     \]
   立刻得到球心到焦点 \(F\) 的精确距离：
   \[
   CF = n\, AF = n\sqrt{f^2 + h^2}.
   \]
   再利用 \(\triangle ACO\) 的勾股定理（\(CO = CF - OF = n\sqrt{f^2 + h^2} - f\)）：
   \[
   R = \sqrt{CO^2 + AO^2} = \sqrt{\left(n\sqrt{f^2 + h^2} - f\right)^2 + h^2} = \sqrt{(n^2 + 1)(f^2 + h^2) - 2nf\sqrt{f^2 + h^2}}.
   \]

2. **第（1）问：各环带的球半径和球心到焦点距离**：
   对第 \(k\) 个环带（\(k = 0\) 为中心球冠，\(k = 1, 2, \dots\) 为同心球台环带，对应径向高度 \(h_k = kd\)，当 \(d \ll f\) 时取内径、中径或外径差异可略）：
   - 球心到焦点 \(F\) 的距离：
     \[
     s_k = C_k F = n\sqrt{f^2 + k^2 d^2};
     \]
   - 所属球面的球半径：
     \[
     R_k = \sqrt{(n^2 + 1)(f^2 + k^2 d^2) - 2nf\sqrt{f^2 + k^2 d^2}}.
     \]
   **近轴极限检验**（\(k = 0\)）：\(s_0 = nf\)，\(R_0 = (n - 1)f\)，完美退化为单球面平凸透镜焦距公式 \(f = \frac{R_0}{n-1}\)！

3. **第（2）问：透镜有效半径的最大值与有效环带条数**：
   随着径向高度 \(h\) 增大，折射角 \(\beta = \alpha + \arctan(h/f)\) 不断增大，直至达到掠射出射极限 \(\beta = \frac{\pi}{2}\)（此时发生全反射临界条件）：
   \[
   \sin\alpha_c = \frac{1}{n}.
   \]
   此时在 \(\triangle ACF\) 中 \(\angle CAF = \pi - \frac{\pi}{2} = \frac{\pi}{2}\)，在直角三角形 \(\triangle AOF\) 与 \(\triangle CAF\) 关系（或 \(\alpha_c + \angle AFO = \frac{\pi}{2}\)）中直接有：
   \[
   \sin\alpha_c = \cos\angle AFO = \frac{f}{\sqrt{f^2 + h_{\max}^2}} = \frac{1}{n}.
   \]
   （也可从任意出射折偏角极限直接证明：平板入、空气出能实现的最大偏折角 \(\delta_{\max} = \frac{\pi}{2} - \arcsin\frac{1}{n} = \arccos\frac{1}{n}\)，要求 \(\arctan(h/f) \le \delta_{\max}\)。）
   解得该菲涅尔透镜有效半径的最大值为：
   \[
   r_{\max} = h_{\max} = f\sqrt{n^2 - 1}.
   \]
   对应有效环带的条数为不大于 \(\frac{r_{\max}}{d}\) 的最大整数（取整函数）：
   \[
   k_{\max} = \left[\frac{f\sqrt{n^2 - 1}}{d}\right].
   \]
   （注：若中心球冠 \(k=0\) 也计入“环带”总数且第 \(k\) 带覆盖 \([(k-1)d, kd]\)，则恰好有 \(k_{\max}\) 条；若按 \(k=0, 1, \dots, k_{\max}\) 计且不含中心圆冠，则外环带为 \(k_{\max}\) 条，总计含中心冠共 \(k_{\max}+1\) 个带，与 \(h_k = kd\) 的代表点取法自洽。）

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题剖析了大口径平凸菲涅尔（同心圆阶梯）透镜的非近轴几何光学设计原理。如果沿用薄透镜近轴近似，将无法解释为何透镜有效半径存在严格物理上限。解题关键在于直接在非近轴条件下，结合 Snell 折射定律与 \(\triangle ACF\) 的正弦定理，导出单色平行光精准聚焦于 \(F\) 点所需的球心距 \(CF = n\sqrt{f^2+h^2}\)；进而当折射光线恰好沿出射面切向掠出（发生全反射临界角，偏转角达到极限 \(\arccos(1/n)\)）时，立刻锁死最大有效半径 \(h_m = f\sqrt{n^2-1}\)。
- **递进拆解脉络**：
  1. 第一步（构建非近轴单球面折射三角形 \(\triangle ACF\)）：利用 \(d\) 很小的条件把各环带切点 \(A\) 置于同一物面 \(OA = h\)，识别出入射角 \(\alpha = \angle ACF\)、折射角补角 \(\angle CAF = \pi - \beta\) 与距离 \(AF = \sqrt{f^2 + h^2}\)。
  2. 第二步（正弦定理联立 Snell 定律秒解球心位置与半径）：由 \(\frac{CF}{\sin\beta} = \frac{AF}{\sin\alpha}\) 与 \(\sin\beta = n\sin\alpha\) 一步消去三角函数得 \(CF = n\sqrt{f^2 + h^2}\)，再由 \(R = \sqrt{(CF - f)^2 + h^2}\) 解出第 \(k\) 环带（\(h_k = kd\)）的 \(C_k F\) 与 \(R_k\)，并验证 \(k=0\) 退化为 \(R_0 = (n-1)f\)。
  3. 第三步（利用全反射临界条件导出有效半径上限）：当 \(\beta = 90^\circ\) 时 \(\angle CAF = 90^\circ\) 且 \(\sin\alpha_c = 1/n\)，利用 \(\alpha_c\) 与 \(\angle AFO\) 互余立得 \(\frac{f}{\sqrt{h_m^2+f^2}} = \frac{1}{n}\)，求出 \(h_m = \sqrt{n^2 - 1}f\) 并取整得有效环带数 \(k_m = \left[\frac{\sqrt{n^2-1}f}{d}\right]\)。
- **盲解手记**：盲解时没有陷入逐级展开近似的泥潭，而是直接针对单个折射点 \(A\) 画出 \(\triangle ACF\)，第一时间用“正弦定理 + Snell 定律”直接得出精确式 \(s_k = n\sqrt{f^2 + h_k^2}\)，随后又通过检查单调性证明 \(\theta_2 = \theta_1 + \alpha\) 在 \(\theta_2 = \pi/2\) 处达到全反射极限，给出最大偏折角 \(\arccos(1/n)\) 对应的最大有效半径 \(f\sqrt{n^2-1}\)，逻辑严密且无额外近似。
- **对照结论**：与官方参考解答几乎一模一样！官方解答（第 17–19 页）同样采用“在 \(\triangle ACF\) 中联立正弦定理 \(\frac{CF}{\sin\beta} = \frac{AF}{\sin\alpha}\) 与折射定律”的优雅捷径，得出与盲解完全相同的 \(C_k F\)、\(R_k\)（取 \(h_k = kd,\ k = 0,1,2,\dots\)）、\(h_m = \sqrt{n^2-1}f\) 以及 \(k_m = \left[\frac{\sqrt{n^2-1}f}{d}\right]\)。
- **核心难点**：
  - 难点1：摆脱中学教材中近轴公式 \(f = \frac{R}{n-1}\) 的惯性束缚，在一般大入射角条件下直接列写精确几何光学关系。
  - 难点2：准确寻找“有效半径为什么有上限”的物理瓶颈——不是透镜材料厚度，而是出射面发生全反射时所能提供的最大光线偏折角限制。
- **高频易错点**：
  - 易错点1：用近轴公式对每层环带做近似处理（如错误以为 \(R_k\) 处处相等或用薄棱镜近似 \((n-1)\theta = h/f\)），那样算不出全反射上限 \(f\sqrt{n^2-1}\)。
  - 易错点2：找 \(\beta = 90^\circ\) 全反射临界位置时，忘记用几何互余关系 \(\alpha_c + \angle AFO = 90^\circ\)（因为入射光平行于 \(OF\)，折射光线为 \(AF\)，\(\angle CAF = 90^\circ\) 直接构成垂直偏转），而在复杂根式求导中迷失。
- **教练总结**：非近轴球面单折射面的经典利器就是“找包含球心 \(C\)、入射点 \(A\)、像点 \(F\) 的三角形使用正弦定理 + Snell 定律”，它常能把极繁杂的代数消元压缩成两行！另外，平面入、曲面出的折光元件偏转角总有刚性上限 \(\arccos(1/n)\)，记住这一点可迅速锁定有效数值孔径 \(\text{NA}_{\max} = \sin\alpha_{\max} = \frac{\sqrt{n^2-1}}{n}\)。

# 决赛理论试题（Final Theory）

## 9. 光滑水平面上带电双球弹簧系统的运动与微振动 (`cpho-2017-final-theory-problem-slice-q1`)

- **难度评级**：`D2`
- **物理模型**：两体动力学 · 质心-相对运动解耦与库仑-弹性耦合微振动线性化
- **教学标签**：`两体约化质量`、`质心速度分离`、`库仑排斥平衡态`、`小振动等效劲度`、`量纲与极限校验`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：不带电两球弹簧振子的任一时刻速度**：
   两球在光滑水平面上水平方向不受外力，系统质心速度守恒：
   \[
   v_c = \frac{m_a V_0}{m_a + m_b} \quad (\text{方向向右}).
   \]
   取两球相对伸长量 \(u = (x_a - x_b) - l_0\)，系统的约化质量为 \(\mu = \frac{m_a m_b}{m_a + m_b}\)。相对运动满足简谐振动方程：
   \[
   \mu \ddot{u} = -k_0 u \implies \omega = \sqrt{\frac{k_0}{\mu}} = \sqrt{\frac{k_0(m_a + m_b)}{m_a m_b}}.
   \]
   由初始条件 \(u(0) = 0\)、\(\dot{u}(0) = V_0\)，得 \(u(t) = \frac{V_0}{\omega}\sin(\omega t)\)，故 \(a\) 相对 \(b\) 的速度为：
   \[
   v_{\text{rel}}(t) = \dot{u}(t) = V_0 \cos(\omega t).
   \]
   利用 \(v_a = v_c + \frac{m_b}{m_a + m_b}v_{\text{rel}}\) 和 \(v_b = v_c - \frac{m_a}{m_a + m_b}v_{\text{rel}}\)（均以向右为正），得任一时刻 \(t > 0\) 两球速度分别为：
   \[
   v_a(t) = \frac{V_0}{m_a + m_b}\left(m_a + m_b \cos\omega t\right) = \left[1 + \frac{m_b}{m_a}\cos\left(\sqrt{\frac{k_0(m_a+m_b)}{m_a m_b}}t\right)\right]\frac{m_a V_0}{m_a + m_b},
   \]
   \[
   v_b(t) = \frac{m_a V_0}{m_a + m_b}(1 - \cos\omega t) = \left[1 - \cos\left(\sqrt{\frac{k_0(m_a+m_b)}{m_a m_b}}t\right)\right]\frac{m_a V_0}{m_a + m_b}.
   \]
   **特例检验**：\(t = 0\) 时 \(v_a = V_0, v_b = 0\)；\(m_a = m_b\) 时 \(v_a = \frac{V_0}{2}(1 + \cos\omega t)\)、\(v_b = \frac{V_0}{2}(1 - \cos\omega t)\)，且恒满足 \(m_a v_a + m_b v_b = m_a V_0\)。

2. **第（2）问：等量同号电荷下的电量与微振动频率**：
   平衡时弹簧长度为 \(L_0\)（\(L_0 > l_0\)），弹簧拉力平衡静电斥力：
   \[
   k_0(L_0 - l_0) = \frac{K q^2}{L_0^2} \implies |q| = L_0\sqrt{\frac{k_0(L_0 - l_0)}{K}} \quad (\text{两球带同号电荷，电性可正可负}).
   \]
   设两球相对间距偏离平衡位置为 \(x = L - L_0\)（\(|x| \ll L_0\)），相对运动方程为：
   \[
   \mu \ddot{x} = -k_0(L_0 + x - l_0) + \frac{K q^2}{(L_0 + x)^2}.
   \]
   利用泰勒一阶展开 \((1 + x/L_0)^{-2} \approx 1 - \frac{2x}{L_0}\) 及平衡条件 \(k_0(L_0 - l_0) = \frac{Kq^2}{L_0^2}\)：
   \[
   \mu \ddot{x} \approx -\left(k_0 + \frac{2 K q^2}{L_0^3}\right)x = -k_0\left(1 + \frac{2(L_0 - l_0)}{L_0}\right)x = -\frac{3L_0 - 2l_0}{L_0}k_0\, x.
   \]
   因 \(L_0 > l_0\)，等效劲度 \(k_{\text{eff}} = k_0\frac{3L_0 - 2l_0}{L_0} > k_0 > 0\)，稳定微振动频率为：
   \[
   f = \frac{1}{2\pi}\sqrt{\frac{k_{\text{eff}}}{\mu}} = \frac{1}{2\pi}\sqrt{\frac{k_0(3L_0 - 2l_0)(m_a + m_b)}{m_a m_b L_0}}.
   \]
   **极限检验**：\(q \to 0\) 时 \(L_0 \to l_0\)，\(3L_0 - 2l_0 \to l_0\)，回归无电振动频率；\(l_0 \to 0\) 时 \(k_{\text{eff}} \to 3k_0\)，与 \(U(r) = \frac{1}{2}k_0 r^2 + \frac{C}{r}\) 极小值二阶导数吻合。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题作为决赛开篇基础题，典型示范了“两体约化质量解耦”和“非线性势场微振动线性化”两大竞赛基本功。第（1）问分离质心平动与相对简谐振动即可写出两球各自的速度时间函数；第（2）问引入库仑排斥力将平衡长度推长至 \(L_0\)，通过展开 \(1/r^2\) 并将平衡条件回代消去 \(q^2\)，得到简洁而深刻的等效劲度增强因子 \(\frac{3L_0 - 2l_0}{L_0}\)。
- **递进拆解脉络**：
  1. 第一步（分离质心运动与相对振动）：计算约化质量 \(\mu = \frac{m_a m_b}{m_a + m_b}\) 与相对振动圆频率 \(\omega = \sqrt{k_0/\mu}\)，由初始条件定出相对速度 \(v_{\text{rel}} = V_0\cos\omega t\)。
  2. 第二步（合成两球地面系速度）：由动量守恒 \(m_a v_a + m_b v_b = m_a V_0\) 与 \(v_a - v_b = v_{\text{rel}}\) 解出 \(v_a(t)\) 与 \(v_b(t)\)。
  3. 第三步（平衡态求带电量）：在 \(L = L_0\) 处令弹力与静电力平衡 \(k_0(L_0 - l_0) = K q^2 / L_0^2\)，解得 \(q\)。
  4. 第四步（一阶微扰展开求微振动频率）：对相对动力学方程在 \(L_0\) 附近展开至 \(x/L_0\) 一阶项，消去 \(q^2\) 后得出 \(k_{\text{eff}} = k_0(3L_0 - 2l_0)/L_0\)，进而求得频率 \(f\)。
- **盲解手记**：盲解全程一步到位，不仅在形式上与参考答案完全等价，还刻意保留了带同号电荷时 \(q\) 的正负号兼容性（\(|q| = L_0\sqrt{k_0(L_0-l_0)/K}\)），并用 \(L_0 \to l_0\) 与 \(l_0 \to 0\) 两个边界核对了等效劲度系数。
- **对照结论**：与官方参考解答完全一致！官方第（1）问式⑪–⑫与盲解等价，第（2）问式⑭、⑳亦完全相同。仅注一处官方排版微瑕：官方参考解答图 II 中左侧标记小球 `b` 的圆圈文字被误印成类似 `\theta` 的字形。
- **核心难点**：
  - 难点1：第（2）问化简等效劲度系数时，必须想到用静态平衡方程 \(Kq^2/L_0^2 = k_0(L_0 - l_0)\) 去替换 \(2Kq^2/L_0^3\) 中的 \(q^2\)，从而得到不含 \(K, q\) 的纯几何因子 \((3L_0 - 2l_0)/L_0\)。
- **高频易错点**：
  - 易错点1：把静电力展开项 \((1+x/L_0)^{-2} \approx 1 - 2x/L_0\) 的系数 \(-2\) 漏掉或算成 \(-1\)，导致等效劲度算错。
  - 易错点2：忘记题问“微振动的频率”而不是“角频率”，漏除以 \(2\pi\)；或在用约化质量时把公式写倒为 \((m_a + m_b)/(m_a m_b)\) 放错分子分母位置。
- **教练总结**：遇到两体一维弹簧/相互作用系统，优先用“质心速度 + 相对振动”拆解；遇到平衡位置受非简谐长程力（如库仑力、万有引力）偏置的小振动，先把平衡条件写成 \(F_{\text{extra}}(L_0) = k_0(L_0 - l_0)\)，再用对数求导或幂律指数律迅速心算 \(k_{\text{eff}} = k_0 - F_{\text{extra}}'(L_0) = k_0 + 2k_0\frac{L_0 - l_0}{L_0}\)。

## 10. 超新星各向同性抛射质量后双星轨道周期与解体判据 (`cpho-2017-final-theory-problem-slice-q2`)

- **难度评级**：`D3`
- **物理模型**：两体万有引力突变 · 瞬时变质量双星质心能量与开普勒第三定律
- **教学标签**：`双星系统`、`超新星抛射解体判据`、`质心系相对轨道能量`、`开普勒第三定律`、`物理约束条件完备性`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：爆炸前两星间距 \(r_0\)**：
   两星围绕共同质心做周期为 \(T_0\) 的匀速圆周运动。在相对运动描述下，等效为质量为总质量 \(M + m\) 的引力源吸引相对位矢 \(\mathbf{r}\)（或令 \(r_M = \frac{m}{M+m}r_0,\ r_m = \frac{M}{M+m}r_0\)）：
   \[
   \frac{G M m}{r_0^2} = m\left(\frac{2\pi}{T_0}\right)^2 \frac{M}{M + m}r_0 \implies \frac{G(M+m)}{r_0^2} = \left(\frac{2\pi}{T_0}\right)^2 r_0,
   \]
   解得：
   \[
   r_0 = \left[\frac{G(M + m)T_0^2}{4\pi^2}\right]^{1/3}.
   \]

2. **第（2）问：爆炸后仍做周期运动时的轨道周期 \(T_1\)**：
   爆炸瞬间两星位置（间距 \(r_0\)）与各自速度均不变，故爆炸后 \(M' = M - \Delta M\) 星与 \(m\) 星的相对速率仍等于爆炸前圆周运动相对速率：
   \[
   v_0 = \frac{2\pi r_0}{T_0} = \sqrt{\frac{G(M + m)}{r_0}} \quad (\text{方向仍垂直于两星连线}).
   \]
   爆炸后双星系统 \((M', m)\) 的总质量变为 \(M_{\text{tot}}' = M' + m = M + m - \Delta M\)，约化质量变为 \(\mu' = \frac{M' m}{M + m - \Delta M}\)。在新的质心系中，系统总机械能为：
   \[
   E' = \frac{1}{2}\mu' v_0^2 - \frac{G M' m}{r_0} = \mu'\left[\frac{G(M+m)}{2r_0} - \frac{G(M + m - \Delta M)}{r_0}\right] = -\frac{G\mu'}{2 r_0}(M + m - 2\Delta M).
   \]
   当系统做周期运动（椭圆轨道，\(E' < 0\)，即 \(\Delta M < \frac{M+m}{2}\)）时，设相对椭圆轨道半长轴为 \(a\)，利用椭圆轨道能量公式 \(E' = -\frac{G M' m}{2a} = -\frac{G\mu'(M+m-\Delta M)}{2a}\)：
   \[
   \frac{M + m - \Delta M}{a} = \frac{M + m - 2\Delta M}{r_0} \implies a = \frac{M + m - \Delta M}{M + m - 2\Delta M} r_0.
   \]
   由开普勒第三定律，新周期 \(T_1\) 满足：
   \[
   T_1 = 2\pi\sqrt{\frac{a^3}{G(M + m - \Delta M)}} = 2\pi\sqrt{\frac{r_0^3}{G(M+m)}}\cdot\sqrt{\frac{M+m}{M+m-\Delta M}}\left(\frac{M+m-\Delta M}{M+m-2\Delta M}\right)^{3/2},
   \]
   化简得：
   \[
   T_1 = \frac{(M+m)^{1/2}(M + m - \Delta M)}{(M + m - 2\Delta M)^{3/2}} T_0 = \sqrt{\frac{(M+m)(M + m - \Delta M)^2}{(M + m - 2\Delta M)^3}}\, T_0.
   \]
   **极限检验**：\(\Delta M \to 0\) 时 \(T_1 \to T_0\)；\(\Delta M \to \frac{M+m}{2}^-\) 时 \(a \to \infty,\ T_1 \to \infty\)。

3. **第（3）问：两星最终永远分开的条件**：
   两星最终能分离至无穷远（抛物线或双曲线轨道），要求新质心系总机械能 \(E' \ge 0\)，即：
   \[
   \Delta M \ge \frac{M + m}{2}.
   \]
   同时，因爆炸失去的抛射质量不能超过星体 \(M\) 自身（需留有残余体 \(M' = M - \Delta M > 0\)），故还隐含物理条件：
   \[
   M > \Delta M \ge \frac{M + m}{2} \implies M > m!
   \]
   （若 \(M \le m\)，即使 \(M\) 几乎全被炸光也不可能使抛射损失超过总质量的一半，双星无法仅靠各向同性抛射而解体；若 \(M = m\) 仅在完全消失 \(\Delta M = M\) 极限才达 \(E'=0\)。）

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题是天体物理中经典的“双星超新星爆发（Blaauw 解体判据）”模型。尽管背景是两体同时绕质心旋转，爆炸后整个系统的质心速度还会发生变化，但在**相对坐标描述**下（或爆炸后瞬间转入新双星质心系），由于各向同性抛射不改变残余星瞬时速度且抛射壳对伴星无影响，两星相对位置 \(r_0\) 与相对速度 \(v_0\) 保持不变，唯独引力耦合总质量由 \(M+m\) 突降至 \(M+m-\Delta M\)。借助相对质心总能量公式直接反推椭圆半长轴与解体判据，可极大简化计算。
- **递进拆解脉络**：
  1. 第一步（求初始圆轨道间距 \(r_0\)）：利用双星相对运动方程 \(\ddot{\mathbf{r}} = -\frac{G(M+m)}{r^3}\mathbf{r}\) 或质心圆周向心力方程，由开普勒第三定律得 \(r_0 = \left[\frac{G(M+m)T_0^2}{4\pi^2}\right]^{1/3}\)。
  2. 第二步（利用瞬时连续性确定爆炸后初条件）：爆炸后瞬间间距仍为 \(r_0\)，相对速率仍为 \(v_0 = \sqrt{G(M+m)/r_0}\) 且垂直于连线，引力源等效总质量减为 \(M_{\odot} = M + m - \Delta M\)。
  3. 第三步（求周期 \(T_1\)）：既可用近/远星点角动量与能量守恒二次方程韦达定理求半长轴 \(a = (r_0+r_1)/2\)，也可直接利用新质心系总能量 \(E' = -\frac{GM'm}{2a}\) 一步写出 \(a = \frac{M+m-\Delta M}{M+m-2\Delta M}r_0\)，再代入新开普勒第三定律算出 \(T_1\)。
  4. 第四步（完备性检验导出解体条件）：轨道不闭合（\(E' \ge 0\)）要求 \(\Delta M \ge \frac{M+m}{2}\)；又因残余体存在（\(M > \Delta M\)），联立得出必要前置条件 \(M > m\)。
- **盲解手记**：盲解全程采用官方“解法（二）”的质心相对能量捷径，直接由 \(E' = \frac{1}{2}\mu' v_0^2 - \frac{GM'm}{r_0} = -\frac{GM'm}{2a}\) 一步解出椭圆半长轴 \(a\) 与新周期 \(T_1\)，并在第（3）问主动补充了物理前提 \(M > \Delta M \implies M > m\)。
- **对照结论**：与官方参考解答完全一致！官方在第（2）问同时展示了“近远拱点二次方程韦达定理法（解法一）”与“质心系能量法（解法二，式⑤–⑬）”，并在第（3）问同样通过 \(\Delta M \ge (M+m)/2\) 与 \(M > \Delta M\) 联立特意指出必须满足 \(M > m\)（式⑰–⑲）。
- **核心难点**：
  - 难点1：在双星质量都不固定的情况下，必须迅速剥离整体质心的额外平动，将问题收归到两星“相对运动”或“爆炸后新质心系”。如果硬在旧质心系里写单星能量，会因为爆炸瞬间质心跑动而算错束缚条件。
  - 难点2：第（3）问很容易漏掉 \(M > \Delta M \implies M > m\) 这一隐藏物理条件（题目明确问“求 \(M, m\) 和 \(\Delta M\) 三者应满足的条件”，就是特意在等学生写出 \(M > m\)）。
- **高频易错点**：
  - 易错点1：套用开普勒第三定律时分子分母总质量忘记同步更新为 \(M + m - \Delta M\)，或忘记把 \(r_0\) 本身的表达式代回消去 \(r_0\) 与 \(G\)。
  - 易错点2：把解体边界写为严格大于 \(\Delta M > \frac{M+m}{2}\) 而漏掉等号（抛物线轨道 \(E' = 0\) 时速度趋于零但仍可到达无穷远，不再返回）；或者忽略了若 \(M \le m\)，无论 \(M\) 怎么炸都无法甩飞伴星。
- **教练总结**：天体两体突变问题（瞬时撞击、星体质量抛射等）的黄金模板：（1）爆炸不直接改变各质点瞬时位矢和速度，故**相对位矢 \(\mathbf{r}\) 与相对速度 \(\mathbf{v}\) 在爆炸前后瞬时连续**；（2）利用新质量计算新质心系能量 \(E' = \frac{1}{2}\mu' v^2 - \frac{GM'm}{r}\)，直接通过正负判定椭圆/抛物线/双曲线并用 \(E' = -\frac{GM'm}{2a}\) 直接定出半长轴与周期，免解二次方程！

## 11. 计及摆动阻尼耗散的荡秋千参数泵浦递推模型 (`cpho-2017-final-theory-problem-slice-q3`)

- **难度评级**：`D3`
- **物理模型**：变摆长参数受迫振动 · 径向内力矩角动量守恒、多段能量演化与线性递推
- **教学标签**：`荡秋千物理模型`、`角动量守恒做功`、`过程耗散线性建模`、`一阶线性递推数列`、`参数泵浦临界阈值`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **几何坐标与核心机制分析**：
   取最低点 \(B\)（摆长 \(l + d\) 时的最低点）为重力势能零点，故摆长为 \(l\) 时的最低点 \(B'\) 处于高度 \(d\)。
   若第 \(n\) 个最高点（站立态，摆长 \(l\)）相对 \(B\) 高度为 \(h_n\)（第 1 个为 \(A\) 点高度 \(h_1\)），则该处摆杆与竖直方向夹角 \(\alpha_n\) 满足：
   \[
   h_n = l(1 - \cos\alpha_n) + d \implies l\cos\alpha_n = l + d - h_n.
   \]
   人在 \(A \to A'\) 迅速下蹲至摆长 \(l + d\)，其质心沿摆杆向外移 \(d\)，高度下降 \(d\cos\alpha_1\)，故 \(A'\) 点相对 \(B\) 的高度为：
   \[
   h_1' = (l + d)(1 - \cos\alpha_1) = \frac{l + d}{l}(h_1 - d).
   \]

2. **第（1）问：无摆动耗散时各阶段机械能及其变化**：
   - **\(A\) 点**：动能 \(K_A = 0\)，机械能 \(E_A = mgh_1\)。
   - **\(A \to A'\)（最高点迅速下蹲）**：人从静止下蹲至静止（受摆杆约束切向仍静止，末径向速度为零），机械能为：
     \[
     E_{A'} = mgh_1' = mg\frac{l+d}{l}(h_1 - d),
     \]
     机械能变化量：
     \[
     \Delta E_{A\to A'} = E_{A'} - E_A = -mg\frac{d}{l}(l + d - h_1) = -mgd\cos\alpha_1.
     \]
   - **\(A' \to B\)（始终完全蹲下下摆）**：此过程无机械能损失，机械能守恒：
     \[
     E_B = E_{A'} = mg\frac{l+d}{l}(h_1 - d), \qquad \Delta E_{A'\to B} = 0,
     \]
     其中在最低点 \(B\) 势能为零，动能 \(K_B = \frac{1}{2}mv_B^2 = E_B\)。
   - **\(B \to B'\)（最低点迅速站起）**：人在站起过程中与秋千相互作用力始终沿摆杆（径向），重力在最低点也通过悬点 \(O\)，故系统对 \(O\) 的角动量守恒！由 \(m v_B (l + d) = m v_{B'} l\)（且站起后径向速度为零），得：
     \[
     v_{B'} = \frac{l + d}{l}v_B \implies K_{B'} = \left(\frac{l + d}{l}\right)^2 K_B = mg\left(\frac{l + d}{l}\right)^3(h_1 - d).
     \]
     加上 \(B'\) 点重力势能 \(mgd\)，机械能为：
     \[
     E_{B'} = mg\left(\frac{l + d}{l}\right)^3(h_1 - d) + mgd,
     \]
     此阶段机械能变化量（人站起做正功）：
     \[
     \Delta E_{B\to B'} = E_{B'} - E_B = mg\left[\left(\frac{l+d}{l}\right)^3 - \frac{l+d}{l}\right](h_1 - d) + mgd.
     \]
   - **\(B' \to C\)（始终完全站立上摆）**：无机械能损失，\(E_C = E_{B'} = mgh_2\)，\(\Delta E_{B'\to C} = 0\)。由此可见单次半周期内高度增量满足：
     \[
     h_2 - d = \left(\frac{l+d}{l}\right)^3(h_1 - d), \qquad \Delta E_{\text{总}} = E_C - E_A = mg\left[\left(\frac{l+d}{l}\right)^3 - 1\right](h_1 - d) > 0.
     \]

3. **第（2）问：计及“始终完全蹲下”与“始终完全站立”耗散时的递推关系**：
   - **(i) \(h_n\) 与 \(h_{n+1}\) 的递推关系**：
     在第 \(n\) 次半周期中：
     - **始终完全蹲下过程（\(A'_n \to B_n\)）**：高度差绝对值 \(\Delta h_1 = h_n' = \frac{l+d}{l}(h_n - d)\)，故耗散 \(\Delta E_1 = k_1 mg(h_0 + h_n')\)。到达 \(B_n\) 处动能为：
       \[
       \frac{1}{2}m v_{Bn}^2 = mgh_n' - k_1 mg(h_0 + h_n') = (1 - k_1)mg\frac{l+d}{l}(h_n - d) - k_1 mgh_0.
       \]
     - **最低点站起过程（\(B_n \to B'_n\)）**：角动量守恒仍给出 \(v_{B'n} = \frac{l+d}{l}v_{Bn}\)。
     - **始终完全站立过程（\(B'_n \to C_n\)）**：起始点 \(B'_n\) 高度为 \(d\)，最高点高度为 \(h_{n+1}\)，故过程前后高度差绝对值 \(\Delta h_2 = h_{n+1} - d\)，耗散 \(\Delta E_2 = k_2 mg[h_0' + (h_{n+1} - d)]\)。由 \(E_{B'n} - \Delta E_2 = mgh_{n+1}\)：
       \[
       \frac{1}{2}m v_{B'n}^2 + mgd - k_2 mg[h_0' + (h_{n+1} - d)] = mgh_{n+1} \implies \frac{1}{2}m v_{B'n}^2 = (1 + k_2)mg(h_{n+1} - d) + k_2 mgh_0'.
       \]
     代入 \(v_{B'n}^2 = \left(\frac{l+d}{l}\right)^2 v_{Bn}^2\) 并消去 \(mg\)：
     \[
     (1 + k_2)(h_{n+1} - d) + k_2 h_0' = (1 - k_1)\left(\frac{l+d}{l}\right)^3(h_n - d) - k_1\left(\frac{l+d}{l}\right)^2 h_0.
     \]
     令：
     \[
     \lambda \equiv \frac{1 - k_1}{1 + k_2}\left(\frac{l + d}{l}\right)^3, \qquad \mu \equiv \frac{k_1}{1 + k_2}\left(\frac{l + d}{l}\right)^2 h_0 + \frac{k_2}{1 + k_2} h_0',
     \]
     即得简洁的一阶线性递推关系：
     \[
     h_{n+1} - d = \lambda(h_n - d) - \mu, \quad \text{或} \quad h_{n+1} = \lambda h_n + (1 - \lambda)d - \mu.
     \]
   - **(ii) \(h_n\) 与 \(h_1\) 及 \(h_{n+1} - h_n\) 与 \(h_1\) 的关系式**：
     由 \(h_{k+1} - d = \lambda(h_k - d) - \mu\) 逐级递推 \(n-1\) 步：
     - 当 \(\lambda \neq 1\) 时：
       \[
       h_n - d = \lambda^{n-1}(h_1 - d) - \mu\frac{1 - \lambda^{n-1}}{1 - \lambda} \implies h_n = \lambda^{n-1}(h_1 - d) + d - \mu\frac{1 - \lambda^{n-1}}{1 - \lambda}.
       \]
       （若特殊情况下 \(\lambda = 1\)，则退化为线性递减 \(h_n = h_1 - (n-1)\mu\)。）
     - 相邻高度增量（对 \(\lambda = 1\) 也直接给出 \(-\mu\)）：
       \[
       h_{n+1} - h_n = (h_{n+1} - d) - (h_n - d) = \lambda^{n-1}\left[(\lambda - 1)(h_1 - d) - \mu\right].
       \]
     **物理意义检验**：唯有当 \(\lambda > 1\) 且初起高度 \(h_1 > d + \frac{\mu}{\lambda - 1}\) 时，才有 \(h_{n+1} - h_n > 0\)，秋千越荡越高；反之则会逐渐停下。

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题精细化地剖析了“荡秋千为何能越荡越高”的参数泵浦物理机制，并进一步把摆动过程中的阻尼耗散抽象为与垂直高度差相关的线性模型。核心规律有两层：（1）在最高点下蹲虽降低势能，但换来了更长摆臂（角动量泵浦储备）；在最低点沿径向快速站起时因外力均过悬点而角动量守恒，摆臂缩短使切向速率按 \(\frac{l+d}{l}\) 放大，进而使机械能净增；（2）以 \(B'\) 处基准高度 \(d\) 为枢纽，所有动力学与耗散公式都能自然写成关于 \((h_n - d)\) 的比例形式，使复杂的多参数递推化归为极简的一阶线性常系数递推数列。
- **递进拆解脉络**：
  1. 第一步（厘清几何基准与“始终”语义）：定出 \(B\) 点势能零点下 \(B'\) 高度为 \(d\)，站立最高点 \(h_n\) 对应下蹲后 \(A'\) 点高度 \(h_n' = \frac{l+d}{l}(h_n - d)\)。明确“始终完全蹲下”指 \(A'\to B\) 摆动段，“始终完全站立”指 \(B'\to C\) 摆动段。
  2. 第二步（分五点求无损各阶段机械能及变化）：依次计算 \(E_A, E_{A'}, E_B, E_{B'}, E_C\)，重点在 \(B\to B'\) 段利用系统对 \(O\) 轴角动量守恒 \(m(l+d)v_B = ml v_{B'}\) 求出动能暴增因子 \(\left(\frac{l+d}{l}\right)^2\)，推得理想增长率 \(\left(\frac{l+d}{l}\right)^3\)。
  3. 第三步（代入耗散公式列能量-高度方程）：在 \(A'\to B\) 段取 \(\Delta h = h_n'\) 得 \(\frac{1}{2}mv_{Bn}^2\)；在 \(B'\to C\) 段取 \(\Delta h = h_{n+1} - d\)（注意减去 \(B'\) 本身的高度 \(d\)！）反推出 \(\frac{1}{2}mv_{B'n}^2\)，联立 \(B\to B'\) 角动量守恒得到线性递推式 \(h_{n+1}-d = \lambda(h_n-d) - \mu\)。
  4. 第四步（等比展开求解通项与差分）：写出 \(h_n\) 关于 \(h_1\) 的通项（并留意 \(\lambda=1\) 的临界极限），以及 \(h_{n+1}-h_n = \lambda^{n-1}[(\lambda-1)(h_1-d)-\mu]\)。
- **盲解手记**：盲解时第一时间精准把握了题干“始终完全蹲下/站立”与“迅速下蹲/站起”的语义区分，确认阻尼耗散发生在 \(A'\to B\) 与 \(B'\to C\) 两段摆动过程，且在 \(B'\to C\) 段准确使用了 \(\Delta h = h_{n+1} - d\)。随后一次性导出 \(\lambda\) 与 \(\mu\) 及完整递推通项，并校验了 \(k_1 = k_2 = 0\) 退回第（1）问及小角泵浦功率极限。
- **对照结论**：与官方参考解答高度一致！官方第（1）问列出 \(U_A, U_{A'}, K_{B1}, U_{B'1}, U_C\) 与增量 \(U_C - U_A\)，第（2）问引入的常数符号 \(\lambda\) 与 \(\mu\)（式⑬–⑮）与盲解完全吻合。唯一小差异在于官方式⑰写出的是 \(h_{n+1}\) 的通项表达式 \(h_{n+1} = \lambda^n(h_1-d) + d - \mu\frac{1-\lambda^n}{1-\lambda}\)（即把下标顺移了一位，等价于盲解中的 \(h_n\) 式），且官方未单独说明 \(\lambda = 1\) 时的退化情况。
- **核心难点**：
  - 难点1：准确理解题干措辞“始终完全蹲下”是指摆动下坠段 \(A'\to B\)，“始终完全站立”是指摆动上冲段 \(B'\to C\)，且后者的高度差绝对值 \(\Delta h\) 必须是 \(h_{n+1} - d\) 而非 \(h_{n+1}\)。
  - 难点2：在“人蹲下或站起”的快速动作期间，人与秋千间的相互作用虽做内功改变了总机械能，但因交互力始终沿摆杆（对悬点 \(O\) 无力矩），在最低点（重力亦无力矩）系统对 \(O\) 角动量守恒，这正是能够定量算清人做功的关键抓手。
- **高频易错点**：
  - 易错点1：在计算 \(B'\to C\) 的机械能损失时误把 \(\Delta h\) 当作 \(h_{n+1}\)（忘记 \(B'\) 已经在 \(B\) 点上方 \(d\) 处），不仅算错 \(\mu\)，还会破坏 \((h_{n+1} - d)\) 与 \((h_n - d)\) 的齐次对称结构。
  - 易错点2：把 \(B\to B'\) 过程当成机械能守恒，或者把人站起做的功误以为只有克服重力势能的 \(mgd\) 而漏掉克服离心力做的功（动能增量）。
- **教练总结**：遇到变摆长/变半径摆动泵浦题，记住三句口诀：**最高点变形只换势能、最低点变形角动量守恒、摆动过程看清起始高度差**。在整理递推关系时，不要急于拆开括号，先观察物理偏置基准（如这里的 \(h - d\)），保留整体结构即可一眼看出等比递推规律。

## 12. 竖直磁场中方形线框的磁力矩简谐振动、断路电动势与电磁阻尼制动 (`cpho-2017-final-theory-problem-slice-q4`)

- **难度评级**：`D3`
- **物理模型**：刚体与电磁感应耦合 · 转动惯量、直流回复力矩简谐振与短路角冲量积分
- **教学标签**：`刚体转动惯量`、`右手坐标系力矩判向`、`小角磁力矩简谐振动`、`旋转切割感生电压`、`电磁阻尼角冲量定理`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：线框绕 \(OO'\) 轴的转动惯量 \(J\)**：
   每条边质量为 \(\frac{m}{4}\)、长度为 \(l\)：
   - `ab` 和 `cd` 平行于 \(OO'\)，距轴距离为 \(\frac{l}{2}\)：\(J_{ab} = J_{cd} = \frac{m}{4}\left(\frac{l}{2}\right)^2 = \frac{1}{16}ml^2\)；
   - `ad` 和 `bc` 垂直并被 \(OO'\) 平分：\(J_{ad} = J_{bc} = \frac{1}{12}\left(\frac{m}{4}\right)l^2 = \frac{1}{48}ml^2\)。
   总转动惯量：
   \[
   J = 2\cdot\frac{1}{16}ml^2 + 2\cdot\frac{1}{48}ml^2 = \frac{1}{6}ml^2.
   \]

2. **第（2）问：通恒定直流电后的运动方程**：
   建立右手直角坐标系：\(+\hat{x}\) 水平向右，\(+\hat{y}\) 沿 \(O \to O'\)（向里），\(+\hat{z}\) 竖直向上（验证 \(\hat{x}\times\hat{y} = +\hat{z}\)）。
   电流沿 \(P \to a \to b \to c \to d \to Q\)，故 `ab` 边电流沿 \(+\hat{y}\)、`cd` 边沿 \(-\hat{y}\)。在 \(\mathbf{B} = B\hat{z}\) 中：
   \[
   \mathbf{F}_{ab} = I(l\hat{y}) \times (B\hat{z}) = + BIl\,\hat{x}, \qquad \mathbf{F}_{cd} = -BIl\,\hat{x}.
   \]
   当 `ab` 侧与 \(+x\) 轴夹角为 \(\theta\)（小角近似 \(\sin\theta \approx \theta\)）时，`ab` 处于上方（\(\mathbf{r}_{ab} = \frac{l}{2}(\cos\theta\,\hat{x} + \sin\theta\,\hat{z})\)），向右的安培力将其向水平面拉回（与 \(\theta\) 增大方向相反），力偶矩为：
   \[
   M = - 2 \cdot \frac{l}{2} BIl \sin\theta = - B I l^2 \sin\theta \approx - B I l^2 \theta.
   \]
   （注：`ad` 和 `bc` 边所受安培力竖直或沿面内过轴方向，对 \(OO'\) 轴合力矩为零。）
   由刚体定轴转动定律 \(J\ddot{\theta} = M\)：
   \[
   \frac{1}{6}m l^2 \ddot{\theta} = -B I l^2 \theta \implies \ddot{\theta} + \omega^2 \theta = 0, \qquad \omega = \sqrt{\frac{6BI}{m}}.
   \]
   结合初条件 \(\theta(0) = \theta_0,\ \dot{\theta}(0) = 0\)，线框做简谐振动：
   \[
   \theta(t) = \theta_0 \cos\left(\sqrt{\frac{6BI}{m}}\, t\right),
   \]
   \[
   \dot{\theta}(t) = -\theta_0\sqrt{\frac{6BI}{m}}\sin\left(\sqrt{\frac{6BI}{m}}\, t\right),
   \]
   \[
   \ddot{\theta}(t) = -\theta_0 \frac{6BI}{m}\cos\left(\sqrt{\frac{6BI}{m}}\, t\right).
   \]

3. **第（3）问：\(t = t_0 > 0\) 断开外电路后的运动与 \(V_{PQ}(t)\)**：
   注意简谐振动第一次经过水平面是在 \(t = \frac{T}{4}\)（此时顺时针转动，\(\dot{\theta} < 0\)），而首次**逆时针**转至水平面（`da` 边与 \(+X\) 轴重合，从负角向正角穿过平衡位置）发生在 \(t_0 = \frac{3T}{4} = \frac{3\pi}{2}\sqrt{\frac{m}{6BI}}\)（一般地 \(t_0 = (k + \frac{3}{4})T\)），此时线框角速度大小为：
   \[
   \dot{\theta}_0 = \dot{\theta}(t_0) = \theta_0\sqrt{\frac{6BI}{m}}.
   \]
   断开 \(P, Q\) 后，线框无电流、不受安培力矩且轴光滑，此后线框将以恒定角速度 \(\dot{\theta}_0\) 绕 \(OO'\) **做匀速转动**：
   \[
   \theta(t) = \dot{\theta}_0 (t - t_0) \quad (t \ge t_0).
   \]
   由法拉第定律，穿过回路 \(P \to a \to b \to c \to d \to Q\) 的磁通量为 \(\Phi = B l^2 \cos\theta\)（俯视逆时针回路面元法向与 \(+\hat{z}\) 夹角为 \(\theta\)），故沿 \(P \to Q\) 方向的感应电动势为：
   \[
   \mathcal{E}_{P\to Q} = -\frac{d\Phi}{dt} = B l^2 \dot{\theta}_0 \sin\left[\dot{\theta}_0(t - t_0)\right] = B l^2 \theta_0\sqrt{\frac{6BI}{m}}\sin\left[\theta_0\sqrt{\frac{6BI}{m}}(t - t_0)\right]
   \]
   （用 `ab`、`cd` 切割磁感线 \(\mathbf{v}\times\mathbf{B}\) 验证：`ab` 向上左转动，\(\mathbf{v}_{ab}\times\mathbf{B}\) 恰沿 \(a\to b\)，驱动正电荷从 \(P\) 流向 \(Q\)）。因外电路断开，内部电动势将正电荷推向 \(Q\) 端，故 \(Q\) 端电势高于 \(P\) 端，\(P, Q\) 间电压为：
   \[
   V_{PQ} = V_P - V_Q = -\mathcal{E}_{P\to Q} = - B l^2 \theta_0\sqrt{\frac{6BI}{m}}\sin\left[\theta_0\sqrt{\frac{6BI}{m}}(t - t_0)\right].
   \]

4. **第（4）问：在 \(\theta_1 \in \left[\frac{\pi}{4}, \frac{3\pi}{4}\right]\) 处将 \(P, Q\) 短路后的制动小角 \(\alpha\)**：
   短路后，在任意角位置 \(\theta\)，感应电动势大小为 \(Bl^2\dot{\theta}\sin\theta\)，感应电流 \(i = \frac{Bl^2\dot{\theta}\sin\theta}{R}\)，形成阻碍转动的电磁阻尼力偶矩：
   \[
   M_{\text{damp}} = -B i l^2 \sin\theta = -\frac{B^2 l^4 \sin^2\theta}{R}\dot{\theta}.
   \]
   由角动量定理 \(J\, d\dot{\theta} = M_{\text{damp}}\, dt = -\frac{B^2 l^4}{R}\sin^2\theta\, d\theta\)，从 \((\theta_1, \dot{\theta}_0)\) 积分至停止 \((\theta_1 + \alpha, 0)\)：
   \[
   J\dot{\theta}_0 = \frac{B^2 l^4}{R}\int_{\theta_1}^{\theta_1 + \alpha} \sin^2\theta\, d\theta.
   \]
   因 \(\alpha\) 为小角度（且 \(\theta_1 \in [\frac{\pi}{4}, \frac{3\pi}{4}]\) 使 \(\sin\theta_1 \ge \frac{1}{\sqrt{2}}\) 远离零点），利用 \(\int_{\theta_1}^{\theta_1+\alpha}\sin^2\theta\,d\theta \approx \alpha\sin^2\theta_1\)：
   \[
   \alpha = \frac{R J \dot{\theta}_0}{B^2 l^4 \sin^2\theta_1} = \frac{R\left(\frac{1}{6}ml^2\right)\theta_0\sqrt{\frac{6BI}{m}}}{B^2 l^4 \sin^2\theta_1} = \frac{R \theta_0}{l^2 \sin^2\theta_1}\sqrt{\frac{m I}{6 B^3}}.
   \]
   在区间 \(\theta_1 \in \left[\frac{\pi}{4}, \frac{3\pi}{4}\right]\) 内，当 \(\theta_1 = \frac{\pi}{2}\)（线框处于竖直平面，磁通量变化率最大）时 \(\sin^2\theta_1 = 1\) 取得最大值，此时 \(\alpha\) 达到最小值：
   \[
   \alpha_{\min} = \frac{R \theta_0}{l^2}\sqrt{\frac{m I}{6 B^3}}.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题通过一个刚性导电方形线框串联了电磁学与力学的三大经典阶段：阶段一（恒流激振）考查三维安培力矩的正确方向判定与小角简谐振动；阶段二（断路旋转）考查无阻尼匀速转动及动生电压的正负极性 \(V_{PQ}\)；阶段三（短路制动）考查自感忽略下的非恒定电磁阻尼，利用角动量定理把时间积分巧妙转化为对角度 \(d\theta\) 的积分，并在 \(\alpha \ll 1\) 条件下导出 \(\alpha(\theta_1)\) 及其最小值。
- **递进拆解脉络**：
  1. 第一步（求转动惯量 \(J\)）：将线框拆分为平行于轴的 `ab`、`cd` 两杆与垂直于轴的 `ad`、`bc` 两杆，分别计算叠加得 \(J = \frac{1}{6}ml^2\)。
  2. 第二步（小角简谐振动求解）：建立右手系确认 `ab`、`cd` 所受安培力构成回复力偶 \(M = -BI l^2\sin\theta \approx -BIl^2\theta\)，由转动定律写出 \(\theta(t), \dot{\theta}(t), \ddot{\theta}(t)\)。
  3. 第三步（断路匀速转动与感生电压 \(V_{PQ}\)）：确定 \(t_0\) 时刻逆时针过水平平衡位置时速率为 \(\dot{\theta}_0 = \theta_0\sqrt{6BI/m}\)；断开后匀角速转动，由动生电动势或 \(-d\Phi/dt\) 得出电动势方向沿 \(P\to Q\)，从而 \(V_{PQ} = V_P - V_Q = -Bl^2\dot{\theta}_0\sin[\dot{\theta}_0(t-t_0)]\)。
  4. 第四步（短路阻尼角冲量积分与极值）：写出阻尼力偶矩 \(M = -\frac{B^2 l^4}{R}\dot{\theta}\sin^2\theta\)，对 \(dt\) 积分并换元为 \(\dot{\theta}\,dt = d\theta\)，利用 \(\alpha\) 小角度近似求出 \(\alpha(\theta_1)\)，在 \(\theta_1 = \pi/2\) 处取得最小值。
- **盲解手记**：盲解时在三维右手坐标系检验上格外谨慎（核对了左手定则与 \(\hat{y}_{\text{into}} \times \hat{z} = +\hat{x}\)），确认磁力矩为回复力矩并严格区分了初次经过水平位置（顺时针）与首次逆时针经过水平位置的相位，从而理清了题干“逆时针转至水平”的含义。随后所有表达式及 \(V_{PQ}\) 正负号、\(\alpha(\theta_1)\) 和 \(\alpha_{\min}\) 与参考答案完全一致。
- **对照结论**：与官方参考解答完全一致！官方第（1）–（4）问的最终公式①–⑲（包括 \(V_{PQ}\) 的负号和 \(\alpha_{\min} = \frac{R}{Bl^2}\sqrt{\frac{mI}{6B}}\theta_0\)）均与盲解分毫不差。**官方排版微瑕**：官方解答第 11 页式⑪第一行出现印刷笔误，写成了 \(2Blv\sin\left[\theta_0\sqrt{\frac{6BI}{m}}(t-t_0)\right] = 2Bl\frac{l}{2}\dot{\theta}\sin[...]\)（其中 \(v\) 应对应 \(\frac{l}{2}\dot{\theta}_0\) 而非含时符号 \(\dot{\theta}\)，且其实前一步已写为 \(\dot{\theta}(t) = \dot{\theta}_0\)），不过第二行最终化简结果完全正确。
- **核心难点**：
  - 难点1：三维空间内安培力与感生电势正负号的精准判定。特别要注意 \(V_{PQ} = V_P - V_Q\) 是外电路断路时的开路端电压，电势在电源内部从低（\(P\)）升高到高（\(Q\)），因此 \(V_{PQ} < 0\)（当电动势沿 \(P\to Q\) 为正时）。
  - 难点2：第（4）问中用角冲量积分 \(\int M\,dt\) 并将 \(\dot{\theta}\,dt\) 置换为 \(d\theta\)，直接消去未知的角速度时间演化细节。很多学生会去死解非线性微分方程 \(J\ddot{\theta} = -C\sin^2\theta\dot{\theta}\) 导致卡壳。
- **高频易错点**：
  - 易错点1：求 \(J\) 时误以为正方形线框与正方形薄板的转动惯量相同，错写成 \(\frac{1}{12}ml^2\) 而非 \(\frac{1}{6}ml^2\)（线框质量集中在边界，惯量加倍）。
  - 易错点2：把开路电源内部的电势高低与外部负载混为一谈，写出 \(V_{PQ} = +\mathcal{E}\)（忽略了电动势方向是从 \(P\) 指向 \(Q\)，故正电荷聚集在 \(Q\) 端，\(\varphi_Q > \varphi_P\)）。
- **教练总结**：电磁阻尼制动求“停下前走过的距离或转过的角度”时，只要磁感应强度和阻力与速度成线性正比（即 \(F_{\text{damp}} = -k(x)\dot{x}\) 或 \(M_{\text{damp}} = -k(\theta)\dot{\theta}\)），一律**动量定理/角动量定理积分**，把 \(\dot{x}\,dt = dx\) 或 \(\dot{\theta}\,dt = d\theta\) 消掉时间，瞬间化为纯几何积分！

## 13. 电磁约束圆柱内非弹性碰撞沉降粒子的立体角与三维路程 (`cpho-2017-final-theory-problem-slice-q5`)

- **难度评级**：`D3`
- **物理模型**：三维螺旋动力学 · 电磁束缚立体角统计、抛物线投影极值与空间弧长无穷级数
- **教学标签**：`柱形磁约束`、`立体角统计分布`、`带电粒子螺旋运动`、`空间弧长微元积分`、`相似缩放无穷等比级数`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：弹性碰撞下实现 \(50\%\) 束缚率的圆片半径 \(R\)**：
   粒子从原点 \(O\) 以初速率 \(V\)、与 \(+z\) 轴夹角 \(\theta \in [0, \frac{\pi}{2}]\) 发射。在 \(xOy\) 平面内，粒子受洛伦兹力做匀速圆周运动（圆周经过 \(O\) 点），回旋半径为：
   \[
   r(\theta) = \frac{m V \sin\theta}{q B}.
   \]
   每次与材料表面发生**弹性碰撞**时，\(v_z\) 反向而水平速度 \(\mathbf{v}_\perp\) 大小方向均保持不变，因此粒子的水平投影始终沿同一经过 \(O\) 点的圆周运动，其到 \(O\) 点的最大水平距离为圆周直径 \(2r(\theta)\)。
   要使粒子始终被束缚在半径为 \(R\) 的圆柱体区域内（一旦 \(r_{\text{pos}} > R\) 就离开磁场区飞出），充要条件是圆周全在圆盘内，即：
   \[
   2 r(\theta) \le R \iff \sin\theta \le \frac{q B R}{2 m V}.
   \]
   设临界极角为 \(\Theta\)（\(\sin\Theta = \frac{qBR}{2mV}\)）。对上半球各方向均匀发射（总立体角 \(2\pi\)），束缚立体角为：
   \[
   \Delta\Omega = \int_0^{2\pi} d\varphi \int_0^\Theta \sin\theta\, d\theta = 2\pi(1 - \cos\Theta).
   \]
   由束缚比例 \(\eta = \frac{\Delta\Omega}{2\pi} = 1 - \cos\Theta = 50\% = \frac{1}{2}\)，得 \(\cos\Theta = \frac{1}{2}\)，即 \(\Theta = \frac{\pi}{3}\)。从而 \(\sin\Theta = \frac{\sqrt{3}}{2}\)，解得圆半径：
   \[
   R = \frac{2 m V}{q B}\sin\frac{\pi}{3} = \frac{\sqrt{3}\, m V}{q B}.
   \]

2. **第（2）问：非弹性碰撞每次动能损失 \(10\%\)**：
   - **(i) 首次碰撞前 \(xOy\) 平面投影点走过路程的最大值**：
     竖直方向粒子做加速度 \(a = \frac{qE}{m}\) 的竖直上抛运动，从射出到首次落回 \(z = 0\) 所需飞行时间为：
     \[
     t_1(\theta) = \frac{2 V \cos\theta}{a} = \frac{2 m V \cos\theta}{q E}.
     \]
     水平方向速率恒为 \(v_\perp = V\sin\theta\)（即使走圆弧，沿圆弧轨迹的**路程**仍等于水平速率乘以时间！），故首次碰前水平投影点走过的路程为：
     \[
     s_{\perp, 1}(\theta) = v_\perp t_1(\theta) = \frac{2 m V^2}{q E}\sin\theta\cos\theta = \frac{m V^2}{q E}\sin(2\theta).
     \]
     注意当 \(\theta = \frac{\pi}{4}\) 时，不仅 \(\sin(2\theta)\) 取得绝对极大值 \(1\)，而且 \(\frac{\pi}{4} < \Theta = \frac{\pi}{3}\)，确保粒子全程严格停留在圆柱内（\(2r(\pi/4) = \frac{\sqrt{2}mV}{qB} < R\)）并与材料表面发生碰撞。因此投影点路程最大值为：
     \[
     s_{\perp, 1,\max} = \frac{m V^2}{q E}.
     \]

   - **(ii) 该最大投影路程粒子直到动能耗尽沉积的总三维路程**：
     对 \(\theta = \frac{\pi}{4}\) 射出的粒子，初速度水平与竖直分量大小均为 \(v_{\perp 0} = v_{z0} = \frac{V}{\sqrt{2}}\)。
     在第一次飞行 \([0, t_1]\) 中，瞬时三维速率为：
     \[
     v(t) = \sqrt{v_{\perp 0}^2 + (v_{z0} - a t)^2}.
     \]
     利用上升与下降对称性（令 \(\tau = \frac{t_1}{2} - t\)，代换 \(u = \frac{a\tau}{v_{\perp 0}}\)，上界 \(u_{\max} = \frac{v_{z0}}{v_{\perp 0}} = 1\)）：
     \[
     s_1 = 2\int_0^{t_1/2} \sqrt{v_{\perp 0}^2 + a^2\tau^2}\,d\tau = \frac{2 v_{\perp 0}^2}{a}\int_0^1 \sqrt{1 + u^2}\,du = \frac{m V^2}{q E}\int_0^1 \sqrt{1 + u^2}\,du.
     \]
     代入题给积分公式 \(\int \sqrt{1+u^2}\,du = \frac{1}{2}u\sqrt{1+u^2} + \frac{1}{2}\ln\left(u + \sqrt{1+u^2}\right) + C\)：
     \[
     s_1 = \frac{m V^2}{q E}\cdot\frac{\sqrt{2} + \ln(1 + \sqrt{2})}{2}.
     \]
     由题设碰撞规律：“竖直与水平速度大小按**同比例**减小，使动能减小 \(10\%\)”，意味着：
     1. 每次碰撞后反弹极角依然保持 \(\theta = \frac{\pi}{4}\) 不变，且回旋半径进一步缩小、绝不会跑出圆柱；
     2. 每段抛体弧长 \(s_n \propto V_{n-1}^2 \propto K_{n-1}\)（正比于该段初始动能），故构成公比 \(k = 1 - 10\% = 0.9\) 的等比数列 \(s_n = 0.9^{n-1} s_1\)。
     总三维路程为无穷等比级数之和：
     \[
     s_{\text{总}} = \sum_{n=1}^\infty s_n = \frac{s_1}{1 - 0.9} = 10 s_1 = \left[\sqrt{2} + \ln(1 + \sqrt{2})\right]\frac{5 m V^2}{q E}.
     \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题构建了一个真空室薄膜沉积物理场景：向下匀强电场提供竖直回复力，有限半径圆柱匀强磁场提供水平回旋束缚。第（1）问通过将水平回旋圆周完全内包于半径 \(R\) 的圆盘中导出 \(2r(\theta) \le R\)，再用立体角积分求解 \(R\)；第（2）问首先揭示了一个有趣巧合：在满足圆柱束缚的条件（\(\theta \le 60^\circ\)）下，水平投影路程恰在 \(\theta = 45^\circ\) 处达到极大；随后利用等比例衰减维持抛射角不变的标度不变性，把无穷多次反弹的三维螺旋弧长化为公比为 \(0.9\) 的几何级数求和。
- **递进拆解脉络**：
  1. 第一步（分析水平圆周包络与立体角束缚率）：由过原点的水平回旋圆最大离轴距为直径 \(2r(\theta) = \frac{2mV\sin\theta}{qB}\)，得出束缚条件 \(\sin\theta \le \frac{qBR}{2mV}\)。利用上半球束缚立体角占比 \(1 - \cos\Theta = 0.5\) 解得 \(\Theta = \pi/3\) 与 \(R = \frac{\sqrt{3}mV}{qB}\)。
  2. 第二步（求首次碰前水平投影最大路程）：算出竖直飞行时间 \(t_1(\theta) = \frac{2mV\cos\theta}{qE}\) 与水平恒速率 \(V\sin\theta\)，两者相乘得 \(s_{\perp,1}(\theta) = \frac{mV^2}{qE}\sin 2\theta\)。检验 \(\theta = \pi/4 < \pi/3\) 在圆片范围内，确定最大投影路程为 \(\frac{mV^2}{qE}\)。
  3. 第三步（积分单次三维弧长并级数求和）：由 \(v_{\text{合}} = \sqrt{v_{\perp}^2 + v_z^2}\) 与对称换元 \(u = at/v_\perp\) 计算第一段三维弧长 \(s_1 = [\sqrt{2}+\ln(1+\sqrt{2})]\frac{mV^2}{2qE}\)；利用竖直与水平速度同比例衰减（动能公比 \(0.9\)、发射角 \(\pi/4\) 恒定）得出 \(s_{\text{总}} = \frac{s_1}{1-0.9} = 10 s_1\)。
- **盲解手记**：盲解完全一次做对。特别验证了两个关键细节：（1）为什么只需检验 \(2r(\theta) \le R\) 而不用管垂直碰撞周期是否与回旋周期公度（因为水平投影在 \(r(\theta)\) 圆上匀速扫过，只要 \(2r > R\) 且持续弹性反弹，必在一两个回旋周期内跨出 \(R\) 界外）；（2）在（2）（i）中主动校验了最优角 \(45^\circ < 60^\circ\) 确实落回材料表面而未飞出圆柱外。
- **对照结论**：与官方参考解答百分之百一致！官方同样通过立体角 \(\Delta\Omega = 2\pi(1-\cos\Theta)\) 得 \(R = \frac{\sqrt{3}mV}{qB}\)、由 \(\theta = \pi/4\) 得 \(s_{z=0}^{\max} = \frac{mV^2}{qE}\)，并利用 \(s_n = 0.9^{n-1}s_1\) 得出 \(s_{\text{总}} = [\sqrt{2}+\ln(1+\sqrt{2})]\frac{5mV^2}{qE}\)。**官方微瑕注记**：官方第 13 页式②把板半径写成了 \(R_0\)（其余地方为 \(R\)），式③积分上限写成了小写 \(\theta\)（应为大写 \(\Theta\)）。
- **核心难点**：
  - 难点1：识别“最大离轴距离 = 回旋直径 \(2r(\theta)\)”而非“回旋半径 \(r(\theta)\)”。粒子从原点 \(O\) 射出，圆心位于距离原点 \(r(\theta)\) 处，故其轨迹最远端距原点为 \(2r(\theta)\)。
  - 难点2：求水平投影点走过的**路程**与三维**路程**的区别——投影点是沿着圆周走曲线，其路程就是速率 \(V\sin\theta\) 乘以时间 \(t_1\)（而不是位移弦长）；三维空间曲线弧长则需把 \(\sqrt{v_\perp^2 + v_z(t)^2}\) 沿时间积分，且注意到每段弧长严格正比于初动能。
- **高频易错点**：
  - 易错点1：把束缚条件错写成 \(r(\theta) \le R\)（错把圆心当原点），导致半径算大一倍 \(R = \frac{\sqrt{3}mV}{2qB}\)（错算成一半 \(\frac{\sqrt{3}}{2}\)）。
  - 易错点2：把立体角均匀分布误当成极角 \(\theta\) 均匀分布（错令 \(\Theta/(\pi/2) = 50\% \implies \Theta = 45^\circ\)），忽略立体角元中的 \(\sin\theta\) 权重。
  - 易错点3：第（2）（ii）问错用公比 \(\sqrt{0.9}\)（速度比）而非 \(0.9\)（动能比），忘记路程量纲 \(L \propto V^2/(qE/m)\) 与动能成正比！
- **教练总结**：遇到三维各向同性发射统计占比，永远先写立体角积分 \(1 - \cos\Theta\)；遇到带电粒子在正交/平行电磁场中发生恒比例非弹性反弹，只要反射不改变水平/竖直速度之比（即保持发射角不变），单次飞行的**时间和长度尺度分别按速率 \(\propto v\) 和速率平方 \(\propto v^2 \propto K\)** 缩放，无穷多次碰撞的总时间与总路程就能直接用等比级数秒算！

## 14. 毛细管悬垂水滴底部曲率半径与部分浸水管的受力平衡 (`cpho-2017-final-theory-problem-slice-q6`)

- **难度评级**：`D2`
- **物理模型**：流体静力学与表面张力 · 拉普拉斯附加压强、毛细上升与双面接触线受力
- **教学标签**：`拉普拉斯附加压强`、`毛细上升高度校验`、`玻璃管与水柱受力分析`、`浸润零接触角模型`、`原题与解答勘误辨析`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：悬垂水滴底部表面的曲率半径 \(a\)**：
   （注：原题切片图像第 3 页“3.50cm”后夹杂蓝色残留字样 `R = 3mm R = 3mm`，审视物理条件可知此为电子文档残留批注而非已知物理条件，全题仅用已知内径即可封闭求解。）
   设大气压强为 \(p_0\)，玻璃毛细管内半径 \(r = 0.500\,\text{mm}\)，外半径 \(R = 5.00\,\text{mm}\)，水柱上端面中心到悬垂水滴底部的竖直高度为 \(h = 3.50\,\text{cm}\)。
   - 因水与玻璃接触角 \(\theta \approx 0\)（且内径 \(r = 0.500\,\text{mm}\) 远小于水毛细长度 \(l_c = \sqrt{\sigma/(\rho_0 g)} \approx 2.72\,\text{mm}\)），管内水柱上端呈半球形凹弯月面，曲率半径等于内半径 \(r\)。由杨-拉普拉斯方程，紧贴上弯月面下方的水内压强为：
     \[
     p_1 = p_0 - \frac{2\sigma}{r}.
     \]
   - 沿水柱向下到水滴底部表面处，由流体静力学平衡得水滴底部内侧压强为：
     \[
     p_2 = p_1 + \rho_0 g h = p_0 - \frac{2\sigma}{r} + \rho_0 g h.
     \]
   - 水滴底部顶点因轴对称，两个主曲率半径均等于 \(a\) 且向外凸出，故附加压强为 \(\frac{2\sigma}{a}\)，即：
     \[
     p_2 = p_0 + \frac{2\sigma}{a}.
     \]
   联立以上三式消去 \(p_0\)：
   \[
   \frac{2\sigma}{a} = \rho_0 g h - \frac{2\sigma}{r} \implies a = \frac{2\sigma r}{\rho_0 g h r - 2\sigma}.
   \]
   代入数据（\(\rho_0 = 1.00\times 10^3\,\text{kg/m}^3,\ g = 9.80\,\text{m/s}^2,\ \sigma = 7.27\times 10^{-2}\,\text{N/m},\ h = 3.50\times 10^{-2}\,\text{m},\ r = 5.00\times 10^{-4}\,\text{m}\)）：
   \[
   \frac{2\sigma}{r} = 290.8\,\text{Pa}, \qquad \rho_0 g h = 343.0\,\text{Pa}, \qquad p_2 - p_0 = 52.2\,\text{Pa},
   \]
   \[
   a = \frac{2\times 7.27\times 10^{-2}}{52.2}\,\text{m} \approx 2.79\times 10^{-3}\,\text{m}\ (2.79\,\text{mm}).
   \]
   （合理性检验：\(a = 2.79\,\text{mm} < R = 5.00\,\text{mm}\)，水滴可稳定悬垂于下端中央而不越出管外缘。）

2. **第（2）问：三分之一长度竖直浸入水中时所需向上的拉力 \(F\)**：
   管长 \(L = 6.00\,\text{cm}\)，浸入水深 \(h_{\text{imm}} = \frac{1}{3}L = 2.00\,\text{cm}\)，管在管外水面以上的长度为 \(4.00\,\text{cm}\)。
   - **第一步（校验管内水柱是否溢出顶端）**：
     水在毛细管内上升的高度（相对管外水平面）为：
     \[
     h_1 = \frac{2\sigma}{\rho_0 g r} = \frac{2\times 7.27\times 10^{-2}}{1.00\times 10^3\times 9.80\times 5.00\times 10^{-4}} \approx 2.97\times 10^{-2}\,\text{m} = 2.97\,\text{cm}.
     \]
     因 \(h_1 = 2.97\,\text{cm} < 4.00\,\text{cm}\)，水柱不会到达或溢出玻璃管上端口！
   - **第二步（双途径隔离受力分析与校验）**：
     - **途径 A（仅隔离玻璃管本身）**：
       1. 玻璃管重力（向下）：\(G = 2\rho_0 \pi(R^2 - r^2) L g\)；
       2. 下端玻璃环形截面所受净水静压浮力（向上，大气压在上下端抵消）：\(F_0 = \rho_0 g \frac{L}{3}\pi(R^2 - r^2)\)；
       3. 管内壁与弯月面接触线处表面张力（向下，因接触角 \(\theta = 0\)）：\(F_{1} = 2\pi r \sigma\)；
       4. 管外壁与管外水面接触线处表面张力（向下，接触角 \(\theta = 0\)）：\(F_{2} = 2\pi R \sigma\)。
       （管内外圆柱面均为竖直壁，水静压沿径向水平，不提供竖直分量。）
     - **途径 B（以“玻璃管 + 管内水柱”整体为控制体校验）**：
       管内水面以上水柱重为 \(G_1 = \rho_0 g \pi r^2 h_1\)，由于 \(h_1 = \frac{2\sigma}{\rho_0 g r}\)，恰有 \(G_1 = 2\pi r \sigma = F_1\)，两者数学完全等价！
     由竖直方向平衡得所需向上的外力：
     \[
     F = G - F_0 + F_1 + F_2 = \frac{5}{3}\rho_0 g \pi L(R^2 - r^2) + 2\pi\sigma(R + r).
     \]
     代入数据（\(R^2 - r^2 = (5.00^2 - 0.500^2)\times 10^{-6} = 2.475\times 10^{-5}\,\text{m}^2\)，\(R + r = 5.50\times 10^{-3}\,\text{m}\)）：
     \[
     \frac{5}{3}\rho_0 g \pi L(R^2 - r^2) \approx 7.620\times 10^{-2}\,\text{N}, \qquad 2\pi\sigma(R + r) \approx 2.512\times 10^{-3}\,\text{N},
     \]
     \[
     F \approx 7.87\times 10^{-2}\,\text{N}.
     \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题围绕表面张力的两大经典应用展开：第（1）问借助管内顶端凹弯月面与底端凸水滴的两重拉普拉斯附加压强差和中间水柱的静水平衡，通过压强桥接求解底部曲率半径；第（2）问考查将厚壁毛细管部分浸入水中后的静力平衡，既须先行校核管内毛细上升高度是否会从管口溢出，又需同时计入玻璃管内、外壁两条润湿接触线的表面张力（或者等效理解为管内高于外部液面水柱的重量与外壁附着力之和）。
- **递进拆解脉络**：
  1. 第一步（压强传递求解底部曲率半径）：确定管内上凹月面内压强 \(P_1 = P_0 - \frac{2\sigma}{r}\) 与下凸液滴底部内压强 \(P_2 = P_0 + \frac{2\sigma}{a}\)，结合静水压强 \(P_2 = P_1 + \rho_0 g h\) 解出 \(a = \frac{2\sigma r}{\rho_0 g h r - 2\sigma} \approx 2.79\times 10^{-3}\,\text{m}\)。
  2. 第二步（检验毛细上升高度）：算出管内水柱相对外界水面上升高度 \(h_1 = \frac{2\sigma}{\rho_0 g r} = 2.97\,\text{cm}\)，确认小于管露在水面以上的高度 \(4.00\,\text{cm}\)，水不会从上端溢出。
  3. 第三步（综合重力、浮力与双壁附着力求平衡拉力）：分别计入玻璃管自重 \(G = 2\rho_0 g\pi(R^2-r^2)L\)、浸没体积浮力 \(F_0 = \frac{1}{3}\rho_0 g\pi(R^2-r^2)L\)、内壁水柱下拉力 \(F_1 = 2\pi r\sigma\)（等于额外水柱重 \(G_1\)）与外壁表面张力 \(F_2 = 2\pi R\sigma\)，求和得出 \(F = 7.87\times 10^{-2}\,\text{N}\)。
- **盲解手记**：盲解时敏锐识别出原题切片第（1）问中 `3.50cm` 后的蓝色字样 `R = 3mm R = 3mm` 系电子排版残留批注而非已知条件，未受干扰地直接利用 \(h = 3.50\,\text{cm}\) 算出 \(a = 2.785\,\text{mm} \approx 2.79\,\text{mm}\)；第（2）问主动先检验了 \(h_1 = 2.97\,\text{cm} < 4.00\,\text{cm}\) 不溢出，并用“玻璃管孤立接触线表面张力”与“管加管内水柱控制体”两种途径交叉验证，最终算得 \(7.87\times 10^{-2}\,\text{N}\)。
- **对照结论**：最终公式与数值结果（\(a = 2.79\times 10^{-3}\,\text{m}\)，\(F = 7.87\times 10^{-2}\,\text{N}\)）与官方参考解答完全一致！**原题与官方解答排版勘误汇总**：（1）2017 年原版 `.doc` 转 PDF 时遗留了多处隐藏草稿或批注残影：题干图 `page-3.jpg` 中出现多余蓝色字符 `R = 3mm R = 3mm`（解答完全不用它），解答 `page-16.jpg` 与 `page-17.jpg` 同样出现重复蓝色残影 `\theta = 0 \theta = 0` 和 `G_1 = m_1 g = \rho_0 g\pi r^2 h`；（2）官方解答第（2）问沿用了字母 \(h\) 代表管长 \(6.00\,\text{cm}\)（与第（1）问液柱高度 \(h = 3.50\,\text{cm}\) 符号冲突）；（3）官方第 17 页式⑬第一行首项将玻璃管重力的 \(2\rho_0\) 漏印为 \(\rho\)，但第二行已自动纠正回 \(\frac{5}{3}\rho_0 g\pi h(R^2-r^2)\)。
- **核心难点**：
  - 难点1：第（2）问同时存在管内和管外两个润湿界面，必须计及两条接触线 \(2\pi r\) 和 \(2\pi R\) 上的向下表面张力（即不要遗漏外壁的表面张力 \(2\pi R\sigma\)，也不能把水柱重量 \(G_1\) 和内壁表面张力 \(2\pi r\sigma\) 重复计算两次）。
  - 难点2：在计算浮力时，需先校验毛细上升是否会冲出管口——若管太短导致溢出，顶部弯月面曲率半径会变大以适应管长，不能再直接使用 \(2\sigma/(\rho_0 g r)\)。
- **高频易错点**：
  - 易错点1：第（1）问中把凹弯月面和凸水滴的附加压强方向记反（凹面内部压强比外部低，凸面内部压强比外部高），导致写出 \(\frac{2\sigma}{a} = \rho_0 g h + \frac{2\sigma}{r}\) 的错误公式。
  - 易错点2：第（2）问同时算了管内液柱重力 \(G_1 = \rho_0 g\pi r^2 h_1\) 又加上内壁接触线拉力 \(2\pi r\sigma\)（双倍计入！），或者直接完全忘记算外壁接触线拉力 \(2\pi R\sigma\)（漏掉约 \(2.29\times 10^{-3}\,\text{N}\)）。
- **教练总结**：浸润液柱与毛细管力学平衡有个最不易重算或漏算的黄金法则：**始终只隔离固体管壁本身**！固体只受自身重力、底部端面液体静水压（减大气压基准）以及所有三相接触线上的表面张力 \(\sum \sigma L \cos\theta\)，彻底远离“管内水柱算不算浮力、管外爬升液面算不算重力”的糊涂账。

## 15. 引力红移、等效原理与庞德-雷布卡穆斯堡尔实验验证 (`cpho-2017-final-theory-problem-slice-q7`)

- **难度评级**：`D2`
- **物理模型**：广义相对论初步 · 弱场引力红移、匀加速箱相对论多普勒频移与实验补偿
- **教学标签**：`爱因斯坦等效原理`、`引力红移`、`相对论多普勒效应`、`庞德-雷布卡实验`、`一阶弱场近似`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）（i）问：球形星体表面的引力红移波长 \(\lambda'\)**：
   \(A\) 处发射波长为 \(\lambda_0\) 的光子能量为 \(E_0 = \frac{hc}{\lambda_0}\)，等效引力质量 \(m = \frac{E_0}{c^2} = \frac{h}{\lambda_0 c}\)。因 \(R \gg L\)，在高度 \(L\) 范围内重力加速度近似恒为 \(g' = \frac{GM}{R^2}\)。由能量守恒：
   \[
   \frac{hc}{\lambda_0} = \frac{hc}{\lambda'} + m g' L = \frac{hc}{\lambda'} + \frac{h}{\lambda_0 c}\frac{GM}{R^2} L.
   \]
   两边同除以 \(hc\)：
   \[
   \frac{1}{\lambda'} = \frac{1}{\lambda_0}\left(1 - \frac{G M L}{R^2 c^2}\right).
   \]
   在弱场条件 \(\frac{GM L}{R^2 c^2} \ll 1\) 下保留一阶小量：
   \[
   \lambda' = \frac{\lambda_0}{1 - \frac{GM L}{R^2 c^2}} \approx \lambda_0\left(1 + \frac{G M L}{R^2 c^2}\right).
   \]

2. **第（1）（ii）问：无引力匀加速箱内的接收波长 \(\lambda''\)**：
   在静止惯性系中考察光从 \(A\) 到 \(B\) 的传播：\(t = 0\) 时光以速度 \(c\) 向上射向初始距离为 \(L\) 的 \(B\)，同时箱子由静止开始以加速度 \(a\) 向上运动。光到达 \(B\) 的时刻 \(t\) 满足：
   \[
   c t = L + \frac{1}{2} a t^2.
   \]
   由 \(a L \ll c^2\)，传播时间一阶近似为 \(t \approx \frac{L}{c}\)，此时接收器 \(B\) 相对于激光发出时刻光源 \(A\) 的远离速度为：
   \[
   v = a t \approx \frac{a L}{c} \quad \left(\beta \equiv \frac{v}{c} \approx \frac{a L}{c^2} \ll 1\right).
   \]
   根据狭义相对论纵向多普勒效应（接收器背离静止发射源以速率 \(v\) 运动），接收频率与波长满足：
   \[
   \nu'' = \nu_0\sqrt{\frac{1 - \beta}{1 + \beta}} \implies \lambda'' = \lambda_0\sqrt{\frac{1 + \beta}{1 - \beta}}.
   \]
   因 \(\beta \ll 1\)，一阶展开 \(\sqrt{\frac{1+\beta}{1-\beta}} \approx 1 + \beta\)，得：
   \[
   \lambda'' \approx \lambda_0\left(1 + \frac{a L}{c^2}\right).
   \]

3. **第（1）（iii）问：由等效原理对比确定加速度 \(a\)**：
   爱因斯坦等效原理要求有引力的静止参考系（i）与无引力的加速参考系（ii）物理规律相同（即 \(\lambda' = \lambda''\)）：
   \[
   1 + \frac{G M L}{R^2 c^2} = 1 + \frac{a L}{c^2} \implies a = \frac{G M}{R^2}
   \]
   （方向竖直向上，即与引力场方向相反）。

4. **第（2）问：庞德-雷布卡-斯奈德实验中的探测器速度 \(v\)**：
   伽马光子到达高塔顶部 \(B\) 处时，在地面静止系中的频率因引力红移降至：
   \[
   \nu' = \nu_0\left(1 - \frac{g L}{c^2}\right).
   \]
   为使探测器在自身静止系中观测到的频率重新回到共振吸收频率 \(\nu_0\)，探测器必须迎着光子竖直向下（沿 \(BA\) 方向）以速率 \(v\) 运动，利用多普勒蓝移补偿引力红移：
   \[
   \nu_0 = \nu'\sqrt{\frac{1 + v/c}{1 - v/c}} \approx \nu_0\left(1 - \frac{g L}{c^2}\right)\left(1 + \frac{v}{c}\right).
   \]
   保留小量至一阶，得：
   \[
   \frac{v}{c} = \frac{g L}{c^2} \implies v = \frac{g L}{c}.
   \]
   代入实验数据（\(g = 9.81\,\text{m/s}^2,\ L = 22.6\,\text{m},\ c = 3.00\times 10^8\,\text{m/s}\)）：
   \[
   v = \frac{9.81 \times 22.6}{3.00\times 10^8}\,\text{m/s} \approx 7.39\times 10^{-7}\,\text{m/s}.
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题以广义相对论最核心的基石——爱因斯坦等效原理为线索，完整重现了物理学史上经典的理论推导与实验验证闭环。第（1）问分别从“光子等效质量能量守恒”与“加速箱狭义相对论多普勒频移”两条路推出一阶红移量 \(\frac{\Delta\lambda}{\lambda_0} = \frac{gL}{c^2}\)，印证向下引力等效于向上加速度 \(a = GM/R^2\)；第（2）问将其落实到哈佛大学高塔 \(22.6\,\text{m}\) 庞德-雷布卡穆斯堡尔共振实验，算得补偿速度仅 \(7.39\times 10^{-7}\,\text{m/s}\)，直观展现穆斯堡尔效应极高的能量分辨本领。
- **递进拆解脉络**：
  1. 第一步（光子等效质量法求引力红移）：利用 \(m = h/(\lambda_0 c)\) 与 \(g' = GM/R^2\) 写能量守恒 \(\frac{hc}{\lambda_0} = \frac{hc}{\lambda'} + mg'L\)，弱场近似得 \(\lambda' \approx \lambda_0(1 + \frac{GML}{R^2c^2})\)。
  2. 第二步（相对论多普勒法求加速箱频移）：在惯性系中算出光走过高度 \(L\) 用时 \(t \approx L/c\)，此时接收器相对发射瞬间源的远离速率为 \(v \approx aL/c\)，一阶多普勒公式给出 \(\lambda'' \approx \lambda_0(1 + \frac{aL}{c^2})\)。
  3. 第三步（等效原理对比）：令 \(\lambda' = \lambda''\)，导出等效加速度 \(a = \frac{GM}{R^2}\)。
  4. 第四步（穆斯堡尔共振补偿计算）：使向下运动的探测器接收到的多普勒蓝移因子 \(1+v/c\) 精确抵消引力红移因子 \(1-gL/c^2\)，导出 \(v = \frac{gL}{c} = 7.39\times 10^{-7}\,\text{m/s}\)。
- **盲解手记**：盲解全程一步到位，清晰把握了弱场与 \(aL \ll c^2\) 条件下仅需保留一阶微扰的原则（二阶相对论时延与洛伦兹因子修正均为 \(O((aL/c^2)^2)\)，在标准广义相对论弱场展开之外故统一舍去），最终所有符号表达式及实验数值 \(7.39\times 10^{-7}\,\text{m/s}\) 与官方完全一致。
- **对照结论**：与官方参考解答百分之百吻合！官方第（1）（i）–（iii）问与第（2）问均采用一阶弱场近似和一阶相对论多普勒展开，其中第（1）（ii）问式⑫巧妙借用 \(\sqrt{\frac{1-\beta}{1+\beta}} = \sqrt{1 - \frac{2\beta}{1+\beta}} \approx 1 - \frac{\beta}{1+\beta} = \frac{1}{1+\beta}\) 来直接得到 \(\lambda'' = \lambda_0(1 + aL/c^2)\)，与标准的泰勒一阶展开 \(1 - \beta\) 在 \(\beta \ll 1\) 下等价。
- **核心难点**：
  - 难点1：严格区分“加速参考系”与“惯性系”的分析视角。必须在无引力的外部惯性系中追踪“光源发射时刻的惯性态”与“光到达时刻接收器的瞬时速度”，不能混用同一瞬时共动速度导致得出多普勒为零的荒谬结论。
  - 难点2：准确理解多普勒补偿方向——引力造成频率变低（红移），探测器必须**向着光源向下运动**才能产生频率升高的蓝移来恢复共振。
- **高频易错点**：
  - 易错点1：在（1）（ii）问错用非相对论或混淆相对运动速度，或在多普勒公式中把接近与远离的 \(1\pm\beta\) 符号写反，得出 \(\lambda'' < \lambda_0\)（蓝移）。
  - 易错点2：保留二阶项导致纠结于非相对论匀加速位移公式 \(\frac{1}{2}at^2\) 是否需要换成双曲运动（实际上题设已明示 \(aL \ll c^2\) 且引力端也是弱场一阶理论，强求二阶展开既超纲也与牛顿引力势不匹配）。
- **教练总结**：处理等效原理与引力红移题时，记住关键的“延迟差速度”图像：光在箱中飞越 \(L\) 耗时 \(\Delta t = L/c\)，箱子在这段飞行时间内额外积累的逃逸速度 \(\Delta v = a\Delta t = aL/c\) 直接贡献多普勒红移 \(\Delta\lambda/\lambda_0 = \Delta v/c = aL/c^2\)。而穆斯堡尔重力红移实验的本质就是用实验室中微米每秒级的机械速度产生 \(10^{-15}\) 量级的多普勒频移去抵消引力频移。

## 16. 氮化镓色散薄膜干涉测厚与双线摆光压转矩平衡 (`cpho-2017-final-theory-problem-slice-q8`)

- **难度评级**：`D4`
- **物理模型**：波动光学与电磁场动量力矩 · 色散介质薄膜干涉定级、斜入射光压与双线摆力矩
- **教学标签**：`色散薄膜干涉`、`半波损失判别`、`干涉级次单调性夹逼`、`光压斜入射动量通量`、`双线摆精确回复力矩`
- **适用层次**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：氮化镓薄膜厚度 \(d\) 与另一加强波长 \(\lambda_2\)**：
   由色散公式 \(n^2 = 2.26^2 + \frac{330.1^2}{\lambda^2 - 265.7^2}\)（\(\lambda\) 以 \(\text{nm}\) 为单位），在 \(\lambda \in [450, 1200]\,\text{nm}\) 内计算端点及已知峰值处折射率：
   \[
   n(450) \approx 2.436, \qquad n(600) \approx 2.3418, \qquad n(1200) \approx 2.278.
   \]
   可见在整个波段内满足 \(n_{\text{air}} = 1 < n_{\text{GaN}}(\lambda) \in [2.278, 2.436] < n_{\text{Si}}(\lambda) \in [3.49, 5.49]\)。
   因此空气-氮化镓界面与氮化镓-硅界面**均发生半波损失**（或均记入 \(\pi\) 相位突变），两束反射光的附加光程差相互抵消！正入射反射最大相干加强条件为：
   \[
   2 n(\lambda) d = m \lambda \quad (m = 1, 2, 3, \dots) \iff \frac{2d}{\lambda} n(\lambda) = m.
   \]
   注意到 \(n(\lambda)\) 与 \(1/\lambda\) 均随 \(\lambda\) 严格单调递减，故 \(f(\lambda) \equiv \frac{n(\lambda)}{\lambda}\) 在 \([450, 1200]\,\text{nm}\) 上严格单调递减！
   设 \(\lambda_1 = 600\,\text{nm}\) 对应干涉级次 \(m_1\)，即 \(2d = \frac{m_1}{f(600)}\)，则任意波长 \(\lambda \in [450, 1200]\,\text{nm}\) 的级次 \(m = m_1 \frac{f(\lambda)}{f(600)}\) 必位于区间：
   \[
   \left[m_1 \frac{f(1200)}{f(600)},\;\; m_1 \frac{f(450)}{f(600)}\right] \approx \left[0.4863\, m_1,\;\; 1.3869\, m_1\right].
   \]
   要使该区间内**仅有 2 个**正整数（其中一个为 \(m_1\)）：
   - \(m_1 = 1 \implies [0.486, 1.387]\)，仅含 \(m = 1\)（1 个，舍去）；
   - \(m_1 = 2 \implies [0.973, 2.774]\)，恰含 \(m = 1, 2\)（**2 个，符合题意！**）；
   - \(m_1 \ge 3 \implies [1.459, 4.161]\) 及更宽，至少含 3 个整数（舍去）。
   故唯一解为 \(m_1 = 2\)，另一加强级次为 \(m_2 = 1\)。由此得氮化镓厚度：
   \[
   d = \frac{2\times 600\,\text{nm}}{2\, n(600)} = \frac{600}{2.3418}\,\text{nm} \approx 256.2\,\text{nm}\ (\approx 256\,\text{nm}).
   \]
   另一加强波长 \(\lambda_2\)（\(m_2 = 1\)）满足：
   \[
   \frac{\lambda_2}{n(\lambda_2)} = 2d = \frac{1200}{2.3418} \approx 512.42\,\text{nm}.
   \]
   将 \(\lambda_2^2 = (2d)^2 n^2\) 代入色散方程，得关于 \(n^2\) 的一元二次方程：
   \[
   (n^2 - 2.26^2)\left((2d)^2 n^2 - 265.7^2\right) = 330.1^2 \implies 2.41 n^4 - 12.95 n^2 + 2.31 = 0.
   \]
   解出符合范围的实根 \(n(\lambda_2) \approx 2.2786\)，对应波长为：
   \[
   \lambda_2 \approx 1168\,\text{nm}\ (1167.6\,\text{nm}) \in [450, 1200]\,\text{nm}
   \]
   （另一小根在紫外区 \(\sim 220\,\text{nm}\)，不在测量波段内，舍去）。

2. **第（2）问：强激光的电场强度有效值 \(E\)**：
   - **激光辐射压力矩**：
     真空中平均能量密度 \(w = \varepsilon_0 E^2\)（\(E\) 为有效值），正入射全吸收面光压为 \(P_0 = w = \varepsilon_0 E^2\)。
     当样品绕 \(OO'\) 轴转过角度 \(\alpha\) 时（\(|\alpha| < \frac{\pi}{2}\)），涂层表面面积 \(ab\) 在垂直光束截面上的投影面积减为 \(ab\cos\alpha\)：
     - **左半面（全吸收，面积 \(\frac{ab}{2}\)）**：单位时间吸收光束沿传播方向的动量为 \(P_0\frac{ab}{2}\cos\alpha\)，其垂直于板面的力分量为 \(P_0\frac{ab}{2}\cos^2\alpha\)（或直接乘以力臂 \(\frac{a}{4}\cos\alpha\)），对 \(OO'\) 产生的反抗力矩为 \(P_0\frac{a^2 b}{8}\cos^2\alpha\)；
     - **右半面（全反射，面积 \(\frac{ab}{2}\)）**：垂直板面的镜面反射使法向动量改变量加倍，所受纯法向辐射压力为 \(2P_0\frac{ab}{2}\cos^2\alpha\)，力臂为 \(\frac{a}{4}\)，产生驱动转动的力矩为 \(2P_0\frac{a^2 b}{8}\cos^2\alpha\)。
     因此光压对样品的净合力矩为：
     \[
     L_p = P_0 \frac{a^2 b}{8}\cos^2\alpha = \frac{1}{8}\varepsilon_0 E^2 a^2 b \cos^2\alpha.
     \]
   - **双线摆重力回复力矩**：
     两根竖直细线长度为 \(a\)，悬点间距亦为 \(a\)。当样品水平转动 \(\alpha\) 后，细线偏离竖直方向的角度 \(\beta\) 满足几何关系（底边绕中心转角 \(\alpha\)，悬点到端点水平弦长为 \(2\cdot\frac{a}{2}\sin\frac{\alpha}{2} = a\sin\frac{\alpha}{2}\)）：
     \[
     \sin\beta = \frac{a\sin(\alpha/2)}{a} = \sin\frac{\alpha}{2} \implies \beta = \frac{\alpha}{2}.
     \]
     样品总质量 \(M = (\rho' d' + \rho d)ab\)。由竖直方向受力平衡，每根细线拉力 \(N\) 满足 \(2 N\cos\beta = M g\)，水平分力 \(N\sin\beta = \frac{1}{2}Mg\tan\frac{\alpha}{2}\)。在水平面内，连接原投影点与转动后挂点的直线到中心 \(OO'\) 的力臂为 \(\frac{a}{2}\cos\frac{\alpha}{2}\)，故双线拉力提供的回复力矩为：
     \[
     L_N = 2\left(N\sin\frac{\alpha}{2}\right)\left(\frac{a}{2}\cos\frac{\alpha}{2}\right) = \frac{1}{2}M g a \sin\frac{\alpha}{2} = \frac{1}{2}(\rho' d' + \rho d)a^2 b g \sin\frac{\alpha}{2}
     \]
     （亦可直接由上升高度 \(\Delta h = a(1 - \cos\frac{\alpha}{2})\) 对势能 \(M g\Delta h\) 求导 \(\frac{dU_g}{d\alpha}\) 一步秒得！）。
   - **力矩平衡求解 \(E\)**：
     令 \(L_p = L_N\)，几何尺寸 \(a^2 b\) 完美消去：
     \[
     \frac{1}{8}\varepsilon_0 E^2 \cos^2\alpha = \frac{1}{2}(\rho' d' + \rho d)g\sin\frac{\alpha}{2} \implies E = \frac{2}{\cos\alpha}\sqrt{\frac{(\rho' d' + \rho d)g\sin(\alpha/2)}{\varepsilon_0}}.
     \]

3. **第（3）问：数值求解平衡转角 \(\alpha\)**：
   代入 \(E = 5.00\times 10^4\,\text{V/m}\)，\(d' = 3.00\times 10^{-4}\,\text{m}\)，\(\rho' = 2.33\times 10^3\,\text{kg/m}^3\)，\(\rho = 6.10\times 10^3\,\text{kg/m}^3\)，\(d = 2.562\times 10^{-7}\,\text{m}\)，\(\varepsilon_0 = 8.85\times 10^{-12}\,\text{F/m}\)，\(g = 9.80\,\text{m/s}^2\)：
   \[
   \rho' d' = 0.699\,\text{kg/m}^2, \qquad \rho d \approx 1.56\times 10^{-3}\,\text{kg/m}^2, \qquad \rho' d' + \rho d \approx 0.7006\,\text{kg/m}^2,
   \]
   \[
   \frac{\sin(\alpha/2)}{\cos^2\alpha} = \frac{\varepsilon_0 E^2}{4(\rho' d' + \rho d)g} = \frac{8.85\times 10^{-12}\times (5.00\times 10^4)^2}{4\times 0.7006\times 9.80} \approx 8.06\times 10^{-4}.
   \]
   因右端极小，\(\alpha \ll 1\)，作小角近似 \(\sin(\alpha/2) \approx \frac{\alpha}{2}\)、\(\cos\alpha \approx 1\)：
   \[
   \alpha \approx 2\times 8.057\times 10^{-4}\,\text{rad} \approx 1.61\times 10^{-3}\,\text{rad}\ (\approx 0.0923^\circ).
   \]

### Phase 2：对照参考解答与教学拆解

- **物理图像与模型总览**：本题作为决赛压轴大题，将半导体薄膜光学测量与微纳光力机械（光压扭秤）深度融合。第（1）问通过辨别空气-氮化镓-硅三层折射率的单调递增关系排除附加半波损失差，并结合色散函数 \(n(\lambda)/\lambda\) 的单调性夹逼出唯一干涉级次组合 \((m_1=2, m_2=1)\)；第（2）（3）问通过精妙的双线摆（Bifilar Pendulum）与左右非对称光压涂层平衡，利用斜入射截面积投影与法向动量传递导出精确力矩方程，并消去样品宏观几何尺寸 \(a, b\) 算出微弱激光辐射压力导致的毫弧度级偏转。
- **递进拆解脉络**：
  1. 第一步（检验半波损失与单调夹逼干涉级次）：算出 \(n_{\text{GaN}} \in [2.278, 2.436]\) 介于空气 \(1\) 与硅 \(3.49\sim 5.49\) 之间，确定上下界面均有半波损失故相消，增强条件为 \(2nd = m\lambda\)。由 \(n(\lambda)/\lambda\) 在 \([450, 1200]\,\text{nm}\) 的端点比值 \([0.486, 1.387]\) 锁定 \(600\,\text{nm}\) 必为 \(k_1 = 2\) 级、另一峰为 \(k = 1\) 级。
  2. 第二步（求薄膜厚度 \(d\) 与第二加强波长 \(\lambda_2\)）：由 \(2n(600)d = 2\times 600\,\text{nm}\) 解得 \(d \approx 256\,\text{nm}\)；将 \(\lambda_2 = 2dn(\lambda_2)\) 代回色散关系解四次/二次方程得 \(\lambda_2 \approx 1168\,\text{nm}\)。
  3. 第三步（推导斜入射光压净力矩）：由电磁能量密度 \(w = \varepsilon_0 E^2\) 得正入射全吸收压强 \(P_0 = \varepsilon_0 E^2\)；转角 \(\alpha\) 后考虑光束截取截面缩减因子 \(\cos\alpha\) 与力臂/法向投影因子 \(\cos\alpha\)，算出全反射与全吸收两半区转矩之差 \(L_p = \frac{1}{8}\varepsilon_0 E^2 a^2 b\cos^2\alpha\)。
  4. 第四步（导出双线摆重力回复力矩及平衡求 \(\alpha\)）：由线长 \(a\) 与间距 \(a\) 推得细线偏角 \(\beta = \alpha/2\)（或势能虚功 \(\frac{d}{d\alpha}[Mga(1-\cos\frac{\alpha}{2})]\)），得 \(L_N = \frac{1}{2}M g a\sin\frac{\alpha}{2}\)；令 \(L_p = L_N\) 消去 \(a^2 b\) 求出 \(E\)，并在小角近似下解得 \(\alpha \approx 1.61\times 10^{-3}\,\text{rad}\)。
- **盲解手记**：盲解全程严密自洽。第（1）问用 \(f(\lambda) = n(\lambda)/\lambda\) 单调区间一举锁定 \(m_1 = 2, m_2 = 1\)，精确数值 \(d = 256.21\,\text{nm},\ \lambda_2 = 1167.59\,\text{nm}\)；第（2）问同时用“斜弦线水平张力几何力臂法”与“上升高度重力势能求导法”互验了双线摆精确大角回复力矩 \(\frac{1}{2}M g a\sin\frac{\alpha}{2}\)，并对吸收端（沿光束方向力 \(\propto\cos\alpha\) 乘以投影力臂 \(\frac{a}{4}\cos\alpha\)）与反射端（纯法向力 \(\propto 2\cos^2\alpha\) 乘以原力臂 \(\frac{a}{4}\)）做了细致的物理矢量分解。
- **对照结论**：主体物理公式与结论与官方参考解答完全一致！但通过精确复算与图像审读发现了**三处有价值的官方勘误与差异**：（1）**Word 草稿漏印残影**：官方解答第 24、25 页中紧贴主推导出现蓝色重复残影 `\alpha \approx 0.5167 rad \alpha \approx 0.5167 rad`（应系命题组早期用更大激光场强试算的废弃草稿遗留在 `.doc` 文件中误印出，与式⑳ `1.62 \times 10^{-3} rad` 无关）；（2）**小角近似笔误**：官方第 25 页式⑳前文字误写为“小角度近似 \(\sin\alpha \approx \alpha\)”，实际公式中出现的是 \(\sin(\alpha/2)\)（而官方代入数值时正确按 \(\sin(\alpha/2) \approx \alpha/2\) 乘以了 2！）；（3）**数值舍入微差**：盲解以未修约的 \(d = 256.21\,\text{nm}\) 算出 \(\frac{\sin(\alpha/2)}{\cos^2\alpha} = 8.057\times 10^{-4}\) 及 \(\alpha \approx 1.61\times 10^{-3}\,\text{rad}\)，而官方第 25 页式⑲–⑳给出 \(8.12\times 10^{-4}\) 与 \(1.62\times 10^{-3}\,\text{rad}\)（约 \(0.7\%\) 中间修约差异）。此外官方在式⑫将反射端也写成 `(2P_0 \frac{ab}{2}\cos\alpha)\cdot\frac{a}{4}\cos\alpha`，虽然结果 \(\cos^2\alpha\) 相同，但严格从矢量力学讲：反射面受力是纯法向（力臂 \(\frac{a}{4}\)），两个 \(\cos\alpha\) 分别来自“拦截光束截面积缩小”与“光子法向动量投影”；吸收面受力才沿光束方向（一个 \(\cos\alpha\) 来自截面积，另一个来自斜力臂投影）。
- **核心难点**：
  - 难点1：含强色散薄膜的多峰排查——折射率 \(n(\lambda)\) 本身随波长变化，不可当作常数直接简单取比例，必须结合 \(n(\lambda)/\lambda\) 的单调性严格限定级次整数个数为 2。
  - 难点2：双线摆大转角下的三维几何关系——转动后两根细线在空间成异面斜拉态，必须看出水平弦长等于 \(a\sin(\alpha/2)\) 才能求出线倾角 \(\beta = \alpha/2\) 与水平力臂 \(\frac{a}{2}\cos(\alpha/2)\)（或者改用高度上升势能求导 \(\frac{dU_g}{d\alpha}\)，极大幅度降低三维空间想象出错概率！）。
- **高频易错点**：
  - 易错点1：忘记校验氮化镓与硅的相对折射率大小，误以为“下界面不发生半波损失”或“全都不发生半波损失”，若错加了半波长 \(\lambda/2\) 会算错厚度 \(d\) 与 \(\lambda_2\)。
  - 易错点2：光压斜入射时漏掉一个 \(\cos\alpha\)（只算了受光面积投影 \(\cos\alpha\) 而忘了力的有效力矩投影 \(\cos\alpha\)，错得 \(\cos\alpha\) 一次方而非 \(\cos^2\alpha\)），或把电磁波平均能量密度错写成 \(\frac{1}{2}\varepsilon_0 E^2\)（对有效值 \(E = E_0/\sqrt{2}\)，总能量密度 \(\frac{1}{2}\varepsilon_0 E^2 + \frac{1}{2\mu_0}B^2 = \varepsilon_0 E^2\)，勿遗漏磁场那一半能量！）。
  - 易错点3：双线摆求力矩时误以为细线偏角 \(\beta = \alpha\) 或忘记两根线的力臂也随 \(\alpha\) 缩减为 \(\frac{a}{2}\cos\frac{\alpha}{2}\)。
- **教练总结**：（1）双线摆在任意大转角 \(\alpha\) 下的通用技巧：**几何难画就上虚功势能法**！算出底杆端点与顶悬点水平距 \(a\sin(\alpha/2)\)，立得竖直缩短量 \(a\cos(\alpha/2)\) 与重力势能 \(Mga(1-\cos(\alpha/2))\)，对 \(\alpha\) 求导一行写出精确回复力矩 \(\frac{1}{2}Mga\sin(\alpha/2)\)；（2）平面电磁波光压公式记住 \(P_{\text{abs}} = \varepsilon_0 E_{\text{rms}}^2 = \frac{1}{2}\varepsilon_0 E_0^2\)，斜入射在平板法向产生的力矩与垂直压强均按 \(\cos^2\alpha\) 衰减。
