## 1. 复赛第1题 · 正交平凸柱面间的等厚干涉椭圆条纹 (`cpho-2016-semifinal-theory-problem-slice-q1`)

- **难度评级**：`D2`
- **核心物理模型**：三维正交外切柱面近轴空气膜厚度近似与薄膜等厚干涉光程差模型
- **教学标签**：`等厚干涉`、`半波损失`、`牛顿环推广`、`三维曲面几何近似`、`傍轴条件`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **三维柱面几何与空气膜厚度分布**：
   上侧平凸透光柱面半径为 \(R_1\)，其过切点 \(O(0,0,0)\) 的母线为 \(Y\) 轴（轴线平行于 \(Y\) 轴，平面在上、凸面在下）；下侧平凸透光柱面半径为 \(R_2\)，其过切点 \(O\) 的母线为 \(X\) 轴（轴线平行于 \(X\) 轴，平面在下、凸面在上）。
   - 对于上侧柱面上的任意近轴点 \((x, y, z_1)\)，其在 \(X\text{-}Z\) 截面内满足 \(x^2 + (R_1 - z_1)^2 = R_1^2\)，即 \(z_1 = R_1(1 - \cos\alpha_1) = 2R_1\sin^2(\alpha_1/2)\)，其中 \(x = R_1\sin\alpha_1\)。在傍轴条件 \(|x| \ll R_1\)（即 \(|\alpha_1| \ll 1\)）下，利用小角近似 \(\sin\theta \approx \theta\)，得：
     \[
     z_1(x, y) \approx \frac{x^2}{2 R_1} \ge 0
     \]
   - 同理，下侧柱面在 \(Y\text{-}Z\) 截面内满足 \(y^2 + (R_2 + z_2)^2 = R_2^2\)。在傍轴条件 \(|y| \ll R_2\) 下，其上表面的 \(z\) 坐标为：
     \[
     z_2(x, y) \approx -\frac{y^2}{2 R_2} \le 0
     \]
   - 因此，在水平坐标 \((x, y)\) 处两柱面之间的空气间隙厚度（沿 \(Z\) 轴方向）为：
     \[
     d(x, y) = z_1(x, y) - z_2(x, y) \approx \frac{x^2}{2 R_1} + \frac{y^2}{2 R_2}
     \]

2. **傍轴反射光程差与半波损失**：
   由于 \(R_1, R_2\) 远大于干涉区最大间隙 \(d_{\max}\)，干涉区内曲面切面倾角 \(\alpha_1 \approx x/R_1 \ll 1\)、\(\alpha_2 \approx y/R_2 \ll 1\)，沿 \(-Z\) 方向垂直傍轴入射的光线经折射和反射后均近似平行于 \(Z\) 轴，反射光线 1（上柱面下表面反射）与光线 2（下柱面上表面反射后返回）在原坐标 \((x, y)\) 附近相遇干涉（斜入射导致的横移与 \(\cos\theta\) 修正均为更高阶小量）。
   - 设两透光柱面介质折射率均大于空气折射率 \(n_0 = 1.00\)：
     - **光线 1**：从光密介质（上柱面）射向光疏介质（空气）分界面反射，**无半波损失**；
     - **光线 2**：透射进入空气（折射无半波损失），在下柱面上表面（空气 \(\to\) 光密介质）反射，**存在半波损失**（附加相位突变 \(\pi\)，等价光程 \(\frac{\lambda}{2}\)），再折射返回上柱面（无半波损失）。
   - 故两相干光在 \((x, y)\) 处的总光程差为：
     \[
     \Delta L = 2 n_0 d(x, y) + \frac{\lambda}{2} = 2 n_0 \left(\frac{x^2}{2 R_1} + \frac{y^2}{2 R_2}\right) + \frac{\lambda}{2} = n_0\left(\frac{x^2}{R_1} + \frac{y^2}{R_2}\right) + \frac{\lambda}{2}
     \]

3. **第 \(k\) 级亮纹投影曲线方程**：
   亮纹干涉加强条件为 \(\Delta L = k\lambda\)。由于 \(d(x, y) \ge 0\)，在切点 \(O\)（\(d = 0\)）处 \(\Delta L = \frac{\lambda}{2}\) 为中央暗斑（0级暗纹），故亮纹级次只能取正整数 \(k = 1, 2, 3, \dots\)：
   \[
   n_0\left(\frac{x^2}{R_1} + \frac{y^2}{R_2}\right) + \frac{\lambda}{2} = k\lambda \implies \frac{x^2}{R_1} + \frac{y^2}{R_2} = \frac{(2k - 1)\lambda}{2 n_0}
   \]
   代入空气折射率 \(n_0 = 1.00\)，化为标准椭圆方程：
   \[
   \frac{x^2}{A_k^2} + \frac{y^2}{B_k^2} = 1, \qquad A_k = \sqrt{\left(k - \frac{1}{2}\right)\frac{R_1 \lambda}{n_0}} = \sqrt{\left(k - \frac{1}{2}\right) R_1 \lambda}, \quad B_k = \sqrt{\left(k - \frac{1}{2}\right)\frac{R_2 \lambda}{n_0}} = \sqrt{\left(k - \frac{1}{2}\right) R_2 \lambda} \quad (k = 1, 2, 3, \dots)
   \]
   （注：若按部分教材以 \(k'=0,1,2,\dots\) 编号亮纹，则将 \(2k-1\) 替换为 \(2k'+1\)，几何轨迹完全相同。）

4. **极限自检**：
   - 量纲检验：\([R_1 \lambda] = \text{m}^2\)，开方得半轴长度量纲 \(\text{m}\)。
   - 退化极限：当 \(R_1 = R_2 = R\) 时，椭圆退化为圆 \(x^2 + y^2 = (k - \frac{1}{2})\lambda R\)，与标准牛顿环亮环半径公式 \(r_k = \sqrt{(k - 1/2)\lambda R}\) 完全吻合。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解最终方程、椭圆半轴表达式及级次取值 \(k=1,2,\dots\) 与官方参考解答完全一致。官方解答先追踪光线 \(1\) 经 \(P\to Q\to P'\) 折射反射后与光线 \(2'\) 相遇，分 9 个公式细致证明了傍轴条件下 \(P'Q \approx PQ \approx z_P - z_Q\) 与 \(z_{P'} \approx z_P\)，步骤严谨详尽；盲解则抓住傍轴小倾角直接略去高阶横向偏移，推导路径更简明紧凑。
- **核心难点**：
  - 难点1：准确区分两个正交柱面的母线方向与弯曲方向——母线沿 \(Y\) 轴的柱面反而只在 \(X\) 方向弯曲（\(z_1 \propto x^2\)），母线沿 \(X\) 轴的柱面只在 \(Y\) 方向弯曲（\(z_2 \propto -y^2\)），初学者极易把 \(x\) 与 \(y\) 弄反。
  - 难点2：说明为何在曲面上斜入射仍可用垂直间隙 \(2n_0 d\) 计算光程差（基于 \(R_1, R_2 \gg d_{\max}\) 的傍轴条件）。
- **高频易错点**：
  - 易错点1：把『过切点的母线为 \(Y\) 轴』误解为柱面沿 \(Y\) 方向弯曲，导致椭圆半轴中 \(R_1\) 与 \(R_2\) 互换。
  - 易错点2：漏掉下柱面上表面反射的半波损失 \(\lambda/2\)，或者错误地对上下两面都加半波损失，导致 \(k - 1/2\) 错写为 \(k\)。
  - 易错点3：亮纹级次 \(k\) 误从 \(0\) 开始取（忽略了 \(d \ge 0\) 且中心 \(O\) 处应为暗斑）。
- **教练总结**：牛顿环的本质是二次曲面间的等厚干涉；当两个曲率半径沿正交主方向分布时，间隙函数天然表现为 \(\frac{x^2}{2R_1} + \frac{y^2}{2R_2}\) 的二次型，等厚线即从圆推广为椭圆，求解时务必先用『母线方向不变、垂直母线方向弯曲』检验坐标对应关系。

## 2. 复赛第2题 · 密闭水罐与观察柱热膨胀下的水位及气体热容量 (`cpho-2016-semifinal-theory-problem-slice-q2`)

- **难度评级**：`D3`
- **核心物理模型**：理想气体状态方程 + 液体热膨胀静水压平衡耦合准静态热力学过程模型
- **教学标签**：`热力学第一定律`、`准静态过程做功`、`液体热膨胀`、`连通器静水压强`、`变过程热容量`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **状态参量与基本几何量**：
   - 水罐内横截面积 \(S = \pi\left(\frac{D}{2}\right)^2 = \pi \times (1.00\text{ m})^2 = \pi\text{ m}^2\)，罐高 \(H = 2.00\text{ m}\)。
   - 观察柱内横截面积 \(s = \pi\left(\frac{d}{2}\right)^2 = \pi \times (0.0200\text{ m})^2 = 4.00\times 10^{-4}\pi\text{ m}^2\)，面积比 \(\varepsilon = \frac{s}{S} = 4.00\times 10^{-4}\)。
   - 初态（清晨密闭时）：\(t_1 = 4.0^\circ\text{C}\)，\(T_1 = 277.15\text{ K}\)，罐内外水位相等 \(h_1 = 1.00\text{ m}\)，罐内封闭空气压强 \(p_1 = p_0 = 1.01\times 10^5\text{ Pa}\)，空气体积 \(V_{a1} = S(H - h_1) = \pi\text{ m}^3\)，水总体积 \(V_{w1} = (S + s)h_1\)。

2. **第（1）问：中午时观察柱内水位 \(h_c\)**：
   气温缓慢升至 \(t_2 = 24.0^\circ\text{C}\)，即 \(T_2 = 297.15\text{ K}\)，温升 \(\Delta T = 20.0\text{ K}\)。
   - 忽略蒸发与罐体、观察柱热膨胀，水的热膨胀系数 \(\kappa = 3.03\times 10^{-4}\text{ K}^{-1}\)，则 \(\kappa\Delta T = 6.06\times 10^{-3}\)。由质量守恒，中午时水的密度与总体积分别为：
     \[
     \rho_2 = \frac{\rho_0}{1 + \kappa\Delta T} \approx 993.98\text{ kg/m}^3, \qquad V_{w2} = (S + s)h_1(1 + \kappa\Delta T)
     \]
   - 设中午时罐内水位为 \(h_t\)、观察柱内水位为 \(h_c\)、罐内空气压强为 \(p_2\)。由水体积守恒、底部连通器静水压强平衡与理想气体状态方程联立：
     \[
     S h_t + s h_c = (S + s) h_1 (1 + \kappa\Delta T) \implies h_t = (1 + \varepsilon)h_1(1 + \kappa\Delta T) - \varepsilon h_c
     \]
     \[
     p_2 = p_0 + \rho_2 g (h_c - h_t), \qquad \frac{p_2 (H - h_t)}{T_2} = \frac{p_0 (H - h_1)}{T_1}
     \]
   - 消去 \(p_2\) 与 \(h_t\)，记 \(A = (1+\varepsilon)h_1(1+\kappa\Delta T) = 1.006462\text{ m}\)，得到关于 \(h_c\) 的一元二次方程：
     \[
     \left[p_0 + \rho_2 g\big((1+\varepsilon)h_c - A\big)\right]\left(H - A + \varepsilon h_c\right) = p_0 (H - h_1)\frac{T_2}{T_1}
     \]
     代入数据解出正根（另一负根/超界根舍去）：
     \[
     h_c = 1.8181\text{ m} \approx 1.82\text{ m}
     \]
     同时求得 \(h_t = 1.00574\text{ m} > h_1\)，\(\Delta h = h_c - h_t = 0.8124\text{ m}\)，\(p_2 = 1.08913\times 10^5\text{ Pa}\)。
     （注：由于观察柱截面积 \(s\) 极小，在求 \(h_c\) 时即使忽略 \(\varepsilon\) 引起的罐内水位微降，也会得到 \(h_c \approx 1.822\text{ m}\)，三位有效数字仍为 \(1.82\text{ m}\)；但在第 2 问求气体体积变化时，柱中水柱体积占水膨胀总体积约 \(5.7\%\)，不可忽略 \(\varepsilon\)！）

3. **第（2）问：罐内空气对外做功 \(W\)、吸热 \(Q\) 与热容量 \(C\)**：
   - **关键物理洞察**：虽然部分水被压入观察柱，但罐内水因受热膨胀增高约 \(6.06\text{ mm}\)，远大于水流进细观察柱引起的液面下降 \(0.32\text{ mm}\)，因此罐内水位净升高 \(h_t - h_1 = +5.735\times 10^{-3}\text{ m}\)，罐内空气体积反而被**压缩**：
     \[
     \Delta V_a = V_{a2} - V_{a1} = -S(h_t - h_1) = -0.01802\text{ m}^3 < 0
     \]
   - **做功计算**：由于温度缓慢升高，整个过程为准静态过程；且体积相对变化 \(|\Delta V_a|/V_{a1} \approx 0.57\% \ll 1\)，压强随温度（从而随体积）几乎呈线性变化（\(p\) 从 \(1.010\times 10^5\text{ Pa}\) 升至 \(1.089\times 10^5\text{ Pa}\)），可用平均压强计算准静态功（并可数值积分校核）：
     \[
     W = \int_{V_{a1}}^{V_{a2}} p\,\mathrm{d}V_a \approx \frac{p_1 + p_2}{2} \Delta V_a = \frac{1.0100\times 10^5 + 1.0891\times 10^5}{2} \times (-0.018018) \approx -1.891\times 10^3\text{ J} \approx -1.89\times 10^3\text{ J}
     \]
     （直接沿着平衡路径对 \(T \in [T_1, T_2]\) 精确积分得 \(W = -1890.9\text{ J}\)，梯形平均压强近似误差不足 \(0.01\%\)。）
   - **内能变化与吸热**：空气在常温下主要为双原子分子理想气体（自由度 \(i = 5\)），由理想气体状态方程 \(\nu R = \frac{p_0 V_{a1}}{T_1} = \frac{1.01\times 10^5 \times \pi}{277.15} = 1144.87\text{ J/K}\)，得内能增量：
     \[
     \Delta U = \frac{5}{2} \nu R \Delta T = 2.5 \times 1144.87 \times 20.0 = 5.724\times 10^4\text{ J} \approx 5.72\times 10^4\text{ J}
     \]
     由热力学第一定律，空气吸收的热量为：
     \[
     Q = \Delta U + W = 5.7244\times 10^4 - 1.891\times 10^3 = 5.535\times 10^4\text{ J} \approx 5.54\times 10^4\text{ J}
     \]
   - **过程中空气的热容量**：
     \[
     C = \frac{Q}{\Delta T} = \frac{5.5353\times 10^4}{20.0} = 2.768\times 10^3\text{ J/K} \approx 2.77\times 10^3\text{ J/K}
     \]
     （比定容热容量 \(C_V = 2.86\times 10^3\text{ J/K}\) 略小，正体现了气体在升温过程中同时被略微压缩、外界对其做正功。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解的所有物理结论与数值结果均与官方参考解答高度一致：官方解答算得 \(\Delta h = 0.812\text{ m}\)、\(l_1 = 1.82\text{ m}\)、\(\Delta V = 0.0180\text{ m}^3\)，并在做功部分给出了平均压强法（\(-1.889\times 10^3\text{ J}\)）以及两种解析积分近似法（\(-1.890\times 10^3\text{ J}\) 与 \(-1.896\times 10^3\text{ J}\)），与盲解精确值 \(-1.891\times 10^3\text{ J}\) 吻合极好；\(\Delta U = 5.724\times 10^4\text{ J}\)、\(\Delta Q = 5.535\times 10^4\text{ J}\)、\(C = 2.77\times 10^3\text{ J/K}\) 完全一致。对照时发现官方式 (4) 下标将 \(\Delta h\) 误印为 \(\Delta h_1\)，且官方将做功修约为两位有效数字 \(-1.9\times 10^3\text{ J}\) 而其余量保留三位有效数字。
- **核心难点**：
  - 难点1：打破『气体升温膨胀必然对外做正功』的直觉定势——本题中水受热膨胀体积（约 \(1.90\times 10^{-2}\text{ m}^3\)）是挤入细观察柱水体积（约 \(1.02\times 10^{-3}\text{ m}^3\)）的近 19 倍，导致气体实际被压缩做负功。
  - 难点2：在近似尺度上做好分级取舍——观察柱内径 \(4.00\text{ cm}\) 虽远小于水罐内径 \(2.00\text{ m}\)，但在计算气体体积变化 \(\Delta V_a\) 时占了 \(5.7\%\) 的贡献，不能在体积方程中轻易忽略；而在求 \(W\) 时利用 \(\Delta p/p_0 \ll 1\) 取平均压强则精度极高。
- **高频易错点**：
  - 易错点1：忽略水的热膨胀（或忘了同步更新中午水密度 \(\rho_2\)），不仅会让 \(h_c\) 算错成 \(1.74\text{ m}\)，更会把做功符号算反成正值。
  - 易错点2：直接套用等压功 \(p_0\Delta V\) 估算做功（产生近 \(4\%\) 偏差），或将做功符号写成 \(+1.89\times 10^3\text{ J}\) 导致 \(Q\) 与 \(C\) 偏大。
  - 易错点3：把『热容量』误算成比热容或摩尔热容，未注意单位应为 \(\text{J/K}\)。
- **教练总结**：热学综合题出现多种微小变化量（液体热膨胀、连通器细管液柱变化、容器内气压变化）时，务必先用数量级估算比较各项大小，再决定哪些小量可略、哪些决定了最终符号与有效数字；非标准准静态过程若压强/体积变化平缓，『平均压强 \(\times \Delta V\)』往往兼具极高精度与极大计算优势。

## 3. 复赛第3题 · 太阳质量骤减后地球相对木星的逃逸判据 (`cpho-2016-semifinal-theory-problem-slice-q3`)

- **难度评级**：`D2`
- **核心物理模型**：圆轨道天体瞬时解绑后的相对速度合成与二体引力逃逸判据模型
- **教学标签**：`开普勒第三定律`、`逃逸速度`、`矢量相对速度`、`极值比较法`、`二体约化质量`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：相对速度 \(v_{ej}\) 与不被俘获的最小速率 \(v_0\)**：
   太阳质量突然变为零的瞬间，地球与木星的瞬时位置和速度均来不及发生突变，仍保持此前各自绕太阳做匀速圆周运动的状态。
   - 设太阳质量 \(m_s \gg m_j, m_e\)，由万有引力提供向心力，地球与木星绕太阳的速率分别为：
     \[
     v_e = \sqrt{\frac{G m_s}{r_e}}, \qquad v_j = \sqrt{\frac{G m_s}{r_j}}
     \]
   - 太阳系中行星均沿同一方向（同向）绕太阳公转。设太阳为原点，某一瞬时木星与太阳连线和地球与太阳连线夹角为 \(\theta\)，因各自线速度均垂直于各自向径且转向相同，故 \(\vec{v}_e\) 与 \(\vec{v}_j\) 的夹角也为 \(\theta\)。由余弦定理，地球相对木星的速度大小为：
     \[
     v_{ej} = |\vec{v}_e - \vec{v}_j| = \sqrt{v_e^2 + v_j^2 - 2 v_e v_j \cos\theta} = \sqrt{G m_s\left(\frac{1}{r_e} + \frac{1}{r_j} - \frac{2\cos\theta}{\sqrt{r_e r_j}}\right)}
     \]
     （注：若假设两者反向公转，则上式 \(-2\cos\theta\) 变为 \(+2\cos\theta\)，相对速率更大。）
   - 此时地球与木星之间的距离为：
     \[
     r_{ej} = \sqrt{r_e^2 + r_j^2 - 2 r_e r_j \cos\theta}
     \]
   - 太阳消失后系统仅剩地球和木星相互作用。在两星质心系中，当总机械能 \(E_{\text{cm}} = \frac{1}{2}\mu v_{\text{rel}}^2 - \frac{G m_e m_j}{r_{ej}} \ge 0\)（其中 \(\mu = \frac{m_e m_j}{m_e + m_j}\)）时，地球不被木星引力俘获，所需最小相对速率为 \(\sqrt{\frac{2G(m_j + m_e)}{r_{ej}}}\)。题目已指出木星质量约为地球的 \(318\) 倍（\(m_j \gg m_e\)，且未设 \(m_e\) 符号），故忽略地球反冲（\(m_j + m_e \approx m_j\)，误差约 \(0.3\%\)），得：
     \[
     v_0 = \sqrt{\frac{2 G m_j}{r_{ej}}} = \sqrt{\frac{2 G m_j}{\sqrt{r_e^2 + r_j^2 - 2 r_e r_j \cos\theta}}} = \frac{(2 G m_j)^{1/2}}{(r_e^2 + r_j^2 - 2 r_e r_j \cos\theta)^{1/4}}
     \]

2. **第（2）问：讨论地球此后是否会围绕木星转动**：
   判断依据是：若 \(v_{ej} \ge v_0\)（\(E_{\text{cm}} \ge 0\)），地球相对木星做抛物线或双曲线逃逸，不会围绕木星转动；若 \(v_{ej} < v_0\)，则被木星俘获。
   - 地球公转周期 \(T_e = 1\text{ y}\)，木星公转周期 \(T_j \approx 12\text{ y}\)。由开普勒第三定律：
     \[
     \alpha \equiv \frac{r_j}{r_e} = \left(\frac{T_j}{T_e}\right)^{2/3} = 144^{1/3} \approx 5.24
     \]
   - 考察最有利于被木星俘获的极值位置：随着 \(\cos\theta\) 从 \(-1\) 增至 \(+1\)，\(v_{ej}(\theta)\) 单调减小，而 \(v_0(\theta)\) 因距离 \(r_{ej}\) 减小而单调增大！因此**在 \(\theta = 0\)（日、地、木三体同侧共线，地球最接近木星且速度同向）处**，比值 \(v_{ej}/v_0\) 取得全局最小值：
     \[
     v_{ej,\min} = v_e - v_j = \sqrt{\frac{G m_s}{r_e}}\left(1 - \frac{1}{\sqrt{\alpha}}\right) \approx 0.563 \sqrt{\frac{G m_s}{r_e}}
     \]
     \[
     v_{0,\max} = \sqrt{\frac{2 G m_j}{r_j - r_e}} = \sqrt{\frac{G m_s}{r_e}}\sqrt{\frac{2 m_j / m_s}{\alpha - 1}}
     \]
   - 代入数据 \(m_s \approx 2.0\times 10^{30}\text{ kg}\)，\(m_j \approx 1.9\times 10^{27}\text{ kg}\)（\(\frac{m_j}{m_s} = 9.5\times 10^{-4}\)）：
     \[
     \left(\frac{v_{ej}}{v_0}\right)_{\min} = \frac{1 - 5.24^{-1/2}}{\sqrt{\frac{2\times 9.5\times 10^{-4}}{5.24 - 1}}} \approx \frac{0.563}{0.0212} \approx 26.6 \gg 1
     \]
     （即便采用精确二体约化质量修正 \(m_j \to m_j + m_e \approx 1.003 m_j\)，或假设反向公转，结论均更强成立。）
   - 因此对任意夹角 \(\theta\) 恒有 \(v_{ej} \gg v_0\)，地球相对木星总机械能严格为正，**太阳质量突然为零后，地球不会围绕木星转动**（将沿双曲线轨线脱离木星飞向深空）。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）问的全部公式、极值论证及结论（比值约 26）与官方参考解答高度吻合。官方解答同时给出了『整体考察比值函数极小值』与『先算 \(\theta = 0\) 再论证 \(\theta\ne 0\) 单调性』两种路线。需要特别指出的是：官方解法（二）式 (14) 在计算 \(\theta = 0\) 处的 \(v_0\) 时，前置系数写为 \(0.44\sqrt{2m_j}\)（似把 \((5.2 - 1)^{-1/2} \approx 0.488\) 误按 \(5.2^{-1/2} \approx 0.439\) 估算），但不影响数量级远小于 \(v_{ej}\) 的最终判断；此外官方直接忽略了地球质量，盲解则从质心系约化质量出发严格证明其正当性。
- **核心难点**：
  - 难点1：题干未直接给出地球公转周期 \(T_e = 1\text{ y}\) 与 \(r_j/r_e\)，需要自主调用常识 \(T_e = 1\text{ y}\) 并联立开普勒第三定律反推轨道半径之比。
  - 难点2：准确运用『最不利边界放缩法』——无须逐一求解任意 \(\theta\) 的轨道，只需证明在 \(v_{ej}\) 最小且 \(v_0\) 最大的共线位置 \(\theta = 0\) 仍满足 \(v_{ej} \gg v_0\) 即可全盘定论。
- **高频易错点**：
  - 易错点1：把地球绕太阳速度直接拿来与逃逸木星速度比较，忘记必须转换到木星参考系求相对速度 \(v_{ej} = |\vec{v}_e - \vec{v}_j|\)。
  - 易错点2：用几何位置三角形余弦定理时误把 \(\vec{v}_e - \vec{v}_j\) 的夹角算成 \(\pi - \theta\)，从而错把 \(-2\cos\theta\) 写成 \(+2\cos\theta\)。
  - 易错点3：只考虑了 \(\theta = 0\) 就下结论而未论证 \(\theta \ne 0\) 时 \(v_{ej}\) 更大、\(v_0\) 更小的单调性。
- **教练总结**：当题目出现带参数 \(\theta\) 的不等式判定（如『是否会被俘获』）时，最优策略不是盲目画图分类，而是抓住函数单调性证明『最有利俘获的极端构型（\(\theta=0\)）依然失败』，即可一锤定音。

## 4. 复赛第4题 · 弹性蹦极绳无损下落超重加速与悬点张力 (`cpho-2016-semifinal-theory-problem-slice-q4`)

- **难度评级**：`D4`
- **核心物理模型**：变质量连续体 U 型折叠绳保守下落（机械能守恒 + 整体/弯折微元动量定理）模型
- **教学标签**：`变质量系统`、`连续体机械能守恒`、`悬链动量定理`、`超重力加速度`、`平滑弯折微元分析`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：下落距离 \(y\)（\(y < L\)）处的速度、加速度及其上限**：
   在 \(0 \le y < L\) 阶段，弹性绳尚未被向下拉紧，因绳在自身重力下几乎不可伸长，故弹性势能忽略，又题设不考虑水平运动和能量损失，系统机械能守恒。
   - **几何与运动学分布**：取桥面为重力势能零点，\(y\) 轴竖直向下。当物块 \(M\) 下落距离 \(y\) 时，折弯最低点位于深度 \(\frac{L+y}{2}\)：
     - 左侧悬挂段长为 \(\frac{L+y}{2}\)，质量 \(m_{\text{左}} = \frac{m(L+y)}{2L}\)，各处静止（速度为 0），质心深度 \(\frac{L+y}{4}\)；
     - 右侧下落段长为 \(\frac{L-y}{2}\)，质量 \(m_{\text{右}} = \frac{m(L-y)}{2L}\)，整体以与物块 \(M\) 相同的速度 \(v = \dot{y}\) 竖直下落，质心深度 \(y + \frac{L-y}{4} = \frac{L+3y}{4}\)。
   - **机械能守恒**：初态 \(y = 0, v = 0\)，初能量 \(E_0 = -mg\frac{L}{4}\)。任意位置 \(y\) 处的总机械能为：
     \[
     E(y) = \frac{1}{2}\left(M + \frac{m(L-y)}{2L}\right) v^2 - M g y - \frac{m(L+y)}{2L}g\frac{L+y}{4} - \frac{m(L-y)}{2L}g\frac{L+3y}{4}
     \]
     化简绳的重力势能项：\((L+y)^2 + (L-y)(L+3y) = 2L^2 + 4Ly - 2y^2\)，故绳势能增量 \(\Delta U_{\text{绳}} = -\frac{mgy(2L - y)}{4L}\)。由 \(E(y) = E_0\) 得：
     \[
     \frac{2ML + m(L - y)}{4L} v^2 = \frac{g y \left[4ML + m(2L - y)\right]}{4L}
     \]
     从而求得下落速度大小：
     \[
     v(y) = \sqrt{g y \frac{4ML + 2mL - my}{2ML + mL - my}} = \sqrt{g y \left(2 + \frac{my}{2ML + mL - my}\right)}
     \]
   - **加速度 \(a(y)\)**：令 \(B = (2M + m)L\)，则 \(v^2 = g \frac{2By - my^2}{B - my}\)。利用 \(a = \frac{\mathrm{d}v}{\mathrm{d}t} = \frac{1}{2}\frac{\mathrm{d}(v^2)}{\mathrm{d}y}\) 对 \(y\) 求导：
     \[
     a(y) = \frac{g}{2}\frac{(2B - 2my)(B - my) + m(2By - my^2)}{(B - my)^2} = \frac{g}{2}\frac{2B^2 - 2Bmy + m^2 y^2}{(B - my)^2}
     \]
     注意到代数恒等式 \(2B^2 - 2Bmy + m^2 y^2 = (B - my)^2 + B^2\)，上式可化为极简形式：
     \[
     a(y) = \frac{g}{2}\left[1 + \left(\frac{2ML + mL}{2ML + mL - my}\right)^2\right] = g\left[1 + \frac{m y (4ML + 2mL - my)}{2(2ML + mL - my)^2}\right]
     \]
     可见 \(a > g\)（超重下落），因为无能量损失时弯折处通过张力对下落段向下做正功。
   - **速度与加速度上限**：在区间 \(y \in [0, L)\) 上，\(v(y)\) 与 \(a(y)\) 的分子单调增（对 \(v^2\) 而言随 \(y\) 严格递增）、分母严格单调减，故两者均在 \(y \to L^-\) 时趋于上确界（上限）：
     \[
     v_{\max} = \lim_{y\to L^-} v(y) = \sqrt{2gL\left(1 + \frac{m}{4M}\right)} = \sqrt{2gL + \frac{m}{2M}gL}
     \]
     \[
     a_{\max} = \lim_{y\to L^-} a(y) = \frac{g}{2}\left[1 + \left(\frac{2M + m}{2M}\right)^2\right] = g\left[1 + \frac{m(4M + m)}{8M^2}\right]
     \]

2. **第（2）问：左端悬点 \(b\) 处张力 \(T_b\)**：
   - **整体动量定理法**：取整条绳与物块 \(M\) 为系统，\(y\) 轴向下为正。总向下动量为：
     \[
     P(y) = \left[M + \frac{m(L - y)}{2L}\right] v = \frac{B - my}{2L} v
     \]
     外力合力向下为 \((M + m)g - T_b\)。由质点系动量定理 \(\frac{\mathrm{d}P}{\mathrm{d}t} = (M + m)g - T_b\)：
     \[
     \frac{\mathrm{d}P}{\mathrm{d}t} = \frac{B - my}{2L} a - \frac{m}{2L} v^2
     \]
     代入 \(a\) 与 \(v^2\)：
     \[
     \frac{\mathrm{d}P}{\mathrm{d}t} = \frac{g}{2L}\left[(B - my) + \frac{my(2B - my)}{2(B - my)} - \frac{my(2B - my)}{B - my}\right] = \frac{g}{2L}\left[(B - my) - \frac{my(2B - my)}{2(B - my)}\right]
     \]
     利用 \(M + m = \frac{B + mL}{2L}\)，解得左端悬点张力：
     \[
     T_b = (M + m)g - \frac{\mathrm{d}P}{\mathrm{d}t} = \frac{mg}{2L}\left[L + y + \frac{y(4ML + 2mL - my)}{2(2ML + mL - my)}\right] = mg\frac{L+y}{2L} + \frac{m}{4L}v^2
     \]
   - **弯折处稳恒参考系物理解释**：以速度 \(v/2\) 随 U 形底端一起向下运动的参考系中，绳以速率 \(v/2\) 从右侧绕过底端进入左侧，无能量损耗意味着弯折处两侧张力连续相等 \(T_{\text{左}} = T_{\text{右}} = T_0\)，而质量流率 \(\dot{\mu} = \frac{m}{L}\frac{v}{2}\) 速度从 \(+v/2\) 变为 \(-v/2\)（动量改变量 \(v\)），故 \(2T_0 = \dot{\mu} v = \frac{m}{2L}v^2 \implies T_0 = \frac{m}{4L}v^2\)。左侧绳段静止，悬点张力即为左侧绳段自重 \(m_{\text{左}}g\) 与弯折张力 \(T_0\) 之和！
   - **边界检验**：\(y = 0\) 时 \(v=0, a=g, T_b = \frac{1}{2}mg\)；\(y \to L^-\) 时 \(T_b \to \frac{3}{2}mg + \frac{m^2 g}{8M}\)。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解的最终表达式与官方解答完全一致（包括 \(v(y)\)、\(a(y)\) 的两种等价写法、\(v_{\max}, a_{\max}\) 及 \(T_b\)）。第（2）问官方提供了三种解法：解法一先对底端微元 \(\mathrm{d}y/2\) 列动量定理并结合能量守恒导数证明两侧张力相等 \(F_1 = F_2\)，解法二、三用整体系统动量定理与右侧牛顿定律联立。对照时还发现官方解法一存在两处瑕疵：其一，式 (13)-(16) 将 \(F_1, F_2\) 定义为张力大小却在向下为正的方程中解出负值 \(F_1 = F_2 = -\frac{1}{2}\frac{m}{L}\frac{\mathrm{d}y}{2}g - \frac{1}{4}\frac{m}{L}v^2\)，符号约定不够自洽；其二，式 (14) 漏写了微元 \(\mathrm{d}y/2\) 的重力。盲解的『全系统动量定理直接代入 \(a(y)\)』与『随动系稳恒流法』完全规避了微元无穷小量符号混用的陷阱。
- **核心难点**：
  - 难点1：理解『无能量损失的折叠绳下落加速度大于 \(g\)』的反直觉物理机制——当右段绳进入静止左段时，若无耗散则其动能必然通过弯折张力向下传递回右段及物块，导致超重加速。
  - 难点2：第（2）问悬点张力既含静止段重量 \(m_{\text{左}}g\)，又含底端弯折动量流冲击项 \(\frac{1}{4}\lambda v^2\)（注意是 \(1/4\) 而非非弹性碰撞锁链的 \(1/2\)）。
- **高频易错点**：
  - 易错点1：受常见落链模型误导，以为右段绳与物块自由落体（\(a = g, v = \sqrt{2gy}\)），完全忽略了机械能守恒下弯折张力的向下牵引。
  - 易错点2：使用变质量动量定理 \(\mathrm{d}P/\mathrm{d}t\) 时忘记 \(M_{\text{动}}(y)\) 随时间减小会产生 \(-\frac{m}{2L}v^2\) 的质量迁移项，导致张力系数错算成 \(+\frac{1}{2}\lambda v^2\) 或 \(0\)。
  - 易错点3：在 \(y\) 接近 \(L\) 求上限时误用 \(M\gg m\) 把 \(m\) 全部舍掉，从而丢失了题干专门考查的高阶修正项。
- **教练总结**：连续变质量折叠绳问题必须先辨明『耗散落链（底端无张力传递，\(a=g\)）』与『保守弹力绳（无耗散，\(T_0 = \frac{1}{4}\lambda v^2\) 向下加速，\(a>g\)）』的本质分野；计算内部或支点反力时，优先对含静止段在内的**全系统**列总体动量定理 \(F_{\text{外}} = \mathrm{d}P_{\text{总}}/\mathrm{d}t\)，避免在弯折微元上丢失高阶或符号项。

## 5. 复赛第5题 · 涂覆石墨烯细绳拉伸传感器的应变、电阻与磁场 (`cpho-2016-semifinal-theory-problem-slice-q5`)

- **难度评级**：`D3`
- **核心物理模型**：倾斜椭圆绕组几何变形 + 并联/串接接触电阻网络 + 远场磁偶极子轴向磁场模型
- **教学标签**：`传感器应变建模`、`椭圆周长近似`、`接触电阻网络`、`毕奥-萨伐尔定律`、`模型对比辨析`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

**注记（关于原题图缺失的说明）**：原题正文提及“（见图 b）”，但在 2016 年官方复赛 PDF 试题第 3 页中并未印出图 b。盲解阶段严格依据文字描述与图 a 几何参数重构拉伸后的缝隙结构，同时辨析电路拓扑的两种物理可能。

1. **第（1）问之一：拉伸后传感器的伸长率 \(\varepsilon\)**：
   - **未拉伸时的几何与原长**：塑料棒半径为 \(r_2\)，细绳半径为 \(r_1\)（\(t \ll r_1 \ll r_2\)），共紧密缠绕 \(N\)（\(N \gg 1\)）圈。每圈绳所在平面与塑料棒横截面成夹角 \(\theta\)，切圆柱面形成椭圆环，其短半轴为 \(b = r_2' = r_2 + r_1 + t \approx r_2\)，长半轴为 \(a = r_2'/\cos\theta \approx r_2/\cos\theta\)。利用题给椭圆周长公式，单圈绳长为：
     \[
     l = \pi\left(3\frac{a+b}{2} - \sqrt{ab}\right) \approx \frac{\pi r_2}{2}\left(\frac{3}{\cos\theta} - \frac{2}{\sqrt{\cos\theta}} + 3\right)
     \]
     在棒轴线方向，相邻两倾斜圆环平面间的垂直距离至少为绳直径 \(2r_1\)（否则在圆柱两侧 \(y=\pm r_2\) 处相邻细绳将互相交叠），故每圈沿轴向所占螺距为 \(p = \frac{2r_1}{\cos\theta}\)。因此未拉伸时两电极间原长为：
     \[
     L_0 = N \frac{2r_1}{\cos\theta}
     \]
     （注：若直接按图 a 示意图顶部圆截面水平紧挨读取轴向间距 \(2r_1\)，则原长记为 \(L_0' = 2Nr_1\)。）
   - **拉伸后的长度与伸长率**：拉伸后出现 \(n\) 个缝隙，每个缝隙中的整圈绳调整为“未封闭圆环（长 \(2\pi r_2\)）+ 两段平行轴线的短直线段”。由单圈总绳长 \(l\) 守恒，两短直线段总长为：
     \[
     l_{\text{直}} = l - 2\pi r_2 \approx \frac{\pi r_2}{2}\left(\frac{3}{\cos\theta} - \frac{2}{\sqrt{\cos\theta}} - 1\right)
     \]
     由于圆环自身沿轴向仍占宽度 \(2r_1\)，该缝隙的总轴向宽度为 \(L_{\text{隙}} = l_{\text{直}} + 2r_1\)，替换掉原来一圈的轴向宽度 \(\frac{2r_1}{\cos\theta}\)。故总伸长量为：
     \[
     \Delta L = n\left(L_{\text{隙}} - \frac{2r_1}{\cos\theta}\right) = n\left[\frac{\pi r_2}{2}\left(\frac{3}{\cos\theta} - \frac{2}{\sqrt{\cos\theta}} - 1\right) + 2r_1\left(1 - \frac{1}{\cos\theta}\right)\right]
     \]
     因 \(r_1 \ll r_2\)，第二项 \(2r_1(1 - 1/\cos\theta)\) 远小于第一项，可忽略。因此伸长率为：
     \[
     \varepsilon = \frac{\Delta L}{L_0} \approx \frac{\pi r_2\left(3 - 2\sqrt{\cos\theta} - \cos\theta\right)}{4 r_1} \frac{n}{N}
     \]
     （若取 \(L_0' = 2Nr_1\)，则 \(\varepsilon\) 表达式少一个 \(\cos\theta\) 展开前因子，即分母多 \(\cos\theta\)。）

2. **第（1）问之二与第（2）问：连续螺旋并联模型下的电阻变化率与轴向磁感应强度**：
   考虑到传感器是由**一根连续细绳**紧密缠绕 \(N\) 圈而成（而非互不相连的孤立闭合环），在未拉伸时，每圈绳自身石墨烯涂层沿绳长方向的电阻为：
   \[
   R_e = \rho \frac{l}{2\pi r_1 t} = \frac{\rho r_2}{4 r_1 t \cos\theta}\left(3 - 2\sqrt{\cos\theta} + 3\cos\theta\right)
   \]
   由于紧密缠绕时相邻两圈存在接触电阻 \(R_c\)，对于任意连续螺旋段，电流既可沿该圈绳环绕流过（电阻 \(R_e\)），也可直接经接触面轴向跨接至下一圈（电阻 \(R_c\)）。在 \(N \gg 1\) 下，每一紧密接触单元等价于 \(R_e\) 与 \(R_c\) **并联**：
   - **未拉伸状态**：总电阻 \(R_0 \approx N\frac{R_e R_c}{R_e + R_c}\)，每圈环绕电流为 \(I_{\text{环}} = I\frac{R_c}{R_e + R_c}\)。倾斜椭圆面积在轴线法平面上的投影恰好为圆面积 \(\pi r_2^2\)，故在轴线上距中点 \(O\) 为 \(D\)（\(D \gg L_0\)）的 \(P\) 点产生的轴向磁感应强度为：
     \[
     B_{\text{前}} = \frac{\mu_0 N r_2^2}{2 D^3} \frac{R_c}{R_e + R_c} I
     \]
   - **拉伸状态（出现 \(n\) 个孤立缝隙圈）**：若每个缝隙中的整圈绳与左右相邻椭圆圈均脱离接触，则每个独立缝隙打破 \(2\) 处相邻接触（即 \(2n\) 圈失去并联分流通道而承载全部电流 \(I\)，若缝隙相邻或按单边断接计则为 \(n\) 圈）。以每缝隙断 2 个接触计：
     \[
     R_{\text{后}} = (N - 2n)\frac{R_e R_c}{R_e + R_c} + 2n R_e \implies \frac{\Delta R}{R_0} = \frac{2n}{N}\frac{R_e}{R_c}
     \]
     此时缝隙圈及其邻接边界圈均载有全部电流 \(I\)（直线段平行轴线在轴线上不产生轴向磁场，圆环面积仍为 \(\pi r_2^2\)），故拉伸后 \(P\) 点轴向磁感应强度为：
     \[
     B_{\text{后}} = \frac{\mu_0 r_2^2}{2 D^3} \left[(N - 2n)\frac{R_c}{R_e + R_c} + 2n\right] I = \left(1 + \frac{2n}{N}\frac{R_e}{R_c}\right) B_{\text{前}}
     \]
   - （**重要物理退化极限注记**：由于 \(r_1 \ll r_2\)，沿周向绕一圈的电阻 \(R_e \propto r_2/r_1\) 极大，若接触电阻 \(R_c \ll R_e\)，电流在未拉伸时将几乎全部沿轴向经接触电阻和绳截面直通，此时 \(B_{\text{前}} \approx 0\)，这正是若将未拉伸绕组视为“互不相接、仅靠侧面接触串联的 \(N\) 个独立椭圆环”时的极限情形。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：这是全卷对照最具教学洞察的一题：第一，第（1）问伸长率 \(\varepsilon\) 盲解与官方公式 (5) 完完全全一致（官方亦取 \(L_1 = N\frac{2r_1}{\cos\theta}\) 并化简掉 \(4r_1(\cos\theta - 1)\)）。第二，对照揭晓了两大关键差异与题干/原卷瑕疵：（a）原卷第 3 页在文字中写明『见图 b』但官方 PDF 却漏印了图 b；（b）在电阻与磁场模型上，官方参考解答将『未拉伸时可视为 \(N\) 个椭圆环挨在一起放置』逐字当作**互不连通的闭合独立椭圆环**，认为未拉伸时电流纯沿轴向横向跨过绳截面（两半圆弧并联给出 \(R_1 = \frac{1}{2}\rho\frac{\pi r_1}{l t}\)，与接触电阻 \(R_c\) 串联 \(R_0 \approx N(R_1 + R_c)\)，故未拉伸 \(B_{\text{前}} = 0\)），拉伸后 \(n\) 个缝隙中各有一整圈以单根绳绕行贡献 \(R_2 = \rho\frac{l}{2\pi r_1 t}\) 并替代原 \(2R_c + R_1\)，故仅这 \(n\) 个圆环载流产生 \(B_{\text{后}} = \frac{\mu_0 n r_2^2 I}{2D^3}\)。客观而言，官方模型在文字上存在轻微自相矛盾（闭合独立环无法在拉伸时突然断成『未封闭圆环加两直段』，且官方未考虑与电极及相邻椭圆环如何过渡），而盲解的『连续螺旋 \(R_e \parallel R_c\) 网络』虽在拓扑上更严密，但未计入相邻圈轴向直穿绳截面 \(R_1\) 的横向电阻（实际上因 \(R_1 \ll R_2\) 且若 \(R_c \ll R_2\)，真实物理器件在未拉伸时电流确实主要走轴向、\(B_{\text{前}} \approx 0\)）。两相对照，能让学生彻底看清工程简化模型背后的隐含假设。
- **核心难点**：
  - 难点1：准确理解倾斜缠绕的紧密堆叠几何——两倾斜椭圆沿轴向不互相穿透的最小螺距是 \(2r_1/\cos\theta\) 而非 \(2r_1\)，且拉伸后圆环释放出的多余周长转化为两段平行轴线的直线段。
  - 难点2：辨析未拉伸状态下电流究竟是『沿螺旋绕圈还是直接轴向穿透接触面』——这是决定 \(R_0\) 公式（\(R_1\) 与 \(R_2\) 分子分母完全颠倒）以及未拉伸磁场 \(B_{\text{前}}\) 是否为零的分水岭。
- **高频易错点**：
  - 易错点1：把未拉伸时每圈椭圆周长算成 \(2\pi r_2 / \cos\theta\) 或忘记用题给的椭圆周长近似公式，导致 \(\sqrt{\cos\theta}\) 项全部缺失。
  - 易错点2：按官方模型计算横向电阻 \(R_1\) 时，误按沿绳长度方向（\(l\) 在分子）计算，忽略了轴向穿流时导电路径长度是半圆弧 \(\pi r_1\)、截面积是 \(l t\)（内外两半圆并联还得再乘 \(1/2\)）。
  - 易错点3：拉伸后算变化率 \(\Delta R/R_0\) 时，只减去 1 个 \(R_c\) 而忘记一圈孤立进缝隙会同时断开左右两侧的 **2 个**接触电阻 \(2R_c\)。
- **教练总结**：面对现代新型材料传感器的竞赛改编题，一方面要严格抓紧几何约束（投影螺距、绳长守恒、微元串并联截面）；另一方面当试题给出『可视为……』的理想化措辞时，要善于通过前后问的逻辑互证（如第 2 问同时询问拉伸前后磁场与电阻变化率）去识别出题者预设的等效导电通道。

## 6. 复赛第6题 · 光电倍增管能耗与匀强磁场电子聚焦收集 (`cpho-2016-semifinal-theory-problem-slice-q6`)

- **难度评级**：`D3`
- **核心物理模型**：几何级数级联放大能量记账模型与垂直匀强磁场圆弧轨迹边界约束模型
- **教学标签**：`光电倍增管`、`等比级数求和`、`电荷与能量守恒`、`洛伦兹力圆周运动`、`官方插图勘误`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：放大一个光电子的平均能耗 \(\bar{E}\)**：
   设光阴极电势为 \(0\)，第 \(i\) 倍增极电势为 \(i V\)（\(i = 1, \dots, n\)），阳极电势为 \((n+1)V\)。考查从光阴极逸出的平均 \(1\) 个光电子引发的级联电子流：
   - 光阴极逸出的 \(1\) 个电子中：\(1 - \eta\) 比例直接到达阳极，经过电势差 \((n+1)V\)；\(\eta\) 比例到达第 \(1\) 倍增极（经过电势差 \(V\)）。
   - 由数学归纳法，到达第 \(k\) 倍增极（\(k = 1, \dots, n\)）的电子数为 \(N_k = \eta(\delta\sigma)^{k-1}\)，并在该极激发出 \(\delta N_k\) 个次级电子。
   - **电源法捷径（按各电极净注入电流记账）**：
     - 光阴极净向真空输出 \(1\) 个电子（相当于从电势 \(0\) 最终移至阳极电势 \((n+1)V\)，消耗电源能量 \((n+1)eV\)）；
     - 第 \(k\) 倍增极（\(k = 1, \dots, n\)）吸收 \(N_k\) 个电子并放出 \(\delta N_k\) 个电子，净向级联电路注入 \((\delta - 1)N_k = \eta(\delta - 1)(\delta\sigma)^{k-1}\) 个电子；这些净产生的电子最终全部在阳极被收集，跨越的电势差为 \((n + 1 - k)V\)！
     - （亦可用逐级飞行段求和：\(\bar{E} = eV\big[\eta + (1-\eta)(n+1) + \sum_{k=1}^{n-1}\eta\delta(\delta\sigma)^{k-1}[\sigma + (1-\sigma)(n+1-k)] + \eta\delta(\delta\sigma)^{n-1}\big]\)，代数上与电源法严格恒等。）
   - 故总平均能耗为（记 \(x = \delta\sigma > 1\)，作变换 \(m = n + 1 - k\)）：
     \[
     \bar{E} = eV\left[(n + 1) + \eta(\delta - 1)\sum_{k=1}^{n} x^{k-1}(n + 1 - k)\right] = eV\left[n + 1 + \eta(\delta - 1) x^n \sum_{m=1}^{n} m x^{-m}\right]
     \]
     利用精确求和 \(\sum_{m=1}^{n} m x^{-m} = \frac{x - (n+1)x^{-n+1} + n x^{-n}}{(x-1)^2}\)（或直接利用 \(x > 1, n \gg 1\) 时 \(x^{-n} \ll 1\) 收敛至 \(\frac{x}{(x-1)^2}\)）：
     \[
     \bar{E} = eV\left[n + 1 + \eta(\delta - 1)\frac{(\delta\sigma)^{n+1} - (n+1)\delta\sigma + n}{(\delta\sigma - 1)^2}\right] \approx \frac{\eta(\delta - 1)(\delta\sigma)^{n+1}}{(\delta\sigma - 1)^2} eV
     \]

2. **第（2）问：匀强磁场方向与磁感应强度大小（按原题图 b 共面几何推导）**：
   - **磁场方向**：在原题图 b 中，第 \(i\) 倍增极位于虚线矩形左下角，电子垂直板面向上左方向射出；第 \(i+1\) 倍增极位于右上侧。为使负电荷电子（\(q = -e\)）向右上方（顺时针）偏转落向第 \(i+1\) 倍增极，洛伦兹力 \(\vec{F} = -e\vec{v}\times\vec{B}\) 须指向第 \(i+1\) 倍增极一侧，由左手定则判得磁场 \(\vec{B}\) 方向必须**垂直纸面向里**。
   - **严格按图 b 所绘共面电极位置的求解**：
     在原题图 b 中，第 \(i\) 倍增极与第 \(i+1\) 倍增极的两段粗实线均画在同一底边直线上（\(x_0 \in [0, a]\) 为发射区，\(x \in [2a, 3a]\) 为接收区；虚线矩形另标有垂直高度 \(a\)）。电子以动能 \(E_e\) 垂直发射，回旋半径为 \(r = \frac{\sqrt{2 m_e E_e}}{e B}\)，圆心在底边延线上，无顶壁阻挡时重新落回底边的位置为 \(x = x_0 + 2r\)：
     - 当 \(2r = 2a\)（即 \(r = a\)）时，\([0, a]\) 全部一一映射至 \([2a, 3a]\)，**100% 电子均被直接收集**：
       \[
       B_{\text{opt}} = \frac{\sqrt{2 m_e E_e}}{e a}
       \]
     - 若仅要求“至少收集到一些电子”：只要区间 \([2r, a + 2r]\) 与 \([2a, 3a]\) 有交集即可，即 \(\frac{a}{2} < r < \frac{3a}{2}\)（或含端点），对应磁感应强度范围为：
       \[
       \frac{2\sqrt{2 m_e E_e}}{3 e a} < B < \frac{2\sqrt{2 m_e E_e}}{e a}
       \]
     （**盲解注记**：若图 b 中虚线高度 \(a\) 意味着上方存在吸收壁（\(r \le a\)），或第 \(i+1\) 倍增极实际位于高度 \(a\) 的顶边，则临界区间会收窄并向下平移；此处严格依据原题图 b 所绘两粗实线共线来计算。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：第（1）问盲解与官方公式 (7) 完全一致，且盲解的『净注入电荷跨阳极电势差法』大幅压缩了代数求和步数。第（2）问通过对照查出了 2016 年官方原卷一处极其隐蔽且严重的制图与排版事故：在原卷图 b（第 3 页）和官方解答插图（第 19 页）中，『第 \(i+1\) 倍增级』的粗实线均画在了虚线框底边 \([2a, 3a]\) 处（与第 \(i\) 倍增级在同一条直线上），文字也只字未提两倍增极存在垂直错位；但官方解答式 (8)–(12) 却列出了 \(r_1 = \sqrt{(3a-r_1)^2 + a^2}\)、\(r_2 = \sqrt{(2a-r_2)^2 + a^2}\)、\(r_3 = \sqrt{(2a-r_3)^2 + a^2}\)、\(r_4 = \sqrt{(a-r_4)^2 + a^2}\)，将第 \(i+1\) 倍增级当成位于**高度 \(a\) 的顶边 \([(2a,a), (3a,a)]\)** 来求解，得出 \(r_1 = \frac{5}{3}a, r_2 = r_3 = \frac{5}{4}a, r_4 = a\)，从而得 \(B_{\text{最多}} = \frac{4}{5}\frac{\sqrt{2m_e E_e}}{ea}\) 与收集范围 \(\frac{3}{5}\frac{\sqrt{2m_e E_e}}{ea} \le B \le \frac{\sqrt{2m_e E_e}}{ea}\)！有趣的是，官方解答第 19 页插图甚至把轨迹 1、3、4 硬生生穿过了 \((3a,a)\) 和 \((2a,a)\) 后再向下延伸到画错位置的底边粗实线上；同时官方第 19–20 页出现多处公式编号错位引用（如把 ⑧⑨⑩⑪ 错引为 ⑪⑫⑬⑭、⑬ 错引为 ⑯、⑭⑫ 错引为 ⑮⑰）。
- **核心难点**：
  - 难点1：第（1）问准确处理多级耦合的能量分配——不仅级间传输的 \(\sigma\) 比例要耗能，每级未进入下一级而直接飞往阳极的 \((1-\sigma)\) 电子会一次性跨越余下的 \((n+1-k)V\) 全部电势差。
  - 难点2：第（2）问将圆轨迹边界条件 \(x(y)\) 与发射区、收集区端点的四种临界相交（轨迹 1–4）一一对应，判定最大收集率对应双边界重叠点 \(r_2 = r_3\)。
- **高频易错点**：
  - 易错点1：第（1）问误以为到达第 \(i\) 级的电子从阴极直接加速而来只算一次总电压，或漏掉直飞阳极的那部分电子所消耗的电势差 \((n+1-i)V\)。
  - 易错点2：确定磁场方向时忽略电子带负电（\(q = -e\)），把『垂直纸面向里』答反成『垂直纸面向外』。
  - 易错点3：算 \(\sum_{m=1}^{n} m x^{-m}\) 时套错等比求和与差比求和公式，在 \((\delta\sigma - 1)^2\) 分母上漏掉平方或少乘一个 \(\delta\sigma\)。
- **教练总结**：计算多级分支放大器总功耗，『统计每个电极净吐出的电荷乘以它到最终汇流极（阳极）的电势差』是最不易漏项的通用记账法；处理有界极板间磁聚焦问题，一定要用『左端打最右、左端打最左、右端打最右、右端打最左』四条极值轨迹画出可行域；另外读题审图若发现多余标尺（如图 b 神秘的高度 \(a\)），往往暗示命题人脑海中的真实几何位置！

## 7. 复赛第7题 · 双杆固结与铰接下摆的角加速度及铰链内力 (`cpho-2016-semifinal-theory-problem-slice-q7`)

- **难度评级**：`D3`
- **核心物理模型**：定轴刚体转动（平行轴定理 + 能量守恒）与多刚体光滑铰接瞬时耦合动力学模型
- **教学标签**：`平行轴定理`、`刚体机械能守恒`、`多刚体动力学`、`瞬时角加速度`、`铰链相互作用力`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

初始时 \(A, C\) 位于同一水平线 \(AD\) 上，\(AB = BC = l\) 且 \(\angle ABC = 60^\circ\)，故 \(\triangle ABC\) 构成边长为 \(l\) 的正三角形。取 \(A\) 为原点，水平向右（沿 \(AD\)）为 \(+x\)，竖直向上为 \(+y\)。

1. **第（1）问：两杆在 \(B\) 点固结（刚体绕 \(A\) 定轴转动）**：
   - **（i）初始角加速度 \(\alpha\)**：
     两杆构成一个绕 \(A\) 轴转动的刚体。杆 \(AB\) 对 \(A\) 点的转动惯量 \(I_1 = \frac{1}{3}m l^2\)；在正三角形 \(ABC\) 中，\(A\) 到 \(BC\) 中点（质心 \(G_2\)）的连线即为中线/高，距离 \(AG_2 = \frac{\sqrt{3}}{2}l\)，由平行轴定理得杆 \(BC\) 对 \(A\) 点的转动惯量：
     \[
     I_2 = \frac{1}{12}m l^2 + m\left(\frac{\sqrt{3}}{2}l\right)^2 = \frac{5}{6}m l^2
     \]
     总转动惯量 \(I_A = I_1 + I_2 = \frac{7}{6} m l^2\)。
     初始时刻 \(G_1\) 横坐标 \(x_1 = \frac{1}{4}l\)，\(G_2\) 横坐标 \(x_2 = \frac{3}{4}l\)，总重力对 \(A\) 的顺时针力矩为 \(\tau_A = mg(\frac{l}{4} + \frac{3l}{4}) = mgl\)。故初始角加速度（顺时针）为：
     \[
     \alpha = \frac{\tau_A}{I_A} = \frac{mgl}{\frac{7}{6}ml^2} = \frac{6g}{7l}
     \]
   - **（ii）\(AB\) 杆与 \(AD\) 夹角为 \(\theta\) 时的角速度 \(\omega\)**：
     当 \(AB\) 顺时针摆至与射线 \(AD\) 成夹角 \(\theta\) 时，\(\vec{AB} = l(\cos\theta, -\sin\theta)\)，而刚体整体转过角度 \(\Delta\varphi = \theta - \frac{\pi}{3}\)，\(\vec{BC}\) 与水平方向夹角变为 \(\frac{2\pi}{3} - \theta\)。故两杆质心的 \(y\) 坐标分别为：
     \[
     y_1(\theta) = -\frac{l}{2}\sin\theta, \qquad y_2(\theta) = -l\sin\theta + \frac{l}{2}\sin\left(\frac{2\pi}{3} - \theta\right) = -\frac{3l}{4}\sin\theta + \frac{\sqrt{3}l}{4}\cos\theta
     \]
     初始时（\(\theta_0 = \frac{\pi}{3}\)），\(y_1 + y_2 = -\frac{\sqrt{3}}{2}l\)。由机械能守恒 \(\frac{1}{2}I_A \omega^2 = mg\left[(y_1+y_2)_{\text{初}} - (y_1+y_2)_\theta\right]\)：
     \[
     \frac{7}{12}m l^2 \omega^2 = mgl\left(\frac{5}{4}\sin\theta - \frac{\sqrt{3}}{4}\cos\theta - \frac{\sqrt{3}}{2}\right)
     \]
     \[
     \implies \omega = \sqrt{\frac{3g}{7l}\left(5\sin\theta - \sqrt{3}\cos\theta - 2\sqrt{3}\right)}
     \]
     （自检：\(\theta = \frac{\pi}{3}\) 时 \(\omega = 0\)；对 \(\theta\) 求导验证 \(\frac{1}{2}\frac{\mathrm{d}(\omega^2)}{\mathrm{d}\theta}\big|_{\theta=\pi/3} = \frac{6g}{7l}\)；全摆程最大角 \(\theta_{\max} = \frac{2\pi}{3} + 2\arctan\frac{\sqrt{3}}{5} \approx 158.2^\circ < 180^\circ\)，杆 \(AB\) 始终处于 \(AD\) 下方。）

2. **第（2）问：两杆在 \(B\) 点光滑铰接的初始角加速度与相互作用力**：
   刚撤去外力瞬间，两杆角速度均为零（无向心加速度）。设杆 \(AB\) 顺时针角加速度为 \(\alpha_1\)，杆 \(BC\) 绕其质心顺时针角加速度为 \(\alpha_2\)；设在 \(B\) 点处杆 \(AB\) 对杆 \(BC\) 的作用力为 \(\vec{F} = (F_x, F_y)\)（则杆 \(BC\) 对杆 \(AB\) 作用力为 \(-\vec{F}\)，沿 \(+x\) 右、\(+y\) 上为正）。
   - **运动学约束（\(B\) 点加速度）**：
     \(\vec{a}_B = l\alpha_1\left(-\frac{\sqrt{3}}{2}, -\frac{1}{2}\right)\)。由刚体平面运动，杆 \(BC\) 质心 \(G_2\) 的加速度为 \(\vec{a}_{G2} = \vec{a}_B + \vec{\alpha}_2\times\vec{r}_{BG_2}\)，其中 \(\vec{r}_{BG_2} = \frac{l}{2}(\frac{1}{2}, \frac{\sqrt{3}}{2})\)，顺时针 \(\vec{\alpha}_2 = -\alpha_2\hat{z}\)，故：
     \[
     a_{G2,x} = -\frac{\sqrt{3}}{2}l\alpha_1 + \frac{\sqrt{3}}{4}l\alpha_2, \qquad a_{G2,y} = -\frac{1}{2}l\alpha_1 - \frac{1}{4}l\alpha_2
     \]
   - **动力学方程**：
     1. 杆 \(AB\) 绕固定轴 \(A\) 转动定理（顺时针为正）：
        \[
        \frac{1}{3}m l^2 \alpha_1 = \frac{1}{4}mgl + \frac{l}{2}F_y + \frac{\sqrt{3}l}{2}F_x \qquad \text{(1)}
        \]
     2. 杆 \(BC\) 质心运动定理：
        \[
        m a_{G2,x} = F_x, \qquad m a_{G2,y} = F_y - m g \qquad \text{(2)}
        \]
     3. 杆 \(BC\) 绕质心 \(G_2\) 转动定理（顺时针为正）：
        \[
        \frac{1}{12}m l^2 \alpha_2 = \frac{l}{4}F_y - \frac{\sqrt{3}l}{4}F_x \qquad \text{(3)}
        \]
   - **消元求解**：将 (2) 中 \(F_x, F_y\) 代入 (3) 得：
     \[
     \frac{1}{12}l\alpha_2 = \frac{1}{4}g + \frac{1}{4}l\alpha_1 - \frac{1}{4}l\alpha_2 \implies l\alpha_2 = \frac{3}{4}g + \frac{3}{4}l\alpha_1
     \]
     （亦可用以 \(B\) 点为非惯性基点的惯性力矩方程 \(\frac{1}{3}ml^2\alpha_2 = \frac{1}{4}mgl + ma_B\frac{l}{4}\) 一步得出。）
     将 \(F_x, F_y\) 代入 (1) 得 \(\frac{4}{3}l\alpha_1 = \frac{3}{4}g + \frac{1}{4}l\alpha_2\)。联立解得两杆顺时针初始角加速度：
     \[
     \alpha_1 = \frac{9 g}{11 l}, \qquad \alpha_2 = \frac{15 g}{11 l}
     \]
     回代求得两杆间相互作用力（\(AB\) 对 \(BC\) 向左上拉，\(BC\) 对 \(AB\) 向右下拽）：
     \[
     F_x = -\frac{3\sqrt{3}}{44} m g, \qquad F_y = \frac{1}{4} m g
     \]
     相互作用力大小与方向（与竖直方向夹角 \(\phi\)）：
     \[
     F = \sqrt{F_x^2 + F_y^2} = \frac{\sqrt{37}}{22} m g \approx 0.276\, mg, \qquad \tan\phi = \frac{|F_x|}{F_y} = \frac{3\sqrt{3}}{11} \approx 0.472
     \]
     （即杆 \(BC\) 对杆 \(AB\) 的力沿右下方，偏离竖直向下向右成 \(\arctan\frac{3\sqrt{3}}{11} \approx 25.3^\circ\)。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）两问的全部公式、系数、正负号及数值近似（\(\frac{\sqrt{37}}{22}mg \approx 0.276mg\)、\(\tan\phi = \frac{3\sqrt{3}}{11} \approx 0.472\)）与官方参考解答分毫不差。注意两者仅在互作用力符号正方向选取上互为反作用力（官方设 \(BC\) 对 \(AB\) 为正且 \(y\) 轴向下，故得 \(F_x = +\frac{3\sqrt{3}}{44}mg, F_y = +\frac{1}{4}mg\)，物理方向同为右下偏竖直 \(25.3^\circ\)）。盲解额外补充了以 \(B\) 为参考点的非惯性系转动捷径，且对第（1）（ii）问进行了摆动角范围严格校验。
- **核心难点**：
  - 难点1：第（1）问中，杆 \(BC\) 绕 \(A\) 转动时其自身质心到 \(A\) 的距离不再是简单的 \(l\)，需要发现 \(\triangle ABC\) 为等边三角形，从而利用平行轴定理 \(\frac{1}{12}ml^2 + m(\frac{\sqrt{3}}{2}l)^2\) 精确求出 \(I_2\)。
  - 难点2：第（2）问解耦双杆瞬时运动时，必须严格保留节点 \(B\) 的矢端加速度关系 \(\vec{a}_{G2} = \vec{a}_B + \vec{\alpha}_2\times\vec{r}_{BG2}\) 的正负号，且不可错把静止释放在初瞬的角加速度当成速度。
- **高频易错点**：
  - 易错点1：第（1）问误以为两杆只绕 \(A\) 的转动惯量等于两杆都直接铰在 \(A\) 上的 \(\frac{2}{3}ml^2\)，漏了 \(BC\) 杆离 \(A\) 更远带来的移轴项。
  - 易错点2：第（1）（ii）问写 \(BC\) 杆随 \(AB\) 转角变化时把 \(BC\) 转角方向搞反（顺时针转 \(\theta - \pi/3\) 时 \(BC\) 抬高而非降低）。
  - 易错点3：第（2）问忘记刚撤去外力瞬间 \(\omega_1 = \omega_2 = 0\) 令法向加速度为零，误添加多余未知项，或对 \(AB\) 杆没有绕固定轴 \(A\) 取矩而被 \(A\) 点未知支反力卡住。
- **教练总结**：遇到多杆铰接刚体在『刚释放瞬间（\(\omega=0\)）』求角加速度与内力的问题，核心是『对固定铰链杆绕定轴取矩避开支反力 + 对自由杆列质心牛顿方程与绕质心转动方程 + 用铰接点切向加速度衔接两杆』，切忌在 \(t=0^+\) 误用速度法而应直接写加速度约束。

## 8. 复赛第8题 · LHC 部分子对撞湮灭与轻粒子双光子衰变角 (`cpho-2016-semifinal-theory-problem-slice-q8`)

- **难度评级**：`D2`
- **核心物理模型**：极端相对论无质量部分子对撞四动量守恒与质心系各向同性双光子衰变张角模型
- **教学标签**：`相对论能量动量`、`部分子模型`、`不变质量`、`双光子衰变`、`洛伦兹聚束效应`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：部分子能量比乘积 \(x_a x_b\)**：
   每束质子能量 \(E = 7.0\text{ TeV}\)。因部分子 \(\text{a, b}\) 动能远大于各自静能（极端相对论近似），其总能量与动量分别为：
   \[
   E_a \approx x_a E, \quad p_a \approx \frac{x_a E}{c}; \qquad E_b \approx x_b E, \quad p_b \approx -\frac{x_b E}{c}
   \]
   湮灭生成静质量为 \(m_s = 1.0\text{ TeV}/c^2\) 的新粒子 \(\text{S}\)，由能量与动量守恒：
   \[
   E_s = E_a + E_b = (x_a + x_b) E, \qquad p_s = p_a + p_b = \frac{(x_a - x_b) E}{c}
   \]
   代入相对论质壳关系 \(E_s^2 - p_s^2 c^2 = m_s^2 c^4\)：
   \[
   \left[(x_a + x_b)^2 - (x_a - x_b)^2\right] E^2 = 4 x_a x_b E^2 = m_s^2 c^4
   \]
   \[
   \implies x_a x_b = \frac{(m_s c^2)^2}{4 E^2} = \frac{(1.0\text{ TeV})^2}{4 \times (7.0\text{ TeV})^2} = \frac{1}{196} \approx 5.1\times 10^{-3}
   \]

2. **第（2）问：\(\text{S}\) 静止系中衰变双光子的频率 \(\nu\)**：
   在 \(\text{S}\) 静止参考系中，\(\text{S}\) 衰变为两个光子，由动量守恒 \(\vec{p}_1 + \vec{p}_2 = 0\) 知两光子动量等大反向、频率相等（\(\nu_1 = \nu_2 = \nu\)）。由能量守恒 \(2 h \nu = m_s c^2\)：
   \[
   \nu = \frac{m_s c^2}{2 h} = \frac{1.0\times 10^{12} \times 1.60\times 10^{-19}\text{ J}}{2 \times 6.63\times 10^{-34}\text{ J}\cdot\text{s}} \approx 1.21\times 10^{26}\text{ Hz} \quad (\text{两位有效数字取 } 1.2\times 10^{26}\text{ Hz})
   \]

3. **第（3）问：\(\text{S} \to 2\text{A},\ \text{A} \to 2\gamma\) 实验室等频光子夹角 \(\theta\)**：
   - 在 \(\text{S}\) 静止系中，\(\text{S}\) 衰变为两个质量 \(m_A = 1.0\text{ GeV}/c^2\) 的轻粒子 \(\text{A}\)，由对称性与动量守恒，每个粒子 \(\text{A}\) 能量为 \(E_A = \frac{1}{2}m_s c^2 = 500\text{ GeV}\)，动量 \(p_A c = \sqrt{E_A^2 - m_A^2 c^4}\)。
   - 每个粒子 \(\text{A}\) 再衰变为两个**同频率**光子（设各自能量 \(E_\gamma\)），由能量守恒 \(2 E_\gamma = E_A \implies E_\gamma = \frac{1}{2} E_A = \frac{1}{4} m_s c^2\)，光子动量 \(p_\gamma = \frac{E_A}{2c}\)。
   - 由动量矢量三角形对称性（设两光子夹角为 \(\theta\)），沿 \(\vec{p}_A\) 方向动量守恒有 \(2 p_\gamma \cos(\theta/2) = p_A\)，即：
     \[
     \cos\frac{\theta}{2} = \frac{p_A}{2 p_\gamma} = \frac{p_A c}{E_A} = \sqrt{1 - \left(\frac{m_A c^2}{E_A}\right)^2}
     \]
     故半张角满足（亦可用四动量不变质量 \((p_1+p_2)^2 = m_A^2 c^2\) 一步导出）：
     \[
     \sin\frac{\theta}{2} = \frac{m_A c^2}{E_A} = \frac{2 m_A}{m_s} = \frac{2 \times 1.0\text{ GeV}}{1.0\times 10^3\text{ GeV}} = 2.0\times 10^{-3} \ll 1
     \]
     利用小角近似 \(\sin\alpha \approx \alpha\)，得两光子动量间夹角为：
     \[
     \theta \approx \frac{4 m_A}{m_s} = 4.0\times 10^{-3}\text{ rad}
     \]

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）、（3）问的所有公式推导和数值结果（\(0.0051\)、\(1.2\times 10^{26}\text{ Hz}\)、\(0.0040\)）与官方参考解答完全一致。官方按动量分量方程逐式展开，而盲解利用四动量不变质量 \((p_1+p_2)^2 = m_A^2 c^2\) 可更迅速地看出 \(\sin(\theta/2) = \frac{2m_A}{m_s}\) 的对称本质。
- **核心难点**：
  - 难点1：正确理解部分子模型——两质子对撞时，并不是整个质子与质子整体湮灭，而是携带动量分数 \(x_a, x_b\) 的两个超相对论夸克/胶子对撞产生新粒子 \(\text{S}\)，\(\text{S}\) 通常并非在质子质心系中静止（即 \(x_a\) 不必等于 \(x_b\)）。
  - 难点2：第（3）问利用『两光子同频率』锁定对称衰变构型，从 \(\cos(\theta/2) = \beta_A\) 转换为 \(\sin(\theta/2) = 1/\gamma_A\) 以契合极小角近似。
- **高频易错点**：
  - 易错点1：算第（1）问时误以为 \(x_a = x_b\)，或忘掉正反方向相撞使能量相加而动量相减，漏掉因子 4。
  - 易错点2：第（2）问把 \(1.0\text{ TeV}\) 换算为焦耳时漏乘电子电荷量 \(e = 1.60\times 10^{-19}\text{ C}\) 或错将 \(10^{12}\) 记作 \(10^9\)。
  - 易错点3：第（3）问直接用非相对论或粗暴令 \(p_A \approx E_A/c\) 代入 \(\cos(\theta/2) = p_A c / E_A\) 导致算出 \(\theta = 0\) 的平庸退化结果，必须先用 \(\sin^2(\theta/2) = 1 - \cos^2(\theta/2)\) 精确保留 \(m_A^2 c^4\) 项再做小角近似。
- **教练总结**：极端相对论高能物理题的黄金工具是『四动量不变质量平方 \(E^2 - p^2c^2 = m^2c^4\)』：碰撞合并用 \((p_a+p_b)^2 = m_S^2c^2\) 一秒出 \(4x_ax_bE^2\)；高能母粒子衰变双光子张角用 \((p_1+p_2)^2 = m_A^2c^2\) 一秒出 \(4E_1E_2\sin^2(\theta/2) = m_A^2c^4\)，完美规避 \(\cos\theta \approx 1\) 时的数值相消失效陷阱。

## 9. 决赛第1题 · 大秦铁路重载运煤列车势能回收与功率 (`cpho-2016-final-theory-problem-slice-q1`)

- **难度评级**：`D1`
- **核心物理模型**：重力势能-阻耗-电储能双向能量转换效率及平均输出功率模型
- **教学标签**：`功与能`、`能量转换效率`、`双向行程能量核算`、`临界条件`、`平均功率`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：空车返回大同时剩余的电能 \(E\)**：
   - **去程（大同 \(\to\) 秦皇岛）**：列车与煤总质量 \(m_t + m_c\)，高度下降 \(h_c\)，行驶路程 \(l\)。
     - 损失总重力势能：\(\Delta E_{p1} = (m_t + m_c) g h_c\)；
     - 克服铁轨与空气阻力做功：\(W_{f1} = \mu (m_t + m_c) g l\)；
     - 剩余可供发电机转化的机械能：\(E_{\text{机}} = (m_t + m_c) g (h_c - \mu l)\)（要求 \(h_c > \mu l\)）；
     - 蓄电池储存的总电能：\(E_{\text{存}} = \eta_1 (m_t + m_c) g (h_c - \mu l)\)。
   - **返程（秦皇岛 \(\to\) 大同，空车质量 \(m_t\)）**：
     - 需克服重力和阻力所做的有用机械功：\(W_{\text{需}} = m_t g h_c + \mu m_t g l = m_t g (h_c + \mu l)\)；
     - 消耗的蓄电池电能：\(E_{\text{耗}} = \frac{W_{\text{需}}}{\eta_2} = \frac{m_t g (h_c + \mu l)}{\eta_2}\)。
   - **剩余电能**：
     \[
     E = E_{\text{存}} - E_{\text{耗}} = \eta_1 (m_t + m_c) g (h_c - \mu l) - \frac{m_t g (h_c + \mu l)}{\eta_2}
     \]

2. **第（2）问：刚好能返回大同的最少载煤质量 \(m_{c,\min}\)**：
   令 \(E \ge 0\)（且要求 \(h_c > \mu l\)）：
   \[
   \eta_1 (m_t + m_c)(h_c - \mu l) \ge \frac{m_t (h_c + \mu l)}{\eta_2} \implies m_{c,\min} = \left[\frac{h_c + \mu l}{\eta_1 \eta_2 (h_c - \mu l)} - 1\right] m_t = \frac{(1 - \eta_1\eta_2)h_c + (1 + \eta_1\eta_2)\mu l}{\eta_1 \eta_2 (h_c - \mu l)} m_t
   \]

3. **第（3）问：去程中发电机的平均输出功率 \(P\)**：
   去程运行时间 \(t = \frac{l}{V}\)，发电机输出的总电能为 \(E_{\text{存}}\)，故平均输出功率为：
   \[
   P = \frac{E_{\text{存}}}{t} = \frac{\eta_1 (m_t + m_c) g (h_c - \mu l) V}{l} = \eta_1 (m_t + m_c) g V \left(\frac{h_c}{l} - \mu\right)
   \]

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解三问的符号、结构与最终表达式与官方参考解答完全一致，是决赛中最为基础送分的工程物理背景题。
- **核心难点**：
  - 难点1：准确区分发电阶段（机械能输入转化为电能输出，乘以 \(\eta_1\)）与电动返程阶段（蓄电池输出电能转化为机械功，需要除以 \(\eta_2\)）。
  - 难点2：第（2）问隐含必要物理前提 \(\mu < h_c / l\)（否则下坡重力做功连克服阻力都不够，装再多煤也无法发电）。
- **高频易错点**：
  - 易错点1：把去程阻力做功也错乘进 \(\eta_1\) 里，或返程时错把 \(\eta_2\) 乘在分子上而非除在分母上。
  - 易错点2：返程计算阻力功和重力势能时误把煤的质量 \(m_c\) 也保留下来（忘记在秦皇岛已卸载空车返回）。
  - 易错点3：第（3）问求平均输出功率时漏乘效率因子 \(\eta_1\)（把输入功率当成输出功率）。
- **教练总结**：能量双向转换题目（如抽水蓄能、再生制动列车）最关键的是画清能量流向箭头：『由机械能发电乘效率 \(\eta_1\)，用电能驱动对外做功除效率 \(\eta_2\)』，严防乘除倒置。

## 10. 决赛第2题 · 轻绳悬挂匀质细杆的打击中心与耦合角加速度 (`cpho-2016-final-theory-problem-slice-q2`)

- **难度评级**：`D3`
- **核心物理模型**：质心系冲量-冲量矩打击中心模型与绳-杆双自由度耦合平面动力学模型
- **教学标签**：`打击中心`、`冲量与动量矩定理`、`刚体平面运动`、`非惯性约束消元`、`双摆耦合动力学`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：打击点位置 \(x\) 与初始角速度 \(\omega_0\)**：
   初始时绳与杆均竖直静止下垂。沿水平方向在 \(D\) 点施加瞬时冲量 \(I\) 瞬间，绳只能提供沿竖直方向 \(BO\) 的拉力；由于 \(B\) 点绕 \(O\) 做圆周运动的初速度方向严格水平（竖直速度分量为零），且细杆刚性，质心 \(C\) 的竖直速度分量也为零，故绳中无竖直冲量（有限力在 \(\Delta t\to 0\) 内冲量为零）。
   - 设冲量作用后瞬间杆质心 \(C\) 的水平速度为 \(v_C\)，杆绕质心转动的角速度与 \(B\) 点绕 \(O\) 转动的角速度均为 \(\omega_0\)（同向）。
   - 对杆列水平动量定理、绕质心 \(C\) 冲量矩定理以及刚体运动学关系：
     \[
     m v_C = I, \qquad \frac{1}{12}m l_2^2 \omega_0 = I\left(x - \frac{l_2}{2}\right), \qquad v_B = l_1 \omega_0 = v_C - \frac{l_2}{2}\omega_0
     \]
   - 由运动学关系与动量定理直接解出 \(\omega_0\)（此时绳与杆相当于整条围绕 \(O\) 刚性旋转，故 \(v_C = (l_1 + \frac{l_2}{2})\omega_0\)）：
     \[
     \omega_0 = \frac{I}{m\left(l_1 + \frac{l_2}{2}\right)} = \frac{2 I}{m(2l_1 + l_2)}
     \]
   - 代入冲量矩方程求得 \(x\)（即绳+杆组合摆相对 \(O\) 点的打击中心到 \(B\) 的距离）：
     \[
     x = \frac{l_2}{2} + \frac{m l_2^2 \omega_0}{12 I} = \frac{l_2}{2} + \frac{l_2^2}{6(2l_1 + l_2)} = \frac{l_2(3l_1 + 2l_2)}{3(2l_1 + l_2)}
     \]
     显然 \(\frac{l_2}{2} < x < \frac{2}{3}l_2 < l_2\)，打击点恒在杆上。

2. **第（2）问：一般位形 \((\theta_1, \theta_2, \omega_1, \omega_2)\) 下的角加速度 \(\alpha_1, \alpha_2\)**：
   设绳保持张紧（张力 \(T > 0\)），以 \(O\) 为原点、随绳 \(OB\) 建立正交极坐标基 \(\hat{e}_{r1} = (\sin\theta_1, \cos\theta_1)\)（沿 \(OB\) 向下）与 \(\hat{e}_{\theta 1} = (\cos\theta_1, -\sin\theta_1)\)（逆时针切向，以水平向右、竖直向下为坐标分量），类似定义杆方向基 \(\hat{e}_{r2}, \hat{e}_{\theta 2}\)。
   - **运动学（质心 \(C\) 加速度）**：
     \[
     \vec{a}_B = l_1\alpha_1 \hat{e}_{\theta 1} - l_1\omega_1^2 \hat{e}_{r1}, \qquad \vec{a}_C = \vec{a}_B + \frac{l_2}{2}\alpha_2\hat{e}_{\theta 2} - \frac{l_2}{2}\omega_2^2\hat{e}_{r2}
     \]
   - **动力学**：外力为重力 \(m\vec{g}\)（作用于 \(C\)）与绳张力 \(\vec{T} = -T\hat{e}_{r1}\)（作用于 \(B\)）。
     - 绕质心 \(C\) 转动定理（逆时针增大 \(\theta_2\) 为正）：
       \[
       \frac{1}{12}m l_2^2 \alpha_2 = -\frac{l_2}{2} T \sin(\theta_2 - \theta_1) \implies \frac{T}{m}\sin(\theta_2 - \theta_1) = -\frac{1}{6} l_2 \alpha_2 \qquad \text{(1)}
       \]
     - 质心牛顿第二定律 \(\vec{a}_C = \vec{g} - \frac{T}{m}\hat{e}_{r1}\) 分别向 \(\hat{e}_{\theta 1}\)（直接消去未知张力 \(T\)）和 \(\hat{e}_{r1}\)（直接消去 \(\alpha_1\)）投影，利用 \(\Delta \equiv \theta_2 - \theta_1\)：
       \[
       l_1\alpha_1 + \frac{l_2}{2}\alpha_2\cos\Delta - \frac{l_2}{2}\omega_2^2\sin\Delta = -g\sin\theta_1 \qquad \text{(2)}
       \]
       \[
       -l_1\omega_1^2 - \frac{l_2}{2}\alpha_2\sin\Delta - \frac{l_2}{2}\omega_2^2\cos\Delta = g\cos\theta_1 - \frac{T}{m} \qquad \text{(3)}
       \]
   - **解耦**：由 (3) 解出 \(\frac{T}{m}\) 代入 (1)，一举求得 \(\alpha_2\)：
     \[
     \left(g\cos\theta_1 + l_1\omega_1^2 + \frac{l_2}{2}\omega_2^2\cos\Delta + \frac{l_2}{2}\alpha_2\sin\Delta\right)\sin\Delta = -\frac{1}{6}l_2\alpha_2
     \]
     \[
     \implies \alpha_2 = -\frac{6\left[g\cos\theta_1 + l_1\omega_1^2 + \frac{l_2}{2}\omega_2^2\cos(\theta_2 - \theta_1)\right]\sin(\theta_2 - \theta_1)}{l_2\left[1 + 3\sin^2(\theta_2 - \theta_1)\right]}
     \]
     将 \(\alpha_2\) 回代入 (2)，利用恒等式 \(-\sin\theta_1[1 + 3\sin^2\Delta] + 3\cos\theta_1\sin\Delta\cos\Delta = -\sin\theta_1 + 3\sin\Delta\cos(\theta_1+\Delta) = -\sin\theta_1 + 3\sin(\theta_2-\theta_1)\cos\theta_2\)，整理得 \(\alpha_1\)：
     \[
     \alpha_1 = \frac{-g\sin\theta_1 + 3g\sin(\theta_2 - \theta_1)\cos\theta_2 + \frac{3}{2}l_1\omega_1^2\sin[2(\theta_2 - \theta_1)] + 2 l_2 \omega_2^2 \sin(\theta_2 - \theta_1)}{l_1\left[1 + 3\sin^2(\theta_2 - \theta_1)\right]}
     \]
     （附带校验张力 \(T = \frac{m[g\cos\theta_1 + l_1\omega_1^2 + \frac{l_2}{2}\omega_2^2\cos\Delta]}{1+3\sin^2\Delta} > 0\) 为轻绳不松弛条件。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）问全部结果与官方参考解答完全等价（官方第（2）问中 \(\sin(\theta_1-\theta_2) = -\sin(\theta_2-\theta_1)\)，故 \(\alpha_1, \alpha_2\) 完全一致）。对照可见，官方解答先建立直角坐标系 \(O\text{-}xy\) 列出 \(a_{Bx}, a_{By}, a_{Cx}, a_{Cy}\) 与 \(T\) 联立求解，需从 4 个耦合含三角函数方程中硬消 \(T\) 和坐标二阶导；而盲解沿 \(\hat{e}_{r1}, \hat{e}_{\theta 1}\) 投影一步拆解出 \(T\) 与 \(\alpha_2\)，运算简洁性与物理透明度均更胜一筹。
- **核心难点**：
  - 难点1：第（1）问需严格论证为什么轻绳没有在 \(B\) 点施加竖直冲量（因 \(B\) 在最低点、切向水平，竖直速度恒为零，不产生动量突变）。
  - 难点2：第（2）问面对由绳张力耦合的双摆非线性体系，需准确展开两级相对角加速度及各自离心项 \(\omega_1^2, \omega_2^2\)，并在三角化简中不出错。
- **高频易错点**：
  - 易错点1：第（1）问误把 \(x\) 写成单独细杆绕 \(B\) 的打击中心 \(\frac{2}{3}l_2\)（忽略了绳长 \(l_1\) 引起的整体质心下移 \(v_B = l_1\omega_0 \ne 0\)）。
  - 易错点2：第（2）问写绳张力对质心 \(C\) 的力矩 \(-\frac{l_2}{2}T\sin(\theta_2-\theta_1)\) 时搞反符号，或在投影质心加速度时漏掉 \(\omega_1^2, \omega_2^2\) 项。
  - 易错点3：直角坐标法消元时容易漏用 \(\sin^2\Delta + \cos^2\Delta = 1\) 导致最终分母化简不全。
- **教练总结**：处理绳/杆牵连的平面多刚体动力学题，优先把矢量方程投影到『沿绳方向（自动消去 \(\alpha_1\) 只留张力 \(T\)）』与『垂直绳方向（自动消去张力 \(T\)）』这两个自然正交基上，往往比死算固定直角坐标 \((x, y)\) 快一倍且几乎不出错。

## 11. 决赛第3题 · 火星大气温度廓线与着陆器二次阻力减速 (`cpho-2016-final-theory-problem-slice-q3`)

- **难度评级**：`D3`
- **核心物理模型**：变重力球对称静水力平衡积分模型与平方空气阻力一维动力学微分方程
- **教学标签**：`静流体平衡`、`变重力积分`、`理想气体状态方程`、`平方空气阻力`、`双曲正切解`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：火星大气温度 \(T(h)\) 随高度 \(h\) 的表达式**：
   在高度 \(h\) 处取一水平极薄气层，考虑到第（1）问未限定 \(h \ll R_m\)，引力加速度随高度变化，\(g(h) = \frac{G M_m}{(R_m + h)^2}\)。由球对称静流体平衡：
   \[
   \frac{\mathrm{d}p}{\mathrm{d}h} = -\rho(h) g(h) = -\rho_0 \left(1 + \frac{h}{R_m}\right)^{1-n} \frac{G M_m}{(R_m + h)^2} = -G M_m \rho_0 R_m^{n-1} (R_m + h)^{-(n+1)}
   \]
   由于 \(n > 4\)（不仅保证了总压强积分收敛，也确保球壳总质量 \(\int_{R_m}^\infty 4\pi r^2\rho(r)\mathrm{d}r\) 收敛），由 \(h\) 积分至无穷远（\(p(\infty) = 0\)）：
   \[
   p(h) = \int_h^\infty G M_m \rho_0 R_m^{n-1} (R_m + x)^{-(n+1)}\,\mathrm{d}x = \frac{G M_m \rho_0 R_m^{n-1}}{n}(R_m + h)^{-n} = \frac{G M_m \rho_0}{n R_m}\left(1 + \frac{h}{R_m}\right)^{-n}
   \]
   由稀薄理想气体状态方程 \(p(h) = \frac{\rho(h)}{\mu} R T(h)\)（\(R\) 为普适气体常量），解得温度分布：
   \[
   T(h) = \frac{\mu p(h)}{R \rho(h)} = \frac{\mu}{R} \frac{G M_m \rho_0}{n R_m} \frac{(1 + h/R_m)^{-n}}{\rho_0 (1 + h/R_m)^{1-n}} = \frac{\mu G M_m}{n R (R_m + h)}
   \]
   （自检：当 \(h \to \infty\) 时 \(T(h) \to 0\)；量纲 \([\mu GM_m/(R R_m)] = \text{K}\)。）

2. **第（2）问：着陆器着陆前瞬间的速度大小 \(v_l\)**：
   在远小于 \(R_m\) 的高度下落，火星表面重力加速度 \(g_m = \frac{G M_m}{R_m^2}\) 与表面大气密度 \(\rho(0) = \rho_0\) 均视为常量，且着陆器密度较大可忽略浮力。取竖直向下为正，着陆器下落速度为 \(v(t) \ge 0\)，牛顿第二定律为：
   \[
   m_l \frac{\mathrm{d}v}{\mathrm{d}t} = m_l g_m - k \rho_0 v^2
   \]
   记收尾极限速度 \(v_T = \sqrt{\frac{m_l g_m}{k\rho_0}} = \frac{1}{R_m}\sqrt{\frac{m_l G M_m}{k\rho_0}}\)，分离变量从 \(t = 0, v = 0\) 积分至 \(t = t_l, v = v_l\)：
   \[
   \int_0^{v_l} \frac{\mathrm{d}v}{v_T^2 - v^2} = \frac{k \rho_0}{m_l} t_l = \frac{g_m}{v_T^2} t_l \implies \frac{1}{2 v_T}\ln\left(\frac{v_T + v_l}{v_T - v_l}\right) = \frac{g_m t_l}{v_T^2}
   \]
   解出速度大小 \(v_l\)：
   \[
   v_l = v_T \tanh\left(\frac{g_m t_l}{v_T}\right) = \frac{1}{R_m}\sqrt{\frac{m_l G M_m}{k\rho_0}}\tanh\left(\frac{t_l}{R_m}\sqrt{\frac{k\rho_0 G M_m}{m_l}}\right)
   \]
   （极限校验：\(t_l \to 0\) 或 \(k\to 0\) 时 \(v_l \approx g_m t_l\)；\(t_l \to \infty\) 时趋于收尾速度 \(v_T\)。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）问最终表达式与官方参考解答完全一致。官方解答在第（1）问还额外展示了一种对球冠壳层垂直受力积分的替代证法，且在第 8–10 页遗留了几处蓝色/橙色文档修订残留字符（如重复 \(T(h)\)、\(m_x = 4\pi(R_s+x)^2\cdot\mathrm{d}x\cdot\rho(x)\)）；同时发现官方解答第（2）问式 (13) 误将 \(\rho(h(t))\) 印成 \(\rho_0(h(t))\)，且式 (16) 因取竖直向上为正而保留了负号 \(-v_T\tanh(\dots)\)（但题干明确问的是『瞬间速度的**大小**』）。
- **核心难点**：
  - 难点1：第（1）问不能随意做恒定重力加速度近似，必须看出密度规律中的尺度正是 \(R_m\)，从而引入 \(G M_m/(R_m+h)^2\) 并积分至无穷远。
  - 难点2：第（2）问需识别这是关于时间 \(t_l\)（而非下落高度）的积分，需用 \(\int \frac{\mathrm{d}v}{v_T^2-v^2}\) 得 \(\tanh\) 函数。
- **高频易错点**：
  - 易错点1：第（1）问用 \(g = GM_m/R_m^2\) 常重力近似去积分 \(\rho(h)\)，导致幂次错差 2 阶且与 \(n > 4\) 条件脱节。
  - 易错点2：第（2）问错用对空间积分的 \(v\mathrm{d}v/\mathrm{d}h\) 求解，或者忘记求『速度大小』而在最后保留负号。
  - 易错点3：理想气体状态方程混淆普适气体常数 \(R\) 与玻尔兹曼常数 \(k_B\)（题中已明确给出『摩尔质量 \(\mu\)』，故分母必配 \(R\)）。
- **教练总结**：天体大气剖面题若给出特征尺度为行星半径 \(R_m\)，务必保留万有引力平方反比变化 \(g(h) = GM_m/(R_m+h)^2\) 并从 \(h\) 积分至无穷远；常系数平方阻力动力学则记住『对时间积分出 \(\tanh\)，对位移积分出 \(\sqrt{1-e^{-2x}}\)』。

## 12. 决赛第4题 · 圆偏振激光驱动水中金纳米球旋转与脉冲响应 (`cpho-2016-final-theory-problem-slice-q4`)

- **难度评级**：`D3`
- **核心物理模型**：光子自旋角动量吸收光力矩与黏性液体一阶阻尼弛豫及方波脉冲周期迭代模型
- **教学标签**：`光子角动量`、`光学吸收截面`、`液体黏滞力矩`、`一阶线性弛豫`、`周期脉冲递推`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：激光频率 \(\nu\) 与光强 \(I\)**：
   忽略界面反射与水、玻璃吸收，真空波长 \(\lambda = 830\text{ nm}\)，光斑直径 \(d = 1.20\times 10^{-6}\text{ m}\)，功率 \(P = 20.0\text{ mW}\)：
   \[
   \nu = \frac{c}{\lambda} = \frac{3.00\times 10^8}{830\times 10^{-9}} \approx 3.61\times 10^{14}\text{ Hz}
   \]
   \[
   I = \frac{P}{\pi (d/2)^2} = \frac{4 P}{\pi d^2} = \frac{4 \times 20.0\times 10^{-3}}{\pi \times (1.20\times 10^{-6})^2} \approx 1.77\times 10^{10}\text{ W/m}^2
   \]

2. **第（2）问：金纳米球质量 \(m\) 与绕对称轴转动惯量 \(J\)**：
   球半径 \(R = 100\text{ nm} = 1.00\times 10^{-7}\text{ m}\)，密度 \(\rho = 19.32\times 10^3\text{ kg/m}^3\)：
   \[
   m = \frac{4}{3}\pi R^3 \rho = \frac{4}{3}\pi (1.00\times 10^{-7})^3 \times 19.32\times 10^3 \approx 8.09\times 10^{-17}\text{ kg}
   \]
   \[
   J = \frac{2}{5} m R^2 = \frac{8}{15}\pi \rho R^5 \approx 3.24\times 10^{-31}\text{ kg}\cdot\text{m}^2
   \]

3. **第（3）问：激光驱动力矩大小 \(M\)**：
   吸收光功率 \(P_{\text{abs}} = I\sigma_{\text{abs}}\)（\(\sigma_{\text{abs}} = 0.123\pi R^2\)），单位时间吸收光子数 \(\frac{\mathrm{d}N}{\mathrm{d}t} = \frac{I\sigma_{\text{abs}}}{h\nu}\)。因每个圆偏振光子传递角动量 \(\hbar = \frac{h}{2\pi}\)，力矩大小为（普朗克常量 \(h\) 严格消去！）：
   \[
   M = \hbar \frac{\mathrm{d}N}{\mathrm{d}t} = \frac{I \sigma_{\text{abs}}}{2\pi \nu} = \frac{0.123 R^2 I}{2 \nu} = \frac{0.246 P R^2 \lambda}{\pi d^2 c} \approx 3.01\times 10^{-20}\text{ N}\cdot\text{m}
   \]

4. **第（4）问：稳定旋转时的转速 \(f\)**：
   稳定时驱动力矩与水黏滞阻力矩平衡：\(M = 8\pi \eta R^3 \omega_s = 16\pi^2 \eta R^3 f_s\)，代入 \(\eta = 8.00\times 10^{-4}\text{ Pa}\cdot\text{s}\)：
   \[
   f = f_s = \frac{M}{16\pi^2 \eta R^3} = \frac{I\sigma_{\text{abs}}}{32\pi^3 \eta R^3 \nu} \approx 2.38\times 10^2\text{ Hz}\ (\text{即 } 238\text{ 转/秒})
   \]

5. **第（5）问：连续照射下任意时刻转速 \(f(t)\)**：
   由刚体定轴转动定理 \(J\frac{\mathrm{d}\omega}{\mathrm{d}t} = M - 8\pi \eta R^3 \omega\)，定义转动弛豫特征时间 \(\tau\)：
   \[
   \tau = \frac{J}{8\pi \eta R^3} = \frac{\rho R^2}{15 \eta} = \frac{19.32\times 10^3 \times 10^{-14}}{15 \times 8.00\times 10^{-4}} = 1.61\times 10^{-8}\text{ s}
   \]
   则 \(\frac{\mathrm{d}f}{\mathrm{d}t} = \frac{f_s - f}{\tau}\)。由初值 \(f(0) = 0\) 积分得：
   \[
   f(t) = f_s \left(1 - e^{-t/\tau}\right) = \frac{I\sigma_{\text{abs}}}{32\pi^3 \eta R^3 \nu}\left(1 - e^{-\frac{15\eta}{\rho R^2} t}\right)
   \]
   （代入数值：\(f(t) = 238\left(1 - e^{-6.21\times 10^7 t}\right)\text{ Hz}\)，\(t\) 单位为 \(\text{s}\)。）

6. **第（6）问：方波脉冲周期后的瞬间转速 \(f_n\) 与极限 \(f_{n\to\infty}\)**：
   设第 \(k\) 个完整周期 \((T_1 + T_2)\) 结束时的转速为 \(f_k\)（\(f_0 = 0\)）。在第 \(k+1\) 个周期内：
   - 激光开启时段 \(T_1\)（一阶驰豫趋向 \(f_s\)）：\(f_k' = f_s + (f_k - f_s)e^{-T_1/\tau}\)；
   - 激光间歇时段 \(T_2\)（纯指数阻尼衰减）：\(f_{k+1} = f_k' e^{-T_2/\tau} = f_s(1 - e^{-T_1/\tau})e^{-T_2/\tau} + f_k e^{-(T_1+T_2)/\tau}\)。
   此为一阶线性等比递推 \(f_{k+1} = A + r f_k\)（\(0 < r = e^{-(T_1+T_2)/\tau} < 1\)），由 \(f_0 = 0\) 展开等比数列得：
   \[
   f_n = f_s \frac{\left(1 - e^{-T_1/\tau}\right) e^{-T_2/\tau}}{1 - e^{-(T_1+T_2)/\tau}}\left[1 - e^{-n(T_1+T_2)/\tau}\right], \qquad \tau = \frac{\rho R^2}{15\eta} = \frac{m}{20\pi\eta R}
   \]
   令 \(n \to \infty\) 得第 \(n\) 个完整周期末的极限转速（占空比周期谷值稳态）：
   \[
   f_{n\to\infty} = f_s \frac{\left(1 - e^{-T_1/\tau}\right) e^{-T_2/\tau}}{1 - e^{-(T_1+T_2)/\tau}} = \frac{I\sigma_{\text{abs}}}{32\pi^3\eta R^3 \nu} \frac{e^{T_1/\tau} - 1}{e^{(T_1+T_2)/\tau} - 1}
   \]
   （极限自检：\(T_2 \to 0\) 退化为连续激光解；\(T_1, T_2 \ll \tau\) 时趋于占空比平均转速 \(f_s \frac{T_1}{T_1 + T_2}\)。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解的符号表达式与官方参考解答完全一致（官方亦给出三种同构的等比递推解法）。值得指出的两处数值修约细节差异：在计算第（3）问 \(M\) 和第（4）问 \(f\) 时，官方代入了前问已修约为三位有效数字的 \(I = 1.77\times 10^{10}\text{ W/m}^2\) 与 \(\nu = 3.61\times 10^{14}\text{ Hz}\)，算得 \(M = 3.02\times 10^{-20}\text{ N}\cdot\text{m}\)、\(f = 2.39\times 10^2\text{ s}^{-1}\)；而盲解沿用精确符号式一步代入原始数据，得到更准确的 \(M = 3.01\times 10^{-20}\text{ N}\cdot\text{m}\) 与 \(f = 2.38\times 10^2\text{ Hz}\)。这提示考生考场务必用原始表达式做连算、最后一步再修约。
- **核心难点**：
  - 难点1：光力矩与角动量传递的结合——利用 \(P_{\text{abs}} = \dot{N}h\nu\) 与 \(M = \dot{N}\hbar\) 发现 \(M = \frac{P_{\text{abs}}}{2\pi\nu}\)（即使未给出 \(h\) 也能准确算出）。
  - 难点2：第（6）问方波脉冲切换——每个周期内部是两段不同常微分方程的拼接，只有抓住『周期末瞬态转速递推映射』才能绕开繁杂的分段函数直接写出 \(f_n\) 通项。
- **高频易错点**：
  - 易错点1：把『转速 \(f\)（转数/秒）』直接当作『角速度 \(\omega\)』代入黏滞力矩公式 \(M_f = 8\pi\eta R^3\omega\)，算错 \(2\pi\) 倍。
  - 易错点2：第（1）问使用光斑半径 \(d\) 当作直径或者把水折射率错误地用于改变真空光斑输入功率/频率。
  - 易错点3：第（6）问在写 \(f_{n\to\infty}\) 时写成『激光刚刚结束加速（脉冲峰顶）』的值而忘记题干问的是『完整脉冲周期 \((T_1+T_2)\) 后的瞬间』，漏乘尾段衰减因子 \(e^{-T_2/\tau}\)。
- **教练总结**：计算中间物理量切忌拿修约后的中间数值再回代下一问，必须尽量把符号化简到最简（如本题 \(\tau = \rho R^2/(15\eta)\) 直接消去了 \(\pi\) 与 \(R\) 的高次幂）；面对周期性方波激励的一阶系统，标准解法是『分段求解建映射 \(f_{k+1} = r f_k + A\)，不动点与等比数列求通项』。

## 13. 决赛第5题 · 赛车可调导流翼片最大功率与转弯极限速率 (`cpho-2016-final-theory-problem-slice-q5`)

- **难度评级**：`D4`
- **核心物理模型**：气动附加升/下压力-滚动阻力-矢量静摩擦约束的分段极值优化模型
- **教学标签**：`分类讨论`、`导数极值与边界最值`、`静摩擦矢量极限`、`流体气动下压力`、`非线性约束优化`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：前方上翘（气动升力）直道匀速行驶的最大输出功率**：
   导流翼片前方上翘时，产生向上的气动升力 \(f_B = c_B v^2\)，故地面对车的竖直支持力为：
   \[
   N(v) = m g - c_B v^2 \ge 0 \implies v \le v_{\text{飞}} = \sqrt{\frac{mg}{c_B}}
   \]
   匀速直线行驶时，发动机通过轮胎静摩擦获得的驱动牵引力 \(F_{\text{牵}}\) 平衡迎面空气阻力 \(f_A = c_A v^2\) 与形变地面阻力 \(f_R = \mu_R N\)：
   \[
   F_{\text{牵}}(v) = c_A v^2 + \mu_R (m g - c_B v^2) = \mu_R m g + (c_A - \mu_R c_B) v^2
   \]
   牵引力受限于最大静摩擦力 \(F_{\text{牵}} \le \mu_S N = \mu_S (m g - c_B v^2)\)，整理得不打滑的速率上限 \(v_{\text{滑}}\)：
   \[
   \left[c_A + (\mu_S - \mu_R)c_B\right] v^2 \le (\mu_S - \mu_R)m g \implies v \le v_{\text{滑}} = \sqrt{\frac{(\mu_S - \mu_R) m g}{c_A + (\mu_S - \mu_R)c_B}}
   \]
   因 \(\mu_R < \mu_S\) 且 \(c_A > 0\)，显然 \(N(v_{\text{滑}}) = \frac{c_A m g}{c_A + (\mu_S - \mu_R)c_B} > 0\)，即 \(v_{\text{滑}} < v_{\text{飞}}\)，故可行速度区间为 \(0 \le v \le v_{\text{滑}}\)。在此区间内发动机输出功率为：
   \[
   P(v) = F_{\text{牵}}(v) v = \mu_R m g v + (c_A - \mu_R c_B) v^3, \qquad P'(v) = \mu_R m g + 3(c_A - \mu_R c_B)v^2
   \]
   需按参数 \(c_A\) 与 \(\mu_R c_B\) 的关系分情况讨论 \(P(v)\) 在闭区间 \([0, v_{\text{滑}}]\) 上的最大值：
   - **情况 1：\(c_A \ge \mu_R c_B\)**：\(P'(v) > 0\) 恒成立，\(P(v)\) 单调递增，最大值在右边界 \(v = v_{\text{滑}}\) 处取得：
     \[
     v = \sqrt{\frac{(\mu_S - \mu_R) m g}{c_A + (\mu_S - \mu_R)c_B}}, \qquad P_{\max} = \mu_S c_A \sqrt{\mu_S - \mu_R}\left(\frac{mg}{c_A + (\mu_S - \mu_R)c_B}\right)^{3/2}
     \]
   - **情况 2：\(c_A < \mu_R c_B\)**：三次函数 \(P(v)\) 在 \(v^* = \sqrt{\frac{\mu_R m g}{3(\mu_R c_B - c_A)}}\) 处有导数零点（极大值点），比较 \(v^*\) 与边界 \(v_{\text{滑}}\)：
     - \(v^* \ge v_{\text{滑}} \iff \frac{c_A}{c_B} \ge \frac{2\mu_R(\mu_S - \mu_R)}{3\mu_S - 2\mu_R}\)（边界或区间外极值）：在 \([0, v_{\text{滑}}]\) 上 \(P(v)\) 仍单调递增，最大值仍在 \(v = v_{\text{滑}}\) 处，\(P_{\max}\) 同情况 1；
     - \(v^* < v_{\text{滑}} \iff \frac{c_A}{c_B} < \frac{2\mu_R(\mu_S - \mu_R)}{3\mu_S - 2\mu_R}\)（内部极值）：功率先增后减，在内部驻点处取最大值：
       \[
       v = v^* = \sqrt{\frac{\mu_R m g}{3(\mu_R c_B - c_A)}}, \qquad P_{\max} = \frac{2}{3}\mu_R m g v^* = \frac{2\sqrt{3}}{9}\frac{(\mu_R m g)^{3/2}}{\sqrt{\mu_R c_B - c_A}}
       \]

2. **第（2）问：水平圆周道路匀速率行驶的最大速率 \(v_{\max}\) 与翼片朝向**：
   不计轮胎形变地面阻力（\(\mu_R = 0\)）。设地面支持力 \(N' = m g + \varepsilon c_B v^2\)（后方上翘下压力取 \(\varepsilon = +1\)，前方上翘升力取 \(\varepsilon = -1\)），且要求不飞离地面 \(N' \ge 0\)。
   水平面内，地面静摩擦力必须同时提供**切向驱动力**（平衡空气阻力 \(f_t = c_A v^2\)）和**径向向心力**（\(f_r = \frac{m v^2}{r}\)），因两者正交，总静摩擦力大小为：
   \[
   f_{\text{静}} = \sqrt{(c_A v^2)^2 + \left(\frac{m v^2}{r}\right)^2} = v^2 \sqrt{c_A^2 + \frac{m^2}{r^2}}
   \]
   不滑动也不离地的充要条件为 \(N' \ge 0\) 且 \(f_{\text{静}} \le \mu_S N'\)（因两边非负，直接关于 \(v^2\) 线性移项而不必平方）：
   \[
   \left(\sqrt{c_A^2 + \frac{m^2}{r^2}} - \varepsilon \mu_S c_B\right) v^2 \le \mu_S m g
   \]
   - **当翼片前方上翘（\(\varepsilon = -1\)，升力）时**：
     \[
     v \le v_{\max,\text{前翘}} = \sqrt{\frac{\mu_S m g}{\sqrt{c_A^2 + \frac{m^2}{r^2}} + \mu_S c_B}}
     \]
     （此时 \(N' = mg - c_B v^2 > 0\) 自动满足，即先打滑后离地。）
   - **当翼片后方上翘（\(\varepsilon = +1\)，下压力）时**：\(N' = m g + c_B v^2 > 0\) 恒不离地，按分母符号分两类：
     - 若 \(\mu_S c_B < \sqrt{c_A^2 + \frac{m^2}{r^2}}\)，则：
       \[
       v \le v_{\max,\text{后翘}} = \sqrt{\frac{\mu_S m g}{\sqrt{c_A^2 + \frac{m^2}{r^2}} - \mu_S c_B}} > v_{\max,\text{前翘}}
       \]
     - 若 \(\mu_S c_B \ge \sqrt{c_A^2 + \frac{m^2}{r^2}}\)，不等式左端非正而右端为正，**任何速度下均不打滑亦不离地**，即在发动机功率足够大前提下 \(v_{\max,\text{后翘}} \to \infty\)！
   - 结论：无论参数如何，应将导流翼片调至**后方上翘**（产生下压力增大正压力与最大静摩擦力），才能获得更大的 \(v_{\max}\)。

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）两问的全部分类阈值和全部表达式与官方参考解答分毫不差（官方第（1）问阈值写为 \(\frac{2\mu_R c_B}{3}[1 - \frac{\mu_R}{3\mu_S-2\mu_R}]\)，化简后与盲解 \(\frac{2\mu_R(\mu_S-\mu_R)}{3\mu_S-2\mu_R}c_B\) 完全一致）。第（2）问方法对比极富教学价值：官方解答将 \(F_\parallel'^2 + F_\perp'^2 \le (\mu_S N')^2\) 两边平方化为关于 \(v^2\) 的四次/二次不等式 \(a v^4 + b v^2 + c \ge 0\)，不得不分 \(a=0\)、\(a>0\)、\(a<0\) 三层再结合 \(N'\ge 0\) 剔除 \(v \ge v_1\) 的增根；而盲解直接在取正根后按一次不等式求解，步骤减半且物理边界（\(N'\ge 0\)）透明直观。
- **核心难点**：
  - 难点1：第（1）问最易忽视的分类分支——当升力系数较大（\(c_A < \mu_R c_B\)）时，高速减重带来的滚动阻力下降甚至能盖过风阻上升，使匀速所需功率 \(P(v)\) 在未打滑前就先达到极大值然后下降！
  - 难点2：第（2）问中圆周运动地面静摩擦力的总需求是切向风阻与径向向心力的**矢量和**，不可只算向心力而丢掉维持匀速必须克服风阻的切向分量。
- **高频易错点**：
  - 易错点1：第（1）问未检验 \(F_{\text{牵}} \le \mu_S N\) 而直接用起飞条件 \(v = \sqrt{mg/c_B}\) 算最大功率，忽略了 \(\mu_R < \mu_S\) 所暗示的打滑先于离地约束。
  - 易错点2：第（1）问在 \(c_A < \mu_R c_B\) 时直接认为极大值必在 \(v^*\) 处取得，未核对 \(v^*\) 是否落在了可行区间 \([0, v_{\text{滑}}]\) 之内。
  - 易错点3：第（2）问把水平静摩擦写成 \(m v^2 / r \le \mu_S N'\)（漏掉 \(c_A v^2\)），或把两边平方解二次方程后忘记用 \(N' \ge 0\) 舍去高速伪根。
- **教练总结**：极值优化题牢记『先定可行域边界，再比对区间内驻点与边界』的闭区间极值铁律；解含非负模长的不等式（如 \(\sqrt{A^2+B^2} \le \mu_S N\)）时，保持非负一次性开方线性求解远胜于平方后引入二次增根。

## 14. 决赛第6题 · Hyperloop 气垫托举与直线电机电磁制动/加速 (`cpho-2016-final-theory-problem-slice-q6`)

- **难度评级**：`D4`
- **核心物理模型**：多孔喷流反冲气垫静平衡 + 线框磁阻尼链式积分 + 闭合矩形回路毕奥-萨伐尔安培力模型
- **教学标签**：`伯努利方程`、`气体射流反冲`、`电磁阻尼制动`、`毕奥-萨伐尔定律`、`直线电机模型`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：运输车刚好被托起时的内部高压 \(P\)**：
   运输车内气体流速近零、压强为 \(P\)，细孔出口外压强均等于较低环境压强 \(P_{\text{low}}\)。
   - 对每个小孔内外应用（等温/定密度近似）伯努利方程：
     \[
     P = P_{\text{low}} + \frac{1}{2}\rho v^2 \implies \rho v^2 = 2(P - P_{\text{low}})
     \]
   - 考查包围运输车外表面与各细孔出口的封闭控制面：由于车厢上部外壁及下部无孔外壁、所有小孔出口处压强均为 \(P_{\text{low}}\)，环境压强在封闭外表面上的合力恒为零！因此全部托举力纯粹来自下半部细孔高速喷气带走的动量通量（反冲推力）。单个面积为 \(s\) 的小孔沿径向喷出的有效推力为：
     \[
     f_1 = \dot{m} v = (\rho s v) v = \rho s v^2 = 2(P - P_{\text{low}})s
     \]
   - 设极角 \(\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]\) 为下半圆柱面某位置相对竖直向下的偏角，角元 \(\mathrm{d}\theta\) 内面元面积 \(l R\,\mathrm{d}\theta\) 上有 \(n l R\,\mathrm{d}\theta\) 个细孔，竖直向上托举力分量为：
     \[
     F_{\text{托}} = \int_{-\pi/2}^{\pi/2} 2(P - P_{\text{low}}) s \cdot n l R \cos\theta\,\mathrm{d}\theta = 4 n s l R (P - P_{\text{low}})
     \]
     由 \(F_{\text{托}} = M g\) 解得：
     \[
     P = P_{\text{low}} + \frac{M g}{4 n s l R}
     \]
     （注：若按理想气体严格可压缩等温伯努利方程 \(\int\frac{\mathrm{d}p}{\rho} = \frac{P_{\text{low}}}{\rho_{\text{low}}}\ln\frac{P}{P_{\text{low}}}\)，则得 \(P = P_{\text{low}}\exp\left(\frac{Mg}{4nslR P_{\text{low}}}\right)\)，小压差下退化为同一表达式；本题题干按标准代数伯努利方程处理。）

2. **第（2）问：两根导线全进入匀强磁场后的滑动速度 \(v_1\)**：
   两导轨轴心间距 \(2(D + r_d)\)，圆导轨半径 \(r_d\)，故导轨内侧净间距（即每根导线长度）为 \(2D\)。记长度为 \(D\) 的单段导轨电阻为 \(r_0 = \frac{\rho_d D}{\pi r_d^2}\)，则每根导线电阻 \(R_w = 2 r_0\)，两导线与间段导轨构成闭合矩形回路的总电阻为：
   \[
   R_{\text{回}} = 2 R_w + 2 r_0 = 6 r_0 = \frac{6\rho_d D}{\pi r_d^2}
   \]
   从导线 1 进入磁场（\(x = 0\)）至导线 2 进入磁场（\(x = D\)）期间，只有导线 1 切割磁感线，动生电动势 \(\mathcal{E}_{\text{动}} = 2 B D v\)，回路电流 \(I = \frac{2 B D v}{R_{\text{回}}}\)，受到向后制动力 \(F = 2 B D I = \frac{4 B^2 D^2}{R_{\text{回}}} v\)。由牛顿第二定律结合链式法则 \(a = v\frac{\mathrm{d}v}{\mathrm{d}x}\)：
   \[
   M v\frac{\mathrm{d}v}{\mathrm{d}x} = -\frac{4 B^2 D^2}{R_{\text{回}}} v \implies \frac{\mathrm{d}v}{\mathrm{d}x} = -\frac{4 B^2 D^2}{M R_{\text{回}}}
   \]
   积分得进入距离 \(D\) 后的速度大小（需初速 \(v_0 > \frac{2\pi B^2 D^2 r_d^2}{3M\rho_d}\)，否则此前已停止，\(v_1 = 0\)）：
   \[
   v_1 = v_0 - \frac{4 B^2 D^3}{M R_{\text{回}}} = v_0 - \frac{2\pi B^2 D^2 r_d^2}{3 M \rho_d}
   \]
   此后两导线均处于匀强磁场内，磁通量不再变化、电流为零，速度保持 \(v_1\) 匀速滑行。

3. **第（3）问：接通直流电源瞬间运输车的加速度大小 \(a\)**：
   - **直流分流电路**：电源接在导线 2 后方距离 \(D\) 处（正极在上导轨，负极在下导轨）。导线 1 支路（含两段长 \(D\) 导轨及导线 1）总电阻 \(4 r_0\)，与导线 2（\(2 r_0\)）并联，等效电阻 \(\frac{4 r_0 \cdot 2 r_0}{4 r_0 + 2 r_0} = \frac{4}{3}r_0\)，再串联电源到导线 2 的两段导轨 \(2 r_0\)，总电阻 \(R_{\text{总}} = \frac{10}{3}r_0\)。故：
     \[
     I_{\text{总}} = \frac{3\mathcal{E}}{10 r_0}, \qquad I_2 = \frac{2}{3}I_{\text{总}} = \frac{\mathcal{E}}{5 r_0}, \qquad I_1 = \frac{1}{3}I_{\text{总}} = \frac{\mathcal{E}}{10 r_0}
     \]
     导线 1 与导线 2 中电流均竖直向下（由上轨流向下轨），两导线间互作用磁力为系统内力，相互抵消。
   - **外部导轨对导线 1、2 的安培力**：由对称性，上下两根圆柱形导轨（均匀电流等效于轴线处细线流）对导线的作用力完全相同（均向左，使回路磁通量增大）。由题给公式与积分提示，记（注意积分限从内表面 \(x = r_d\) 到另一侧内表面 \(x = 2D + r_d\)）：
     \[
     f(c) \equiv \int_{r_d}^{2D+r_d} \frac{1}{x}\frac{c}{\sqrt{x^2 + c^2}}\,\mathrm{d}x = \ln\left(\frac{2D+r_d}{r_d}\frac{c + \sqrt{c^2 + r_d^2}}{c + \sqrt{c^2 + (2D+r_d)^2}}\right)
     \]
     - 导线 2 受紧邻两段导轨（电源至导线 2 载流 \(I_{\text{总}}\)，导线 2 至导线 1 载流 \(I_1\)）合力：
       \[
       F_{\text{轨}\to 2} = \frac{\mu_0 I_2}{2\pi}\left[(I_{\text{总}} + I_1) f(D)\right] = \frac{\mu_0 I_2 (2I_1 + I_2)}{2\pi} f(D)
       \]
     - 导线 1 受紧邻段（载流 \(I_1\)）与次紧邻段（电源至导线 2，载流 \(I_{\text{总}} = I_1 + I_2\)）合力：
       \[
       F_{\text{轨}\to 1} = \frac{\mu_0 I_1}{2\pi}\left[I_1 f(D) + (I_1 + I_2)\big(f(2D) - f(D)\big)\right] = \frac{\mu_0}{2\pi}\left[I_1(I_1+I_2)f(2D) - I_1 I_2 f(D)\right]
       \]
     - 两者相加（交叉项 \(I_1 I_2 f(D)\) 恰好抵消！）：
       \[
       F_{\text{轨}} = \frac{\mu_0 I_{\text{总}}}{2\pi}\left[I_2 f(D) + I_1 f(2D)\right] = \frac{3 \mu_0 \mathcal{E}^2}{200 \pi r_0^2}\left[2 f(D) + f(2D)\right]
       \]
   - **电源竖直段对导线 1、2 的安培力**：电源连接导线（长 \(2D\)，载流 \(I_{\text{总}}\) 向上）与导线 2（间距 \(D\)）、导线 1（间距 \(2D\)）电流反向相斥（推力均向左）。利用 \(B(y) = \frac{\mu_0 I_{\text{总}}}{4\pi s}\left(\frac{y}{\sqrt{y^2+s^2}} + \frac{2D-y}{\sqrt{(2D-y)^2+s^2}}\right)\) 对 \(y\in[0, 2D]\) 积分得单个竖直段推力 \(\frac{\mu_0 I_{\text{总}} I_k}{2\pi s}(\sqrt{4D^2+s^2}-s)\)：
     \[
     F_{\text{源}\to 2} = \frac{\mu_0 I_{\text{总}} I_2}{2\pi}(\sqrt{5} - 1), \qquad F_{\text{源}\to 1} = \frac{\mu_0 I_{\text{总}} I_1}{2\pi}(\sqrt{2} - 1)
     \]
     \[
     \implies F_{\text{源}} = \frac{3 \mu_0 \mathcal{E}^2}{200\pi r_0^2}\left[2(\sqrt{5}-1) + (\sqrt{2}-1)\right] = \frac{3\mu_0\mathcal{E}^2}{200\pi r_0^2}\left(2\sqrt{5} + \sqrt{2} - 3\right)
     \]
   - **总加速度**：代回 \(r_0 = \frac{\rho_d D}{\pi r_d^2}\)：
     \[
     a = \frac{F_{\text{轨}} + F_{\text{源}}}{M} = \frac{3\pi \mu_0 r_d^4 \mathcal{E}^2}{200 M \rho_d^2 D^2}\left[2\sqrt{5} + \sqrt{2} - 3 + \ln\left(\frac{(2D+r_d)^3}{r_d^3}\frac{\left(D + \sqrt{D^2 + r_d^2}\right)^2}{\left(D + \sqrt{D^2 + (2D+r_d)^2}\right)^2}\frac{2D + \sqrt{4D^2 + r_d^2}}{2D + \sqrt{4D^2 + (2D+r_d)^2}}\right)\right]
     \]

### Phase 2：对照参考解答与教学拆解

## 15. 决赛第7题 · 引力波时空度规微扰、干涉与双星四极辐射 (`cpho-2016-final-theory-problem-slice-q7`)

- **难度评级**：`D3`
- **核心物理模型**：弱场线性化平面引力波空间度规、TT 规范物理拉伸椭圆及双星四极矩辐射模型
- **教学标签**：`引力波`、`时空度规微扰`、`波的叠加干涉`、`双星四极矩辐射`、`二倍频特性`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问（i）：两点间距相对于 \(R\) 的偏离**：
   无引力波时，微探测器位于原点 \(O(0,0)\) 与 \((R\cos\theta, R\sin\theta)\)。固定某观测平面 \(z\)（若取 \(z=0\) 则相因子简化为 \(\sin\omega t\)），沿极角 \(\theta\) 的径向线段微元满足 \(\mathrm{d}x = \cos\theta\,\mathrm{d}\rho\)，\(\mathrm{d}y = \sin\theta\,\mathrm{d}\rho\)。代入引力波距离元公式（\(f_2 = 0\)）：
   \[
   \mathrm{d}r = \sqrt{(1+f_1)\cos^2\theta + (1-f_1)\sin^2\theta}\,\mathrm{d}\rho = \sqrt{1 + f_1\cos(2\theta)}\,\mathrm{d}\rho
   \]
   由于 \(f_1 = A\sin\left[\omega\left(t - \frac{z}{c}\right)\right]\) 且 \(0 < A \ll 1\)，利用一阶泰勒展开 \(\sqrt{1+\epsilon} \approx 1 + \frac{1}{2}\epsilon\) 并积分 \(\rho\in[0, R]\)：
   \[
   r \approx R\left\{1 + \frac{1}{2} A \cos(2\theta)\sin\left[\omega\left(t - \frac{z}{c}\right)\right]\right\}
   \]
   故两探测器间距相对于 \(R\) 的偏离为：
   \[
   \Delta r = r - R \approx \frac{1}{2} R A \cos(2\theta)\sin\left[\omega\left(t - \frac{z}{c}\right)\right]
   \]

2. **第（1）问（ii）：阵列在新坐标系 \((X, Y)\) 中的分布形状**：
   由 \(\mathrm{d}r^2 = (1 + f_1)(\mathrm{d}x)^2 + (1 - f_1)(\mathrm{d}y)^2 = (\mathrm{d}X)^2 + (\mathrm{d}Y)^2\)，得局部欧氏坐标变换：
   \[
   X = \sqrt{1 + f_1}\, x \approx \left(1 + \frac{1}{2}f_1\right)x, \qquad Y = \sqrt{1 - f_1}\, y \approx \left(1 - \frac{1}{2}f_1\right)y
   \]
   原圆形微探测器阵列方程 \(x^2 + y^2 = R^2\) 变换为：
   \[
   \frac{X^2}{\left(R\sqrt{1 + A\sin\left[\omega\left(t - \frac{z}{c}\right)\right]}\right)^2} + \frac{Y^2}{\left(R\sqrt{1 - A\sin\left[\omega\left(t - \frac{z}{c}\right)\right]}\right)^2} = 1
   \]
   （一阶近似下两半轴为 \(R(1 \pm \frac{1}{2}A\sin[\omega(t-z/c)])\)。）因此给定时刻 \(t\)，阵列分布为一个以原点为中心、主轴沿 \(X, Y\) 轴且长短轴随时间周期性交替拉伸压缩的**椭圆**（当 \(f_1=0\) 时退化为圆）。

3. **第（1）问（iii）：两列引力波叠加时距扰动振幅的最值条件**：
   线性叠加两列引力波（\(f_2 = 0\)）：
   \[
   f_1 = A\sin\left[\omega\left(t - \frac{z}{c}\right)\right] + A\sin\left[\omega\left(t - \frac{z}{c}\right) + \phi\right] = 2 A \cos\left(\frac{\phi}{2}\right)\sin\left[\omega\left(t - \frac{z}{c}\right) + \frac{\phi}{2}\right]
   \]
   由（i）知距离扰动为 \(\Delta r \approx A R \cos\left(\frac{\phi}{2}\right)\cos(2\theta)\sin\left[\omega\left(t - \frac{z}{c}\right) + \frac{\phi}{2}\right]\)，其振幅为 \(A R \left|\cos\left(\frac{\phi}{2}\right)\cos(2\theta)\right|\)：
   - **振幅达到最大（\(A R\)）**：需 \(\left|\cos(\phi/2)\right| = 1\) 且 \(\left|\cos(2\theta)\right| = 1\)。在 \(0 \le \phi < 2\pi\) 下：
     \[
     \phi = 0, \quad \text{且} \quad \theta = \frac{k\pi}{2}\ \left(\text{即 } 0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}\right)
     \]
   - **振幅达到最小（\(0\)，完全无扰动）**：只需 \(\cos(\phi/2) = 0\) 或 \(\cos(2\theta) = 0\)，即：
     \[
     \phi = \pi\ (\text{任意 }\theta) \quad \text{或} \quad \theta = \frac{\pi}{4} + \frac{k\pi}{2}\ \left(\text{即 } \frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4},\ \text{任意 }\phi\right)
     \]

4. **第（2）问：双星系统辐射引力波 \(f_1, f_2\) 在探测点处的振幅**：
   等质量双星（各质量 \(M\)）在质心系中以半径 \(r_0\)（两星间距 \(L = 2r_0\)）、轨道角频率 \(\Omega\) 做圆周运动：
   \[
   x_1'(t) = r_0\cos\Omega t, \quad y_1'(t) = r_0\sin\Omega t; \qquad x_2'(t) = -r_0\cos\Omega t, \quad y_2'(t) = -r_0\sin\Omega t
   \]
   代入题给 \(I_1(t), I_2(t)\) 定义：
   \[
   I_1(t) = [x_1'^2(t) + x_2'^2(t)]M = 2 M r_0^2 \cos^2\Omega t = M r_0^2 (1 + \cos 2\Omega t)
   \]
   \[
   I_2(t) = x_1'(t) y_2'(t) M = -M r_0^2 \cos\Omega t \sin\Omega t = -\frac{1}{2} M r_0^2 \sin 2\Omega t
   \]
   可见引力波角频率是轨道角频率的两倍，即 \(\omega = 2\Omega \implies \Omega = \frac{\omega}{2}\)。由万有引力提供圆周向心力：
   \[
   \frac{G M^2}{(2 r_0)^2} = M \Omega^2 r_0 \implies r_0^3 = \frac{G M}{4 \Omega^2} = \frac{G M}{\omega^2} \implies r_0 = \left(\frac{G M}{\omega^2}\right)^{1/3}
   \]
   对 \(I_1(t - l/c), I_2(t - l/c)\) 求时间二阶导：
   \[
   \frac{\mathrm{d}^2 I_1}{\mathrm{d}t^2} = -M r_0^2 \omega^2 \cos\left[\omega\left(t - \frac{l}{c}\right)\right], \qquad \frac{\mathrm{d}^2 I_2}{\mathrm{d}t^2} = \frac{1}{2} M r_0^2 \omega^2 \sin\left[\omega\left(t - \frac{l}{c}\right)\right]
   \]
   代入题给表达式 \(f_{1,2} = \frac{8\pi G}{c^4}\frac{2}{l} \ddot{I}_{1,2}(t-l/c)\) 并消去 \(r_0^2 = (GM)^{2/3}\omega^{-4/3}\)，得探测点处 \(f_1, f_2\) 的振幅分别为：
   \[
   A_{f_1} = \frac{16\pi G M r_0^2 \omega^2}{c^4 l} = \frac{16\pi (G M)^{5/3} \omega^{2/3}}{c^4 l}, \qquad A_{f_2} = \frac{8\pi G M r_0^2 \omega^2}{c^4 l} = \frac{8\pi (G M)^{5/3} \omega^{2/3}}{c^4 l}
   \]
   （注：结合题干括号中 \(f_2 \to 2f_2\) 的替换说明，物理交叉偏振应变振幅 \(2 A_{f_2}\) 恰好等于 \(A_{f_1}\)，体现圆偏振引力波沿轨道轴方向两个偏振分量的对称性。）

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）问的每一步解析式与最值条件均与官方参考解答完全一致。微小差异在于：官方第（1）问前两小问静默令 \(z = 0\) 将相位简写作 \(\sin\omega t\)（直到（iii）才写『在 \(z=0\) 处两列波发生干涉』），而盲解保留了通用的 \(\omega(t - z/c)\) 更具普遍性。从广义相对论标准公式看，题干给的 \(f_1 = \frac{8\pi G}{c^4}\frac{2}{l}\ddot{I}_1\) 多出了一个 \(8\pi\) 系数（标准四极矩公式为 \(h_+ = \frac{2G}{c^4 l}\ddot{I}_{xx}\)，命制时应是顺手代入了爱因斯坦场方程系数 \(8\pi G/c^4\)），解题时严格遵从题给公式即可。
- **核心难点**：
  - 难点1：理解坐标 \((x,y)\) 与物理测地距离坐标 \((X,Y)\) 的区分——在引力波的 TT 坐标下自由探测器坐标不变，改变的是空间度规；映射回平坦欧氏坐标系才表现为椭圆周期形变。
  - 难点2：第（2）问正确建立引力波频率与轨道频率的 2 倍关系（\(\omega = 2\Omega\)），并准确理清 \(I_1\) 取两星之和、\(I_2\) 只取交叉乘积这一题干特殊定义与 \(f_2\) 振幅相差 2 倍的关系。
- **高频易错点**：
  - 易错点1：第（1）（iii）问求最小值条件时只答出 \(\phi = \pi\)（两列波反相消光），漏掉『在偏振节点方向 \(\theta = \frac{\pi}{4} + \frac{k\pi}{2}\) 上对任意 \(\phi\) 间距微扰恒为零』的另一大类解。
  - 易错点2：第（2）问直接错把双星绕转角频率 \(\Omega\) 当成引力波频率 \(\omega\)（漏掉倍频因子 2），导致半径 \(r_0\) 与最终振幅系数算错 \(2^{4/3}\) 倍。
  - 易错点3：算双星轨道动力学时把两星间距 \(2r_0\) 误写为 \(r_0\)，或误将自己熟记的标准广义相对论公式套用来替换题给含 \(8\pi\) 和特定 \(I_2\) 定义的式子。
- **教练总结**：竞赛中遇到前沿物理『给公式现推』的题型，最重要的是**忠实于题干自己给出的公式和符号定义**（哪怕其中有特殊的归一化系数或约定），通过二倍角/倍频检查与量纲核对（如 \([(GM)^{5/3}\omega^{2/3}/(lc^4)] = 1\)）把常数因子守住。

## 16. 决赛第8题 · 电子偶素（Ps）约化能级与双光子湮灭动力学 (`cpho-2016-final-theory-problem-slice-q8`)

- **难度评级**：`D3`
- **核心物理模型**：两体玻尔约化质量能级缩放模型与相对论两体（质量含结合能）衰变四动量模型
- **教学标签**：`电子偶素`、`约化质量修正`、`结合能与静质量亏损`、`相对论多普勒频移`、`双光子湮灭`
- **适用对象**：高中竞赛 (复赛/决赛) · 兼顾本科普通物理

### Phase 1：独立盲解记录（只看原题）

1. **第（1）问：电子偶素（Ps）基态能量 \(E_{n=1}^{\text{Ps}}\)**：
   按题设质心系总角动量量子化规则，类氢二体系统的能量本征值正比于其约化质量 \(\mu = \frac{m_1 m_2}{m_1 + m_2}\)。
   - 氢原子（\(\text{p}\text{-}\text{e}^-\)，质子与电子质量比 \(m_p/m_e = 1836\)）的约化质量为：
     \[
     \mu_{\text{H}} = \frac{m_p m_e}{m_p + m_e} = \frac{1836}{1837} m_e
     \]
   - 电子偶素（\(\text{e}^+\text{-}\text{e}^-\)）的约化质量为：
     \[
     \mu_{\text{Ps}} = \frac{m_e \cdot m_e}{m_e + m_e} = \frac{1}{2} m_e
     \]
   - 故保留四位有效数字，基态能量为：
     \[
     E_{n=1}^{\text{Ps}} = \frac{\mu_{\text{Ps}}}{\mu_{\text{H}}} E_{n=1}^{\text{H}} = \frac{1837}{2 \times 1836} \times (-13.60\text{ eV}) = -6.8037\text{ eV} \approx -6.804\text{ eV}
     \]

2. **第（2）问（i）：低速（\(v_0 \ll c\)）湮灭时 \(v_0, E_1, E_2\) 的表达式与数值**：
   基态 \(\text{Ps}\) 静质量 \(M_{\text{Ps}} = 2m_e + \frac{E_{n=1}^{\text{Ps}}}{c^2}\)，因 \(|E_{n=1}^{\text{Ps}}| \ll m_e c^2\)，在求（i）问保留四位有效数字时 \(M_{\text{Ps}} \approx 2m_e\)。
   由题图知，光子 \(\gamma_1\) 偏角为 \(\theta_1\)，光子 \(\gamma_2\) 偏角为 \(\theta_2 = \pi + \theta_1 + \Delta\theta\)（\(\Delta\theta \ll 1\)）。低速下 \(\gamma \approx 1\)，能量和动量守恒为：
   \[
   E_1 + E_2 \approx 2 m_e c^2, \qquad p_1 \sin\theta_1 - p_2 \sin(\theta_1 + \Delta\theta) = 0, \qquad p_1 \cos\theta_1 - p_2 \cos(\theta_1 + \Delta\theta) = 2 m_e v_0
   \]
   其中 \(p_1 = E_1/c, p_2 = E_2/c\)。利用动量三角形正弦定理（或将 \(\sin(\theta_1+\Delta\theta) \approx \sin\theta_1 + \Delta\theta\cos\theta_1\) 保留至 \(\Delta\theta\) 一阶小量）：
   - 零级有 \(E_1 \approx E_2 \approx m_e c^2\)，\(p_1 \approx p_2 \approx m_e c\)，由正弦定理 \(\frac{2m_e v_0}{\sin\Delta\theta} = \frac{p_2}{\sin\theta_1}\) 得：
     \[
     v_0 \approx \frac{c\,\Delta\theta}{2\sin\theta_1}
     \]
   - 保留一阶多普勒修正（由 \(E_1/E_2 = \sin(\theta_1 + \Delta\theta)/\sin\theta_1 \approx 1 + \Delta\theta\cot\theta_1\) 与 \(E_1 + E_2 = 2m_e c^2\)）：
     \[
     E_1 \approx m_e c^2\left(1 + \frac{1}{2}\Delta\theta\cot\theta_1\right) = m_e c^2\left(1 + \frac{v_0}{c}\cos\theta_1\right)
     \]
     \[
     E_2 \approx m_e c^2\left(1 - \frac{1}{2}\Delta\theta\cot\theta_1\right) = m_e c^2\left(1 - \frac{v_0}{c}\cos\theta_1\right)
     \]
   代入 \(\theta_1 = \frac{\pi}{3}\)，\(\Delta\theta = 3.464\times 10^{-3}\)，\(m_e c^2 = 0.5110\text{ MeV}\)：
   \[
   v_0 = \frac{3.464\times 10^{-3}}{2 \times \frac{\sqrt{3}}{2}} c = 2.000\times 10^{-3} c \approx 5.996\times 10^5\text{ m/s}\ (\text{若取 } c=3.00\times 10^8\text{ m/s 则 } 6.000\times 10^5\text{ m/s})
   \]
   \[
   E_1 = 0.5110\times(1 + 1.000\times 10^{-3}) = 0.5115\text{ MeV}, \qquad E_2 = 0.5110\times(1 - 1.000\times 10^{-3}) = 0.5105\text{ MeV}
   \]

3. **第（2）问（ii）：静止湮灭时光子能量与自由电子静能之差**：
   此时不可把 \(M_{\text{Ps}}\) 近似为 \(2m_e\)，精确守恒能量为 \(E_1 + E_2 = M_{\text{Ps}} c^2 = 2 m_e c^2 + E_{n=1}^{\text{Ps}}\)，且 \(E_1 = E_2\)，故各自能量与单个自由电子静能 \(m_e c^2\) 之差为：
   \[
   \Delta E = E_1 - m_e c^2 = E_2 - m_e c^2 = \frac{1}{2} E_{n=1}^{\text{Ps}} \approx -3.402\text{ eV}
   \]
   （即每个光子能量比单个自由电子静能少 \(3.402\text{ eV}\)。）

4. **第（3）问：高速（\(v_0\) 与 \(c\) 可比）湮灭的 \(E_1, E_2, \theta_2\) 关系与数值**：
   记 \(\beta = v_0/c\)，\(\gamma = (1 - \beta^2)^{-1/2}\)，质心动能可比于静能，电子偶素四动量 \(p_0 = (\gamma M_{\text{Ps}} c,\ \gamma\beta M_{\text{Ps}} c, 0, 0)\)。
   - 对四动量 \(p_2 = p_0 - p_1\) 取平方并利用 \(p_2^2 = 0\) 得：
     \[
     M_{\text{Ps}}^2 c^2 - 2 \gamma M_{\text{Ps}} E_1 (1 - \beta\cos\theta_1) = 0 \implies E_1 = \frac{M_{\text{Ps}} c^2\sqrt{1 - \beta^2}}{2(1 - \beta\cos\theta_1)}
     \]
   - 由能量守恒 \(E_2 = \gamma M_{\text{Ps}} c^2 - E_1\) 化简得：
     \[
     E_2 = \frac{M_{\text{Ps}} c^2 (1 + \beta^2 - 2\beta\cos\theta_1)}{2\sqrt{1 - \beta^2}(1 - \beta\cos\theta_1)}
     \]
   - 由横向动量守恒 \(E_1\sin\theta_1 + E_2\sin\theta_2 = 0\) 及纵向动量守恒 \(E_1\cos\theta_1 + E_2\cos\theta_2 = \gamma\beta M_{\text{Ps}} c^2\)，同时导出 \(\sin\theta_2\) 与 \(\cos\theta_2\)（避免仅用正弦反三角出现象限二义性！）：
     \[
     \sin\theta_2 = -\frac{(1 - \beta^2)\sin\theta_1}{1 + \beta^2 - 2\beta\cos\theta_1}, \qquad \cos\theta_2 = \frac{2\beta - (1 + \beta^2)\cos\theta_1}{1 + \beta^2 - 2\beta\cos\theta_1}
     \]
   - 代入 \(v_0 = \frac{c}{2}\)（\(\beta = \frac{1}{2}, \gamma = \frac{2}{\sqrt{3}}\)）、\(\theta_1 = \frac{\pi}{3}\) 及 \(M_{\text{Ps}} c^2 \approx 2m_e c^2 = 1.022\text{ MeV}\)：
     \[
     E_1 = E_2 = \frac{1.022\text{ MeV}}{\sqrt{3}} = 0.590052\text{ MeV} \approx 0.5901\text{ MeV}
     \]
     \[
     \cos\theta_2 = \frac{1 - \frac{5}{8}}{\frac{3}{4}} = \frac{1}{2}, \quad \sin\theta_2 = -\frac{\frac{3}{4}\cdot\frac{\sqrt{3}}{2}}{\frac{3}{4}} = -\frac{\sqrt{3}}{2} \implies \theta_2 = \frac{5\pi}{3}\ (\approx 5.236\text{ rad 或 } 300.0^\circ)
     \]

### Phase 2：对照参考解答与教学拆解

- **对照结论**：盲解第（1）、（2）、（3）问物理模型与公式结构同官方参考解答完全一致，且在细致比对中抓出官方解答的三处疏漏/笔误：（1）**重大有效数字修约笔误**：官方第（3）问式 (20) 将 \(E_1 = E_2 = \frac{2\times 0.5110}{\sqrt{3}} = 0.590052\text{ MeV}\) 误修约为 \(0.5900\text{ MeV}\)（显系错将 \(1/\sqrt{3}\) 截断为 \(0.5773\) 再乘以 \(1.022\) 所致），按四位有效数字四舍五入（或四舍六入五成双）精确结果均应为 **\(0.5901\text{ MeV}\)**！（2）官方解答第 23 页在代入第（2）（i）问数据时把题干原给的 \(\Delta\theta = 3.464\times 10^{-3}\) 错印成了 \(3.462\times 10^{-3}\)（因 \(2\sqrt{3} \approx 3.4641\)，题干 \(3.464\) 才对应整洁的 \(2.000\times 10^{-3}c\)）。（3）官方第 22–23 页式 (2)–(3) 未作说明即将脚标 \(p, e\) 混写成了 \(1, 2\)。
- **核心难点**：
  - 难点1：第（1）问为何给到『四位有效数字』与『质子电子质量比 1836』——若粗暴按无穷大质子质量减半取 \(-6.800\text{ eV}\)，在第四位有效数字就会偏差 4 个单位。
  - 难点2：第（2）（i）问既要求出小数点后第四位有效数字（0.5115 vs 0.5105），就不能在能量表达式里简单令 \(E_1 = E_2 = m_e c^2\)，必须保留至 \(\mathcal{O}(\Delta\theta)\) 一阶多普勒项。
- **高频易错点**：
  - 易错点1：第（1）问忽略有限质子质量修正，直接写 \(-13.60 / 2 = -6.800\text{ eV}\)；以及第（2）（ii）问漏掉 1/2 因子错把结合能 \(-6.804\text{ eV}\) 当作单光子能量亏损。
  - 易错点2：第（2）（i）问直接把双光子能量都写成 \(0.5110\text{ MeV}\)，丢失了 0.0005 MeV 的多普勒分裂。
  - 易错点3：第（3）问仅凭 \(\sin\theta_2 = -\sqrt{3}/2\) 在 \((\pi, 2\pi)\) 内错选 \(4\pi/3\)（未检验该角下高速向前的纵向总动量 \(p_{1x}+p_{2x}\) 必须等于 \(+p_{\text{Ps}} > 0\)，而 \(\cos(4\pi/3) = -1/2\) 会导致总动量为零的矛盾！）。
- **教练总结**：遇到要求『保留四位有效数字』的原子与粒子物理题，题干给的每一个微小修正参数（如 \(m_p/m_e=1836\)、微弱夹角 \(\Delta\theta\)）几乎都在第 3–4 位有效数字处发挥决定性作用；处理高能二体衰变方向角时，务必同时解出 \(\sin\theta_2\) 与 \(\cos\theta_2\) 以避免反三角函数象限丢失。
